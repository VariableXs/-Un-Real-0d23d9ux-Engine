# Variable — Private Space

完全离线、无账号、无云同步的私人写作 + 思维导图 + 项目分析 + 命运推演 Windows 桌面应用。

- **技术栈**：Tauri 2.x · React 18 · TypeScript(严格模式) · Vite · TipTap · rusqlite(SQLite) · 原生 WebGL 星空/极光背景
- **定位**：启动即写作；层级文件夹、记录、回收站、全文搜索、无限画布思维导图、本地媒体、备份/恢复/导入/导出、
  项目分析空间（代码可视化解读引擎）、命运推演空间（FTPE 行为树命运引擎）
- **隐私**：所有数据仅存于本机 `%APPDATA%\com.variable.app`（或便携目录），无任何联网依赖

## 八、命运推演空间（FTPE · 第三大独立空间）

顶栏**✨ 命运推演**按钮进入。无模板哲学：人格/性格/主义思想全部为抽象自构条目，
每个特质 -100..+100 无级滑块，并对 7 大事件类别持有精确影响权重表。

- **六域独立面板**：人格（1-3 主导人格加权混合）· 性格（正反极滑块）· 主义思想（高值互斥对触发"内心挣扎"）·
  事件库（7 层分类种子 100+ 条，可扩展）· 随机因素（运气/时代/健康…强度可调）· 推演参数（年数/分支/混沌/种子）
- **推演算法**：确定性种子（mulberry32），最终概率 = 基础概率 × 特质乘子 × 混沌扰动 × 随机因素，
  同种子完全可重现；每步按权重采样分支，终点按路径基调分配 10 种结局原型
- **命运树画布**：横向时间轴无限延伸，连线亮度=概率；**双击事件节点续分子树**并反向反馈主干（10.1/10.2）；
  结局全览面板列出全部结局印章
- **存档**：`.fatetree` 与 `.mindmap`/`.project` 平级（工作区双击打开），含种子/自定义词典/完整树；
  一键导出为思维导图
- 代码位置：`src/features/fate/`（types/dictionaries/engine/FateView + 引擎测试）

## 二、开发运行

```bat
cd variable
npm install
npm run tauri dev      :: 首次编译 Rust 较慢，之后增量
```

仅检查前端：`npm run typecheck`；单元测试：`npm test`。
后端测试：`cd src-tauri && cargo test`。

诊断工具：

```bat
node tools\audit.cjs                                   :: IPC 命令面与 i18n 键完整性审计
cargo run --example pragma_check -- <db路径>            :: 检查数据库 schema 版本与表结构
```

## 三、Windows 打包

双击或命令行执行：

```bat
build-windows.bat            :: 默认 NSIS 安装包
build-windows.bat msi        :: 追加 MSI（需要 WiX，Tauri CLI 自动下载）
build-windows.bat portable   :: 额外产出便携版目录
```

脚本会依次校验 node/npm/rustc/cargo/tauri-cli，再执行类型检查、前端构建、`tauri build`。
任一步失败都会以非零码退出并打印原因（不静默成功）。

产物路径：

| 类型 | 路径 |
| --- | --- |
| NSIS 安装包 | `src-tauri/target/release/bundle/nsis/Variable_1.0.0_x64-setup.exe` |
| MSI（可选） | `src-tauri/target/release/bundle/msi/Variable_1.0.0_x64_en-US.msi` |
| 绿色 exe | `src-tauri/target/release/variable.exe`（及 `dist-portable\`） |

安装器支持卸载；卸载**不会删除用户数据目录**（记录、媒体、备份均保留）。

### 便携版

`build-windows.bat portable` 会把 `variable.exe` 复制到 `dist-portable\` 并放置 `.portable`
标记文件。将该目录拷贝到任意位置运行即可，数据写入同目录下 `data\`。
也可用环境变量 `set VARIABLE_PORTABLE=1` 达到同样效果。

## 四、数据目录结构

```
<数据根>/db/variable.db          SQLite（WAL 模式）
        /media/                 复制进来的图片/视频/附件
        /backups/               手动/自动备份（时间戳命名，恢复前 quick_check 校验）
        /recovery/              异常关闭的恢复文件（JSON）
        /logs/variable.log      前后端错误日志
```

默认数据根：`%APPDATA%\com.variable.app`；便携模式下为 `exe目录\data`。

## 五·五、项目分析空间（PVCCE · 独立模块）

**项目分析（Project Visualization & Code Comprehension Engine）是与思维导图平行的第二大功能空间**，
通过顶部工具栏的「项目分析」按钮（文件夹+放大镜 · 冰蓝）进入，与导图空间随时互切、数据独立保存。
**没有任何弹窗表单**：导入进度是顶栏微进度条；「大白话 → 代码」是画布工具模式（单击放置意图节点，
双击内联编辑，Enter 生成；通俗步骤作为子分支长在意图节点下，代码与粘贴位置进入右侧详情舱）。

- **布局（三栏沉浸）**：左侧可折叠文件树（筛选 / 多选 / 「固定到画布」/「从分析中移除」）·
  中央无限画布（WASD/方向键平移、指针锚点缩放、流光依赖线）· 右侧可收起详情舱（文件通俗解读 / 意图结果）·
  底栏轻提示（节点数 / 引用数 / 缩放 / 模式）；点击空白取消选中并关闭面板
- **数据与存储**：分析档案保存为 `.project`（与 `.mindmap` 平行，工作区面板双击直接进入项目空间）；
  档案内含项目路径、目录树快照、通俗解读、布局坐标、引用关系表与时间戳
- **导入（四）**：整个项目文件夹；单个/多个源文件（增量追加，不打断会话）；工作区拖入；
  非代码文件（README/配置/设计说明）以通俗卡解释「它是说明书/清单/配置」
- **解读结构**：根节点 + 是什么/有什么/怎么运行 三支四层；目录用「厨房/质检车间」比喻；
  悬停节点高亮依赖连线；「下钻进入」展开函数级子空间
- **意图生成（五）**：工具栏灯泡或右键「用大白话加功能」→ 单击画布放置意图节点 → 双击输入
  （Esc 取消）→ 生成通俗步骤子分支 + 代码节点；未导入项目时详情舱提示「先导入项目」并给一键导入
- **双向引用管道**：文件节点右键「引用到思维导图」→ 当前导图生成樱花粉（#f8d4e4）引用节点；
  「双向引用」面板一键跳转导图节点；双击导图引用节点回到该文件的通俗解读卡
- **真实光影极光背景（一）**：项目空间专属 WebGL2 光影管线——Ray-Marching 三维褶皱极光飘带
  （占上部 40%，纯白蓝 #f0f6ff → 冰蓝 #7fa8d6 → 边缘樱花冰晶粉 #f8d4e4，向下投丁达尔光柱）、
  泊松圆盘采样的高熵星河（最亮 2% 带 4 角冷蓝十字衍射星芒）、底层缓流体积冷雾；
  safeMode/减少动效时渲染静态单帧
- **逐行解剖（第一/八章）**：文件节点右键「逐行解剖」进入 L2 结构级 → 双击进 L3 段落级 → 再进 L4 逐行级；
  L4 为**双轨制虚拟滚动**（左源码右大白话，无论 619 行还是 6000 行都只渲染可视区 ~30 行），
  函数行可**块级折叠**只看大白话总结；Esc 逐级返回；右键行节点可续写/大白话改/复制
- **推理链（第二章）**：函数右键「查看推理链」→ 详情舱并列展示纵向（目标→步骤→为什么）、
  横向（依赖/被谁用/平级）、时间因果（入口→步骤→产出）三条链，全部带真实行号映射
- **续写与写入（三/四章）**：内联意图条（非弹窗）输入大白话 → 实时预览 → Enter 先应用到会话 →
  顶栏「**写入源文件**」按钮二次确认 → 备份到 `.backups/*.bak` + 原子写盘 + 樱粉闪烁；
  **Ctrl+Z 先撤销会话内改动、再回滚已落盘写入**
- **深度语义翻译（二章）**：五维分析（意图/手段/输入/输出/副作用）驱动的独特翻译——
  文件级点名明星函数与依赖域、函数级按参数与调用链组装、行级按内容模式生成，
  内置 `dedupeCheck` 品控（词级 Jaccard > 0.9 判退化）；顶栏可切换
  **生活比喻 / 故事叙事 / 工程说明** 三种通俗风格（持久化）
- **语义现场编辑（第四章）**：双击 L4 右侧大白话即可反向编辑该行；意图变换字典（改颜色/加日志/
  加注释/改数字/重命名/删行/改文字/加异常）支持模糊同义与不确定追问；零 AI、零网络
- **七级无限下钻（一章）**：根 › 目录 › 文件 › 类/结构块 › 函数 › **逻辑块（if/for/try…可折叠）** › 逐行；
  画布函数节点双击继续深入（进入 L3 + 推理链舱）；信息卡内嵌**前 10 行真实源码预览** +
  「逐行解剖（完整源码）」按钮
- **词典七级体系**（三章）：L1 通用 / L2 语言 / L3 框架 / L4 领域 / L5 意图变换 /
  L6 惯用短语 / L7 模式识别 + 十大类扩展包（通用/JS/Python/Rust-Go-C/JVM-移动/前端/后端/
  数据库/DevOps/俚语），25+ 旗舰词条带三风格变体；全库经唯一性品控（任意两条比喻文本不重复）
- **布局与避障（三章）**：同级节点最小 44px 垂直安全间距 + 重叠自动推让（resolveOverlaps）；
  连线遇节点自动直角绕行（routeEdge），永不穿透文本框
- **字典管理（第五章）**：工具栏字典面板显示 L1–L5 五级字典概览，用户词典可增删，
  支持 `.dict.json` 词典包离线导入/导出
- **节点语义配色**（低饱和冷调）：根 #4f709c · 目录 #8babc6 · 源码 #a8c8e8 · 配置 #cfe4f8 ·
  文档 #dce4ec · 意图/引用 #f5c6d8（点睛）
- **隐私**：扫描/解析/词典全部本地完成；Rust 侧 `project_scan` 自动跳过 node_modules、.git、
  target 等噪音目录，拒绝符号链接越界，有界读取；用户词典存本地设置表

代码位置：`src/features/projectviz/`（`ProjectAnalysisView` 独立空间 + 词典/解析器/识别/叙述/生成/编排/意图 + 单元测试）、
`src-tauri/src/project_scan.rs`（扫描与档案读取）。
已知边界：v1 结构解析器为"词法降噪 + 语言感知正则"（UIR 同构，可逐语言替换 tree-sitter）；
热更新监听、跨项目对比、本地大模型增强为后续扩展点。

## 七、常见问题

**Q: 提示缺少 WebView2？** 安装 Evergreen Runtime：https://developer.microsoft.com/microsoft-edge/webview2/

**Q: 想彻底离线构建？** 先在联网机器执行一次 `npm install` 与 `cargo fetch`
（或直接完成一次 `build-windows.bat`），之后 `cargo build --offline` + `npm ci --offline` 可复现。

**Q: 卸载后数据在哪？** `%APPDATA%\com.variable.app`，重新安装后自动继续使用。
