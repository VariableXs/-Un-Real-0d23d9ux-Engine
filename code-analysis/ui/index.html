三步上手

  1. 打开项目：启动时带项目路径，或把 IR JSON 拖进画布。
  2. 看懂结构：滚轮缩放、拖拽平移；左侧调下钻级别，点节点看大白话解释。
  3. 切换视角：「通俗 / 专业 / 对照」三种界面模式，Ctrl+K 全局跳转。

本软件全部为离线确定性分析（内置语义词典 + 规则），不联网、无 AI 生成；「大白话」解释与「一键总结」都来自查表，不是理解后的创作。
