## 纪律（开工前必读）

1. **功能零修改**：每项功能的行为、UI、交互一律按《Code Analysis2.md》原文实现，
   不精简、不变更、不重设计。发现主规格歧义时停下询问，不擅自决定。
2. 每个 AI 只修改自己域内文件；三文档为共享文件，编辑前必须先同步远端基线。
3. 完成一项：更新本图勾选 → commit（`codeanalysis(ai-XX): #NNN <功能名>`）→ push GitHub。
4. **三端等价**：任何功能完成时按等价性 DoD 在三端各验一次
   （Windows 独立 / Variable 嵌入 / VARIX 内核用户态；内核未就绪时挂账不计完成）。
5. 波次出口评审通过才可进入下一波次（见总步骤图）。
6. 全部完成后：产物同步到 `C^2 Courage (Un)Real Variable` 文件夹与 GitHub 仓库，打 tag 发布。
