## 0. 总原则

### 0.1 三条铁律
1. **功能零修改**：一切以《Code Analysis2.md》原文为准，不做任何功能/UI/交互变更。
2. **三端等价**：Windows 独立、Variable 收件箱嵌入、VARIX 内核用户态三端功能 100% 一致；
   冲突能力只换实现层（壁纸=应用内背景层、键位=宿主转发/内核事件、写回=磁盘/VFS）。
3. **零 AI 承诺**：全程不调用网络模型，续写=语法+类型枚举。

### 0.2 质量军规
真机优先、数据说话、可回滚、崩溃诚实上报、零回归、艺术品标准、不写非功能性报告、证据归档。

### 0.3 同步纪律（每个 AI 必须执行）
- 每完成一项功能：更新《AI分工完成图》勾选 → commit（`codeanalysis(ai-XX): #NNN <功能名>`）→ push GitHub。
- 每完成一个波次：产物同步到两处——
  ① **文件夹**：`D:\C^2 Courage (Un)Real Variable\C^2 Courage (Un)Real Variable\`（与主规格同目录）；
  ② **GitHub 仓库**：main 分支 + 打 tag。
- 三文档（全景图/总步骤图/分工完成图）为共享文件，编辑前必须先拉取远端基线。

## 2. 各波次明细

### W1 地基（AI-01）
- 工程：`code-analysis/` 独立目录（core + app 双 crate），绝不混入 kernel/ 工作区。
- 交付：项目加载、统一语义 IR、七级下钻模型、七种可视化数据契约、语法续写引擎、逻辑链追踪（#001~#064）。
- 出口评审：core 单测全绿；十万行样例项目 IR 构建通过；七级下钻数据模型评审。

### W2 功能主体（AI-02 / AI-03 / AI-04，可并行）
- AI-02：六类检测开关、深度静态分析、动态分析引擎、一键改进/重构/框架操作、150 语言识别（#065~#150）。
- AI-03：名词提取分类、250 概念×9 语言通俗化翻译、三层比喻校验、L1~L7 树根分级（#151~#250）。
- AI-04：无限全景画布、统一 2D 流程图、通俗/专业/对照三界面、功能区、极简 UI（#251~#336）。
- 出口评审：全部编号功能与主规格逐条对照零偏差；检测/翻译/画布三域互相联测。

### W3 体验层（AI-05 / AI-06 / AI-07 / AI-08，可并行）
- AI-05：调试测试、学习导航、零基础拖拽修改、8 风格 UI、动态壁纸（应用内背景层实现）（#337~#410）。
- AI-06：207 条命令终端、手册、自定义按钮、时间旅行撤回、多源码、框选、双通道、F 键、节点联动（#411~#460）。
- AI-07：键位管理、颜色标记规范、三 OS 兼容、无障碍、语义系统（#461~#530）。
- AI-08：33 章 UI 规范逐条落地 + 8 风格资产 + 嵌入态/内核态渲染差异清零（UI-001~UI-036）。
- 出口评审：UI 规范逐条走查；键盘/命令/按钮/双通道触达全通；时间旅行完整可回放。

### W4 三壳等价（AI-09）
- C01~C24 全部完成：写回通道双后端、Variable 虚拟窗口嵌入适配、VARIX 用户态应用
  （appfw 注册 + VFS 读写 + 键位事件 + 自带资产渲染）、大项目分页加载、等价验收清单生成器。
- 出口评审：**三端等价 DoD**——抽样 100 项功能在三端各验一次，零差异。

### W5 发布收口（AI-10）
- 绿色打包 → SoftwareInbox 投递验收 → 三端全量回归（530 项核对）→
  产物同步文件夹 + GitHub → tag 发布。
- 出口评审：R01~R20 全勾；530 项功能核对表签收；体积/启动/加载/崩溃四项预算达标。
