### 事故（重要）

- `git pull --rebase --autostash` 在多会话并行下把 `.git/objects/pack/*.pack`
  全部删掉（只剩 .idx），refs/heads/main 也丢失 → 本地对象库整体失效。
  **教训：本仓禁止 `pull --rebase --autostash`**；改走 `git fetch` +
  `git update-ref/ reset --mixed`，或先 `git stash`。
- 恢复只能靠 `git fetch origin`（代理 127.0.0.1:55799 间歇 502，需多次重试）；
  工作区文件本身完好，未丢失任何源码。
