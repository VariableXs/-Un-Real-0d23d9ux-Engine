// 循环引擎与待发队列 · 设计（写码前先定死，避免返工）
//
// ═══════════════════════════════════════════════════════════════════
// 一、实测得到的空闲判据（idle_probe.py 8 次采样，各判据完全一致）
// ═══════════════════════════════════════════════════════════════════
//   ① 发送键 class 无 --sending/--stop   ← 最可靠，现有判据
//   ③ 独立停止按钮数：忙=1 / 闲=0      ← 独立交叉验证
//   ④ 生成动画元素数：忙=3 / 闲=0      ← 独立交叉验证
//   ⑦ 末条助手消息字数：忙时=6（"正在生成"）← 最小巧思
//
// ★ 设计决策：三条判据取「多数一致」★
// 单条判据可能因 WorkBuddy 改版而失效，三条同时失效的概率低得多。
// 任一判据"说忙"就视为忙（保守，宁可多等，不误发）。
//
// ═══════════════════════════════════════════════════════════════════
// 二、待发队列（Queue）
// ═══════════════════════════════════════════════════════════════════
// 动因：忙时点发送不该弹错误就结束，要"存下来、空闲了自动发"。
// 队列项：
//   id       : u64 单调递增
//   text     : String 待发内容
//   convId   : String 目标对话（"" = 当前选中对话）
//   loopRound: u32 该项属于第几轮（0 = 单发）
//   state    : pending | sending | done | failed | canceled
//   evidence : String 发送证据
//   err      : String 失败原因
//
// ═══════════════════════════════════════════════════════════════════
// 三、循环（Loop）
// ═══════════════════════════════════════════════════════════════════
// 定序：一次「循环任务」= N 轮，每轮一条（或多条）内容。
// 触发方式（用户可切换，实测依据见上）：
//   "idle"  — 检测对方生成完毕（③/④/① 多数一致）才发下一轮
//   "interval" — 固定间隔 N 秒发（不管忙不忙，忙则退化为待发队列等待）
//   "hybrid" — 先等空闲，超时则按间隔硬发
//
// ★ 无限循环的诚实说明 ★
// 99999 轮 × 每轮耗时 = 可能跑数天。这是用户明确要的。
// 实现上循环就是一个 while + 轮次计数，没有特殊之处。
// 停止：界面必须有停止按钮（不靠关窗口）。
//
// ═══════════════════════════════════════════════════════════════════
// 四、待发队列与循环的关系
// ═══════════════════════════════════════════════════════════════════
// 循环引擎的每一轮，实际就是把一条内容 push 进待发队列；
// 一个后台 worker 持续检查「队列里有 pending && 目标对话空闲」→ 发它。
// 这样"手动点发送"和"循环发布"共用同一条发送路径，只是来源不同。
//
// ═══════════════════════════════════════════════════════════════════
// 五、必须防的坑（都来自本项目实测教训）
// ═══════════════════════════════════════════════════════════════════
// 1. 忙时一个字都不写进输入框（不只是不点发送）——坑 6。
// 2. 干跑只删不插，绝不备份-写回（placeholder 会被固化成真文字）。
// 3. 判"编辑器是否清空"必须排除 placeholder（EDITOR_CHARS_JS）。
// 4. 停循环时若有 sending 中的项，必须等它落地或显式标记，不能丢在中间。
// 5. 无限循环必须能停——界面常驻停止按钮，且不依赖关窗口。
//
// （本文件是设计说明，实现放在 loop.rs / queue.rs）
