# 计划总表（PLAN）

> 50000 条计划按「任务包 Work Package」切块后登记在此。每个任务包是 18 路工人领取的最小单位。
> 调度塔按编号顺序派工；工人只认领到的条目，不读整表。

## 全局规格指针

- 规格 MD：`{SPEC_MD_PATH}`（内核总体规格，工人必读）
- 产物根目录：`{OUTPUT_DIR}`

## 切块原则

1. **零交集**：每个任务包写到的文件路径互不重叠（防止 18 路并发写冲突）。
2. **可独立验收**：每个任务包自带判据原文，工人宿主侧快测可自证。
3. **粒度均匀**：单包工作量目标 15~40 分钟 AI 工时；过大拆分、过小合并。
4. **接口冻结**：跨包依赖先冻结接口（schema/签名），依赖方拿冻结接口+fake 先行开发。

## 任务包条目格式

```
### WP-00001
- 规格: （判据原文，做什么、做到什么程度）
- 输出: kernel-wp/WP-00001/
- 判据:
  1. （可机械验证的验收条件，如 cargo build 通过）
  2. （单测通过 / 文件存在 / 接口签名匹配 …）
- 依赖: 无 | WP-xxxxx（接口已冻结）
- 状态: 待派 | 进行中(WORKER_ID) | DONE | BLOCKED(原因)
```

```
  2. 单测覆盖 alloc/free/耗尽三路径
- 依赖: 无
- 状态: 待派
```
