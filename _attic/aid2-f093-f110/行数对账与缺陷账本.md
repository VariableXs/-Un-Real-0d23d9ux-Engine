## 四、复现口令

```
cd D:\2\aid2-scratch && cargo test
# 期望：129 passed / 0 failed / 0 warnings
# （隔离舱 src/lib.rs 以 #[path] 直挂仓库真实文件：checks.rs、star/sbase.rs、galaxy/math.rs、stard/mod.rs）
```

口径脚本（本表数字来源）：

```bash
cd kernel/varix/src/stard
for f in *.rs; do
  total=$(wc -l < "$f")
  tstart=$(grep -n "^#\[cfg(test)\]$" "$f" | head -1 | cut -d: -f1)
  testlines=$(( total - tstart + 1 ))
  out=$(( total - testlines ))
  c_out=$(head -n $out "$f" | grep -c "^\s*//"); b_out=$(head -n $out "$f" | grep -c "^[[:space:]]*$")
  echo "$f total=$total test=$testlines c_out=$c_out b_out=$b_out func=$(( out - c_out - b_out ))"
done
```
