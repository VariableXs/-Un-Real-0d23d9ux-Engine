## 1. 隔离口径（为什么可隔离、怎么隔离）

E 域落点 `src/system/persona/` 是 TS/React 域，**自包含**：
- 只依赖 `src/system/theme-studio/tokens`（对比度公式一处一事实）与
  `react`/`lucide-react`/`../../state/uiStore`（接线层）；
- 测试全走 vitest，零内核（kernel/）依赖——与 Rust 泳道的隔离舱互不相交；
- 施工期间共享树存在多方并发修改（kernel 在途改动、他人未提交文件），
  E 域验证**不依赖全树状态**：vitest 单目录跑 + tsc 域内过滤即闭环。

## 2. 复现步骤（两分钟）

```bash
cd <repo根目录>
# ① 隔离全量单测（不触碰其他域）
npx vitest run src/system/persona
# ② 本域类型检查（--incremental false 防陈旧缓存假阴性——本批教训，见 §4）
npx tsc --noEmit --incremental false 2>&1 | grep persona
# ③ 生产构建
npx vite build
# ④ F170 walkcheck 三模式
python tools/vx-walkcheck-e.py --selftest
python tools/vx-walkcheck-e.py --checklist
# ⑤ 检查项对账 tally（本目录）
node _attic/aie1-f151-f170/tally.mjs .
```
