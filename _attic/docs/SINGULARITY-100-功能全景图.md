## 0. 总纲

### 0.1 立项铁律（五条）

1. **零重复**：Q-01…Q-100 每一项都经过与 355 项存量功能的逐条比对；「同类不同角度」必须在条目里写明与最近似存量项的边界（每条含 `边界` 行）。
2. **不伤手感**：所有新动效默认**轻量**或**关闭**，开启后不得拖慢任何既有交互；任何效果在 reduce-motion / safeMode / static 模式下自动降级为无动画或静态表达。
3. **零侵入集成**：新功能一律通过 `ai04:open-feature` 挂载协议、CustomEvent 总线、CSS 叠层与只读 DOM 观察实现，**不改写任何既有组件的内部逻辑**；对既有文件的改动仅限「一行 import 激活」级别的接线。
4. **诚实实现**：每一项都有真实代码路径（前端模块 / Rust 命令 / CSS 层），无占位、无假开关；依赖系统 API 的功能在不可用时如实降级并提示。
5. **离线可用**：100 项全部本地运行；无任何联网依赖（涉及「下载文件」的功能只读取本地已下载文件的 NTFS Zone.Identifier 标记，不访问网络）。

### 0.2 与存量 355 项的关系（去重声明）

- 存量五计划：NEXT-40（N，35）、ASCENT-60（U，60）、APEX-70（Z，70）、SUMMIT-90（M，90）、化境 V-100（V，100）。
- 本计划为**第六计划**，对以上全量去重后立项。典型边界示例：
  - 存量 N-24「预测性启动预热」≠ Q-56「网络风向标」（前者是启动预热，后者是任务栏实时网速指示）；

### 0.4 统一运行底座（Q 系列共享基建）

全部 100 项共享同一底座，保证「可拓展性 + 完整性」：

- **Q 注册表**（`src/system/singularity/registry.ts`）：100 项的元数据（编号/领域/默认开关/参数），localStorage 持久化，纯逻辑可测。
- **奇点中枢**（`SingularityHub`，`ai04:open-feature { feature: "singularity-hub" }`）：十五域控制台 —— 搜索、逐项开关、参数调节、工具直开。
- **奇点运行时**（`SingularityRuntime`）：按注册表状态激活各领域模块，统一降级链。
- **Rust 脉搏命令**（`src-tauri/src/shell/singularity.rs`）：`singu_pulse`（CPU/内存/电池/风扇/网络采样）、`singu_temp_scan`（临时文件）、`singu_zone_check`（下载检疫标记）、`singu_journal_*`（访问日志）。
- **样式层**（`src/styles/singularity.css`）：全部动效与面板样式，遵循 tokens.css 语义变量，reduce-motion 全量降级。

## 1. 域一：启动与品牌剧场（Q-01…Q-07）

> 存量 U-01…U-06 覆盖冷启动剧场（胶囊进度/文件流/交响/编排器）；本域补齐**唤醒、谢幕、剧本多样性、日常问候**等剧场空白。

### Q-01 唤醒握手（Wake Handshake）
从睡眠/锁屏返回桌面的过渡剧场：一道竖光自屏幕中央展开，时钟大字问候浮现后让位于桌面。与冷启动（U-01）正交：冷启动走 BootScreen，唤醒握手只在 `tauri://focus` 恢复且距上次失焦超过阈值（默认 ≥ 5 分钟）时触发。
**边界**：U-01 启动剧场管冷启动；Q-01 管会话内唤醒，二者时间线不重叠。
**验收**：连续 10 次失焦/聚焦无重复触发；reduce-motion 下仅显示静态问候 200ms。

### Q-02 谢幕剧场（Curtain Call）
退出/关机流程的告别动画：桌面内容向中心收拢成一线光后熄灭（600ms），配合既有保存冲刷流程，不阻断、不延迟任何退出语义。
**边界**：V-92 关机倒计时取消管「反悔」；Q-02 管「告别体验」，收拢动画挂载于退出编排期（closePhase）之上。
**验收**：退出总耗时增加 ≤ 650ms；动画期间保存冲刷照常完成。

### Q-03 首跑巡礼（First-Run Parade）
版本升级后的首次启动，以 3–5 张全屏巡礼卡展示本版新增能力（数据来自 Q 注册表 changelog 字段），支持跳过与「不再提示」。
**边界**：U-57 引导体系管首次使用引导；Q-03 管版本间的增量介绍，只对「已用过旧版」的用户出现。
**验收**：全新安装不出现（走 U-57）；升级后出现一次。

### Q-04 启动剧本库（Boot Scripts）
多套启动剧场剧本可切换：`aurora`（极光帷幕，默认）、`snowfield`（雪原落定）、`matrix`（数据雨）、`paperplane`（纸飞机航线）。剧本只替换 BootAtmosphere 的视觉层参数，不碰进度真实性与胶囊条结构。
**边界**：U-06 仪式编排器管节奏（走多慢）；Q-04 管视觉剧本（怎么好看）。
**验收**：四剧本均可切换且进度语义一致；safeMode 下回退 aurora 静态版。

### Q-05 启动实况解说（Boot Commentary）
启动阶段底部的实时解说字幕（英文 Consolas 大写微文案，遵循既有 boot 文案纪律）：`MOUNTING KERNEL PANES` / `INDEXING ICONS` / `WARMING SHADERS`……随真实阶段推进，诚实地把每阶段耗时打在字幕旁。
**边界**：U-04 文件流带展示具体文件；Q-05 用工程师腔调解说阶段与耗时，是「氛围字幕」而非数据流。
**验收**：字幕与真实阶段同步（不虚构阶段）；bootAnim=none 时不出现。

### Q-06 品牌时刻（Brand Moments）
特定日期的启动彩蛋：周年日字标微光、跨年夜零点星尘、项目生日纸屑。彩蛋清单内置且全部离线判定。
**边界**：V-73 农历节气与节日是日历信息展示；Q-06 是启动瞬间的品牌彩蛋动画。
**验收**：非彩蛋日零开销；彩蛋动画 ≤ 2.5s 且可被任意按键跳过。

### Q-07 晨昏问候（Day Greeting）
进入桌面后右下角一次性的时间感知问候：清晨/上午/下午/黄昏/深夜五档文案 + 今日日期与一句「今日聚焦」（取自待办首项）。
**边界**：M-69 今日简报卡是常驻卡片；Q-07 是 4 秒即散的开场问候，不占桌面。
**验收**：每次会话只出现一次；深夜档自动使用最暗样式。

## 2. 域二：窗口与空间管理（Q-08…Q-15）

> 存量 33 项覆盖吸附/快照/时间机器/舞台；本域补齐**活性感知、排列算法、监控角、手感物理**。

### Q-08 窗口生命体征环（Vitals Ring）
每个 VWM 窗口标题栏左侧的微型活力环：以 2s 周期采样窗口进程 CPU/IO（`singu_pulse`），环的旋转速度与亮度映射活性 —— 活跃窗口环流转、空闲窗口环静止变暗。
**边界**：M-04 窗口体检标记「无响应」异常态；Q-08 是常态化的活性微显示。
**验收**：100 窗口场景下采样开销 ≤ 1% CPU；reduce-motion 下环静止仅保留亮度映射。

### Q-09 焦点轨迹残影（Focus Trail）
焦点切换时，旧焦点位置留下一道 350ms 消散的流向光轨（从旧窗口指向新窗口），帮助用户在多窗口间建立空间记忆。
**边界**：N-06 动效编排系统是全局动效框架；Q-09 是焦点语义的专属增强，只挂 focus 事件。
**验收**：连按 Alt+Tab 光轨不叠加超过 3 道；reduce-motion 下完全关闭。

### Q-10 窗口年龄衰减（Age Fade）
超过设定时长（默认 30 分钟）未交互的非焦点窗口，标题栏渐变为哑光并显示细沙漏角标；任何交互立即恢复。
**边界**：M-06 窗口挂起是资源动作；Q-10 只是视觉年龄提示，不改变任何窗口状态。
**验收**：年龄计算基于真实 lastInteract 时间戳；悬停立即恢复。

### Q-11 排列画廊（Layout Gallery）
一键将全部可见窗口按算法排列：`grid`（等分网格）、`spiral`（黄金螺旋）、`columns`（横向多列）、`quadrants`（四象限）。纯数学布局函数 + 动画过渡，支持撤销（恢复排列前快照）。
**边界**：Z-40 窗口布局快照保存/恢复用户手动布局；Q-11 是即时自动排列算法。
**验收**：8 窗口以内排列动画 ≤ 400ms；撤销准确还原。

### Q-12 边缘窗口偷看（Edge Peek）
鼠标移至屏幕左右边缘并停留 400ms，该侧被压住的窗口以 70% 透明轮廓浮现预览；移开即散。
**边界**：Z-42 虚拟桌面切换增强管桌面维度；Q-12 是同一桌面内的被遮挡窗口预览。
**验收**：与贴边吸附（U-14）手势不冲突（吸附需按住拖拽，偷看只需悬停）。

### Q-13 镜像监控角（Mirror Corner）
屏幕四角之一的常驻缩略监控位：任意最小化/非焦点窗口的静态快照轮播（10s 一换），点击直接聚焦原窗口。适合监控下载、渲染等长任务。
**边界**：N-04 任意窗口画中画是真窗口化 PiP；Q-13 是环境内的单角静态轮播位，零 GPU 合成开销。
**验收**：快照失败（窗口无内容）时如实显示空态而非黑帧。

### Q-14 动量拖拽（Momentum Drag）
拖拽窗口移动时，窗口依速度产生 ±2° 以内的倾斜（像提起一张卡片），松手回弹归零。
**边界**：V-30 拖拽中断与回弹管拖拽取消；Q-14 只加物理手感，不改变拖拽语义。
**验收**：倾斜由速度微分驱动（不是随机摆动）；reduce-motion 下禁用。

### Q-15 尺寸预设菜单（Resize Presets）
窗口系统菜单新增「尺寸」子菜单：1280×720 / 1600×900 / 1920×1080 / 50% / 66% / 33%×高，一键调整当前窗口几何。
**边界**：V-23 调整大小时显示实时几何提示；Q-15 提供目标尺寸直达。
**验收**：最大化状态下选择预设 = 先还原再应用；预设应用保持左上角不动。

## 3. 域三：桌面与图标表达（Q-16…Q-22）

> 存量 18 项覆盖排列/密度/锁定/模板；本域补齐**物理感、堆叠、缩放舞台、网格微调**。

### Q-16 图标情绪微动效（Icon Mood）
图标悬停时：3° 倾斜朝向鼠标来向 + 轻微放大 + 底光点亮，移开后弹簧回落（cubic-bezier 回弹）。选中时做 4° 摇晃确认。
**边界**：V-10 图标让位 FLIP 动效管重排位移；Q-16 管单图标交互物理。
**验收**：悬停响应 ≤ 16ms；60 个图标同屏悬停无掉帧。

### Q-17 桌面快速堆叠（Desk Stacks）
桌面右键菜单「按类型堆叠/按日期堆叠」：同类图标收拢为单个堆叠柱（扇形展开预览），点击展开选择。
**边界**：V-96 桌面归档建议是建议弹层；Q-17 是即时堆叠交互。
**验收**：堆叠后原位保留；取消堆叠精确还原位置。

### Q-18 框选橡皮筋（Lasso Band）
桌面框选时，选框呈现橡皮筋质感（边缘张力波纹 + 选中图标随框经过连续点亮），释放时框体弹性收缩消失。
**边界**：V-10 FLIP 让位动效管图标位移；Q-18 管框选过程反馈。
**验收**：框选逻辑零改变（只加视觉层）；选中计数实时显示于框角。

### Q-19 图标地面接触（Icon Grounding）
图标默认渲染椭圆接触阴影（贴地感），悬停时阴影扩大 + 图标上浮 2px（拿起感）。
**边界**：U-10 图标语言 2.0 管图标体系；Q-19 是物理纵深微层。
**验收**：与任何图标包兼容（阴影独立于图标位图）。

### Q-20 桌面缩放舞台（Zoom Stage）
Ctrl+滚轮在桌面空白处缩放整个图标层（0.6×–1.6×，跟随光标为锚点），松开 Ctrl 后 1.5s 无操作自动缓动回 1×。
**边界**：V-06 桌面图标密度档位是三档离散设定；Q-20 是即时无级舞台缩放（会话级，不写设置）。
**验收**：缩放期间图标可正常点击；自动回正可被设置关闭。

### Q-21 涟漪重排（Ripple Rearrange）
触发图标自动排列时，以触发点为圆心产生涟漪，图标按距圆心的顺序波次落位（每波 30ms 交错）。
**边界**：V-01 桌面图标排列系统管排列规则；Q-21 管排列的过渡动效。
**验收**：200 图标重排总时长 ≤ 1.2s；reduce-motion 下瞬时落位。

### Q-22 网格微调器（Grid Tuner）
桌面右键菜单「网格微调」：滑块实时调整图标网格间距（横向/纵向独立 8px 步进）与对齐方式（左/中/右），带网格线预览。
**边界**：V-06 密度档位是预设档；Q-22 是无级微调 + 可视网格线。
**验收**：调整实时生效可撤销；重启后保留（会话记忆）。

## 4. 域四：任务栏与开始菜单（Q-23…Q-29）

> 存量 20 项覆盖跳转列表/托盘/时钟/便签；本域补齐**资源温度、键盘直达、隐形、分页**。

### Q-23 任务栏温度计（Bar Thermometer）
任务栏图标下方 2px 温度色条：绿（<40% CPU）/黄（40–75%）/红（>75%），数据来自 `singu_pulse` 每窗口采样；悬停显示精确数值 tooltip。
**边界**：V-18 运行指示样式三选是静态样式；Q-23 是动态资源温度映射。
**验收**：色条更新周期 2s；无采样数据时如实隐藏而非显示假绿。

### Q-24 开始菜单键盘流（Menu Flow）
开始菜单打开时支持拼音首字母流：依次按 `w` `j` 直达「文件管理器」（wj → wjjjgl 模糊命中），匹配高亮 + Enter 启动。

## 5. 域五：键盘与输入手感（Q-30…Q-36）

## 9. 域九：兼容性防线（Q-58…Q-63）
