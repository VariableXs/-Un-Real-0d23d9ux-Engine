# UNREAL-X-15000 实施总步骤图

> **Unreal X 计划**：15000 项全新功能（X00001~X15000）的实施顺序、依赖、自检协议与质量门禁。姊妹文档：《UNREAL-X-15000-功能全景图》（600 族 × 25 项）、《UNREAL-X-15000-AI分工完成图》（AI-01~60 落点）。
> 领域 15 施工规范附册：《docs/UI-品质深化完整方案与步骤.md》（§0~§18 全部内容已入册为领域15 族0521~0560）。
> **纪律红线：三线（内核 / Variable 系统 / 代码分析）功能分布均衡（按项各 ≈5000）；任何功能不得与 NOVA-500 / VARIX-M400 / AURORA-10000 已交付项重复；不得降低既有手感、画质、视觉体验与性能。**

## §1 三线归属矩阵（均衡原则的可执行定义）

| 线 | 落点 | 族主责数 | 项级口径 |
|---|---|---|---|
| 内核 | kernel/varix/src/** | 121 族 | 驱动/调度/合成/文件系统/输入栈/安全基座 |
| Variable 系统 | src/** + src-tauri/** | 296 族 | 桌面壳/窗口/任务栏/设置/应用/浮层 |
| 代码分析 | code-analysis/** | 122 族 | core 引擎/app/ui/基准/回归/静态分析 |
| 三方 | 跨线组合 | 61 族 | 主责方牵头 + 协作方接口冻结 |

**项级均衡规则**：每个主责族的 25 项中含 2~5 项跨线联动项（如 Variable 的窗口族含内核合成器联动项、代码分析的基准族含内核 QEMU 项）。收官时按项统计三线各 ≈5000，偏差 >5% 时在族0593「三线一致性审计」中强制再平衡。

### §3.1 项级明细（全景图已为四部本·15000 条逐条版）

- 《UNREAL-X-15000-功能全景图》拆为**四个独立文件**：第1部（领域01~04·X00001~X04000）/ 第2部（领域05~08·X04001~X08000）/ 第3部（领域09~12·X08001~X11500）/ 第4部（领域13~16·X11501~X15000），每部自带头部、领域总览与 ID 声明。

## §4 自检协议（四道门禁）

### G1 · 族内自检（每个 AI 每完成一族）
1. 25 项 CheckSet 全绿（vitest / cargo test）。
2. 对照 §3 模板：L1~L5 每层 ≥5 项，无空层、无复制粘贴项。
3. 查重：族内 25 项 ID 与名称在 NOVA/VARIX/AURORA 全集 diff 无命中。
4. 三线归属核对：主责线落点真实存在，联动项落点写明。

### G2 · 域验收（每领域完成时）
1. 领域内全部族 G1 绿；`runDomainXXChecks` 式注册表聚合函数入 CI。
2. 手感红线抽查：领域内所有交互项在 dark/light/high-contrast 三主题下截图存档（进视觉回归基线）。
3. 性能红线：不引入首帧回退 >10ms、内存回退 >2MB（基准对比）。
4. 文档：全景图对应行置 ✅，四处副本（根目录 + docs/）md5 对齐。

### G3 · 波次门禁（每波次收官）
1. 全域 G2 绿；ID 唯一性全集校验 unique=N 无缺无重。
2. 跨域回归：前序波次全部 CheckSet 重跑仍绿。
3. W0 BUG 清单复核：波次内声明的修复点实测复验。

### G4 · 终验收（W7，族0592/0597 执行）
1. 15000/15000 置 ✅；unique=15000（X 集）+ 与 F 集零交集。
2. 量化指标全绿（沿用 UI 方案 §18.2：首帧 ≤300ms、掉帧 <1%、HC 对比达标 100%、裸值 0、kit 覆盖 100%）。
3. 基线冻结（族0596）：此后改动需走变更评审。

## §6 分工与 AI 数量依据

- 总量 15000 项 = 60 AI × 250 项（每人 10 族 × 25 项）。60 人规模依据：AURORA-10000 用 80 AI 交付 10000 项（人均 125），本计划人均 250 项，靠 §3 五层模板的成熟度提升人均产出；16 领域按权重分配 3~4 人/域（重体验域 4 人，防线性 3 人）。
- AI-01~60 从 1 起编号；分工落点、归属、波次详见《UNREAL-X-15000-AI分工完成图》。

## §7 同步纪律

1. 三文档（全景图/总步骤图/分工图）每次置 ✅ 同步更新**根目录 + docs/ 双副本**，md5 必须一致。
2. 每波次收官提交一次 git（message 格式：`feat(unreal-x) ai-NN~NN: 领域XX …全量落地`），推送 origin main。
3. 全景图行状态只允许 ⬜/🔶/✅ 三态；✅ 必须有 G1~G4 对应门禁记录。

## §8 回滚与防护

- 每族交付独立 commit，可按族回滚；CheckSet 注册表只增不删（删除需 G4 级评审）。
- 内核项合入前必须过 QEMU 启动矩阵（族0571）+ 存活 72h 长稳抽样（族0585）。
- 视觉项合入前必须过截图 diff（族0545），基线更新需 G2 记录。
