## 二、架构与接线

- **schema**：`src/system/ambience/schema.ts` —— 结构化 `AmbienceSettings` + 全量 coerce（坏值一律回落默认；昼夜边界非严格递增拒收）；
- **settings.ts**：`ambience` 键 + JSON 持久化 + 迁移兼容；
- **运行时**：`AmbienceRuntime.tsx` 挂载于 DesktopShell —— 音景、节律 tick、昼夜切换、精选轮换、纯净模式（Ctrl+Alt+P）、CSS 变量注入（hover 延迟/密度/圆角/图标/焦点环/壁纸滤镜）、情绪引擎偏移；
- **设置页**：`AmbienceTab.tsx` 注册进 SettingsModal（tab id `ambience`）；壁纸主色候选「采样→预览→应用」三步分离 + 对比度不达标候选禁点；
- **任务栏**：时钟悬停卡农历/节气/节日（`lunarCalendar=true` 时）；
- **样式**：`src/styles/ai18-ambience.css` + tokens.css 档位层；
- **i18n**：zh/en 词典 `amb18*` 全量词条。
