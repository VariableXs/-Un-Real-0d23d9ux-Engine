## 二、行数缺口归因（如实陈述，不注水）

1. **主册工程量口径 vs 判据实装层口径**：本域 20 项中 18 项工程量类别为
   「系统服务」，主册预估含服务主逻辑/持久化/错误边界三段。本批交付的是
   **纯逻辑核**（状态机、校验器、账本、门禁），持久化面在内核既有
   KV/蜂巢通道上落位时复用既有件（一处一事实），错误呈现面复用
   三要素文案词典——复用即不重复计行。
2. **文档/资产本体不计入**：F135 文档正文、F136 示例源码、F143 像素资产、
   F145 公开文章本体是**内容**不是逻辑，按分工书口径在对应域/管线落位，
   本批只交付其账本与门禁。
3. **组织动作类判据不计行**：F131 真实 PR 提交、F150 真实外部志愿者、
   F149 连续两季按期（需跨季时间）——机制面已实装，事实面登记随闸门补测。
4. **回炉决策建议**：若 Variable 判定本域需要向目标行数深化，扩列方向
   依次为：F132 差异表与 F040 账本的真实 CI 对接件、F135 API 提取器
   （rustdoc 思路工具链适配）、F136 五示例源码本体、F139 tracker 后端
   自建件（F128 JSON 面）。以上均为增量件，不推翻本批逻辑核。
