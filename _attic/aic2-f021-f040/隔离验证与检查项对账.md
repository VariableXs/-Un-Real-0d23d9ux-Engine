## 1. 为什么用隔离舱

共享树施工期间被多方并发修改（2026-09-27 时点：`lib.rs` 工作区存在他人合并伤
——重复 `pub mod ustar3;` 声明，E0428 编译错；checks.rs 有 U2 在途的 merge 方法），
全树 `cargo test` 不可用。按 AI-C2 完成报告 §4 先例：把 `compatstar2/` +
`checks.rs` 拷入临时 crate 宿主独立验证——`checks.rs` 与 compatstar2 全部 21 文件
只依赖 `core` 与 `crate::checks`，自包含可隔离。

## 2. 复现步骤（三分钟）

```bash
V=$(mktemp -d)/compatstar2-verify
mkdir -p "$V/src"
cp -r <repo>/kernel/varix/src/compatstar2 "$V/src/compatstar2"
cp <repo>/kernel/varix/src/checks.rs "$V/src/checks.rs"
printf '//! 隔离验证宿主\npub mod checks;\npub mod compatstar2;\n' > "$V/src/lib.rs"
printf '[package]\nname = "compatstar2-verify"\nversion = "0.1.0"\nedition = "2021"\n[lib]\npath = "src/lib.rs"\n' > "$V/Cargo.toml"
cd "$V" && cargo test
```

期望输出（2026-09-27 实测）：`test result: ok. 133 passed; 0 failed; 0 ignored;
0 measured`，`cargo build` 零警告。
