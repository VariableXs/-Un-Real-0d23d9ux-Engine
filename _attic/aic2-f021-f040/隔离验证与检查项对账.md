## 1. 为什么用隔离舱

共享树施工期间被多方并发修改（复验轮时点：`lib.rs` 工作区存在他人合并伤
——重复 `pub mod ustar3;` 声明，E0428；批次二时点：全树仍有多方在途改动），
全树 `cargo test` 不可用。按 AI-C2 完成报告 §4 先例：把 `compatstar2/` +
`checks.rs` 拷入临时 crate 宿主独立验证——`checks.rs` 与 compatstar2 全部
42 文件只依赖 `core` 与 `crate::checks`，自包含可隔离。

## 2. 复现步骤（三分钟）

```bash
V=$(mktemp -d)/compatstar2-verify
mkdir -p "$V/src"
cp -r <repo>/kernel/varix/src/compatstar2 "$V/src/compatstar2"
cp <repo>/kernel/varix/src/checks.rs "$V/src/checks.rs"
printf '//! 隔离验证宿主\npub mod checks;\npub mod compatstar2;\n' > "$V/src/lib.rs"
printf '[package]\nname = "compatstar2-verify"\nversion = "0.2.0"\nedition = "2021"\n[lib]\npath = "src/lib.rs"\n' > "$V/Cargo.toml"
cd "$V" && cargo test
```
