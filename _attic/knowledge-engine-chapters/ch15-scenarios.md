# 附录 LL 场景手册：二十个时刻

每个场景格式：**时刻描述 → 涉及设计条款 → 自动化断言**。前 10 个是"日常时刻"（每日使用），后 10 个是"关键时刻"（生命周期节点）。

## 日常时刻

1. **两秒后的世界**——启动。冷启动 ≤2s，直接落在上次位置，无主页、无弹窗。〔14.1 / 启动基准测试〕
2. **种第一颗念头**——双击空白，输入"测量是不是就是宇宙在打草稿"，回车。无保存动作、无命名、无分类。灯火生长动画 ≤300ms。〔X.4 / 交互回归〕
3. **拼音输入到一半**——IME 候选窗跟随光标，组合中的文本不触发任何自动行为（不建节点、不搜索）。〔M.1 / IME 专项〕
4. **遇见旧念头**——漫游经过三个月前的念头，灯火仍亮。停留 8 秒，卡片微摆等待，不催促、不计时。〔X.9 / 漫游回归〕
5. **金线时刻**——用户在"香农熵"与"热力学熵"之间按下 G。金线点亮 + Bloom 增强 + 一声轻泛音（若开声）。〔D.1/X.5 / 视听回归〕
6. **搜一个不存在的东西**——Ctrl+K 输入"孤独的拓扑"，空态文案出现 + 一键就地种下。〔X.6 / 空态断言〕
7. **关掉就走的书写**——书写到一半直接关软件。重开：文字、光标位置、边缘灯火全部原样。〔X.8 / 持久化回归〕
8. **深夜的暗**——23 点使用，ACES 色调下无一处刺眼高光；呼吸节律切"缓慢"后整体更静。〔8.2 / 视觉快照〕
9. **十万灯火的一瞥**——缩放到全景，10 万节点 instancing 一帧画完，星云光斑正确聚合。〔C.2/7.3 / 帧剖面〕
10. **无网的一天**——全程断网使用 8 小时，无任何功能降级、无错误提示、无网络请求。〔GG.3-1 / 断网集成测试〕

## 关键时刻

11. **第一次安装**——下载 exe，双击，世界出现。无安装向导、无注册、无协议弹窗（许可证信息在"关于"页）。〔V 附录 / 分发测试〕
12. **种子收起**——用户在数据页一键收起全部出厂内容。世界只剩自己的节点；导出物中无种子残留。〔H.3 / 导出校验〕
13. **断电时刻**——写入事务组中间断电。重开：恢复提示出现，库完整，丢失 ≤2s。〔KK / 崩溃注入〕
14. **接到一颗胶囊**——从朋友处收到"哲学问题家族"胶囊，织入：来客连接建立、导览线可选。全程 ≤1s、无弹窗任务。〔DD / 织入回归〕
15. **恶意胶囊**——含 50 万节点与循环连接的图炸弹胶囊：审计拦截，以束形态引入的选项出现，世界无损。〔GG.4 / 安全测试〕
16. **插件失控**——某 WASM 视图插件死循环：燃料熔断，主循环 80 帧不受影响，插件面板显示"安静离场"状态。〔GG.5 / 熔断测试〕
17. **Variable 共生**——外壳 A 种念头，Variable 内知识窗口 3 秒内灯火亮起；两端同时编辑无静默丢失。〔II.1 / 双壳集成〕
18. **U 盘整机**——varix.iso 启动，内建 knowledge 应用检索 100 万节点库，IPC 面响应达标。〔E / 内核 ktest〕
19. **一年之后**——库 20 万节点、4 万灯火的长期用户：打开仍 ≤2s，漫游仍丝滑，导出仍是单目录拷贝。〔EE 基准趋势 / 长期回归〕
20. **离开**——用户决定离开：一键导出全库（JSON+媒体），文件在任何文本编辑器里可读，私人语言都在里面。门在身后，没有上锁。〔GG.3-5 / 导出完整性〕

> 场景手册的使用方法：每个季度，团队亲自走一遍 20 个时刻（真人操作，非仅自动化），任何一处"感觉不对"都记录进复盘——**自动化断言保住底线，真人时刻守住灵魂**。

# 附录 MM 测试计划全书

## MM.1 测试金字塔与配比

```
        E2E 场景（20 时刻自动化版）        ~5%   慢、贵、守灵魂
      集成（双壳/内核/断网/崩溃注入）      ~15%
    组件（UI 快照/交互回归/文案断言）      ~20%
  单元（core 算法/格式/恢复/漫游分布）     ~60%   快、密、守正确
```

## MM.2 knowledge-core 单元清单（抽样列纲）

1. model：ID 生成唯一性（10^7 样本）/ NodeHead 体积断言（≤64B）/ 双层文本独立性；
2. format：A.7 全部向量 / 随机截断×1000 / 段隔离 / manifest 重建；
3. index：B+ 树混沌操作对（参照模型比对）/ shard 路由完备性 / 热度 EMA 数值精度；
4. graph：邻域有限性（B.1 预算断言）/ 束操作往返 / 墓碑调和 / 合并冲突矩阵（12 种组合）；
5. wander：分布统计检验（卡方，温度两极）/ 孤岛跳转 / 惯性方向性 / 预取序列覆盖率；
6. 性质测试：任意操作序列 → 邻域查询耗时方差 <10%（规模无关性）。

## MM.3 渲染与 UI 测试清单

1. 三基准 golden image（C.5）× 光影四档 = 12 张基线；
2. 降级链状态机全覆盖（制造超支，断言降级序列与恢复）；
3. UI 快照：卷五全部组件三态（空/载/错）× 明暗（若未来有主题）；
4. 文案断言：Y.2 全表逐条；
5. 交互回归：D.1 全表手势 + 8.4 五断言 + IME 专项（M.1）；
6. 排版：G.5 行长/字重纪律的自动 lint（快照时分析布局树）。

## MM.4 集成矩阵

| 维度 | 组合 |
|---|---|
| 外壳 | A 独立 / B Variable / C 内核(QEMU) |
| 数据 | 空库 / 1 万 / 100 万 / 1 亿(M2 后) |
| 异常 | 断网 / 断电注入 / 恶意胶囊 / 插件熔断 |
| 平台 | Win10 / Win11 / 不同 DPI / 多屏 |

关键组合全跑，边角组合抽样——矩阵的完全积不现实，按风险加权（ ежегодно评审一次权重）。

## MM.5 真人测试规程

1. 每季度 20 时刻全员走查（LL）；
2. 半年度"陌生用户"测试：邀请一位未接触者只用软件过一周，观察其是否自然发现双层语言、金线、漫游——**三大灵魂功能的自然发现率是 UX 的北极星指标**（目标：无人指导下 7 日内全部自然发现）；
3. 开发者自用（dogfood）：核心团队日常知识库必须跑在本软件上——**吃自己的狗粮是这个项目不可协商的纪律**。

# 附录 OO 竞品与差异化分析（为什么不抄、也不必抄）

| 对象 | 它的好 | 为什么不照抄 |
|---|---|---|
| Obsidian | 双链 + 本地 Markdown 生态强 | 文件夹/标签是文件系统隐喻，非"一切皆节点"；无渲染世界层 |
| Notion | 数据库视图灵活 | 云优先、块模型重、协作核心与隐私宪法冲突 |
| Anki | 记忆科学扎实 | 复习=债务模型，违 2.1 负面清单 |
| TheBrain | 中心-卫星大图语义 | 收费锁定、闭源格式、无内核/多端愿景 |
| Logseq | 大纲+双链开源 | 大纲结构强预设，私人语言非一等公民 |
| Moodle/课程平台 | 教学管理完整 | 全部是任务与进度语言，站在哲学的反面 |

差异化的一句话总结：**它们的共同模型是"管理知识"，本软件的模型是"居住知识"。**管理隐喻下的一切优化（检索效率、结构规范、协作流程）在居住隐喻下都要重新回答——这正是本总案存在的理由。

# 附录 PP 增长与可持续（诚实的现实篇章）

1. **它可能永远小众**——这被接受：度量衡（1.5 节）与规模无关；
2. **可持续模型**：软件本体可选付费（买断制，格式与规范仍开放——付费买的是便利不是数据）；胶囊市场不抽成；插件生态自由定价。**绝不采用订阅制锁定数据**（违宪法五）；
3. **团队规模假设**：核心 ≤4 人可维护（crate 边界与门禁自动化就是为此设计）；社区贡献从 fmt 向量、文案翻译、视图插件三个低门槛入口开始；
4. **失败预案**：若项目停止维护——开放格式 + 无锁定架构保证每个用户的世界完整可迁出；规范文档与测试向量永久公开。**优雅的死亡能力是工业级成熟度的最终测试。**
