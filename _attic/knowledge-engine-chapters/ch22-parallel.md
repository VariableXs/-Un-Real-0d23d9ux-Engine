# 附录 XXX 平行宇宙推演：三条被放弃的路

## XXX.1 平行宇宙 A：Electron 路线（"最快见效的宇宙"）

**选择**：TS 全栈 + Electron + WebGL 图谱 + SQLite 存储，三周出 MVP。

**前六个月的模样**：世界上手最快，图谱两万节点流畅，Notion 难民涌入，Star 攀升——所有仪表盘都是绿的。

**第一道裂缝**：十万节点后 WebGL 力导向掉到 30 帧；GPU compute 不可用；力导向回退 CPU——帧预算哨兵（7.1）根本无法成立，因为渲染管线不在自己手里。80 帧目标在 A 宇宙的讣告上写着：**死于借来的渲染器**。

**第二道裂缝**："放进内核"永远不可能——SQLite 无 no_std 等价物，核心逻辑要用 Rust 重写第二遍。三壳愿景退化为一壳。

**结局**：成为一款"不错的笔记软件"，在一个拥挤的赛道上与上百个同类竞争最便宜的维度。**它死于最早实现的那个月。**

## XXX.2 平行宇宙 B：全能结构化路线（"最周到的宇宙"）

**选择**：预设完整的本体类型系统——学科/概念/公式/人物/事件五类节点、八种关系类型（包含/因果/引用/对比…）、内置课程模板、学习进度、复习引擎、协作白板。功能清单长达四十页。

**前三个月的模样**：演示惊艳。每一个需求都能在功能表上指给你看。

**第一道裂缝**：用户开始问"这个该建'概念'还是'事件'？""引用和对比该选哪个？"——**结构的重量落在用户的每一次落笔上**。双击种念头需要先做四个选择题（类型、关系、归属、模板），仪式感杀死零仪式（2.2-4）。

**第二道裂缝**：类型系统成为扩展税——每加一种新内容（比如"我的猜想"），都要改 schema、迁数据、改所有视图。三个月后功能表变成债务表。八种关系里六种没人用，删又不敢删（有用户数据依赖）。

**结局**：它死于"周到"。**定义越多的系统，留给用户的定义越少**——2.4 的围棋论证在 B 宇宙的反面被再次证明。

## XXX.3 平行宇宙 C：云端优先路线（"最性感的宇宙"）

**选择**：云同步实时协作 + AI 全程陪伴 + 社交学习流。增长模型清晰，融资故事完整。

**第一道裂缝**：隐私宪法（GG.3）逐条阵亡——遥测必须上（增长要数据）、云端分析必须上（AI 要语料）、你的语言开始出现"热门说法"的比较压力（2.1-4）。

**第二道裂缝**：无网即无产品。地铁里、飞机上、停电的夜晚——世界一片黑暗。而知识最深的时刻往往恰恰是离线、独处、深夜。

**第三道裂缝**：内核端彻底无意义——U 盘整机、离线世界、裸机检索，这些"不性感"的形态在云架构下连讨论价值都没有。

**结局**：它死于联上网络的那一刻。**云是体验的放大器，但先于体验存在的云是体验的替代品**——C 宇宙用增长换掉了灵魂。

## XXX.4 三个宇宙教会本宇宙的事

- A 教会：**渲染与数据结构必须在第一天就是自己的**（4.2 边界）；
- B 教会：**预置的类型越多，用户的语言越少**（2.4/5.1）；
- C 教会：**本地不是架构选择，是伦理选择**（GG.3）。

本宇宙（本总案）不是三者的折中——它拒绝了三者的前提，才保住了自己的前提。

# 附录 YYY 一页纸总案（浓缩版，传阅用）

> 把 10 万字压进一页。给没时间的人，也给十年后想快速回忆的人。

**它是什么**：一个可以居住的知识世界。独立 Windows 软件 + Variable 系统原生应用 + VARIX 内核内建模块，三副外壳共享一个 no_std Rust 核心与一份开放格式知识库。

**它的信仰**：理解始于私人隐喻；压力被拒绝而非管理；最少的定义、最深的组合；本地优先、永不锁定；你的度量衡是你用自己的话重说了多少东西。

**它的模型**：一切皆节点，节点间唯连接。私人语言是数据第一层。128 位 ID、邻域有限、追加式日志、外存分层——架构从第一天就按 100 亿条设计。

**它的体验**：阅读（书）、图谱（地貌）、漫游（散步，灵魂形态）、书写（零仪式落笔）。暗夜微光的艺术方向，灯火呼吸的世界。

**它的性能**：稳定 80 帧（12.5ms 预算 + 三级 LOD + 帧预算哨兵降级链）；冷启动 2 秒；渲染量与数据总量无关。

**它的开放**：格式人类可读、双向导出、永不锁定；syscall ABI 冻结；WASM 三通道让内核接受所有语言；Unreal 是第四外壳；插件即节点。

**它的成熟**：第四条门禁（哲学断言居首）；崩溃恢复全覆盖；基准趋势入 CI；DoD 十条；dogfood 一票否决。

**它的道路**：第 0 步定稿 → 第 2 步最小可用世界 → 第 4 步渲染引擎 → 第 6 步 Variable → 第 7 步内核 → 第 9 步 Unreal → 第 10 步规模攻坚。可用性先行于完整性。

**它的一句宪法**：这里有多少东西，被你用自己的话重新说过了一遍。
