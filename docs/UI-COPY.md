## 2. 标点与符号规范

- 省略号：表示**截断**用 `…`（单字符）；表示**待输入**不用任何省略号。
- 中文破折号用「——」，省略号用「…」，不混用西文 `...`。
- 按钮文案**动词化**：「删除」而非「删除操作」「执行删除」。
- 中英混排中西文之间留半角空格（CSS 层由 Z-64 `text-autospace` 兜底）。
- 数值与单位间不换行；时间格式统一 `HH:mm`、日期 `yyyy/M/d`。

## 3. 句式规范

- 陈述现状，不指责用户：「文件正被另一个程序使用」而非「你打开了这个文件导致失败」。
- 错误文案四段式（U-56）：发生了什么 / 影响 / 你现在能做什么 / 技术详情折叠。
- 每句 ≤ 40 字（中文）；列表说明每条 ≤ 60 字。
- 不用感叹号（除安全告警）；不用机器翻译腔（"该功能已被支持"→"已支持"）。

## 4. 中英一致（zh/en 同键同义）

- 所有 UI 词条 zh/en 进 `src/i18n/dictionaries.ts`，audit.cjs 强制键位对齐；
- en 文案遵循 Microsoft 英语风格：sentence case、无句号按钮、& 不用 and（空间受限时）。

## 5. 守护

audit.cjs 的 i18n 段守护键位完整性；术语一致性由走查 + code review 守护（无自动化截断检查，诚实口径）。
