# VARIABLE-200 实施总步骤图（完整版 · 内核并入 Variable 系统）

> **VARIABLE-200**：Varix 内核从"能引导的裸机内核"成长为"Variable 系统本体"的并入总规划。
> 8 个 AI（AI-01 ~ AI-08）× 25 项 = **200 项功能**（F001~F200），覆盖三段航程：
> **W2** 内核侧长出用户态（进程 + ELF + 系统调用 ABI）→
> **W3** AURORA-1000 桌面移植到内核上跑（UI 运行时 + 渲染/输入对接 + Tauri 依赖替换）→
> **W5** 引导时直接进 Variable（Limine → 内核 → UI 运行时 → 桌面，整台电脑不再经过 Windows）。
> 配套：《VARIABLE-200-功能全景图》《VARIABLE-200-AI分工完成图》。
> 状态：⬜ 未开始 / 🔶 进行中 / ✅ 完成
>
> 前置基线：VARIX-500 W1 原型已达成 —— QEMU 11.1.0 实测引导至 boot complete，
> 各域自检全绿（boot 13/13），中断 20s/10200+ 次零异常，主机单测 1869 全绿。

## 〇、总纲

### 0.1 三段航程（并入里程碑）

| 航程 | 域 | 并入里程碑 |
|------|----|-----------|
| **W2 用户态地基** | AI-01 进程用户态、AI-02 ELF与ABI、AI-03 系统调用、AI-04 内核服务与initfs | Ring3 跑通第一个用户程序 `hello`（S1~S3） |
| **W3 桌面上内核** | AI-05 图形显示服务、AI-06 输入与事件、AI-07 AURORA移植与兼容 | AURORA-1000 桌面在 Varix 帧缓冲上完整呈现（S4~S6） |
| **W5 引导与交付** | AI-08 引导链与交付 | Limine 选 Varix → 直接进 Variable 桌面；U 盘/ISO 双交付、三系统并存（S7~S8） |

### 0.2 并入判定（Done 的唯一定义）

> **一台电脑开机 → Limine 菜单 → 选 Varix → 内核自检全绿 → AURORA-1000 桌面出现 →
> 能用键鼠操作窗口、打开应用、读写文件 → 关机不丢数据。**
> 全程不出现 Windows。此判定达成前，一切功能项只算"框架就绪"，不算"并入完成"。

### 0.3 质量军规（并入版，每项功能必须全过）

1. **手感无损**：输入→像素全链路延迟不高于 AURORA-1000 在 Windows 上的现值；动效弹簧曲线统一令牌，移植不走样。
2. **画质无损**：合成器禁止降采样；字体亚像素渲染；128px 图标管线平移；主题令牌逐字节复用。
3. **性能预算**：ISR 关中断窗口、调度延迟、syscall 往返、合成帧时间全部有仪表且守红线（见 S6 验收门）。
4. **可回滚**：驱动/服务/应用独立开关与版本回滚；A/B 分区更新；引导菜单永远保留"上一版"。
5. **降级纪律**：无 GPU→软合成；无 USB 控制器→PS/2；无 NVMe→AHCI/SATA；无网络→离线功能清单。
6. **崩溃红线**：任何驱动/服务/应用 panic 不拖垮内核；用户态崩溃只回收该进程并在通知中心明示。
7. **零重复**：立项前对照 VARIX-500 全景图 500 项 + 本图 200 项 + 现有 AURORA 功能查重。
8. **完成即自检**：手感/画质/性能/回滚/崩溃五项自检，不写报告，只留可复现验收（脚本 + 串口日志 + 截屏）。

### 0.4 工程纪律

- 内核侧代码全部在 `kernel/` 独立 Cargo workspace（`x86_64-unknown-none` target）；
  **不碰 `src/`、`src-tauri/`**——AURORA-1000 源码在 W3 之前保持 Windows 可运行状态，
  移植以"新增 Varix 后端"方式进行，绝不删除 Windows 后端（回滚纪律）。
- 用户态运行时与兼容层放 `kernel/userspace/`（新 workspace，target `x86_64-varix`）；
  AURORA 移植产物放 `kernel/userspace/aurora/`。
- 共享 MD（本图、全景图、分工图）编辑前先 `git log` 验 HEAD（并行会话防覆盖）。
- 完成一项：更新分工图 → commit（`var200(ai-XX): Fxxx <功能名>`）→ 推送 GitHub。
- 全程只维护本组 3 个 MD，不新增报告类文档。

## 二、仪表与红线（S6 验收门量化指标）

| 仪表 | 红线 | 测量方式 |
|------|------|----------|
| 输入→像素延迟 | ≤ AURORA Windows 版现值，且 < 33ms 硬红线 | 内核时间戳 + 帧序号回写 |
| 合成帧时间 | p99 < 8ms（60Hz 预算一半） | 合成器内置环形统计 |
| syscall 往返 | p50 < 1μs，p99 < 10μs | vDSO 时钟自测 |
| 上电→桌面 | ≤ 8s（QEMU），真机 ≤ 5s | 引导时间线（F 预留项输出） |
| 内核 panic | 72h 压测 = 0 | 串口日志 grep |
| 崩溃恢复 | 服务重启 ≤ 500ms；应用崩溃桌面零影响 | 看门狗事件 + 截屏对比 |
