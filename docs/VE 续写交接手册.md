## 三、深化体例（七要素，逐字遵守）

每条深化正文是**单个自然段（单行，不含换行符）**，按固定顺序七要素拼接：

```
职责定位：<条目名>——<核心内容（含：定位声明/范围/规则/分工/复用声明等，具体差异化展开）>。数据结构：<本条的数据结构清单>。错误路径与降级矩阵：<错误→处置映射>。性能逐项分解：<复杂度逐项>。跨批对接点：<上游/下游条目指针>。无障碍与隐私：<无障碍要点；无隐私面则写明>。工程量：核心逻辑约 X 行（…）、边界防护约 Y 行（…）、错误路径约 Z 行（…）、测试支撑约 W 行（…），合计约 T 行。判据：<关键词列表、以"、判据"收尾>。
```

**硬性格式规则**（违反即断言拦截）：
1. 单条正文 ≥300 字（目标 330-500，家族平均约 380-430）。
2. 必含 `工程量：`（四项行数拆解，合计 = 条目标题括号里的目标行数附近）。
3. 必含 `判据`，正文以 `。` 结尾。
4. 禁 ASCII 双引号 `"`、禁裸反斜杠 `\`、禁换行。
5. 禁"中文 中文"式杂散空格。
6. `全域` 一词单条 ≤8 次（防堆砌退化；实际应为 0，除非标题自带）。
7. 半角括号统一写盘前替换：`行)` → `行）`。
8. 引用其他条目用 F+四位编号（如 F3986）；家族复用声明要计数（如"模板第九用"——每过一个域递增一用）。

## 五、单轮标准流程（100 条）

1. **读标题**：读本轮 100 个条目标题（fid 范围见断点行）。
   - ⚠️ **引用编号实拉纪律（S201 教训）**：写正文引用其他条目编号前，必须程序化实拉相关域全部标题建立"编号→标题"映射表，以标题语义为准引用；**禁止凭会话日志的组描述、记忆或推断赋编号**——S201 曾凭日志推断致 14 个编号语义错位，靠实拉映射修正 16 处。
2. **生成**：写 Python 生成器脚本（临时文件如 `.gen_s174.py`），每条一个元组（fid/role/core/ds/err/perf/hook/a11y/eng/crit），make() 模板拼装七要素，内建断言（长度/引号/反斜杠/换行/全域）。生成 JSON：`.deep_<组名>.json`，每文件 20 条。
   - ⚠️ 历史教训：上下文过长时直写长文会触发"生成退化"（重复堆砌，单条 >900 字或重复词频爆表）。**程序化生成器 + 手工差异化元组是唯一可靠模式**，不要直写整段长文。若连续 Write 失败/内容堆砌，立即止损停止本轮，主文档零污染比完成一轮重要。
3. **写前硬断言链**（precheck）：见第三节 8 条规则程序化校验 + `len(seen)==100` + 唯一性 + `sorted(seen)==expect` 覆盖断言。
4. **finalize 写盘**：
   - 条目定位替换：`re.search(r'(### VE-F%04d \· [^\n]+\n\n)([^\n]+)', s)`，替换第 2 组。
   - 台账行更新：正则 `\| W1-<TAG> \| F<lo>-F<hi> \| ≈([\d,]+) 字 \| 样板完成 \| 会话 S(\d+) \|`（千分位兼容 `.replace(',','')`），替换为 `≈<新合计> 字（深化 S<NNN>） | 深化完成 | 会话 <旧>/S<NNN> |`。
   - 写盘前最后断言：`len(re.findall(r'### VE-F\d+ · ', s)) == 6400` 且唯一。
5. **写盘后复核**：本轮 100 条四断言（≥300/判据/工程量/句尾）全绿；若本轮含域收官（X10 组），加跑该域 200 条两断言（≥300+判据）。
6. **记账**：memory 日志追加会话段（含断点行，会话号单调性断言 `max==上一轮`）；总表追加状态行。
7. **清理**：删除本轮临时脚本（.gen_*/.precheck_*/.finalize_* 等）；`.deep_*.json` 历史惯例保留。

## 六、红线（凌驾于一切进度目标）

1. **主文档零污染优先**：任何断言失败→不写盘→查因→修复后重跑；绝不绕过断言。
2. **不删除/覆盖既有内容**：只做"定位替换正文"与"台账行更新"两种写操作。
3. **引导与硬件红线**：不碰 BIOS/UEFI/引导/固件/内置盘写操作（Variable 明令，全文见主人格设定）。
4. **诚实**：断点、字数、进度数字必须程序化核实后报告，不凭印象。

## 七、快速自检（新 AI 接手第一分钟）

```python
import re
s = open(r'<主文档路径>', 'rb').read().decode('utf-8')
fids = re.findall(r'### VE-F(\d+) · ', s)
print('条目', len(fids), '| 唯一', len(set(fids)), '| 字数', len(s))   # 应为 6400 | 6400 | ≈261 万+
# 深化条目近似统计（台账口径更准，此为启发式）
deep = sum(1 for f in set(int(x) for x in fids)
           if (m := re.search(r'### VE-F%04d · [^\n]+\n\n([^\n]+)' % f, s))
           and len(m.group(1)) >= 300 and '判据' in m.group(1))
print('启发式深化条目', deep)
```
