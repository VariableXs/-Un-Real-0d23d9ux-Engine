## 第一部分：全局增量纪律（NEXT-40 专属）

1. **命令注册纪律**：每个 N-* 功能收口前，必须把其全部用户可执行动作注册进 N-13 命令注册表（`src/lib/commands/registry.ts`），未注册不算完成——这是「40 个功能缝合为一个整体」的结构性保证。
2. **动效单源纪律**：NEXT-40 期间新增的一切批量/编排动效必须走 N-06 编排器（`src/lib/motion/`），禁止新增裸 CSS animation 编排场景；存量动效按域分批迁移，visual-audit 基线只允许在迁移批次重拍。
3. **数据分片纪律**：一切新增时序数据（快照/洞察/剪贴板/设备日记/焚毁日志）统一格式：`data/<domain>/YYYYMMDD-NN.<ext>`，zstd 压缩、纯追加、按天分片、FIFO 淘汰、上限可查（设置→存储页显示各域占用）。
4. **降级测试纪律**：每个声称「如实降级」的功能，其测试计划必须包含一条**降级注入用例**（模拟 USN 无权限/SMART 读不到/GPU 计数器缺失/语言包缺失），断言 UI 显示降级态而非假数据。
5. **安全分叉不可放宽纪律**：L4 让位、密码框判停、沙箱越权、签名校验、接管互斥五处为硬编码安全分叉；任何 N-03 规则、N-18 宏、N-26 插件、N-28 scope 均不得触碰——code review 门禁项。
6. **性能预算纪律**：后台常驻能力逐项预算——索引 ≤3% CPU、洞察采集 ≤1%、HUD 自身 ≤0.5%、组件刷新空闲 ≥30s 间隔；超预算自动降级并在 N-31 洞察中如实记录。
7. **共享文件流程**：`src/lib/ipc.ts`、`src/i18n/dictionaries.ts`、`src-tauri/src/lib.rs`、`vwm.ts` 等共享文件，修改前 `rg` 核实现状、最小化编辑、改后立即跑 `tools/audit.cjs` 与 `tsc --noEmit`——沿用 project_memory 全部教训。

## 第二部分：公共基座（Wave 0，先于一切功能）

任何 N-* 功能开工前，四个公共基座必须先落地，否则多个功能会重复造轮子：

### P-1 命令注册表骨架（N-13 的先行切片）

1. 新建 `src/lib/commands/types.ts`（Command 声明类型）与 `src/lib/commands/registry.ts`（注册/查询/权重排序内核）；
2. 把开始菜单现有「启动应用」与设置页「打开设置」两个动作迁移进注册表作为首批命令（验证管道）；
3. 模糊匹配内核：倒排索引 + 拼音首字母（zh 用户高频）+ 频率/新近度加权字段（先留空接口，N-13 本体接数据）；
4. 单测：注册/查询/权重/条件可见性四组；`tools/audit.cjs` 增加「命令 id 与 i18n key 对齐」检查。
5. **验收**：注册表管道 tsc/vitest/audit 三绿；后续功能从此只做「注册 + 实现 action」。

### P-2 动效编排器内核（N-06 的先行切片）

1. 新建 `src/lib/motion/orchestrator.ts`（rAF 批调度 + 30ms 默认错峰）、`flip.ts`（First/Last 量测与反演）、`spring.ts`（把既有 vwm spring keyframes 参数化为 JS 模型）；
2. reduce-motion/高对比度下 80ms 直落（读 A-2 既有根属性）；
3. 帧预算守卫：单帧超 8ms 自动放弃剩余动效直落位，事件上报（bench 可见）；
4. 用一个最小改造试点验证：desktop-icons 网格重排走 FLIP（此为第一个迁移样板，重拍该域 visual-audit 基线）。
5. **验收**：编排器单测（错峰/降级/帧预算三组）；试点动效 60fps；reduce-motion 全绿。

### P-3 数据分片与淘汰框架

1. 新建 Rust `src-tauri/src/shell/timeline_store.rs`：分片写入（zstd）、按天滚动、FIFO 淘汰、容量上限回调、损坏分片隔离（单片损坏不影响整读）；
2. IPC：`StoreAppend/StoreList/StoreRead/StoreStats/StorePurge` 五命令进 `ipc.ts` 契约（`rg` 先核对再插入）；
3. 契约测试进 `commands_e2e.rs`；损坏注入用例（截断/乱码分片）必须优雅跳过。
4. **验收**：契约测试绿；损坏注入不 panic；淘汰按 LRU 正确。

### P-4 权限与账本框架（为域 E/F 铺路）

1. 扩展 `netconsent.rs` 为通用「能力同意账本」：网络访问之外，登记 API 网关连接、远程源访问、接力传输三类条目（时间/对端/类别/大小）；
2. 账本查询页骨架进设置→隐私（先只展示既有网络条目）；
3. **验收**：账本写入/查询契约测试；账本自身永不外传（取证扫描）。

## 第三部分：分批施工步骤（按 Wave 顺序）

> 每批八步法：**①契约冻结 → ②数据结构 → ③后端命令 → ④IPC 绑定 → ⑤前端 UI → ⑥命令注册 → ⑦测试三绿（tsc/vitest/cargo test --no-run）→ ⑧验收归档**。
> 下列步骤均按此八步展开；篇幅所限，⑤⑥⑦⑧按域合并表述，①-④逐批展开。

### Wave 1：窗口路与体验路主力（N-01…N-12）

#### N-01 窗口时间机器

1. 契约：`TimelineSnap { ts, scene?, vwm: Vec<VwmWin>, embed: Vec<EmbedWin> }`；`VwmWin { id, x, y, w, h, z, focus, snap, group }`；`EmbedWin { pid, exe_path, hwnd, rect, tier_hint }`；
2. 落盘走 P-3 框架（`data/timeline/`）；触发器挂 `winman.rs` 布局变化事件（去抖 8s）与 VWM store 变更；
3. 后端 `shell/timeline.rs`：`snapshot_now / snapshot_manual / list / load / restore`；restore 三级策略（精确/尽力/诚实报告）——尽力级重启复用 `launcher.rs` 登记项，**tier 必须现场复跑 compat_probe 而非读快照**（写死注释）；
4. IPC 五命令 + 前端时间轴浮层（横向时间带，缩略图用 `capture.rs` 异步批量抓，LRU 缓存）；
5. 验收用例按功能文档四条；bench：快照写入 p95 < 30ms、时间轴滚动 60fps。

#### N-02 舞台管理器

1. 契约：`StageGroup { id, name, members: Vec<winId> }`；持久化 `data/stages.json`（原子写 + 备份）；
2. 纯前端：VWM store 增加 groups 维度；侧幕 UI（气泡列）+ 上台/入组/轮换手势与 `Ctrl+Shift+←/→`；
3. 动效全部走 P-2（上台复用 spring 模型，收拢走 squash）；侧幕热区与贴靠热区错开 24px（常量进 tokens）；
4. 命令注册：「创建组/切换组/解散组」；
5. 验收：重启持久化、60fps bench、贴靠共存、键盘可达。

#### N-03 窗口规则引擎

1. 契约：`Rule { id, trigger, cond, actions, priority, enabled }`（JSON Schema 随文档发布）；
2. 后端 `shell/rules.rs`：规则装载/校验（行级错误报告）/裁决（优先级+specificity）/执行日志环形缓冲 500 条；
3. 执行适配层：动作映射到既有 IPC（snap.applySnap / embed 策略层 / stage 入组）——**不新增任何绕过安全审查的执行路径**；L4 与管理员窗口的动作白名单硬编码在适配层；
4. 前端规则中心（列表+编辑器+实时日志页）；12 条内置模板；
5. 验收：触发 < 500ms、导入合并、L4 不可放宽渗透用例、语法错误行级报错。

#### N-04 任意窗口画中画

1. 后端扩展 `embed.rs`：`pip_enter(hwnd, opts) / pip_exit(hwnd) / pip_list`；PiP 样式（置顶/透明/角落磁吸 8px）在 winman 侧实现；
2. 尺寸/透明度档位记忆 `data/pip_memory.json`（按 exe 记忆）；L4 禁入 PiP（复用 C-6 判定结果）；
3. 前端：红绿灯菜单入口 + `Ctrl+Alt+P`（经 N-17 注册表）+ 托盘聚合图标；
4. 失败路径：detach 抖动→回原位+toast，绝不卡中间态（沿 embed.rs 显式分臂教训）；
5. 验收：5 类样本应用矩阵（真机）、往返无残留、宿主退出回收通知。

#### N-05 工作区场景

1. 契约：`Scene { id, name, visual(DRESS 字段), orchestration{ snapshot_ref?, stage_ref? }, behavior{ dnd, sound, ime }, triggers[] }`；`data/scenes/*.vscene`；
2. 后端 `shell/scenes.rs`：场景 CRUD / 切换编排（视觉包→设置管道；编排包→N-01/N-02 执行器；行为包→通知/声音设置）+ 全量回滚（任一包失败回滚整套并报错）；
3. 触发器：定时（复用 sysmaint 调度内核）/上下文（shell_watch 前台事件→toast 建议非强制）；
4. 前端：场景管理页 + 转场幕（240ms 极光，走 P-2）+ 未保存窗口守卫（标题特征匹配→确认门）；
5. 验收：三触发型全链路、往返 100 次无漂移、守卫生效。

#### N-06 动效编排系统（本体收口）

1. P-2 内核之上补齐：动效实验室 UI（全域 spring 参数可视化调节+实时预览）、`.vmotion` 档案导出/导入；

3. lint：新增 `tools/motion-lint.cjs` 检查新增编排场景禁用裸 animation（存量白名单制）；
4. 验收：三模式 bench、reduce-motion ≤80ms、档案重放一致、基线 diff < 0.5%。

#### N-07 壁纸工坊 2.0

1. 后端扩展 `wallpaper.rs`：`.vwp` 包解析（manifest 校验/资源解包/拒绝远程 URL）、四引擎会话管理（Video 硬解、Shader 编译缓存、Web 本地沙箱、Generative 参数化预设——现有星空/极光渲染器迁入）；

4. 命令注册：切换壁纸/暂停引擎；
5. 验收：四引擎预览/应用/持久化、坏包优雅降级、打字降级联动。

#### N-08 主题工坊

1. 前端为主：`src/features/settings/theme-studio/`（三区编辑器+AA 对比度实时校验+三变体存档）；
2. `.vtheme` 导入导出（版本校验+冲突字段报告）；预览渲染复用真实组件缩样；
3. 裸色迁移第一批：desktop.css 与 tools.css 的语义位（每批 audit 裸色计数只降不升）；
4. 验收：往返一致、AA 红牌门、高对比变体随系统切换、audit 计数下降。

#### N-09 桌面小组件系统

1. 契约：`widget-manifest.json`（尺寸档/权限/刷新策略）+ 宿主容器（桌面常驻网格吸附 + 组件板侧滑）；

3. 内置 8 组件逐个落地（世界时钟→日历→待办→性能迷你条→快捷启动→倒计时→网络→灵感卡）；失败 3 次自动收起+通知；
4. 生命周期联动接口：全屏暂停/低电暂停（先留事件位）；
5. 验收：8 组件全功能、越权 IPC 渗透用例、布局持久化。

#### N-10 锁屏与仪式屏

1. 后端 `shell/lockscreen.rs`：口令哈希（argon2）存 `data/lock.dat`、恢复码（OOBE 集成补生成流程）、错误 5 次指数退避；

5. 验收：1000 次锁解、零内容泄漏、退避、恢复码、失效联动。

#### N-11 实况场景组件

1. 粒子层：独立无边框透明窗口（WS_EX_TRANSPARENT+点击穿透切换），canvas 自绘四类天气粒子；无 GPU 自动关闭粒子只留色温；

5. 验收：穿透正确、离线完整、网络条目对账、高对比度下色温禁用。

#### N-12 图标包系统

1. 后端 `shell/iconpack.rs`：`.vicon` 解析、图标缓存（分批渐进替换节流）、优先级链（用户包>内置>原生提取）、缺键回退计数；

3. 前端：包管理页+安装前 12 宫格对比预览+「从系统图标导出包骨架」工具；
4. 验收：往返/缺键回退/四空间变体/千图标换包无冻结（帧耗时采样）。

### Wave 2：效率路 + 系统路（N-13…N-25）

#### N-13 命令面板（本体收口）

1. P-1 骨架上补：浮层 UI（居中、三类一框、`>`/`?` 前缀切换）、学习排序接数据（本地频次+新近度）、钉选、链式参数模式；

3. 全局热键 `Ctrl+K` 注册+冲突降级；p95 < 50ms（倒排索引基准测试进 bench）；
4. 验收：四条全过+学习排序命中率用例。

#### N-14 统一搜索 2.0

1. 后端 `shell/usn_index.rs`：USN Journal 增量索引（MFT 读权限探测→不可用降级定时扫描并标注）；索引分片落 `data/index/`；排除目录黑名单；**保险箱路径硬编码排除**；
2. 聚合五类（应用/文件/内容/命令/设置），类别权重+Tab 锁定；高级语法解析器（ext/size/modified 子句）；
3. 预览：文本前 3 行/图片缩略/音频时长（复用 capture 与 explorer 既有能力）；行内快捷动作三键；
4. 挂接 N-13（搜索框 `?`/命令入口「搜索一切」）；
5. 验收：百万文件 p95 < 200ms、保险箱零泄漏渗透、降级诚实。

#### N-15 剪贴板历史中心

1. 后端 `shell/cliphist.rs`：序列号轮询（300ms 去抖）、四类型识别、16MB 图片上限、AES-GCM 分片（密钥=保险箱 KDF 派生独立子钥）；
2. 敏感名单：窗口标题/进程匹配→暂停记录（取证用例验证零记录）；「关闭即焚」会话模式；

4. 定时焚毁挂 N-34 调度；验收四条照功能文档。

#### N-16 截图标注与贴图

1. 后端：全屏截图（DXGI 抓帧）、区域取框参数；OCR 走本地引擎（Windows.Media.Ocr 离线语言包优先，缺包给安装指引，绝不云 OCR）；
2. 标注层：矢量六工具（Mindmap 画布技术复用），马赛克破坏性操作确认门；
3. 贴图=PiP 容器装位图（复用 N-04 全套行为）；滚动截图能力探测（不可滚动窗口禁用该项）；

#### N-17 快捷键中心

1. **契约先行**：热键注册表 `src/lib/keys/registry.ts` 单一事实源；先写 `commands_e2e.rs` 迁移契约测试（旧路径行为快照→新路径逐条对照），再逐域迁移 kbdhook 绑定；

3. 学习模式（按键→角落功能卡）+ 速查表导出 PNG/PDF；
