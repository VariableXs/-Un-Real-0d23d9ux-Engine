# APEX-70 — 登顶之后的「工匠计划」功能全景

> 系列：NEXT-40（第二曲线）→ ASCENT-60（登顶计划）→ **APEX-70（工匠计划）**
> 定位：前两轮解决「有没有、强不强」，本轮只解决「像不像 Windows、稳不稳、顺不顺手」。
> 编号：Z-01 … Z-70，共 10 域 × 7 项。

## 0. 总纲

### 0.1 已有规划覆盖的，本文一律不再重复

以下功能**已在** NEXT-40 / ASCENT-60 / 原始五路计划中立项，本文与之严格去重：

- 窗口域：时间机器、舞台管理器、规则引擎、画中画、工作区场景、动效编排、智能吸附 2.0、任务栏进化、多显示器 2.0
- 桌面表达：壁纸工坊、主题工坊、小组件 SDK、锁屏、实况组件、图标包系统
- 效率中枢：命令面板、统一搜索 2.0、剪贴板中心、截图标注、快捷键中心（*注意：N-17 是"中心"的展示层，本轮 Z-08/Z-09 是"注册表与仲裁机制"的地基层，二者互补不重叠*）、宏引擎
- 系统域：性能 HUD、电源管家、网络指挥台、存储健康、设备中心、预测预热、自愈中心、性能模式、音频路由、无线中心
- 开放生态：插件运行时 2.0、插件市场、开放 IPC 网关、CLI、浏览器伴侣、协议中枢、脚本安全屋、.vxs 资源包、诊断导出包

- 安全隐私：隐私仪表盘、应用防火墙、诱饵文件、紧急擦拭、信任链、隐身会话（**本域整体不设新项，用户明令禁止极端化隐私功能**）
- 启动与设计：启动剧场全部 6 项、令牌 2.0、材质引擎、光影、图标语言 2.0、微交互、响应式重构、空状态、错误叙事、引导体系、键盘全景（*N-17/U-58 均为"覆盖广度"，本轮 Z-08…Z-14 是"冲突纪律与作用域机制"，互补*）、触控基础、品质关卡

### 0.2 本轮四条立项铁律（每项 Z 功能必须全部满足）

1. **实用优先**：每个功能必须回答"一个真实用户在什么场景下会用到它"，答不上来的不立项。
2. **零退化**：任何改动不得让现有观感、操作、性能产生哪怕一点回退；拿不准的默认关闭。
3. **零键位冲突**：所有新键位必须经 Z-08 注册表仲裁后才能注册；不确定的组合一律不占用。
4. **无极端化**：不含任何"焚毁/擦除/诱饵"类高危功能，不做哗众取宠的花活。

## 域 A：Windows 一致性工程（Z-01…Z-07）

> 目标：视觉上与 Windows 11 原生环境**无法区分**。用户明确要求"图标和 window 系统一模一样"。

### Z-01 官方图标网格对齐工程（Icon Grid Fidelity）

- **定位**：把系统全部图标（任务栏、开始菜单、资源管理器、通知、设置、工具）按 Windows 11 官方图标网格与 keylines（20×20 主网格、圆角终止线、笔画粗细档位）逐一对齐，达到"并排放一起分不出哪个是系统的"。
- **动机**：当前 lucide-react 线性图标与系统 Fluent 图标混排时风格断裂，是"不像 Windows"的最大来源。
- **具体内容**：① 建立 16/20/24/32 四档尺寸的图标规格表；② 引入 Segoe Fluent Icons 字体（系统自带、零依赖、合法）作为系统图标首选来源，lucide 仅补充缺口；③ 每个图标记录"系统对应物"映射表（如回收站 = Segoe Fluent `\uE74D` 家族）；④ 图标文档 `docs/ICON-SPEC.md` 固化规格。
- **不做清单**：不重绘 Fluent 图标（侵权且无必要）；不引入第三方图标库；不改变现有图标的语义指代。
- **验收**：并排截图对比测试 30 个高频图标，keyline 偏差 ≤ 0.5px@1x；`rg` 全库无未经映射表登记的裸图标引用。

### Z-02 Fluent 控件规格复刻（Control Metrics）

- **定位**：按钮、输入框、下拉、复选、开关、列表项的尺寸、内边距、命中区域全部按 Fluent 2 设计规范复刻。
- **动机**：用户明确要求"界面按钮的尺寸……和 Windows 一模一样"。
- **具体内容**：① 命令栏按钮 32×32（hover 背景 4px 圆角）、对话框按钮最小宽 120px 高 32px、输入框高 32px；② 触控命中区最小 44×44（视觉尺寸可小，命中区不缩）；③ 分隔线 1px、菜单项高 36px、复选框 20×20；④ 全部落成 `tokens.css` 中的 `--ctl-*` 尺寸令牌，替换现有散落硬编码。
- **不做清单**：不改配色体系（那是令牌 2.0 的事）；不做圆角风格切换器；不增加新控件种类。
- **验收**：全局无裸 `width/height` 控件尺寸值（audit.cjs 增加检查项）；8 个代表性控件与 Win11 截图逐像素 diff ≤ 2px。

### Z-03 Segoe UI Variable 字体链（Typography Chain）

- **定位**：系统字体链按 Windows 11 原生方式组织：标题用 Display 档、正文用 Text 档、数字等宽对齐。
- **具体内容**：① font-family 链：`"Segoe UI Variable Text" → "Segoe UI" → "Microsoft YaHei UI" → system-ui`；② 标题/正文/代码三档光学尺寸（optical sizing）配置；③ 中文回退到雅黑时的字号补偿（雅黑视觉偏大，正文 -0.5px 校正）；④ 非 Windows 字体可用环境（测试机）的度量回退表。
- **不做清单**：不引入 Google Fonts 或任何网络字体；不做可换字体设置项（交给主题系统）。
- **验收**：中英混排基线一致；无 FOUT（字体闪烁）；2K 缩放下笔画锐利。

### Z-04 2K/4K 清晰度管线（Hi-DPI Clarity Pipeline）

- **定位**：用户明确要求"整体的清晰度达到 2K 以上"——在高 DPI 下做到文字锐利、图标不糊、线条不发虚。
- **具体内容**：① 全面核对 PerMonitorV2 DPI 感知（Tauri manifest + 前端 devicePixelRatio 联动）；② 125%/150% 缩放下的像素对齐策略（整数像素边框、半像素修正）；③ 图标与位图缓存按实际 DPR 生成多分辨率版本（1x/1.25x/1.5x/2x），禁止低分辨率位图上采样；④ 文字渲染参数对齐系统 ClearType 默认值；⑤ 4K 下 UI 密度适配（不放大位图、放大布局单位）。
- **不做清单**：不做自定义缩放滑杆（系统缩放已够用）；不引入子像素渲染 hack。
- **验收**：125%/150%/200% 三档缩放截图对比无虚边；treemap 式位图检查无上采样拉伸；w2-dpi-regression 回归通过。

### Z-05 焦点环与选择态规范（Focus & Selection States）

- **定位**：键盘焦点环（2px 外环）、hover/按下/选中/禁用四态的视觉层次完全对齐 Win11。
- **具体内容**：① 焦点环：2px、跟随主题色、仅键盘操作时显示（鼠标点击不显示，与系统一致）；② hover = 背景色升一档；按下 = 缩放 0.97 + 背景降一档；选中 = 主题色淡底 + 左侧 3px 指示条；禁用 = 40% 透明度；③ 全部状态落为 `:focus-visible` 令牌化样式，散落实现统一收编。
- **验收**：纯键盘走查全部主要面板，焦点环永不丢失、永不双重显示。

### Z-06 系统光标接管与对齐（Cursor Alignment）

- **定位**：应用内光标形态与系统语义逐项一致：busy、文本、链接、各方向 resize、move、禁止。
- **具体内容**：① 光标语义审计表（当前用 CSS cursor 枚举 × 系统对应）；② 修正所有语义错误的光标（如可拖动区域用 grab 而非 pointer）；③ 自定义光标方案功能保留但默认跟随系统；④ 光标变化必须带热点（hotspot）正确性检查。
- **验收**：走查全部交互区域，无一处"手型出现在不可点击处"或反之。

### Z-07 文案规范对齐（UI Copy Style Guide）

- **定位**：界面文案按 Microsoft 中文风格指南对齐：术语统一、句式简洁、标点规范、中英一致。
- **具体内容**：① 建立 UI 术语表（"确定/取消/应用/恢复默认"等 60+ 高频词条的规范译法）；② 省略号规范（表示截断用 …，表示待输入不用）；③ 按钮动词化（"删除"而非"删除操作"）；④ i18n 双语同步审校，杜绝机器翻译腔；⑤ 术语表落 `docs/UI-COPY.md`，audit.cjs 增加术语一致性抽查。
- **验收**：全库 UI 文案走查零术语漂移；zh/en 同键同义。

## 域 B：键盘纪律（Z-08…Z-14）

> 目标：用户明确要求"键位优化以确保不会键位冲突影响操作体验"。本域是全局地基层，**必须最先施工**。

### Z-08 全局键位注册表与冲突仲裁（Keymap Registry & Arbitration）

- **定位**：所有快捷键的**单一事实源**：一处注册、静态冲突检测、运行时仲裁、改键建议。
- **动机**：当前快捷键分散在各组件内注册，撞键只能在用户撞上时才发现。
- **具体内容**：① 新建 `src/lib/keymap/`：`registry.ts`（注册表）、`arbitrate.ts`（仲裁）、`types.ts`；② 每个 keybinding 声明：组合键、作用域、优先级、来源模块、描述（i18n）；③ 启动时静态扫描全部注册项，输出冲突报告（error 级阻止启动注册，warn 级记录）；④ 运行时按"作用域 + 优先级"裁决唯一赢家；⑤ `tools/keymap-audit.cjs` 离线审计脚本进 CI。
- **不做清单**：不做可视化改键编辑器 UI（那是 N-17 快捷键中心的地盘，本域只提供机制 API）。
- **验收**：全库 `rg "addEventListener\(\"keydown"` 的散落注册全部收编进注册表；审计脚本对现有键位报告零 error 冲突。

### Z-09 系统组合键让位协议（System Combo Yield Protocol）

- **定位**：Win+E / Win+R / Win+L / Win+D / Win+I / Win+V 等 40+ 系统组合键的「转译 / 透传 / 让位」三态规则。
- **具体内容**：① 枚举 40+ 系统组合键清单（含 Win+数字 任务栏固定、Win+Shift+S 截图、Win+Tab 任务视图）；② 每条声明策略：`translate`（Variable 接管并提供等价功能，如 Win+E → 自家 Explorer）、`passthrough`（直接放行给系统）、`yield`（检测到系统占用时让位）；③ 按应用豁免清单（如全屏游戏内全部让位）；④ 协议文档化，行为可预测、可关闭。
- **验收**：40+ 组合键逐条实测记录三态行为表；不存在任何"按下无响应"的组合。

### Z-10 三级作用域分层（Scope Layering）

- **定位**：快捷键分全局 / 窗口 / 上下文三级作用域；输入框聚焦时自动让位。
- **具体内容**：① 作用域栈模型：上下文（如列表、文本编辑）> 窗口 > 全局；② 输入元素聚焦时，除 Ctrl/Win 系修饰组合外的全部单键与 Alt 组合让位；③ 作用域进入/退出与组件生命周期绑定，杜绝"面板关了键还占着"；④ 提供 `useHotkey()` React hook 封装，新代码禁止裸监听。
- **验收**：所有面板的键位在其关闭后 100% 释放（注册表快照 diff 为空）。

### Z-11 全键盘导航网格（Full Keyboard Grid）

- **定位**：所有面板可脱离鼠标完整操作：Tab 序、方向键网格导航、Home/End/Page 快跳。
- **具体内容**：① roving tabindex 模式统一封装（`useGridNav()`）；② 方向键在网格容器内二维移动，Home/End 到行首尾，PageUp/Down 翻页；③ 焦点跟随滚动（scroll into view）；④ Enter/Space 激活、Esc 层层退出、菜单字母快跳（& 助记键）。
- **验收**：主要 12 个面板（开始菜单、设置、资源管理器、任务管理器、通知中心、计算器、日历、剪贴板、笔记、快面板、VWM 切换器、启动器）纯键盘全流程走查通过。

### Z-12 上下文键位速查浮层（Contextual Keymap Overlay）

- **定位**：按 Ctrl+/（或长按 F1）呼出当前界面可用快捷键清单浮层，可搜索筛选。
- **具体内容**：① 从注册表实时读取当前作用域的激活键位；② 浮层毛玻璃、不抢焦点、Esc 关闭；③ 支持键入过滤；④ 键位按来源分组显示。
- **验收**：浮层显示的每一条键位与实际行为一致（同源于注册表，无第二份维护）。

### Z-13 命令提示条（Command Hint Bar）

- **定位**：列表与面板底部固定一行静默提示当前可执行操作（"Enter 打开 · F2 重命名 · Del 删除"）。
- **具体内容**：① 可全局关闭的设置项（默认开，克制样式：次级文字色、28px 高）；② 提示内容从注册表派生，与 Z-12 同源；③ 仅在空间充裕（高度 > 600px 的容器）时显示。
- **验收**：不遮挡内容、不抢焦点、不闪烁（内容变化时淡切）。

### Z-14 键位方案管理（Keymap Profiles）

- **定位**：默认 / 紧凑（减少修饰键）/ 单手（右侧键区）三套预设 + JSON 导入导出 + 一键重置。
- **具体内容**：① 方案 = 注册表全量覆盖补丁的有序集合；② 导入时先过冲突检测（Z-08），冲突项列表化呈现由用户裁决；③ 方案切换即时生效、即时可撤销；④ JSON Schema 文档化供社区分享。
- **验收**：三套预设之间任意切换往返，注册表终态一致；导入恶意 JSON 不崩溃（schema 校验）。

## 域 C：兼容性防线（Z-15…Z-21）

> 目标：用户明确要求"兼容性"。什么机器、什么应用、什么输入法，都要稳。

### Z-15 应用适配等级库（App Compat Matrix）

- **定位**：Top 500 常见应用（游戏、办公、开发工具、国产软件）的适配等级库：A 完美 / B 轻微瑕疵 / C 已知问题 + 避让建议。
- **具体内容**：① 纯数据层（JSON），无任何执行逻辑；② 字段：进程名、窗口特征、等级、症状描述、建议（如"建议窗口化运行"）；③ 与既有 compat.hint（C-5）机制对接——库内 B/C 级自动生成登记库预警；④ 社区可提交 PR 更新，版本化；⑤ 设置内可查询本机已安装应用的适配等级。
- **不做清单**：不做自动修复（只提示不建议）；不采集上报（纯本地）。
- **验收**：库覆盖 Top 500；查询面板与 hint 徽标联动正确；JSON 有 schema 校验 CI。

### Z-16 遗留协议兼容 Shim（Legacy Protocol Shim）

- **定位**：旧版托盘图标协议（Shell_NotifyIcon 旧消息格式）、通知区域遗留消息、气球通知的兼容层。
- **具体内容**：① 托盘后端识别旧格式回调并转译为新事件；② 气球通知映射为原生通知中心条目；③ 旧协议的右键菜单坐标换算（多 DPI 下菜单弹出位置正确）；④ shim 层有独立开关与日志（诊断模式下可见命中次数）。
- **验收**：选取 10 款使用旧协议的老软件（如老版本压缩工具、输入法工具）实测托盘行为正常。

### Z-17 IME 深度兼容（IME Compatibility）

- **定位**：搜狗/微软拼音/QQ 拼音/小狼毫等主流输入法的深度兼容：组合键避让、候选窗跟随、组合窗口层级。
- **具体内容**：① 输入法会话激活时，单键快捷键全部让位（联动 Z-10）；② 候选框定位跟随光标（ime 位置报告）；③ 输入法悬浮窗不被判为普通窗口（VWM 过滤清单）；④ 输入法自身的快捷键（如搜狗 Ctrl+Shift）不冲突清单实测；⑤ 任务栏 IME 指示器（已有）与中/英状态同步正确。
- **验收**：4 款主流输入法各实测 30 分钟输入零冲突、零候选框错位。

### Z-18 全屏与独占模式协议（Fullscreen & Exclusive Protocol）

- **定位**：游戏与视频全屏、独占全屏（exclusive fullscreen）下的行为协议。
- **具体内容**：① 全屏检测（联动 embed.rs 既有全屏判定）；② 全屏时：覆盖层（HUD/通知横幅）自动抑制或降级为角标；③ Alt-Tab 行为对齐系统（VWM 切换器在全屏场景让位原生 Alt-Tab，可配置）；④ 独占模式刷新率切换握手（切换期间 Variable 静默不干预）；⑤ 全屏退出后窗口几何恢复。
- **验收**：3 款独占全屏游戏 + 3 款无边框全屏游戏实测无黑屏、无焦点错乱、无 Alt-Tab 异常。

### Z-19 多屏混合 DPI 兼容（Mixed-DPI Handling）

- **定位**：不同缩放比的多屏（主 150% + 副 100%）跨屏拖动窗口的 DPI 重适配。
- **具体内容**：① 跨屏拖动的几何换算（物理像素锚定，避免"拖过去变大/变小又回弹"）；② 窗口内容在目标屏 DPI 下的重渲染时序（先几何后内容，避免撕裂）；③ 每屏独立的位图缓存命名空间；④ 与 U-43 多显示器编排 2.0 的边界：本项只管 DPI 正确性，编排布局归 U-43。
- **验收**：混合 DPI 双屏拖动 20 次，窗口终态几何误差 ≤ 1px，无闪烁。

### Z-20 远程与虚拟宿主模式（Remote & VM Host Profile）

- **定位**：检测 RDP / VMware / Hyper-V / VirtualBox 会话，自动应用宿主配置档：降特效、禁位图缓存、简化动画。
- **具体内容**：① 检测信号：会话类型 API + 显卡特征 + 性能特征三源交叉；② 宿主档内容：动效 0.25×、壁纸静态化、透明度关闭（RDP 下亚克力开销大）；③ 检测结果与档位在设置中可见、可覆盖；④ 误检安全：检测不确定时按本机模式跑（宁可多耗不可变丑）。
- **验收**：RDP 与 Hyper-V 会话实测自动降级生效、手动覆盖可恢复正常观感。

### Z-21 慢速设备模式（Slow Device Mode）

- **定位**：HDD / 低内存（≤8GB）/ 低端核显设备的自动降级策略与手动开关。
- **具体内容**：① 信号：磁盘类型、可用内存水位、GPU 特征；② 降级阶梯（L0 全功能 → L1 关位图缓存与模糊 → L2 关动效与 WebGL 壁纸 → L3 纯色背景 + 最小动效）；③ 阶梯只降不升（避免抖动），重启或用户手动后重评估；④ 设置内透明呈现当前档位与依据。
- **验收**：HDD + 8GB 测试机上 L2 档桌面操作无可感知卡顿；升级硬件后重评正常升档。

### Z-25 放大镜与取色器（Magnifier & Color Picker）

### Z-27 系统信息面板（System Info Panel）

- **验收**：与系统工具读数逐项一致（CPU 型号、内存总量、GPU 名称）；复制摘要格式整洁。

### Z-28 运行对话框（Run Dialog）

- **定位**：规则化批量重命名：替换 / 序号 / 大小写 / 扩展名，预览 diff 后执行，可撤销。
- **具体内容**：① 规则系统：查找替换（支持正则开关）、序号（起值/步长/位数/位置）、大小写转换、扩展名统一；② 规则可组合成管线、可保存为预设；③ 预览：旧名 → 新名 diff 表，冲突（重名/非法字符/超长）逐行标红；④ 执行仅处理绿色行；⑤ 撤销：一次操作一个撤销点，改名日志持久化。
- **不做清单**：不做 EXIF/媒体元数据变量（后续生态扩展，非本轮）。

### Z-33 重复文件报告器（Duplicate Reporter）

- **定位**：只读扫描 + 报告导出，**绝不自动删除**。

- **验收**：构造 3 组重复（含同内容不同名、同名不同内容）扫描结果精确；1 万文件扫描内存平稳（流式哈希）。

### Z-34 空间分析器（Space Analyzer）

- **定位**：treemap 可视化磁盘占用，只读。
- **具体内容**：① 目录树 + treemap 双视图联动（hover 高亮、点击下钻、面包屑回退）；② 文件类型颜色图例（可折叠）；③ "前 N 大文件/文件夹"排行；④ 扫描进度与取消；⑤ 结果可保存快照对比两次扫描的增量（"最近 7 天涨了什么"）。
- **验收**：与资源管理器属性统计数值一致；百万级目录扫描不冻结 UI（worker 线程）。

### Z-35 发送到菜单（SendTo Extensions）

- **定位**：SendTo 扩展与自定义目标。
- **具体内容**：① 右键"发送到"子菜单：系统 SendTo 目录自动合并显示；② 自定义目标：任意文件夹（复制或移动两种动作）；③ 最近使用的 3 个目标置顶；④ 发送到"桌面快捷方式"（对齐系统行为）；⑤ 进度反馈（大文件复制走既有进度体系）。
- **验收**：与系统 SendTo 目录共存不覆盖；自定义目标增删即生效。

## 域 G：声音与通知基础（Z-43…Z-49）

### Z-43 逐应用音量记忆（Per-App Volume Memory）

- **定位**：每个应用的音量偏好持久化 + 会话恢复。
- **具体内容**：① Mixer（F-5 已有面板）的音量值与会话绑定持久化；② 应用再次发声时恢复上次音量；③ "记住此应用"每应用开关（默认记）；④ 与 Windows 系统逐应用音量共存（读取为主，不抢占系统 Mixer 权威）。
- **验收**：10 款应用启停往返音量偏好保持；系统 Mixer 中数值一致。

### Z-44 勿扰日程（DND Schedule）

- **定位**：定时勿扰 + 日历联动免打扰时段。
- **具体内容**：① 时段规则：每天 X 点到 Y 点自动勿扰；② 日历联动：日历事件进行中自动勿扰（可选，默认关）；③ 勿扰期间：通知静默入存档（联动 Z-47），闹钟类豁免（联动 Z-22）；④ 状态指示：任务栏勿扰图标（Z-01 图标体系）；⑤ 手动勿扰的优先级高于日程。
- **验收**：跨午夜时段（23:00–7:00）正确；勿扰期间通知零弹窗、全量入档。

### Z-45 系统声音方案（Sound Schemes）

- **定位**：开关机/通知/警告/快门等系统事件音的可替换方案包 + 预听。
- **具体内容**：① 方案 = 事件 → 音频文件的映射表 + 元信息；② 内置 3 套（默认/柔和/无声）；③ 每事件可预听、可单独替换、可恢复默认；④ 方案导入导出（.zip 或目录，含 manifest）；⑤ 与既有 sounds.ts 的 6 音源对接为"默认方案"。
- **验收**：方案切换即时生效；无效音频文件被校验拦截并回退默认。

### Z-46 音频设备快切（Audio Device Quick Switch）

- **定位**：托盘一键切换输入/输出设备 + 默认通信设备分离设置。
- **具体内容**：① 托盘菜单列出输出/输入设备（当前项打勾）；② 默认设备 vs 默认通信设备分别可设（对齐 Windows 区分）；③ 切换即时生效；④ 设备热插拔监听，列表实时更新；⑤ 无设备变化时零轮询开销（事件驱动）。
- **验收**：耳机/扬声器切换 < 300ms 生效；拔插设备列表同步正确。

### Z-47 通知存档与搜索（Notification Archive）

- **定位**：全部通知的可靠本地存档、全文搜索、按应用筛选。与 N-32（智能整理）边界：N-32 管"聪明的整理"，本项管"可靠的存档"——先把账本记全，智能才有的放矢。
- **具体内容**：① 存档：SQLite 表，保留策略（30 天/90 天/永久 + 容量上限）；② 搜索：标题+正文全文，按应用/时间筛选；③ 归档通知可重新展开操作按钮（历史通知的动作仍可执行，由发送方决定是否支持）；④ 存档清理只在保留策略到期时发生，且有明确告知。
- **验收**：1 万条通知搜索 < 100ms；保留策略三种模式实测正确。

### Z-48 麦克风使用指示（Mic Usage Indicator）

- **定位**：全局麦克风活动指示器。**仅指示，不拦截**（克制版）。
- **具体内容**：① 任务栏/托盘显示麦克风使用中图标 + 使用它的应用名 tooltip；② 事件驱动（会话回调），零轮询；③ 点击图标显示当前使用应用列表；④ 不做阻断功能（那是防火墙的地盘且易误伤）。
- **验收**：会议软件与浏览器语音各实测，指示即时准确；停止使用后图标消失 < 500ms。

### Z-49 提醒中心（Reminder Hub）

- **定位**：通知承载的轻量定时提醒 + 番茄钟基础。
- **具体内容**：① 提醒：文本 + 时间（相对"30 分钟后"/绝对"明天 9:00"）；② 重复提醒（每天/每周）；③ 番茄钟：25/5 标准预设 + 自定义时长，结束通知 + 可选声音；④ 提醒列表管理（完成/删除/改期）；⑤ 与勿扰联动（Z-44：提醒类豁免勿扰）。
- **验收**：后台精确触发（系统时钟锚定）；重启后未触发提醒不丢失。

## 域 H：开放性与拓展（Z-50…Z-56）

> 目标：用户明确要求"拓展性、开放性、比肩顶级作品"。方向：让用户与三方能**安全、低门槛**地接入，而不是再造一个大平台（插件市场/网关已有）。

### Z-50 主题令牌开放规范（Theme Token Spec）

- **定位**：第三方主题的 CSS 变量覆盖规范 + 主题校验器 + 完整规范文档。
- **具体内容**：① 规范：主题 = 一组符合 schema 的 token 覆盖文件（颜色/字体/圆角/动效参数），变量名即契约；② 校验器（`tools/theme-validate.cjs`）：语法、完备性（缺省回退 OK，非法值 NG）、对比度底线检查（正文对比度 ≥ 4.5:1，防"丑主题"伤观感）；③ 示例主题 2 套进 repo 供参考；④ 安装流程：校验通过 → 预览 → 应用；失败原因逐条呈现。
- **验收**：故意构造 8 种坏主题（缺变量/非法色/低对比）全部被拦截；2 套示例主题往返切换无闪白。

### Z-51 用户数据开放导出（User Data Export）

- **定位**：全部用户数据一键导出开放格式包：JSON/CSV + 媒体原件。
- **具体内容**：① 导出范围：设置、主题偏好、快捷键方案、通知存档、笔记、剪贴板历史（可选）、桌面布局；② 结构：`export-{date}/manifest.json + data/*.json + media/` 原始文件不转码；③ manifest 含版本与字段说明（自描述）；④ 导出进度与结果校验（文件数/大小核对）；⑤ 与诊断导出包（U-42）边界：U-42 是排障用诊断，本项是用户的"数据主权"导出。
- **验收**：导出 → 清空数据目录 → 手动恢复关键 JSON 后设置完整回来（恢复工具不在本轮，格式自描述即可）；大体积（1GB 媒体）导出进度正常。

### Z-52 本地事件流接口（Local Event Stream）

- **定位**：系统事件本地日志的流式只读接口，供用户自建消费（做统计、做自动化触发器）。
- **具体内容**：① 事件目录：应用启动/退出、窗口开/关、主题切换、勿扰开关、音量变更等 20+ 内部事件；② 接口：本地命名管道或 localhost WebSocket（**默认关闭**，用户显式开启）；③ 事件格式：JSON Lines，schema 文档化；④ 订阅可过滤事件类型；⑤ 无鉴权风险说明：仅本机回环、只读、无写操作。
- **验收**：订阅 20+ 事件全部正确推送；默认关闭状态下零监听端口（netstat 验证）。

### Z-53 本地只读状态 API（Read-only Status API）

- **定位**：localhost 只读端口暴露系统状态（CPU/内存/网络/音量/当前壁纸…），供用户自建仪表盘（浏览器全屏页就是仪表盘）。**默认关闭**。
- **具体内容**：① REST 风格只读端点：`/status` `/perf` `/audio` `/desktop`；② 数据源复用既有 Rust 命令层（不重复采集）；③ ETag/轮询节流；④ 示例：一个 `dashboard.html` 单文件示例（仅演示，非产品功能）；⑤ 安全：只绑定 127.0.0.1、只读、无命令端点、默认关。
- **验收**：默认关时端口不存在；开启后只读端点数据与面板一致；无任何写端点。

### Z-54 布局与配置分享格式（Config Share Format）

- **定位**：窗口布局 / 桌面配置 / 快捷键方案的 JSON 分享导入导出 + 冲突检查。
- **具体内容**：① 统一信封格式：`{ kind, version, payload, checksum }`；② 三种 kind 复用各功能已有导出（Z-14 / Z-40 / 主题），加统一信封与校验和；③ 导入：schema 校验 → 内容摘要预览（"将导入 12 个键位绑定，覆盖 3 个现有绑定"）→ 用户确认；④ 与 .vxs（U-39）边界：vxs 是资源包容器，本项是配置片段的轻量交换格式。
- **验收**：三种 kind 导入导出往返一致；坏 checksum 被拒并提示重新分享。

### Z-55 开放数据连接器（Data Connectors）

- **定位**：SQLite / JSON / CSV 文件只读连接器，把任意数据做成桌面只读数据卡（小组件的极简补充路线）。
- **具体内容**：① 连接器 = 文件路径 + 类型 + 只读声明；② 数据卡：简单表格 / 单值 + 迷你趋势线两种展示；③ 刷新策略：手动或定时（最短 10s）；④ SQL 连接器仅允许 SELECT（白名单解析校验，含写关键字的语句直接拒绝）；⑤ 失败静默降级（文件被锁/被删时卡片显示"数据不可用"）。
- **验收**：SELECT-only 校验拦截 20 种注入写法（UPDATE/INSERT/ATTACH/PRAGMA…）；文件锁场景不崩溃。

### Z-56 扩展兼容性承诺与版本矩阵（Ecosystem Compatibility Matrix）

- **定位**：对主题/脚本/配置三类三方资源的版本兼容承诺与弃用策略**文档化 + 自动检查**。
- **具体内容**：① 兼容矩阵文档：Variable 版本 × 资源声明版本 → 支持/警告/不支持；② 资源 manifest 必填 `minShellVersion`；③ 加载时自动比对并给出明确提示（"此主题为旧版设计，可能缺新控件样式，已回退默认"）；④ 弃用流程：提前 2 个版本警告 → 移除；⑤ 面向三方开发者的 CHANGELOG-PIPELINE.md。
- **验收**：构造新旧版本资源各 3 份，加载提示与矩阵文档一致；旧资源自动回退不崩溃。

## 域 I：工程质量与性能基础（Z-57…Z-63）

### Z-57 安全模式启动（Safe Boot Mode）

- **定位**：禁用全部第三方集成（主题/连接器/事件流/手势）的诊断启动一键入口。
- **具体内容**：① 入口：启动参数 `--safe-mode` + 启动菜单（启动失败自动建议下次安全模式）；② 安全模式下：默认主题、零加载项、角标明示"安全模式"；③ 用于诊断"是不是扩展搞坏的"；④ 退出安全模式重启恢复正常配置（不修改用户配置，只是跳过加载）。
- **验收**：构造一个坏主题导致启动失败 → 系统引导进安全模式 → 定位提示准确 → 重启恢复。

### Z-58 UI 线程健康面板（UI Thread Health Panel）

- **定位**：掉帧/长任务/内存的内部诊断面板（开发者与高级用户向，设置内"诊断"页）。
- **具体内容**：① 指标：FPS、长任务（>50ms）计数、React 提交耗时分布、WebView 内存；② 实时图表（最近 60s）；③ 异常事件标记（"14:32:05 出现 230ms 长任务，来源：桌面图标重排"）；④ 面板本身零开销原则（关闭时完全不采集，开启才挂 performance observer）。
- **验收**：开启面板前后 FPS 无可测量差异（±2 帧）；长任务归因准确率抽测。

### Z-59 空闲渲染冻结（Idle Render Freeze）

- **定位**：不可见窗口的渲染暂停与恢复，省电省内存。
- **具体内容**：① 检测：窗口最小化 / 被完全遮挡 / 虚拟桌面非当前 → 暂停其 rAF 循环与重渲染；② 恢复：显示时首帧 < 100ms（预渲染一帧再上屏，避免白屏）；③ 豁免清单：视频播放、下载进度、音频应用；④ 指标：整机 WebView 进程 CPU 空闲占用对比报告。
- **验收**：10 窗口最小化场景 CPU 占用下降 ≥ 60%；恢复无白屏无闪烁。

### Z-60 内存压力自适应（Memory Pressure Adaptation）

- **定位**：系统内存水位驱动的渐进降级（与 Z-21 慢速设备模式的区别：Z-21 管硬件档次的一次性定档，本项管运行中的动态水位）。
- **具体内容**：① 水位：可用内存 < 2GB（警告）/ < 1GB（紧张）/ < 500MB（危急）三档；② 动作：警告=清非可见缓存；紧张=冻结全部后台窗口渲染（联动 Z-59）；危急=提示用户关闭高占用应用（不代杀）；③ 水位恢复后不自动反向升级（避免抖动）；④ 与内存守护（U-20）边界：U-20 是常驻治理服务，本项是压力响应策略。
- **验收**：内存填充测试下三档动作按序触发、恢复平稳。

### Z-61 增量更新通道（Update Channels & Delta）

- **定位**：自更新器增强（F-6 已有自更新+回滚）：增量包 + 稳定/先行双通道。
- **具体内容**：① 双通道：稳定（默认）/ 先行（显式 opt-in，明示风险）；② 增量下载（版本间 diff 包，下载量目标 < 全量 30%）；③ 校验链：签名 + 哈希 + 回滚点保留最近 2 版；④ 更新时机：用户确认制，绝不自动重启。
- **验收**：双通道切换后获取正确版本；增量包完整性校验通过；回滚演练成功。

### Z-62 本地统计面板（Local Usage Stats）

- **定位**：使用数据的纯本地统计与"零外发"开关及声明。
- **具体内容**：① 统计：应用使用时长、窗口切换次数、快捷键使用频率 Top 20（从注册表埋点，联动 Z-08）；② 展示：周/月视图的简洁图表；③ "清除统计"一键；④ 零外发声明：网络守卫（netGuard）规则中明示统计无任何上传路径，技术报告佐证。
- **验收**：netstat/抓包验证统计功能无任何出站流量；清除后不可恢复。

### Z-63 回归基线扩展（Regression Baseline +）

- **定位**：DPI / 键盘导航 / UI 快照三类自动化回归测试基线，防"体验回退"。
- **具体内容**：① DPI 基线：三档缩放 15 个代表界面截图对比（阈值 0.5%）；② 键盘导航基线：12 面板纯键盘脚本化走查（自动按键序列 + 断言焦点落点）；③ UI 快照：视觉审计（visual-audit.cjs）纳入固定基线；④ 全部进 CI 的独立 stage（可跳过但显式标注）。
- **验收**：故意引入退化（改一个控件尺寸/删一个 tabindex）三类基线各自报警。

## 域 J：观感细节打磨（Z-64…Z-70）

> 最后一毫米：每项都是"不做好就总觉得哪里不对"的细节，且全部有克制开关。

### Z-64 CJK 排版精修（CJK Typography）

- **定位**：标点挤压、中西文间距、避头尾规则的统一排版层。
- **具体内容**：① 中西文之间自动 1/8 em 间距（CSS `text-autospace` 不可用时的 polyfill 层）；② 标点行首行尾禁则（避头尾）；③ 省略号、破折号在中文语境的显示宽度规范；④ 行高：中文正文 1.7（西文 1.5）的混排策略；⑤ 仅作用于 UI 文案层，不动四大内置应用的编辑器排版。
- **验收**：中英混排示例页（100 句）与手工排版标准比对通过；性能无退化（批量文本节点才处理）。

### Z-65 拖动清晰度策略（Drag Clarity）

- **定位**：窗口拖动/缩放过程中的临时降质渲染 → 稳定后满清恢复。**观感清晰度的隐形功臣**。
- **具体内容**：① 拖动中：关闭亚克力采样与阴影重算，位图缓存直接搬运；② 松手后：一帧内恢复全质量重绘（用户无感）；③ 与 N-06 动效编排边界：编排管编排逻辑，本项管渲染质量档位；④ 高性能机器可全程满清（自动判档，联动 Z-21）。
- **验收**：4K 屏 10 窗口连续拖动 FPS ≥ 55；松手后 1 帧恢复清晰（录制逐帧确认）。

### Z-66 图标加载零闪烁（Icon Zero-Flicker）

- **定位**：图标异步解码 + 占位骨架 + 多级缓存，列表滚动无跳变。
- **具体内容**：① 解码永远离主线程（worker）；② 占位：同 keyline 的中性灰剪影（而非空白），杜绝"先空后闪"；③ LRU 缓存按 DPI 命名空间（联动 Z-04/Z-19）；④ 列表滚动时复用已解码位图，禁止重复解码。
- **验收**：万图标列表快速滚动零闪烁零白块（录屏逐帧检查）；缓存命中率 > 95%。

### Z-67 滚动与动效一致性（Scroll & Motion Consistency）

- **定位**：全系统列表滚动惯性统一 + 全局动效速度滑杆（0.5×/1×/1.5×）。
- **具体内容**：① 滚动参数统一（减速曲线、过滚行为）落为令牌，散落实现收编；② 动效速度滑杆：乘以全部 `--dur-*` 令牌（reduce-motion 兼容：reduce 优先级更高）；③ 滑杆即时预览；④ 默认 1×（零改变，只是给了调节权）。
- **验收**：主要列表滚动走查手感一致；滑杆三档生效且 reduce-motion 组合正确。

### Z-68 主题切换零闪白（Theme Cross-Fade）

- **定位**：亮暗/主题切换时的交叉淡入与背景预置，杜绝闪白闪黑。
- **具体内容**：① 切换时先在离屏准备新主题的根样式快照；② 双层交叉淡入 170ms（复用动效令牌）；③ 壁纸层不参与淡入（避免大位图重采样开销）；④ 连续快速切换的防抖（最后一次为准）。
- **验收**：亮暗往返切换 20 次录屏逐帧无纯白/纯黑帧。

### Z-69 边缘热区自定义（Edge Hotspots）

- **定位**：屏幕边缘触发角/边可配置、可关闭，**默认仅启用开始菜单左下角一处**（最保守）。
- **具体内容**：① 热区类型：四角（单击/悬停可配）+ 顶边 + 左右边；② 默认动作映射：左下=开始菜单，其余=无（未配置的热区完全无行为）；③ 触发参数：悬停 300ms 防误触；④ 全屏应用内全部热区自动禁用（联动 Z-18）；⑤ 配置面板可视化（小屏示意图标上直接拖放设定）。
- **验收**：默认状态除左下角外全部边缘零响应；全屏游戏内零触发。

### Z-70 帮助中心（Help Center）

- **定位**：F1 上下文帮助 + 离线完整文档 + 搜索。用户"不弄巧成拙"的最后保障：让人随时查得清"这软件到底怎么用、还能怎么关"。
- **具体内容**：① F1 = 当前界面的上下文帮助（帮助主题与界面路由映射表）；② 离线文档：全部功能的说明、快捷键表（从注册表生成，单一事实源）、设置项解释；③ 全文搜索；④ "这是什么"模式（可选开关：点任意控件弹出其说明）；⑤ 文档与版本同发布，随包离线。
- **验收**：主要 15 个界面的 F1 命中正确主题；搜索响应 < 200ms；文档与实际功能零偏差（抽查）。

## 附 B：防弄巧成拙设计通则（每项都适用）

1. **默认最保守**：所有可选行为增强（手势、热区、透明度、滚轮行为）默认关闭或最小化。
2. **全屏豁免**：一切全局行为在全屏应用内自动退场。
3. **一键还原**：每项新功能必须能被完全关闭，且关闭后不留任何残余钩子。
4. **零键位抢占**：新键位一律经 Z-08 仲裁，宁可不绑也不冲突。
5. **性能预算**：任何新常驻逻辑的 CPU 开销 < 0.5%（安全模式下可全部卸载）。
6. **观感零退化**：不做任何"为了炫而存在"的视觉元素；动效只做功能性反馈。

## 附 C：依赖关系与优先级
