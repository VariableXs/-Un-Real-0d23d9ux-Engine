### 0.2 质量军规（内核版，每项功能必须全过）

1. **手感无损**：输入→像素全链路延迟不回退；动效弹簧曲线统一令牌。
2. **画质无损**：合成器禁止降采样；字体亚像素渲染；128px 图标管线平移。
3. **性能预算**：ISR 关中断窗口、调度延迟、内存水位全部有仪表且守红线。
4. **可回滚**：驱动/服务/策略独立开关与版本回滚；A/B 分区更新。
5. **降级纪律**：无 GPU→软合成、无 VT-x→纯引导并存、无网络→离线功能清单。
6. **崩溃红线**：任何驱动/服务 panic 不拖垮内核；用户态崩溃只回收进程。
7. **零重复**：立项前对照本清单 499 项 + 现有 Variable 功能查重。
8. **完成即自检**：手感/画质/性能/回滚/崩溃五项自检，不写报告，只留可复现验收。

### 0.3 工程纪律

- 内核代码全部在 `kernel/` 独立 Cargo workspace（`x86_64-unknown-none` target）；不碰 `src/`、`src-tauri/`。
- 共享 MD 编辑前先 `git log` 验 HEAD（并行会话防覆盖）。
- 完成一项：更新分工图 → commit（`varix500(ai-XX): Fxxx <功能名>`）→ 推送 GitHub。
- 全程只维护本组 3 个 MD，不新增报告类文档。

## 三、风险与红线

1. **QEMU 先行**：W3 之前不碰真机；U 盘部署器落地前主机盘零接触。
2. **数据安全**：部署/安装全程先只读演练；快照脚本 + 修复介质是硬前置。
3. **介质**：1TB U 盘必须 NVMe SSD + 硬盘盒（~1000MB/s），禁 U 盘主控。
4. **手感画质红线**：内核态动效/渲染实现必须过帧预算与延迟仪表。
5. **并行纪律**：共享文件先验 HEAD；备份快照在最后一次编辑之后拍。
6. **野心管理**：AI-14（虚拟化）允许在无 VT-x 机器上整体降级，不阻塞其余 475 项。
