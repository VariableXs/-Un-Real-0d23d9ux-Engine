# 真机验收清单（步骤 0022）

> 目标：QEMU 之外的 4 类真机 smoke + 完整验收。每类烧录 `varix.iso` 到 USB（Rufus/Ventoy，DD 模式）。

## 1. Intel 12/13 代（新平台，UEFI）
- BIOS 设置：Secure Boot 关；CSM 关；SATA=AHCI； Above 4G Decoding 开。
- 待验项：GOP 分辨率枚举（4K 面板）、x2APIC、HPET/TSC 时钟源、NVMe 探测、USB 键盘中断。

## 2. AMD 7000 系（新平台，UEFI）
- BIOS 设置：Secure Boot 关；fTPM 不影响启动即可；Resizable BAR 开。
- 待验项：多输出 EDID（DP+HDMI）、APIC 定时器频率校准、SMBIOS 解析、核显帧缓冲对齐。

## 3. 老 H81（legacy，BIOS/CSM）
- BIOS 设置：CSM 开；启动模式 Legacy；Fast Boot 关。
- 待验项：Limine BIOS 路径启动、VGA 80x25 fallback、PS/2 键盘、串口 0x3F8 输出、AHCI 硬盘。

## 4. 笔记本（混合显卡 + 内建屏）
- BIOS 设置：Secure Boot 关；独显直连关（先用核显）。
- 待验项：内建屏 EDID/DPI、亮度调节、电池/ACPI 事件不致 panic、合盖唤醒、触控板 PS2。

## 通用 smoke 口径
1. 烧 USB → 启动 → 串口输出与 `fixtures/qemu-smoke.golden` 一致（步骤 0024 验收线）。
2. 停留在内核自检横幅无三重故障；`cpu_reset` 计数为 0。
3. 每台机器记录：型号/BIOS 版本/启动模式/串口日志截图。
