## 一、总纲：五指标与红线

| 指标 | 内核接线点 | 口径 |
|---|---|---|
| syscall 延迟 | 系统调用面（C2 域语义） | P50/P95/P99，样本 ≥30 |
| 启动时长 | Limine→varix→ushell→桌面 引导链 | 冷启动全链分段落账 |
| 内存 | 内存管理成熟体（A4 域） | 峰值/驻留/碎片三账 |
| IO | 块层 + VFS（B4/B1 域） | 顺序/随机 4K/QD 分档 |
| 帧率 | vxwm 合成器（F1 域） | 均值 + 1% low ≥ 均值 70% |

**三条铁律（执法项，对应 GOV-88-J1/J2）**：
1. 每行对照必有 Windows 侧同机数据（同一基准机、双系统同盘位）；缺侧即标 N/A，附缺侧原因 + 补测计划——编造侧数据 = 红线级虚报。
2. 样本量 ≥30、P95/P99 全落账；禁选择性取样，样本序列全留档可抽验。
3. 对照行必须带 env_hash（环境指纹）；非同 env_hash 的行禁入账。
