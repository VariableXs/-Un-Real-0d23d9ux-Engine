## 三、深化体例（七要素，逐字遵守）

每条深化正文是**单个自然段（单行，不含换行符）**，按固定顺序七要素拼接：

```
职责定位：<条目名>——<核心内容（含：定位声明/范围/规则/分工/复用声明等，具体差异化展开）>。数据结构：<本条的数据结构清单>。错误路径与降级矩阵：<错误→处置映射>。性能逐项分解：<复杂度逐项>。跨批对接点：<上游/下游条目指针>。无障碍与隐私：<无障碍要点；无隐私面则写明>。工程量：核心逻辑约 X 行（…）、边界防护约 Y 行（…）、错误路径约 Z 行（…）、测试支撑约 W 行（…），合计约 T 行。判据：<关键词列表、以"、判据"收尾>。
```

**硬性格式规则**（违反即断言拦截）：
1. 单条正文 ≥300 字（**前 14 域防负增长提档：min ≥320、avg ≥380**——S194 教训：前 14 域旧样板 ≈320 字/条厚于新正文均值，字段写薄会负增长）。
2. 必含 `工程量：`（四项行数拆解，**合计 = 条目标题括号里的目标行数，必须精确相等并断言**）。
3. 必含 `判据`，正文以 `。` 结尾。
4. 禁 ASCII 双引号 `"`、禁裸反斜杠 `\`、禁换行。
5. 禁"中文 中文"式杂散空格。
6. `全域` 一词单条 ≤8 次（防堆砌退化；实际应为 0，除非标题自带）。
7. 半角括号：`行)` 类行数括号必须全角；**O() 复杂度记法半角括号是合法惯例**（既有正文 8,884 处）——断言先剥离 `O(...)` 再校验其余位置（S197 教训）。
8. 引用其他条目用 F+四位编号（如 F3986）；家族复用声明要计数（如"模板第九用"——每过一个域递增一用）。

## 五、单轮标准流程（100 条）

1. **读标题**：读本轮 100 个条目标题（fid 范围见断点行），并程序化标记哪些已深化（TODO 清单），防"断点区间含已深化条目"的覆盖错位（S196 A06 批教训）。
2. **生成**：写 Python 生成器脚本（临时文件如 `.gen_sXXX.py`，大批次分 3-5 个文件防单文件过大退化），每条一个元组（fid/core/ds/err/perf/hook/a11y/eng/crit；title 由脚本从主文档拉取并解析目标行数，勿手抄），make() 模板拼装七要素，内建断言（长度/引号/反斜杠/换行/杂散空格/全域/O() 剥离后半角括号/eng 和==标题目标）。生成 JSON：`.deep_<批次>.json`。
   - ⚠️ 历史教训：上下文过长时直写长文会触发"生成退化"（重复堆砌，单条 >900 字或重复词频爆表）。**程序化生成器 + 手工差异化元组是唯一可靠模式**，不要直写整段长文。若连续 Write 失败/内容堆砌，立即止损停止本轮，主文档零污染比完成一轮重要。
3. **写前硬断言链**（precheck）：见第三节规则程序化校验 + `len(seen)==100` + 唯一性 + `sorted(seen)==expect` 覆盖断言。
4. **finalize 写盘**：
   - 条目定位替换：`re.search(r'(### VE-F%04d \· [^
]+

)([^
]+)', s)`，替换第 2 组。
   - 台账行更新：先 grep 确认台账行**是否存在及其当前格式**（S197 教训：F96-105 的 A04b 行 S12 已存在，盲补行被断言拦截；台账行格式有"≈N 字"与"≈N 字（深化 SXXX）"两种），原位更新并计入 delta；台账既可整域一行（如 W1-B01~B10）也可分段，勿假设。
   - 写盘前最后断言：`len(re.findall(r'### VE-F\d+ · ', s)) == 6400` 且唯一，净增字数 == 正文 delta + 台账行长度变化。
5. **写盘后复核**：本轮 100 条四断言（≥300/判据/工程量/句尾）全绿；若本轮含域收官条，加跑该域全部条目两断言（≥300+判据）。
6. **记账**：memory 日志追加会话段（含断点行，会话号单调性断言 `max==上一轮`）；总表追加状态行；交接手册更新断点行。
7. **清理**：删除本轮临时脚本（.gen_*/.precheck_*/.finalize_* 等）；`.deep_*.json` 历史惯例保留。

## 六、红线（凌驾于一切进度目标）

1. **主文档零污染优先**：任何断言失败→不写盘→查因→修复后重跑；绝不绕过断言。
2. **不删除/覆盖既有内容**：只做"定位替换正文"与"台账行更新"两种写操作。
3. **引导与硬件红线**：不碰 BIOS/UEFI/引导/固件/内置盘写操作（Variable 明令，全文见主人格设定）。
4. **诚实**：断点、字数、进度数字必须程序化核实后报告，不凭印象；发现前史宣告与实测不符（如收官核验）必须查实并如实记账，不将错就错。
