## 4. 缺陷账本（施工中发现并修复——全记录在 `_attic/aiv1-f111-f130/`）

真缺陷 3 / 设计推演错 4 / 测试基准错 5 / 机械错 5，共 17 项，要点：

- **F114 设计级**：初版「校正=模拟矩阵之逆」数学不成立——Machado severity 1.0 模拟矩阵为奇异阵（二色视觉本质降维），数值逆为垃圾（灰→(0,224,121)）。重构为 daltonize 误差重分配范式（混淆轴误差→保留轴），灰轴零干预改由构造保证，tritan 增益按分离度 ≥+50% 判据标定（实测 2.2-3.7×）。
- **F113 判据级**：初版色板两处不达 7:1（#808080 边框 5.3:1、#FF6060 危险色 6.9:1）——换 #C8C8C8（12.5:1）/ #FF7070（7.6:1），修正记录在案。
- **vbase 算法级**：黑对灰(#777) 对比度误记 4.48（那是灰对白底官方示例值），实测 4.69——对拍基准修正。
- **F119 解析级**：标题层级误用整串字节长度（`# 标题`→level 6）；`[[设置:` 中文标记按 7 字符切片劈进 UTF-8 字节（实为 8 字节）——两处均修。
- **F125 门禁级**：锚点可测性启发式过严（9 条无数字但有取证动词的合法判据误杀）——修正为动作词∧(数字∨取证动词)。
- 其余为测试基准错位与机械笔误，逐条见账本。
