## 4. 全员必须遵守的六条宪法（摘自主册，违者判据即红）

1. **卷首·丁三通则**：一切功能可自调（参数清单强制）+ 排布舒适（乙基线/F302）+ 双入口可达（分类页 + F301 搜索）。
2. **收工五勾**：分类页可达 ✓ / 搜索可达 ✓ / 就地可调或跳转 ✓ / 说明句 ✓ / 导航路径链 ≤4 段走达 ✓——每项功能收工逐勾打，缺一不算完。
3. **控件唯一实现**：10 类控件只认 AI-01 的控件库，任何页内自绘控件 = 缺陷回炉。
4. **4K 硬标准**：全矢量绘制 + 位图 4× 源 + 四档 DPI（1:1/125%/150%/200%）逐档走查，一处模糊整卡回炉。
5. **一处一事实**：路径链/落位/同义词只在登记表记一次，正文引用登记表，禁止三处各写各的。
6. **搜不到 = 不存在**：任一功能名在 F301 搜索结果为 0 = P1 缺陷，总检一票否决。

## 5. 每名 AI 的交付物定义（DoD）

每名 AI 收工时必须交齐六件：

1. **代码**：主责 F 项全部落码，纯功能代码行数落在预算区间内（低于下限 = 漏项，高于上限 = 过度设计，都要书面说明）。
2. **判据证据**：每项 F 的【验收判据】实测数据三件套（数据 + 复现命令 + 日期）。
3. **五勾台账**：600 项里自己主责项的逐项五勾记录（写入《剩余任务推进总表》自己的行）。
4. **自检报告**：按《执行清单》§SOP 走完七步自检，零红项或红项处置记录在册。
5. **登记表条目**：落位（A/B/C）+ 路径链 + 同义词，三列齐。
6. **同步凭证**：代码与文档提交进仓库、push 成功的 commit hash 清单。
