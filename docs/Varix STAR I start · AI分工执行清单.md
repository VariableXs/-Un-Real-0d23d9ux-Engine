## AI-01 设计令牌与控件库（一波 · 可立即开工）

**使命**：把 C-3·补③-5 两张控件总表 + F151 令牌落成全系统唯一控件库。你是最上游，六名后来者都在等你的第一里程碑。

**任务序**：
1. 令牌总线收口：色彩/字号/间距/圆角/动效曲线（F124 三档）全部走 F151 令牌，禁止散落魔法数（对照 MD2 附录 K 旋钮清单）。
2. 逐类实现 10 类控件（两版总表取并集，几何冲突时以「形制与质感总表」为准）：导航行卡 72px / 开关胶囊 40×20 / 滑杆轨 4px 球 16-20px / 展开行 48px 手风琴 / 选择卡 96×72 / 强调按钮 32px（每页至多一枚语义内置）/ 次级按钮 / 链接行 32px / 分组标题 / 状态徽标 20px（绿黄红 15% 透明底）。
3. 每类控件五态齐备：静态/悬停/按下/禁用/焦点环（F206 同形制），过渡曲线全部挂 F124 档位。
4. 4K 管线对齐（F068）：全矢量、1px 描边按 DPI 换算、位图资产 4× 源。
5. 键盘语义全量：F206 焦点环、F435 下拉键盘、F217 三通路（按钮/滚轮/拖拽）。
6. 发布控件库 v1：对外只暴露组件 API + 用法文档（一页/控件：几何、状态、禁则、代码示例）。

**自检重点**：四档 DPI × 12 控件类型 = 48 张放大截图全绿（③-5 硬标准原文）。
**交棒物**：控件库 v1（二波六名 AI 的开工前置）。

## AI-02 设置中心外壳（一波）

**使命**：③-1 全屏外壳规格表逐行落码 + ③-2 十二分类可导航。

**任务序**：
1. 全屏外壳（默认全屏/窗口最小 920×640）；左侧分类栏 300px、行高 40px、图标 16px、当前分类强调色左条 3px、可折叠 64px 图标列。
2. 顶部搜索框 40px 高 / 480px 宽居中，占位「查找设置」，F301 直达就地操作。
3. 面包屑 32px（点击回退 F090 同源、Backspace 上层）+ 分组标题滚动吸顶 40px（③-8 逐级可见）。
4. 内容行卡 72px（图标 20 + 标题 14 + 副标题 12 + 右箭头，圆角 8、悬停亮 4%、8px 档间距）；首页设备卡 96px 横贯（F479/F199 + 更新 F122/备份 F396 快捷卡）。
5. 分类页头大标题 28px + 图标 32px；网络类页头附实时状态区（对齐截图：已连接/流量）。
6. 十二分类骨架逐页搭出（主页/系统/蓝牙和其他设备/网络和 Internet/个性化/应用/账户/时间和语言/游戏/辅助功能/隐私和安全性/更新），每页按 ③-2 表挂 F 锚点占位行。
7. 「个性化」分类与 E 域 E1-E8 的执行面对齐（③-4 条款）。

**自检重点**：③-1 规格表 7 行逐行实测；十二分类点击遍历无死页。
**交棒物**：可导航外壳 v1（AI-04 登记落位的前置、AI-11 的消费面对象）。

## AI-04 全功能索引与搜索（一波）

**使命**：③-5 三落位登记表 + ③-8 路径链登记表 + F301 搜索面，覆盖全部 600 项。

**任务序**：
1. 建两张登记表（落位表/路径链表），三列结构照 ③-5/③-8 原文，落 `docs/` 或仓库数据文件（一处一事实）。
2. 600 项逐项登记：A 直调 / B 跳转（写明现场）/ C 免调节（写一句理由；认知相关的给「查看当前状态」入口）。
3. 每项路径链 ≤4 段登记；超 4 段的回报 AI-02 重排层级（这是唯一合法的层级变更通道）。
4. F301 搜索实现：功能名 + 同义词 + 按控件类型检索（搜「滑杆」列出全部滑杆项）；结果第二行灰字 12px 路径链；C 落位项搜「回收站」式示例照 ③-5 给「功能在：X ｜ 相关设置：Y」。
5. 主页「最近用过」前 12 卡（副标题即路径链）。
6. 与 AI-12 联合定义总检脚本：任一功能名搜索为 0 即红（自动化，不靠人眼）。

**自检重点**：600/600 登记行数断言；抽查 40 项按链逐步点击 100% 走达。
**交棒物**：两张登记表 + 搜索 v1 + 总检脚本。

## 附：人人适用的三条作业纪律

1. **小步提交**：一个任务包一提交一 push，提交信息写明 F 项号；网络失败本地排队，恢复后按序补推（历史教训：GitHub 间歇超时，本地提交永不丢）。
2. **不动别人的泳道**：发现越界问题（如别的域判据疑似错）记总表「跨泳道问题栏」通知对方，禁止直接改。
3. **判据争议找主册**：任何「我觉得应该」都输给主册原文；主册本身有疑义走 Variable 裁决，不许泳道内自行解释。
