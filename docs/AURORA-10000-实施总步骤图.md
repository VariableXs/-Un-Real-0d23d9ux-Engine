## 12. 归属职责矩阵（哪些功能属于谁）

**职责边界原则**
1. **内核（kernel/varix）只提供原语**：系统调用、VFS、调度、驱动、时间、加密原语、内核事件总线。内核不做任何 UI 决策。
2. **Variable 桌面（src/ + src-tauri/）负责一切用户可见的界面与交互**：窗口、任务栏、开始菜单、设置、应用、通知、微件。
3. **代码分析（code-analysis/）是独立工具链**：core（自研 IR/解析/语义分析）、app（Tauri 壳）、ui（界面）。它同时以「Variable Code」应用形态宿主进 Variable 桌面。
4. **跨层功能必须声明主责方**：凡「桌面+内核」族，桌面为主责（交互与呈现），内核为协作（原语与事件）；凡「全部三方」，AI-76~AI-80 的工程门禁为主责，三方各自落实。

## 13. Windows 11 风格设计需求与方案（Variable 独立界面）

**适用对象**：设置中心、开始菜单、通知中心、快捷面板、软件管理、任务栏全部浮层，以及 Write/Mind/Fate/Code 四应用的设置页与独立窗口。

### 13.1 视觉规范（对齐 Win11 设置的观感，见参考截图二）
1. **导航栏**：左侧固定 320px（窄窗 260px）；条目 = 24px 图标 + 14px 文字，行高 40px，圆角 4px；选中态 = 左缘 3px 强调色竖条 + 中性色浅底（hover 8% 白/黑叠加）。
2. **内容区**：最大宽 1000px 居中；页面标题 28px semibold；卡片列表行 = 圆角 8px 卡片、左 32px 图标位、主标题 14px + 副标题 12px 二级色、右缘 chevron；卡片间距 4px、区块间距 12px；行高 ≥48px、整行可点。
3. **底色与材质**：Mica 底（桌面 wallpaper 取色 + 降饱和），浮层用亚克力 60%；三主题（dark 默认/light/high-contrast）全部出图。
4. **控件**：Fluent 开关（44×20，选中 accent 填充）、分段选择器（用于 视图/排序 切换）、下拉用(expander) 展开式而非弹窗；滑杆带数值气泡。
5. **顶部**：返回箭头 + 面包屑；搜索框居中置顶、宽 ≤600px、占位符「查找设置」；窗口控制沿用系统三键。
6. **令牌映射**：全部走 `src/design/tokens.css`——accent/背景层/圆角（corner-2=4px、corner-3=8px）/海拔（elevation-2 卡片）/动效（dur-2=150ms 悬停、dur-3=200ms 页面切换）；禁止硬编码（审计进 CI）。

### 13.2 交互规范
1. 返回 = Alt+← 与面包屑一致；行内展开用 Expander（点击整行切换）；危险操作行尾置「…」溢出菜单。
2. 键盘：Tab 线性遍历、↑↓ 在列表内循环、Enter 触发行、Esc 收起展开/关浮层；焦点环 2px accent，永不隐藏。
3. 触屏目标 ≥44px；悬停与触摸反馈统一 150ms。
4. 搜索即所得：输入即时过滤导航与内容区，命中词高亮；无结果给空态插画 + 建议。

### 13.3 落地范围与验收
- **改造清单**：族0363 设置体验（重组 IA 为 Win11 卡片式）、族0081 开始菜单结构（导航栏同规范）、族0090 快捷面板（卡片化）、族0088 通知中心、族0069 内容风格（全桌面 tokens 对齐）、族0351 组件库（Switch/Expander/分段选择器按本规范实现）。

## 14. 代码分析界面 VS Code 风格重设计方案

**现状**：`code-analysis/ui` 为原生 JS（index.html + js/ + styles.css），与桌面视觉各自独立；功能可用但布局松散。
**目标**：重排为 VS Code 工作台布局（见参考截图一），保持自研引擎与原生 JS 技术栈不变，仅重做外壳与交互层。

### 14.1 布局规格
1. **活动栏（48px，最左）**：竖排图标按钮（资源管理器 / 全局搜索 / IR 图 / 依赖图 / 诊断问题 / 分析报告 / 插件 / 设置），24px 图标、选中态左缘 2px accent 竖条；底部放账号与设置齿轮。
2. **侧边栏（240px，可折叠 Ctrl+B）**：随活动栏切换内容——文件树（资源管理器）、搜索（含替换框 Aa/ab/.* 三开关，对齐截图一）、IR 大纲、诊断列表。
3. **编辑器组（中央）**：多标签页（可拖拽重排/固定/关闭）、标签下面包屑（路径逐级）、代码区用自研高亮引擎 + 行号槽 + 缩进参考线 + minimap（右侧 60px 可关）；空态显示引擎 Logo + 三个快捷键提示（打开聊天占位/显示所有命令 Ctrl+Shift+P/开始分析 F5），对齐 VS Code 欢迎页气质。

## 15. 实用性守卫（10000 项自检结论）

**自检方法**：按「实用性 / 手感影响 / 质量风险 / 视觉损毁 / 弄巧成拙 / 极端性 / 三方兼容」七维逐族复审；结论与修订如下。
1. **生理感知类默认关**：坐姿（F01605）、肩窥（F05991）等摄像头类功能一律默认关闭、纯本地推理、首次显式授权；无硬件时隐藏入口（眼动 F00534 同规则）。
2. **全局热键接管类默认关**：修饰交换（F02309）、连击（F02983）、长按（F02984）、Layer（F02981）等改变既有肌肉记忆的功能默认关闭，首次开启时展示影响清单并提供一键还原。
3. **系统级操作需授权**：端口计划禁用（F05977）、锁盘、粉碎等需管理员确认并保留白名单放行。
4. **彩蛋与氛围低频化**：所有彩蛋（族0024/0285/0299 等）随机率低频 + 总控开关（F00600/F07123 已有），不影响主流程手感。
5. **兼容性免责声明**：兼容域全部「让位优先」——检测到冲突先让位再提示，绝不强制接管（族0202/0204 红线）。
6. **预留位验收口径**：凡「位/预留」条目（约 180 项），交付标准 = 接口冻结 + 文档 + 开关存在，不得虚标完成。
7. **手感保护**：任何新交互不得增加高频路径步数（动线基线见族0373）；动效一律令牌化，掉帧超预算自动降级（族0035）。

**修订记录（本轮已直接改入全景图）**：F00534、F01605、F02309、F02981、F02983、F02984、F05977、F05991 共 8 条追加守卫标注；无删除项——10000 项全部保留并按守卫约束实施。
