## 二、按人格纪律交付的三个要点

**1. 判据载体优先，行数不注水。** 本批纯功能 6,154 行 / 上限口径 17,485 行
= 35.2%（K9 口径修正后），与 K2（同口径约 60%）、D1 批次同口径如实登记。
每模块的 CheckSet
把主册判线逐条钉死（425 条），模型面可复现；回炉路径明确——各模块的
渲染/窗口/资产/平台桥接面属真机 UI 接线批（F094 demux 流、F098 截屏桥、
F110 键位渲染等），已在账本中逐项列明。

**2. 冻结候删按令执行。** F101 天气件、F104 录音件在主册 F200 存量冻结候删
名单内（Variable 已拍板「冻结不删除、编号不复用、不再投入工时」）——本批
**未实现、未投入工时**，只在域聚合器登记结构面守护（实现模块清单与冻结
名单互斥断言）。**正式删除待 Variable 逐项确认**后走冻结流程。

**3. 十六处真缺陷全部测试拦截后修复，无一静默。** 最有价值的三处：
256 位乘法的 OR/进位混淆（D1）、div256 位序交错（D2）——计算器引擎的
数值正确性地基；from_f64 复用 round64 的 i64 中转饱和（D3）——揭示了
galaxy::math 的设计域边界（其 doc 注释已声明「输入量级有限」，本次按
纪律在本模块就地实现大数域舍入，未改动共享底盘）。全账见
`_attic/aid2-f093-f110/行数对账与缺陷账本.md` 第三节。
