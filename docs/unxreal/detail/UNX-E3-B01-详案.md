### UNX-F17601 · inet_handle_tree 与四类超时继承

【功能定位】inet_handle_tree 是 Varix 网络面的骨架数据结构，承担会话—连接—请求三级对象的归属登记、遍历与回收职责，是 WinInet 兼容层的地基。四类超时（连接/发送/接收/解析）沿树继承，父节点设值后子节点默认跟随，子节点可单独覆写。
【行为细节】树节点带类型标签与四槽超时槽位；创建子节点时从父节点拷贝当前生效值而非引用，此后父改不影响已建子，保证语义可预期。遍历接口提供先序/按类型两种，供诊断转储与泄漏看门狗复用，不另造第二套遍历逻辑。
【边界与错误路径】树上不允许出现无父的悬空请求节点：父被强制回收时子节点随账面一起标记废弃并触发回调，绝不静默吞掉。空树遍历、单节点树、深度越界（>8 级即拒绝建子）三条路径均有显式错误码返回。
【验收落实】20 步可运行剧本覆盖建会话→连接→请求→全序关闭；四类超时继承矩阵 20 格逐格断言；泄漏看门狗在剧本结束节点位为零。判据号 UNX-F17601-J1，收编 run-tests fast 分片。

### UNX-F17602 · InternetOpen 根会话对象与 agent/访问类型语义

【功能定位】InternetOpen 是进程内第一个网络对象：根会话。它固化 agent 字符串与访问类型（决定后续是否走代理），是全局配置进入请求路径的第一站。
【行为细节】agent 允许应用自定义并拼入默认后缀（Varix 网络栈标识），保证服务端日志可区分来源；访问类型在会话创建时锁定快照，后续全局代理变更不影响已建会话，避免"半程换轨"的模糊行为。同一进程允许多根并存，各自独立记账。
【边界与错误路径】agent 传空回退默认串并写警告日志（异常零静默）；访问类型传非法值直接拒绝创建并返回 E 型错误码，不做静默纠偏。代理串格式非法在会话创建期即暴露，而非拖到首个请求。
【验收落实】15 剧本覆盖创建/选项/关闭三段生命周期；agent 拼装结果逐字比对；非法参数 10 变体全拒；回调时序断言创建→回调→可用顺序恒定。判据号 UNX-F17602-J1。

### UNX-F17603 · INTERNET_OPEN_TYPE 三模式语义

【功能定位】三模式（直连 PRECONFIG 直接读全局配置、PRECONFIG_WITH_NO_AUTOPROXY 禁自动代理脚本、显式代理串）决定请求出口策略，语义必须与 WinInet 逐项对齐。
【行为细节】直连模式下完全绕过代理账本；预置模式读取全局配置快照并在会话内缓存；显式代理串支持多协议前缀与分号分隔 bypass 清单。三模式的选择结果在诊断转储中可见，用户能回答"这个请求为什么这么走"。
【边界与错误路径】PRECONFIG 在无全局配置环境回退直连并记 info 日志；bypass 清单含通配符匹配逐条单测；模式间互斥，传组合位按最高优先级裁决并记警告。
【验收落实】三模式 × 直连/代理/bypass 三面 9 格矩阵全绿；快照隔离断言（改全局后旧会话行为不变）；异常路径 8 变体。判据号 UNX-F17603-J1。

### UNX-F17604 · 句柄节点引用计数与父子生命周期账

【功能定位】引用计数是句柄树安全回收的机制底座：外部持有的 HINTERNET 加引用，内部父子边加归属计数，两条账分立，混账即缺陷。
【行为细节】外部 Acquire/Release 严格成对，Release 到零不等于回收——还需父边解除；归属计数由树管理，应用侧不可触碰。计数变更全部走体验日志（谁、何时、为何），时间轴可回放，出问题不必猜。
【边界与错误路径】重复 Release 检出即记账缺陷并自愈（钳位到零），同时升级为 🟡 缺陷登记；循环父子边在建立时即拒绝；跨线程 Release 有内存序保障，压力注入 10^5 次不撕账。
【验收落实】并发 Acquire/Release 竞争剧本 ×10^5 全序断言；双账分立对账器逐批核对；泄漏看门狗联动。判据号 UNX-F17604-J1。

### UNX-F17605 · InternetCloseHandle 递归关闭与延迟完成语义

【功能定位】CloseHandle 语义不是立即销毁，而是发起递归关闭流程：先关子后关父，异步回调完成才算数，这是 WinInet 兼容的关键语义点。
【行为细节】关闭请求进入队列后，节点进入"closing"中间态，拒绝新操作但保留可查询性；异步 IO 在途时等回调落地再回收；关闭完成顺序严格子先父后，回调顺序可断言。
【边界与错误路径】对同一句柄并发 Close 多次只生效一次，其余返回已关闭语义错误；关闭中再 Acquire 被拒；进程退出路径强制清扫所有 closing 节点并给警告日志，不留僵尸。
【验收落实】递归关闭 15 剧本 + 延迟完成注入 10^3 次全序断言；回调顺序账逐条复核。判据号 UNX-F17605-J1。

### UNX-F17606 · 子句柄存活期父句柄关闭拒止与排队口径

【功能定位】父句柄在仍有存活子句柄时的 Close 语义：不失败也不立即完成，而是排队——这是兼容性细节，做错会让移植应用直接崩。
【行为细节】父 Close 请求登记为"待决"，账面标记父进入 closing-pending；最后一个子关闭完成的同一事务里触发父关闭流程，对外表现为父 Close 的异步完成回调此刻才到。
【边界与错误路径】子句柄在此窗口新建被拒（父已发起关闭）；待决期间查询父句柄属性返回中间态提示；应用若在待决期继续用子句柄发请求，行为与未关父时完全一致，零惊扰。
【验收落实】父子存活交错剧本 12 条；待决→完成状态机逐迁移断言；排队协议注入 10^3 次。判据号 UNX-F17606-J1。

### UNX-F17607 · 四类超时逐节点覆写矩阵

【功能定位】四类超时（connect/send/receive/resolve）支持会话、连接、请求三级逐节点覆写，矩阵即规范：哪级设、哪级生效、继承还是隔离，一格不糊。
【行为细节】请求级覆写只影响本次请求；连接级影响其上全部后续请求的默认值；会话级最广。覆写动作即时生效于"之后创建的对象"，不追溯改在途请求，避免中途换规则的不确定行为。
【边界与错误路径】零值表示"回退继承"而非"零超时"，语义显式区分并各有专测；设值超过内部硬上限钳位到上限并记警告；负值直接拒绝。
【验收落实】3 级 × 4 类 = 12 格覆写矩阵 + 继承/回退 8 变体；钳位与拒绝路径断言。判据号 UNX-F17607-J1。

### UNX-F17608 · 选项空间注册表与 SetOption/QueryOption 地基

【功能定位】选项空间是网络面所有可配置项的注册表：每个选项号登记类型、长度、允许层级、读写权限，Set/Query 一切行为以此为唯一事实源。
【行为细节】未知选项号返回"不支持"而非猜；类型不符拒绝并说明期望类型；只读选项 Set 直接拒绝。注册表编译期建表，查询 O(1)，无运行时注册竞态。
【边界与错误路径】缓冲区不足返回所需长度（与 WinInet 语义一致）；空缓冲查询长度类选项合法；并发 Set 同一选项有明确先后语义（后写胜出并记日志）。
【验收落实】全选项表扫描断言（无死项、无缺描述）；类型/长度/权限错误 16 变体；并发 Set 竞争剧本。判据号 UNX-F17608-J1。

### UNX-F17609 · 会话级 User-Agent 与代码页选项语义

【功能定位】会话级 UA 与代码页是本地化与兼容性两大高频选项，语义模糊会直接导致服务端误判与乱码，故单独立条固化。
【行为细节】UA 在会话创建时定版，请求级可覆写但不回写会话；代码页决定头部非 ASCII 字符的编解码，默认 UTF-8，兼容模式可切回系统 ANSI 映射。
【边界与错误路径】UA 长度超限截断并记警告；代码页枚举非法值拒绝；混合代码页场景（请求头 UTF-8、正文 ANSI）在文档与诊断转储中显式标注，不猜。
【验收落实】UA 拼装/覆写 8 剧本；代码页往返编解码恒等断言 ×6 页；非法值路径。判据号 UNX-F17609-J1。

### UNX-F17610 · 坏句柄全族错误矩阵（E 型前哨）

【功能定位】对无效/已关闭/类型不符句柄调用任意 API 的返回必须成族一致：这是应用防御性编程依赖的第一道错误信号，立"E 型前哨"专条。
【行为细节】错误码三态：无效值、已关闭、类型错——三者绝不混用；错误回调与同步返回值双通道一致；首次坏句柄调用记 warn 日志并带调用栈摘要，方便定位应用侧 bug。
【边界与错误路径】句柄值恰好复用为同类型新句柄的 ABA 场景用世代号防误判；NULL 句柄恒定返回参数错误；全 API × 三态 = 全族矩阵逐格断言。
【验收落实】E 型矩阵 3 态 × 全 API 扫描自动生成比对；ABA 注入剧本。判据号 UNX-F17610-J1。

### UNX-F17611 · INTERNET_FLAG_ASYNC 挂树与会话模式锁定

【功能定位】异步标志在会话创建时决定整个会话的模式（同步/异步），锁定后不可中途切换——混模式是移植应用崩溃重灾区，故锁死。
【行为细节】异步模式下全部阻塞 API 返回"待定"并由回调交付结果，回调线程模型（单回调串行）写入文档与断言；同步模式零回调。模式在句柄树节点落标签，诊断转储可见。
【边界与错误路径】异步会话误用同步语义（不检查回调返回值）由返回值三态引导修正；回调内再入 API 有重入防护并记警告；异步会话内同步旗标请求按会话模式裁决。
【验收落实】模式锁定断言 ×2 模式；回调串行性注入 10^3 次；重入路径剧本。判据号 UNX-F17611-J1。

### UNX-F17612 · dwContext 上下文值与回调关联账

【功能定位】dwContext 是应用把自己的状态对象挂到请求上的通道，回调时原样带回。语义要点：逐级继承、回调时序、关联一致性。
【行为细节】子句柄创建时继承父 context，可显式覆写；每个回调携带触发它的节点 context 与状态码；关联账记录 context→节点映射，转储时能反查。
【边界与错误路径】context 为零合法（表示无状态）；应用传悬空指针不是栈的问题但崩溃归因日志要能指认调用序；关闭流程中回调的 context 生命周期保障（回调完成后才允许应用释放）写入判据。
【验收落实】继承/覆写 8 剧本；回调关联一致性 ×10^3 注入；关闭时序与 context 存活断言。判据号 UNX-F17612-J1。

### UNX-F17613 · 句柄树诊断转储与运维账

【功能定位】句柄树诊断转储是排查"连接去哪了、谁没关"的核心运维工具：一键导出全树快照（类型/状态/引用计数/超时/存活时长）。
【行为细节】转储为开放格式（文本表 + 可选 JSON），异步生成不阻塞请求路径；支持按类型/状态/存活时长过滤；每节点带创建调用栈摘要（可关，隐私红线：不含请求内容）。
【边界与错误路径】树巨大时转储分页流式，防内存尖峰；转储期间树并发变动取一致性快照（短临界区）；转储自身失败显性报错。
【验收落实】转储一致性剧本（并发增删下快照自洽）；大树 10^5 节点流式断言；隐私红线复核。判据号 UNX-F17613-J1。

### UNX-F17614 · 并发关闭竞争：关闭请求排队协议

【功能定位】多线程同时对同一子树发起 Close 是真实工况，排队协议定义竞争裁决：先到先关、后到幂等返回、绝不双回收。
【行为细节】关闭请求带序号入队，执行器按序处理；后到的 Close 拿到"关闭已排队/已完成"的区分返回；等待方提供可选阻塞等待完成接口。
【边界与错误路径】Close 与 Set/Query 并发：Close 优先，Set/Query 返回中间态错误；执行器线程故障（模拟）有看门狗接管的降级路径；排队深度上限防恶意刷队列。
【验收落实】竞争剧本 ×10^4 次全序断言；零双回收对账（每节点恰好一次回收事件）；看门狗注入。判据号 UNX-F17614-J1。

### UNX-F17615 · ktest 并发关闭悬空回调注入集

【功能定位】把并发关闭 × 悬空回调这一最容易出 UAF 的组合做成常驻注入集，进 ktest 门禁，防回归。
【行为细节】注入器在回调执行中随机时机触发树另一侧关闭，覆盖"回调内访问自身节点/父节点/兄弟节点"三类窗口；每轮注入后全树完整性校验。
【边界与错误路径】注入发现违例立即失败并留存场景序号可复放；随机种子入账，bug 可精确重放；CI 连跑 10^3 轮零违例为绿。
【验收落实】必红三条（人为构造违例验证注入器能抓到）；10^3 轮零违例基线；复放确定性断言。判据号 UNX-F17615-J1。

### UNX-F17616 · 多根会话并存与每会话状态隔离

【功能定位】同进程多根会话并存是浏览器类应用常态：每会话独立 cookie 视图、代理快照、连接池与记账，隔离性即正确性。
【行为细节】会话间零共享可变状态，连接池按会话分桶；全局唯一资源（DNS 缓存等）以只读共享+会话侧缓存实现，避免串味。
【边界与错误路径】跨会话句柄互操作（A 会话句柄传给 B 会话 API）直接拒绝并提示；一会话崩溃性错误不波及他会话（故障隔离断言）；全局配置变更只影响新会话。
【验收落实】双会话并行剧本 ×10；串账检出矩阵（cookie/代理/计数三维）；故障隔离注入。判据号 UNX-F17616-J1。

### UNX-F17617 · 句柄泄漏账与进程退出清扫

【功能定位】泄漏账持续记录存活句柄与分配点，进程退出时强制清扫残余句柄并出报告——防丢失与零残留双目标。
【行为细节】每节点带分配栈摘要入账；退出清扫按"先子后父"安全序执行，全部走正常关闭路径而非暴力释放；清扫报告（数量/类型/栈）写入退出日志。
【边界与错误路径】退出时在途异步请求给有限宽限窗，超时强制取消并记警告；清扫期间新请求拒绝；清扫自身崩溃防护（防御性遍历）。
【验收落实】泄漏注入剧本（故意不关 ×N）清扫全净断言；宽限窗时序断言；退出日志三要素完备。判据号 UNX-F17617-J1。

### UNX-F17618 · HINTERNET 与 D3 句柄表协议消费挂点

【功能定位】HINTERNET 需要与 D3 域句柄表协议对齐消费：跨域句柄走统一登记协议，避免两套句柄体系各说各话。
【行为细节】网络句柄在 D3 句柄表注册影子条目（类型/属主/存活状态），跨域查询走影子；属主进程退出时影子自动清理，防跨域悬空。
【边界与错误路径】D3 表不可用时降级为本地表并记警告（降级池协议）；影子与本地账对账器每批核数；跨域关闭传播语义（谁发起谁通知）冻结。
【验收落实】跨域注册/查询/关闭三剧本；对账器 ×10^4 批零差；降级路径断言。判据号 UNX-F17618-J1。

### UNX-F17619 · 错误码出口统一与 ERROR_INTERNET_* 空间翻译
