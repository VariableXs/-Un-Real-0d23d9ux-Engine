# ADR · B5 域 RAID6 缺席显式声明（b5-raid6-absence）

> 编号承接：UNX-F7405（UNX-B5-B11）｜落纸会话：AI-10｜状态：已接受（Accepted）
> 对应判据：UNX-F7405-J1 ADR 四节齐备落纸、扩展点登记在册、依赖扫描零 RAID6 引用、RAID6 命令拒绝断言
> 复核：AI-86 红线复核清单在册（B11 册末 finalize 表）；形式档案备案待 AI-93

## 一、背景

任务书将 RAID6（双校验 P+Q，耐双盘故障）列入 B5 域 RAID 族远期条目面。本域当前深化收口范围（B01–B15，F7201–F7500）的 RAID 语义完成度止步于：RAID0 条带（B09）、RAID1 镜像全语义含位图/热备/半镜像禁确认（B09）、RAID5 三状态机与分布式校验（B10–B11）。RAID6 需要 P+Q 双校验引擎（GF(2^8) 双生成多项式）、双故障存活语义与重建次序算法，其判据族（双盘并发故障注入 ×100、P/Q 分离校验、降级两档可读性矩阵）依赖的真机对练面与本域当前批次budget不匹配。

缺席不等于沉默：本 ADR 将"RAID6 不在本域当前收口范围"从隐含状态升格为**显式声明三落**——①本 ADR 落纸；②依赖扫描落账（零 RAID6 依赖断言）；③命令注入拒绝断言（ raid6 类表行/target 注入返回缺席码）。

## 二、决策

1. **域内缺席**：B5 域 B01–B40 全批次中，RAID6 不实装、不出现在任何 target 注册表条目（F7203 注册表不登记 raid6 类型）。
2. **缺席可观测**：任何以 raid6 为 target 类型的映射表行（F7202 解析面）在类型分派时返回显式缺席码（DM_ERR 前缀 + UNSUPPORTED_TARGET_RAID6），逐次留拒绝账——禁止静默失败或伪装为 raid5。
3. **命令注入拒绝**：mdadm 语义面的 raid6 创建命令注入用例 100% 返回缺席码并留账（断言随 F7220 ktest dm 面）。
4. **依赖零引用**：已交付 56+ RAID 判据（B08–B11）依赖图扫描断言零 RAID6 依赖（grep 核查全域实现引用 = 0）。

## 三、影响

- **现收口面**：零影响——B01–B15 全部 300 条判据不依赖 RAID6 语义（依赖扫描断言为证）。
- **下游消费面**：L1 安装器卷描述（F7296 冻结接口）与 ktest 注入面在用户请求 raid6 时获得明确缺席码而非未定义行为；对齐 Windows 存储栈"unsupported feature"显式声明惯例（Storage Spaces 双奇偶校验布局在不受支持 SKU 的缺席声明同构）。
- **运维面**：缺席码文档化进 B5 域诊断手册面（F7215 错误码语义），不产生"看似支持实则未实现"的误导路径。

## 四、扩展点（远期条目登记，非代码预留）

- **双校验引擎位预留**：F7376 XOR 单点封装（域内唯一校验运算入口，grep 核查实现 = 1）即 P+Q 引擎的架构预留位——远期启用 RAID6 时以第二生成多项式引擎挂接该封装点，raid5 校验路径零改动。
- **远期条目登记**：RAID6 三件套（双校验引擎 / 双故障存活状态机扩展 / P+Q 双盘重建次序）登记为远期条目文字预留（登记于本 ADR，零实现负担）；启用时以新批次立批承接，本 ADR 状态由"缺席"翻"已承接"并留痕。
- **兼容性说明**：F7203 注册表为类型名→构造函数映射，新增 raid6 注册不影响既有三类（linear/raid/crypt）分派路径；F7202 表格式三段式天然容纳 raid6 参数串，格式无需演进。

——本 ADR 为 UNX-F7405-J1 判据的落纸物；缺席三落断言（ADR 成文/依赖扫描/命令拒绝）随 B5 ktest 常驻。
