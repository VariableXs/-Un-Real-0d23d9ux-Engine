# ADR · B5 域 LVM thin（精简供给）缺席显式声明（b5-thin-absence）

> 编号承接：UNX-F7451（UNX-B5-B13）｜落纸会话：AI-10｜状态：已接受（Accepted）
> 对应判据：UNX-F7451-J1 ADR 四节落纸、三落断言、厚判据零依赖扫描、thin 命令拒绝断言
> 复核：AI-86 红线复核清单在册（B13 册末 finalize 表）；形式档案备案待 AI-93

## 一、背景（分档口径）

任务书在 LVM 供给分档面将"厚供给（thick：预分配）与精简供给（thin：按需分配 + 空间回收 + thin-pool 元数据）"并列入远期条目面。本域当前深化收口范围（B01–B15）的 LVM 语义完成度：PV 三重验证（F7412）、VG 元数据双副本与环形历史 16 代（F7414）、LV 三映射（线性/条带/镜像）、在线扩容表原子替换（F7421）、快照 COW 全链（F7427–F7438）——全部基于**厚供给口径**。

thin 供给引入独立子系统：thin-pool 元数据设备（B-tree 空间账）、provisioning 事件流（95% 水位事件）、discards 回收路径、快照 thin 变体。其判据族（超配比注入、水位事件 ×100、回收后读零残留）依赖的断电对练面（thin 元数据损坏即全池失效）属于 ×1000 断电总账批次（B25–B32）的实机预算，本域当前批次不承载。

## 二、决策（域内缺席）

1. **本域全判据基于厚供给**：B01–B40 全批次 LVM 判据声明为厚供给口径；thin 语义不实装、不出现在任何 LV 类型枚举（LV 类型表无 thin/thin-pool 项）。
2. **缺席可观测**：`lvcreate --thin` 语义面的 thin 类命令注入 100% 返回缺席码（LVM_ERR 前缀 + THIN_UNSUPPORTED），逐次留拒绝账——禁止静默忽略选项或伪装为厚卷。
3. **三落断言**：①本 ADR 落纸；②厚供给判据依赖扫描零 thin 引用（断言：B01–B15 全部 LVM 判据 grep thin 依赖 = 0）；③thin 命令注入拒绝断言随 F7461 LVM ktest 面常驻。
4. **承接声明**：总纲"分档"原文引用存档于 F7451 条目正文；本 ADR 即承接落纸物。

## 三、影响（thin 场景缺席面）

- **现收口面**：零影响——B01–B15 全部 300 条判据在厚供给口径下自洽（依赖扫描断言为证）。
- **L5 消费接口预留**：L5 文件系统域消费 LV 容量呈现（B4 冻结容量接口）为"有效区间和"呈现，thin 缺席对 L5 完全透明（文字预留非代码预留）；远期 thin 启用时水位事件接口需与 L5 容量告警面联签。
- **运维面**：thin 类命令缺席码文档化进 B5 诊断手册面（F7215 错误码语义族）；对齐 Windows 精简卷（Storage Spaces 精简供给）在不受支持配置下的显式缺席声明惯例。
- **快照面澄清**：本域快照（F7427–F7438）为厚 COW 快照（外置快照卷预分配），非 thin 挂起快照——两者判据面完全分立，不存在"快照即 thin"的口径混用。

## 四、扩展点（三远期条目，文字预留零实现负担）

1. **thin-pool 元数据设备**（B-tree 空间账 + 双副本）：远期启用时挂接 F7414 元数据双副本环形历史机制（复用而非新建）。
2. **provisioning 水位事件流**：95%/100% 两档水位事件注册进 F7374 SMART 联动的三档分流告警面（复用告警管线）。
3. **discards 回收路径**：挂接 B4 块层 discard 请求语义（B4 flush/discard 契约冻结面），回收位图复用 F7361 RAID1 位图同构结构。

启用时以新批次立批承接，本 ADR 状态翻"已承接"并留痕；启用前本域任何条目不得引入 thin 语义（含注释级引用，防语义渗透）。

——本 ADR 为 UNX-F7451-J1 判据的落纸物；三落断言随 B5 ktest 常驻。
