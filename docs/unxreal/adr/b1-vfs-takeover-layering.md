# ADR-UNX-004 · B1 域 VFS 升级接管分层
## （m700vfs / storage / fs23_mount / vfsguard 四件现存实现 × 本域 300 条的分层边界账）

- 状态：已生效（AI-06 波 08-M09 · B1 域 B01–B15 finalize 收口登记）
- 决策人：AI-06（承办）｜以 Variable 明令宪章"升级接管体例"为准
- 关联：总纲 §7.3-B1 台账引言、§6 施工协议；登记于 handoff.json `adr_log`

## 背景（Context）

B1 域（VFS 与路径层，F4001–F4800）开工前，现存内核已有四件 VFS 相关最小实现：

1. `kernel/varix/src/**/m700vfs.rs`——F201–F225 语义大典（操作码/挂载/缓存最小语义盘点与统计年报）；
2. `kernel/varix/src/**/storage.rs`——F131/F132 Mount/MountTable；
3. `kernel/varix/src/**/fs/fs23_mount.rs`——挂载表与符号链接环检测（`MAX_SYMLINK_FOLLOWS=8`）；
4. `kernel/varix/src/**/vfsguard.rs`——路径规范化与越权审计。

任务书既定"升级接管"体例：本域 300 条立权威语义，现存实现为早期最小版本，逐条"承接非重复"。本 ADR 把四件的分层边界一次说清，作为域级总账（批内逐条注记的上位依据）。

## 决策（Decision）

四件现存实现与本域 300 条按以下分层边界共存：

| 现存件 | 现存语义 | 本域接管件 | 接管分层规则 |
|---|---|---|---|
| m700vfs.rs | F201–F225 最小 VFS 语义（操作码/挂载/缓存/统计年报） | B01–B08 三对象与操作表段（含 B05 缓存批） | m700vfs 为"最小语义盘点"；B1 权威条目为对象族谱与操作表权威锚；F225 年报作为消费方联动注记（B1 统计账供其读，不重复立账） |
| storage.rs | F131/F132 Mount/MountTable | B12 mount 树批（F4221–F4240） | storage.MountTable 为存储层挂载记录；B12 三向链/覆盖栈为语义层权威，接管账登记 F4235/F4236（8 层上限家族升级注记） |
| fs/fs23_mount.rs | 挂载表 + 符号链接环检测（MAX_SYMLINK_FOLLOWS=8） | B10 符号链接批（F4181–F4200） | 8 层上限为早期最小语义，本域按 POSIX 权威口径升为 ELOOP-40 并全量接管（升级差异登记 F4186：40/41 精确边界断言 + 8→40 接管 grep 留痕；fs23_mount 8→40 升级接管） |
| vfsguard.rs | 路径规范化与越权审计 | B11 规范化批（F4201–F4220） | vfsguard 映射清单与 B1 规范化语义逐条对账（F4216 专项：接管边界账 + 并行对照零差） |

## 理由（Rationale）

1. **现存件不可删**——引导链与既有 ktest 断言面依赖现存件，删改即破坏零回归纪律；
2. **权威语义必须单一**——300 条判据即权威，双权威必漂移；分层后现存件降级为"被接管的最小实现"，其行为语义由 B1 条目判据覆盖；
3. **接管差异必须登记**——如 8→40 层，不允许静默改语义：每处升级都有 grep 留痕与边界断言（判例一：F4186；判例二：F4245 参数透传字节级 diff=0）。

## 后果（Consequences）

- 下游域（B2 ext / B3 NTFS / B4 块层 / B5 dm）消费三操作表语义表（F4141–F4160 快照冻结件，handoff cross_domain_freeze 在册）而非现存件——现存件在 C2 波次接线时由 B1 条目语义整体接管；
- B16–B40 续领批次沿用本分层边界账；新增接管件须追加本 ADR 修订行（append-only）；
- 复测锚四件：F4186（40/41 边界 + 8→40 接管 grep）、F4216（vfsguard 对账零差）、F4235/F4236（storage 接管账）、F4157（三表快照 diff 零差）。
