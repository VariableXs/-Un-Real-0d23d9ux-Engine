# UNX-J3 定制明细 · B13（F37841–F37860 · 密钥隔离与内存卫生 X5 主战场）

### UNX-F37841 · 锁页内存分配（A4 PmLockAlloc 消费·密钥材料只在锁页）
**功能**：密钥材料的天堂与监狱：所有密钥（私钥、DRBG 状态、HMAC 内外状态、PRK）只在锁页内存（不可换出到磁盘的物理页）中存在——换出=密钥落盘=隔离失败。本条消费 A4 的 PmLockAlloc（Schema 先行+fake 态），封装"密钥级分配器"：分配即锁页、free 即清零再归还，调用方拿不到裸指针。
**完成**：分配器封装后全域 grep 验证密钥材料零裸分配（全部经分配器）；锁页失败语义单测（fail 路径见 F37842）；fake↔实机切换点标注（R-J3-002）；分配器开销入性能账（≤10% 摊销）。

### UNX-F37842 · 锁页失败拒绝路径（拒绝生成不降级明文页）
**功能**：熵红线的姊妹条款：锁页配额耗尽时，密钥生成/导入拒绝服务，绝不降级用普通明文页"凑合"。拒绝三要素：发生了什么（锁页配额尽）、为什么（密钥不能落可换出页）、下一步（释放其他锁页或提升配额）。降级=最严重缺陷（等同 rand() 进安全用途）。
**完成**：配额耗尽注入 100% 拒绝且零明文页兜底（内存账验证无普通页密钥）；三要素文案核；拒绝事件入审计；"拒绝不降级"写入域内宪法与开发文档双处。

### UNX-F37843 · secure_zero 单点（volatile 写+屏障·全 J 部禁二写）
**功能**：全 J 部唯一的内存清零原语：volatile 逐字节写 + 编译屏障 + 内存屏障三件套，保证 -O3 下清零不被优化掉（编译器见到"写了不再读"会合法删除 memset——这是真实世界密钥泄漏的经典根因）。本条是任务书示例锚 F37850 的执行核，全域禁第二份清零实现（各处清零必须调它）。
**完成**：-O3 构建下反优化断言绿（读回验证清零真实发生——方法学：清零后经 volatile 指针再读）；全域 grep 零旁路清零（memset 类特征零命中）；单点实现审计（三件套齐备）；开销入账（清零 1KB <1μs）。

### UNX-F37844 · 反优化清零断言（-O3 构建下清零断言仍绿）
**功能**：F37843 的自动化守护：把"清零真的发生了"做成 -O3 构建的常驻断言——测试在优化构建下运行，若编译器优化掉清零，断言即红。防的是"将来某次编译器升级/代码重构让防线静默失效"。断言进 fast 回归每波必跑。
**完成**：断言在 -O3/-O2/-Os 三档构建全绿；演示性破坏（换回 memset）触发断言红验证；断言纳入 fast 回归配置；CI 双构建（debug+release）都跑断言。

### UNX-F37845 · 全内存扫描注入 ×100 零密钥残留（X5 主判据）
**功能**：域判据 X5 的主执行件：密钥全生命周期（生成→用→销毁）各时点对进程全内存做扫描注入——用已知密钥材料字节模式搜全地址空间（含堆/栈/寄存器溢出区/已 free 区），×100 轮零残留。扫描器本身只读、用后自清（扫描模式不能反过来泄漏）。
**完成**：扫描 ×100 轮零命中（生命周期 8 个时点 × 多密钥类型矩阵）；扫描器自清断言；已知命中案例注入（故意留一份）验证扫描器灵敏度 100%；扫描报告入 X5 终账。

### UNX-F37846 · 日志/审计/核心转储三通道抽查 ×10 零密钥材料
**功能**：密钥泄漏的三条暗渠逐条堵：日志通道（任何 log 调用不得格式化密钥缓冲——埋点字段白名单制）、审计通道（审计只记元数据指纹）、核心转储通道（密钥页标记为转储排除段）。三通道 ×10 抽查：触发日志/审计/转储生成后全文搜密钥模式零命中。
**完成**：三通道 ×10 抽查零命中；转储排除段标记断言（密钥页 flag 验证）；日志字段白名单机制（非白名单字段写入被构建期检查拦截）；抽查自动化入回归。

### UNX-F37847 · 密钥生命周期四环判据总闸（生成/存储/使用/销毁）
**功能**：四环总闸：每一环各有判据——生成环（来源审计+熵合规）、存储环（锁页+包裹/文件纪律）、使用环（用途位+审计）、销毁环（清零单点+及时性）。四环齐备是任何新密钥类型接入的准入闸：缺一环，新类型不许接入（闸自动检查新类型的四环登记）。
**完成**：四环判据各自落地（各环用例 ≥3）；准入闸对新类型模拟接入（故意缺销毁环登记）拦截验证；四环状态账入域档供 B40 汇总；闸机制版本化。

### UNX-F37848 · 密钥句柄化全链（用户态只见句柄不见明文）
**功能**：结构隔离的顶梁柱：调用方全链只见不透明句柄，明文密钥材料不可经任何公开 API 读出——导出受双闸、属性只回元数据。句柄化让"误用密钥"在 API 面就不可表达（想打印密钥都拿不到密钥）。本条做全链审计：逐 API 核对返回值与出参无材料泄漏路径。
**完成**：全 API 出参审计（≥40 个 API 逐个核零材料出参）；句柄不可逆解析断言（句柄值不映射地址）；文档明示句柄化语义；API 面新增时的句柄化检查纳入评审清单。

### UNX-F37849 · 进程死则密钥灭（内存 KSP 销毁链）
**功能**：内存 KSP 的终极销毁语义：进程退出（正常/异常/被杀）密钥必灭。三重防线：正常退出扫尾链（逐钥清零）、异常终止靠锁页语义（页回收即灭，无换出残骸）、崩溃转储被 F37846 排除段挡住。语义对齐 Windows"进程生命周期=密钥生命周期"。
**完成**：正常退出扫尾断言（清单零残留）；kill 注入 ×10 后下一启动核对内存账（锁页语义兜底验证）；转储排除联动核验；销毁链时序（清零先于页释放）断言。
