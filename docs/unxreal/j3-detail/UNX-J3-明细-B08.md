# UNX-J3 定制明细 · B08（F37741–F37760 · HMAC 与向量账首批 100 例）

> AI-48 承办 · 波18 定制化扩写批册：每条「功能/完成」≥300 字。判据在册，红线声明见 batches/UNX-J3-B08.md。

### UNX-F37741 · HMAC 全语义（RFC2104 ipad/opad 两轮）
**功能**：HMAC 标准实现：密钥先按块长处理（短则补零、长则先哈希），再与 ipad/opad 异或做内外两轮哈希。对照 RFC 2104 原文（禁自造密码红线），支持 SHA-256/384/512 三底座。密钥处理一次预计算（内外轮初始状态缓存），后续每条消息只需增量哈希——验证型高吞吐场景的关键优化。
**完成**：RFC 2104 向量三底座全过；预计算优化与朴素实现 50 组对照逐字节一致；密钥处理三分支（短/等长/长）边界用例全过；内外状态缓存锁页驻留断言。

### UNX-F37742 · HMAC RFC4231 42 例全量向量账
**功能**：RFC 4231 官方向量 42 例全量入库：三底座 × 密钥边界（短/块长/超长）× 消息边界（空/块界/超长）全组合。生成器自动产断言（禁手抄），来源校验和钉版。这批向量是 HMAC 族 finalize 的硬门。
**完成**：42/42 全过自动注册 ktest；来源钉版与校验和断言；覆盖矩阵（密钥三分支 × 消息三分支）完整性核对；finalize 闸核验通过。

### UNX-F37743 · HMAC 与哈希状态机复用（零重复实现）
**功能**：HMAC 的哈希步骤完全复用 B07 哈希核——HMAC 层只写 ipad/opad 编排与状态缓存，不写第二份压缩函数。这是"零重复实现"审计件：密码学里同一原语的两份实现意味着两份出错机会与两份行为漂移，结构性杜绝。
**完成**：全域 grep 验证压缩函数唯一（HMAC 内零内联副本）；复用经 B02 框架回调（契约符合）；行为等价断言（复用路 vs 独立参考实现 42 向量一致）；审计结论入域档。

### UNX-F37744 · HMAC 多段式消息喂入
**功能**：HMAC 多段喂入语义：消息任意分段经框架 Update 喂入，Finish 出 MAC。内层哈希的分段缓冲全透明——调用方按业务包切分（如逐包认证）无需拼完整消息。流式验证场景（边收边验）是主用例。
**完成**：四种切分结果一致 20 组对照；逐包流式验证剧本（收一段验一段不可行时的中间态方案文档化）；分段缓冲有界断言；与 B02 剧本库共享回归面。

### UNX-F37745 · HMAC 密钥零残留（用毕清零单点调用）
**功能**：HMAC 密钥材料的生命周期纪律：对象关闭或密钥更换时，预计算的内外状态与原始密钥缓冲经 secure_zero 单点清零（B13 供点，全 J 部禁二写）。清零时序先于内存释放；清零不可被编译器优化掉（B13 反优化断言复验）。
**完成**：关闭路径清零时序断言；更换密钥旧材料即时清零断言；清零调用经单点（grep 唯一）；内存扫描注入 ×10 零残留（X5 联动）。
