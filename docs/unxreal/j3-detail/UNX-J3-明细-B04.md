# UNX-J3 定制明细 · B04（F37661–F37680 · NCrypt/KSP 密钥存储骨架与 NTSTATUS 对照面）

### UNX-F37661 · 软件 KSP 密钥文件读写与加密存储骨架
**功能**：密钥落盘的骨架件：文件格式（头 + 版本 + 包裹体 + 完整性校验）、原子写（临时文件 + 改名提交，断电不半文件）、读取校验（magic/版本/校验和三关）。包裹本体依赖 J2 DPAPI（预告位在册）——联签未达前文件 KSP 保持禁用态，格式先冻结、实现后补，杜绝用弱加密顶替的诱惑。
**完成**：文件格式 v1 冻结（字段表+版本规则）；原子写在断电注入（写中途杀进程）×10 后磁盘上永远只有完整旧文件或完整新文件；读取三关校验拒止矩阵 8 格全过；未联签禁用闸生效断言。

### UNX-F37662 · 用户/机器两级密钥域隔离
**功能**：对齐 Windows 密钥域模型：用户域密钥（随用户会话生灭）与机器域密钥（全机共享）严格隔离——用户域密钥机器域上下文打不开，反之亦然；域标签进句柄与文件格式，越域访问精确报错。隔离是结构性强制，不是靠调用方自觉。
**完成**：越域访问矩阵 8 格全部拒止且错误含域信息；域标签进文件格式断言（改标签字节读取被拒）；两域枚举互不可见（枚举隔离断言）；域语义与 Windows 对照零漂移。

### UNX-F37663 · NCryptCreatePersistedKey 类语义
**功能**：持久密钥创建语义：调用方指定 KSP、算法、密钥名与策略位（用途/可导出性），KSP 落一个持久密钥对象并返回句柄。同名创建拒止（防覆盖——与 F37604 注册仲裁同纪律）；创建即挂生命周期四环的"生成环"审计：谁、何时、什么算法、什么策略全入账。
**完成**：同名创建拒止且原名密钥逐字节不变；策略位合法值域校验矩阵全过；生成环审计四要素完整断言；创建→打开→使用→关闭全链往返 100 组用例通过。

### UNX-F37664 · NCryptOpenKey/OpenStorageProvider 与句柄面
**功能**：持久密钥的打开路径：先开 KSP（OpenStorageProvider），再按名开钥（OpenKey）。语义对齐 Windows：不存在的密钥名返回 NOT_FOUND（不存在性不隐藏也不伪报）；打开的句柄继承密钥策略位（不可导出钥开出来也不可导出）；打开事件入审计账。
**完成**：存在/不存在/已损坏密钥三态打开用例语义精确；句柄策略继承断言（打开后导出仍被拒）；KSP 句柄与钥句柄两级校验链完整；打开审计落账可检索；10^4 次开关循环句柄账归零。

### UNX-F37665 · 密钥对象用途绑定（签名/解密用途位）
**功能**：密钥生来有用途：签名钥只能签、解密钥只能解，用途位在创建时定死且不可改。用签名钥去解密的调用在 API 面被拒——用途混用是密钥滥用攻击的第一步，结构性堵死。用途位还进审计：每次使用都核对用途匹配。
**完成**：用途错配矩阵（签名钥解密/解密钥签名 ×双算法族）全部拒止；用途位不可更改注入（重设用途）被拒；使用审计含用途核对记录；与 Windows 用途语义对照零漂移。

### UNX-F37666 · 不可导出位语义与导出审计
**功能**：深化 B04 导出纪律：不可导出位是密钥的最强保护位——置位后任何导出路径（明文/包裹/备份）全部封死，且该位自身不可清除（要"可导出"只能重建钥）。可导出钥的导出走 B04 双闸并追加：导出目标 KSP 记名、导出格式版本记录。
**完成**：不可导出位置位后全导出路径拒止矩阵 6 格全过；清除该位用例被拒（不可逆断言）；可导出钥导出审计含目标与格式四要素；与 F37632 双闸复用单点（grep 无第二份导出闸实现）。

### UNX-F37667 · 密钥删除与销毁语义（进程死则密钥灭）
**功能**：删除的完整语义：显式删除（调用方发起）走确认+审计+材料清零三步；内存 KSP 的密钥随进程消亡——进程退出钩子扫尾清零，异常终止由锁页语义兜底（页回收即灭）。删除不留残骸：文件 KSP 的删除含文件粉碎写零（覆盖后删）。
**完成**：显式删除三步断言（确认/审计/清零时序）；进程正常退出扫尾清单零残留；kill 类异常终止后内存账归零（下一启动核对）；文件粉碎写零断言（删除后读全文零密钥字节）；已删钥句柄访问全拒。

### UNX-F37668 · NTSTATUS 错误码对照表 v2（NCrypt 面）
**功能**：错误码宪法第二版：补齐 NCrypt 存储面错误码（KSP 不存在、密钥不存在、域错配、策略拒止、包裹失败等），延续 v1 的十年不变承诺——只增不改。v2 与 v1 同源联签，与 Windows NCrypt 语义逐格对照。
**完成**：v2 新增 ≥20 格逐格对照零漂移；v1 冻结格零改动（diff 断言）；全域 grep 无表外裸码；联签单与 D1/J2 双域签署；错误三要素模板绑定新码（每码有"怎么办"文案）。

### UNX-F37669 · 句柄泄漏账 30 天零增长（J5 判据预演）
**功能**：域判据 J5 的预演件：句柄泄漏账长期跑——压力剧本（反复开关/异常路径中途弃句柄/进程轮替）下句柄账余额必须 30 天模拟周期（加速时钟）零净增长。泄漏不是靠"记得关"，而是靠哨兵账+退出清单+异常路径兜底关闭三层防线。

### UNX-F37670 · KSP 注册框架与第三方 KSP 扩展点（开放性）
**功能**：开放性纪律的落地：第三方可实现 KSP 接口注册进来（硬件令牌、远程密钥库皆可），但内置内存 KSP 的地位与第三方同名仲裁规则由框架锁定——第三方不能顶掉内置默认。扩展点带沙箱约定：第三方 KSP 崩溃不拖垮 J3 本体（调用隔离+失败降级）。
**完成**：第三方 KSP 注册冒烟通过（样例 KSP 走通存取删）；同名仲裁拒绝覆盖内置断言；第三方 KSP 崩溃注入（样例故意 panic）本体存活且该 KSP 标记不健康；扩展点文档与接口版本化在册。

### UNX-F37671 · TPM 可选层预告位（存在即用/缺席软兜底·如实分档）
**功能**：TPM（可信平台模块）作为密钥保护增强层预告：检测到 TPM 则私钥操作可下沉硬件，缺席则软兜底——功能不缺、保护分档如实标注（"软保护"字样进密钥属性与审计）。诚实三态：不虚报硬件保护，检测与降级全透明。
**完成**：TPM 存在性探测与分档标注断言（有/无两环境）；缺席软兜底功能等价（软路完成签名全链）；分档标注进密钥属性查询结果；预告位冻结（接口签名留位、实装在后续波次 ADR）。

### UNX-F37672 · 密钥属性查询与策略账
