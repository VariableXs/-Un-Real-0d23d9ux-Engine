# UNX-J3 定制明细 · B05（F37681–F37700 · CSPRNG ChaCha20 DRBG 与熵双通道）

### UNX-F37681 · ChaCha20 DRBG 核（存量 ChaCha20 接管）
**功能**：全域随机数的心脏：以 ChaCha20 为基的确定性随机比特发生器（DRBG），对接管 security.rs 存量 ChaCha20 实现作托管收编——对外唯一入口是本 DRBG，存量调用点迁移映射在册。DRBG 按 NIST SP800-90A 类语义工作：种子状态、输出块、更新函数三件齐备，实现对照规范原文（禁自造密码红线）。
**完成**：接管映射表落档（存量调用点 × 新入口对照）；SP800-90A 类测试向量全过；DRBG 核零旁路实现（全域 grep 唯一）；输出吞吐基线入账；实现与规范逐节对照审阅留痕。

### UNX-F37682 · 熵源双通道：RDRAND 类指令 + 中断抖动池 XOR 混音
**功能**：种子的两条来路：硬件指令通道（RDRAND 类，快但按"黑盒"对待）与中断抖动池通道（采集中断到达时刻抖动，慢但自主可控）。两路 XOR 混音进种子——任何单路被预测或失效都不足以预测种子。混音算法对照 NIST SP800-90B 类 conditioner 语义。
**完成**：双通道采样与混音黄金剧本全过；单通道注入失效（模拟）后种子仍通过统计检验；中断抖动池在 QEMU 与实机两环境采样有效性登记（实机判据 R-J3-004 挂账）；混音过程零密钥材料引入断言。

### UNX-F37683 · 熵估计入账与熵健康度量
**功能**：熵不是感觉，是账：每通道按采样窗口估计熵（每比特最小熵估计，SP800-90B 类方法学），估计值滚动入账。健康度量双指标——估计值与通过率；估计低于阈值触发健康事件（降级=拒绝服务红线的执行依据）。账目供"为什么这次拒绝服务"的归因。
**完成**：熵估计方法学钉版（窗口/算法/参数全记录）；估计值滚动账可检索；低于阈值触发健康事件断言（注入低熵采样）；账目与日志中心对接可导出。

### UNX-F37684 · DRBG 状态机（instantiate/generate/reseed）
**功能**：DRBG 的三操作生命周期：instantiate（用熵种子化）、generate（出随机字节并更新内部状态）、reseed（强制重新种子化）。状态机语义对照 SP800-90A：generate 带 additional_input 可选域、输出长度上限（单次 ≤2^19 位档）、状态更新在每次 generate 内强制发生（前向安全的地基）。
**完成**：三操作黄金剧本与规范向量全过；单次输出上限拒止断言；additional_input 域分离（不与输出串扰）断言；状态更新强制发生（连续两次 generate 无重叠状态）断言；非法迁移矩阵精确拒止。

### UNX-F37685 · reseed 强制点（每 2^20 次输出）
**功能**：SP800-90A 的 reseed 纪律：DRBG 每 2^20 次 generate 强制重新种子化——这是硬闸不是建议，计数到线必须 reseed，拒绝服务也好过继续用旧状态。reseed 消耗双通道新熵，过程原子（reseed 中断不产生半种子状态）。
**完成**：计数注入到线用例验证强制 reseed 触发（内部计数断言）；reseed 后状态与旧状态独立（前向安全抽样断言）；reseed 原子性注入（中途异常）不产生半态；2^20 常量与规范对照留痕。

### UNX-F37686 · 前向安全与状态定期擦写
**功能**：前向安全：攻击者拿到当前 DRBG 状态也推不出历史输出。实现依赖每次 generate 的状态更新 + 定期整状态擦写（旧状态字节 secure_zero 后才启用新状态）。擦写用 B13 的 secure_zero 单点（全 J 部禁二写），防编译器把清零优化掉。
**完成**：前向安全抽样断言（状态快照回推历史输出失败率=猜测率）；擦写时序断言（先清零后启用）；清零经单点（grep 无旁路）；擦写开销入性能账。

### UNX-F37687 · NIST SP800-90B 类健康检测（连续失败拒止）
**功能**：熵源的体检仪：连续失败检测（repetition count / adaptive proportion 两类测试）持续盯采样流，异常即判熵源失活。失活的响应执行熵红线：拒绝服务，不降级——DRBG 停止输出并显性化告警，绝不"凑合着继续给随机数"。
**完成**：两类检测注入用例（构造连续重复/比例偏斜采样）100% 检出；检出后 DRBG 进入拒止态且三要素告警落账；恢复（熵源回归健康）路径有明确出口；检测阈值与 SP800-90B 对照留痕。

### UNX-F37688 · 克隆 reseed 钩子（A4 OnClone 消费·同状态两进程防灾难）
**功能**：Varix 的克隆语义是 DRBG 的天敌：克隆出的两进程如果共享 DRBG 状态，会输出完全相同的"随机"数——灾难级。本条经 A4 的 OnClone 钩子在克隆瞬间强制 DRBG 全量 reseed（新进程种子混入克隆标识），从结构上保证克隆体随机流分叉。
**完成**：克隆注入用例验证父子进程输出流 10^3 字节内分叉（零重叠窗口断言）；钩子失败（A4 未就绪 fake 态）时 DRBG 拒绝输出而非共享状态（fail-closed）；与 A4 联签位冻结（R-J3-002 兑现路径）；克隆事件入审计账。

### UNX-F37689 · mock DRBG 编译期隔离（测试种子禁入镜像）
**功能**：测试需要可复现随机数，但测试种子（固定种子 mock DRBG）绝不能进正式镜像——红线：mock DRBG 编译期隔离。正式构建中 mock 符号不存在（链接期排除），测试镜像单独出包。这封死"图省事把固定种子带上线"的最危险捷径。
**完成**：正式构建链接断言（mock 符号不可达，引用即链接失败）；测试镜像 mock 行为可复现（同种子同输出）；两镜像构建产物分离出包；红线执行由构建闸自动守护（CI 必查）。

### UNX-F37690 · CSPRNG 统计检验三项（频数/游程/块内频数·1M 样本）
**功能**：随机质量自证：对 DRBG 输出跑三项统计检验——频数（0/1 是否各半）、游程（连续同比特长度分布）、块内频数（分块均匀性），每项 1M 样本。这不是替代 NIST 认证，是域内持续自检：每波回归跑一遍，统计劣化早于灾难被发现。
**完成**：三项检验 1M 样本 p 值全部落入接受域；检验脚本固化入回归（每波必跑）；劣化注入（人为偏置输出）被检出验证灵敏度；结果落随机质量账供域收官（B40）汇总。

### UNX-F37691 · getrandom 类与 /dev/(u)random 类语义面（POSIX 人格投影）
**功能**：为 POSIX 人格投影提供随机语义面：getrandom 类调用（阻塞语义直到熵就绪）与 /dev/random、/dev/urandom 类字符设备投影（读出随机字节、行为分档与 Linux 对照）。这让移植自 POSIX 世界的软件在 Varix 上拿到等价随机语义，底层统一走本 DRBG。
**完成**：三类投影黄金用例全过；getrandom 阻塞语义在熵未就绪时正确等待、就绪后立返；urandom 类不因"熵账低"拒绝（语义对照 Linux）而 random 类按账拒止——分档行为对照表零漂移；投影层零旁路 DRBG（grep 验证）。

### UNX-F37692 · CSPRNG 输出性能基线（吞吐 P95）
**功能**：随机数不能成为系统瓶颈：DRBG 输出吞吐 P95 预算（小请求 ≤1KB 的延迟敏感档与大请求 1MB 的吞吐档分开计量）。ChaCha20 本身极快，预算约束的是状态机与账目开销——目标是随机数调用对调用方"免费"。
**完成**：双档吞吐/延迟实测入账且低于预算线；开销分离计量（DRBG 核 vs 账目层）；并发 8 线程输出扩展比 ≥6 入账；不达标项优化计划零挂起。

### UNX-F37693 · E 型注入：熵失效全路径（双通道齐失效）
**功能**：最恶劣场景演练：双通道同时失效（硬件指令异常 + 中断池采样失活）时系统行为。预期：健康检测判死 → DRBG 拒止 → 全域依赖方收到明确拒绝与恢复指引 → 显性化告警升级。绝不出现"悄悄用旧状态继续输出"。
**完成**：双失效注入用例验证拒止态进入与全域拒绝传播（≥3 个依赖方收到明确错误）；告警升级链（域日志中心可见）；恢复顺序剧本（先熵池后 DRBG）验证；拒止期间零输出字节（账面断言）。

### UNX-F37694 · CSPRNG 段 fuzz 与状态域注入
**功能**：DRBG 状态域的失败面 fuzz：随机注入 instantiate/generate/reseed 乱序 ×10^4 轮、状态缓冲边界（additional_input 超长/输出长度边界值 ±1）、并发 generate 交错。每轮验证零崩溃、账目闭合、输出仍过抽样统计。
**完成**：fuzz 10^4 轮零崩溃零挂起；边界值矩阵（2^19 位 ±1 等）8 格全过；并发交错后统计抽样仍入接受域；语料与最小复现入库。

### UNX-F37695 · 锁步回归：DRBG 全链剧本库

**完成**：剧本库 20 套建立全绿（测试镜像内可复现）；回归对照零漂移；篡改演示被捕获；剧本与判据交叉引用在册。
