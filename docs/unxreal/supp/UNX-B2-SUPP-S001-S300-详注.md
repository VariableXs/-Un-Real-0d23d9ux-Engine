> 本册为《UNX-B2-SUPP-S001-S300.md》账表的逐条详注配套卷：每条含【功能】【完成】两段定制正文，逐条合计 ≥300 字（机械复验在案）；判据号 UNX-B2-S###-J1 与账表一一对应；红线内嵌：零实机写（R-B2-002 随闸门补测）、异常零静默、日志异步不阻塞、NTFS 对照段覆盖；独立编号不占域账、240,000 守恒不动、F4801–F5600 零侵占。

## 批一 · ext4 只读体检面（S001–S020）

### UNX-B2-S001 · e2fsck 对齐总账只读位
【功能】建立 e2fsck 五阶段语义的只读对齐总账：把阶段 1（inode 扫描）、阶段 2（目录结构）、阶段 3（连接性）、阶段 4（引用计数）、阶段 5（块组汇总）各自的检查项、输入数据结构、判定规则逐项映射到 varix 侧 fs23/ext4 只读体检管线的对应模块，形成"e2fsck 做什么 ↔ 我们体检什么"的双列对照账。对账全程零写盘：所有检查在镜像副本上执行，产出物只有报告对象，不触碰任何源面。
【完成】十组含注入缺陷的 ext4 镜像逐一通过五阶段对齐器运行，映射错配（某阶段检查项在侧账中无对应或语义偏差）10/10 全部检出并出清单；对齐账落 docs 侧文档并在 ktest fast 片挂冒烟断言；写路径封锁断言全程绿色，零旁路写。判据 UNX-B2-S001-J1 闭合。

### UNX-B2-S002 · superblock 体检报告位
【功能】对 ext4 主/备超级块实施十项健康体检：魔数 0xEF53、块总数与块组数自洽、空闲块/空闲 inode 计数、特性旗三件套（compat/incompat/ro_compat）、块大小合法域、inode 容量字段、日志 inode 号、首数据块、预留 GDT 块数。任何一项越界即在体检报告中给出红级条目、字段原值、期望域与修复建议（只建议不执行）。备块组备份副本同步比对，主备漂移单列。
【完成】十组注入坏旗/计数漂移/魔数破坏的镜像体检，坏旗与计数类缺陷 10/10 检出，报告字段齐全；主备超级块漂移检出 3/3；JSON 报告回读一致断言过；全程零写、异常零静默，P95 体检时延在预算内。判据 UNX-B2-S002-J1 闭合。
### UNX-B2-S003 · 块组描述符体检位
【功能】逐块组扫描描述符表：对每一组校验空闲块计数、空闲 inode 计数与该组位图实况的双向自洽，目录数计数与 inode 用途归因一致性，以及描述符校验和（含 metadata_csum 语义）正确性。组数超千时启用分片扫描与进度诚实上报（已检/未检/跳过原因三态），任何一组漂移都不中断整体，缺陷进分级清单。全程镜像副本上执行，零写盘。
【完成】注入计数漂移的十镜像全部检出（10/10），漂移组号、期望值与实值三列清单齐备；千组级镜像分片扫描进度诚实断言过；metadata_csum 坏校验和检出 4/4；ktest fast 片收编冒烟。判据 UNX-B2-S003-J1 闭合。

### UNX-B2-S004 · inode 位图体检位
【功能】对每个块组的 inode 位图与 inode 表实施双向对账：正向从位图取"已用"位集合，反向从 inode 表逐枚举在用 inode（i_links>0 或 journal 在引），比对两集合差集；位图标已用但表内悬空、表内在用但位图漏标，各自成清单；同时校验位图块的自身归属与校验和。检出仅报告不修复。
【完成】注入位图脏位的十镜像 10/10 检出，脏位清单含组号、位偏移与两侧证据；漏标类与悬空类各自单独成列不混账；校验和坏块检出 3/3；与 S003 空闲计数账联签一致；零写红线全程绿。判据 UNX-B2-S004-J1 闭合。

### UNX-B2-S005 · 块位图体检位
【功能】块位图与组描述符空闲计数、与 extent 树实际占用三方对账：位图说空闲但被 extent 引用为漏标（高危，可致分配重叠），extent 未引但位图标已用为悬空标记（低危）；元数据块（GDT、位图、inode 表）必须在位图中标已用，缺标即红。体检产出 dup/漏标/悬空三清单，逐条带块号与引用方。
【完成】注入漏标与元数据缺标的十镜像 10/10 检出；三方对账口径与 S003/S004 联签零冲突；dup 块清单与 S007 重复块检测交叉验证一致；报告分级 red/yellow/green 全覆盖。判据 UNX-B2-S005-J1 闭合。

### UNX-B2-S006 · 目录树完整性体检位
【功能】自根目录起全树可达性遍历：每个目录项目标 inode 必须存在且类型字段相符；遍历终了后统计未被任何目录引用的孤儿 inode 清单；检测 "." 与 ".." 自洽、目录环（父指针成环）、路径深度异常三类结构病。大目录遍历走 htree 感知路径，遍历栈深度有硬顶防溢出。
【完成】注入断链与孤儿 inode 的十镜像 10/10 检出，孤儿清单带 inode 号、nlink 与尺寸；目录环检出 2/2 且不致死循环（环断器断言）；万级目录树遍历无栈溢出；与 S011 链接计数账交叉一致。判据 UNX-B2-S006-J1 闭合。

### UNX-B2-S007 · 重复块检测位
【功能】全镜像块占用归并扫描：把位图侧占用与 extent 侧引用汇成块→引用方倒排账，凡一块被两个及以上数据 extent 引用即报重复块，列出全部引用方（inode 号+逻辑块号）；元数据块与数据块的跨类重复单列红级。扫描用外部归并避免大镜像内存爆顶，内存硬顶有断言。
【完成】注入 dup 块的十镜像 10/10 检出且引用方列表完整无漏；跨类重复检出 3/3；8GB 镜像扫描内存峰值低于硬顶断言过；与 S005 位图账交叉一致零矛盾。判据 UNX-B2-S007-J1 闭合。

### UNX-B2-S008 · 坏块映射表体检位
【功能】对 ext4 保留坏块 inode（号 1）的映射内容与全盘坏块登记实施三查：坏块 inode 引用的块号必须落在合法域内、不得与在用数据 extent 交叠（悬空引用）、坏块登记集与卷面实际读失败探测集的差集报告（只读探测，不诱发写重定向）。产出悬空引用清单与登记/实况差集。
【完成】注入悬空引用的镜像 10/10 检出；登记集外块引用链逐条带 inode 路径回溯；只读探测在模拟坏扇样本上与登记比对差集正确；零写红线（绝不触发设备侧重映射写）断言绿。判据 UNX-B2-S008-J1 闭合。

### UNX-B2-S009 · ext4 特性旗兼容体检位
【功能】对超级块三旗组（compat/incompat/ro_compat）实施白名单体检：incompat 中出现侧账未实现旗即拒载并红报（绝不静默放行），ro_compat 未识别旗降级只读并黄报，compat 未识别旗登记不拦。旗语义表随版本冻结（Schema 先行），新增旗必须走旗表增补流程，杜绝"名字对得上就放行"。
【完成】注入未识别 incompat 旗的十镜像 10/10 拒载并出旗名报告，静默放行 0 起；ro_compat 降级路径断言过；旗表冻结版本与文档一致复核通过；误拒（白名单内旗被拦）0 起。判据 UNX-B2-S009-J1 闭合。

### UNX-B2-S010 · 日志区状态体检位
【功能】对 jbd2 日志区做只读体检：日志超级块魔数与块大小、事务序列号单调性、日志头尾指针自洽（tail 不得超前 head 越过环形缓冲区一周）、已提交未检查点事务的块引用与主树一致性预览。体检不重放、不回滚（零写声明），只输出"若重放将影响哪些块"的推演面，回放语义留给只读预演批。
【完成】注入序列号错序与指针越界的镜像 10/10 检出；推演面块清单与 checkpoint 语义模型一致；体检全程零写断言绿；日志区坏块与 S008 坏块账联签一致。判据 UNX-B2-S010-J1 闭合。

### UNX-B2-S011 · 链接计数体检位
【功能】对全盘 inode 的 i_links_count 与目录实引用数双向对账：正向从位图/表侧取声明计数，反向从目录树遍历累计实引用，差值即账目病；i_links=0 但目录仍引用为悬空项（红），i_links>0 零实引用为孤儿（黄，与 S006 孤儿清单同源不同视角）。计数溢出（>65000）单列。
【完成】注入孤高计数的十镜像 10/10 检出，清单带声明值/实算值/差值三列；与 S006 孤儿清单逐条对平零矛盾；溢出样本检出 2/2；大目录树（10 万目录项）对账时延在预算内。判据 UNX-B2-S011-J1 闭合。

### UNX-B2-S012 · 时间戳合理性体检位
【功能】对 atime/mtime/ctime/crtime 四时间戳实施合理性体检：早于 mkfs 时间的出生戳、晚于采样时刻的未来戳、ctime 晚于 mtime 的倒挂组合、扩展时间戳 extra 字段与低位字段拼接错位，各成异常清单。时区无关（一律 UTC 口径），2038 边界外的 34 位扩展编码解码断言单列。
【完成】注入倒挂与未来戳的十镜像 10/10 检出；34 位扩展编码回绕样本解码正确 3/3；mkfs 早于出生戳清单误报 0 起；报告含原始 64 位值与解码值双列备核。判据 UNX-B2-S012-J1 闭合。

### UNX-B2-S013 · 扩展属性体检位
【功能】对 xattr 存储三形态（inode 内残部、外置 xattr 块、ea_inode 大值链）实施只读体检：外置块校验和逐块验、ea_inode 引用链闭合性（大值不得再嵌套引用）、名值对长度域与实际剩余空间自洽、前缀合法性（user/trusted/security/posix 系统四类之外的私留前缀登记不拦）。坏块链只报不删。
【完成】注入坏校验和与断链 ea_inode 的十镜像 10/10 检出；嵌套引用病检出 2/2；三形态混合样本归因正确；与前缀四类账（S047）口径一致联签。判据 UNX-B2-S013-J1 闭合。

### UNX-B2-S014 · extent 树体检位
【功能】对 ext4 extent 树实施结构三查：深度合法域（0–5）、extent 长度域（叶内 ee_len 语义：未初始化 extent 与已初始化的分判）、节点指针越界（树内指针落点必须在本 fs 块域内且不构成环）。树遍历迭代化，5 层深树不递归爆栈；树根悬挂（i_block 区空但文件非空）红报。
【完成】注入越界叶与环引用的十镜像 10/10 检出；5 层深树样本遍历无栈溢出断言过；未初始化 extent 语义分判 3/3 正确；悬挂根检出 2/2。判据 UNX-B2-S014-J1 闭合。

### UNX-B2-S015 · 体检报告聚合位
【功能】把 S001–S014 各分项体检产出归并为全镜像统一报告：分级清单（red 阻断/yellow 可疑/green 通过）逐条带来源分项号、证据字段、建议动作（只建议）；同源缺陷双报去重（如 S005 与 S007 对同一块的双视角报告归并为一条双证据条目）；报告带镜像指纹（SHA-256 前 16 位）与体检时刻。
【完成】注入多类缺陷的复合镜像聚合报告分级无漏（漏分级检出 10/10 口径）；双报去重 5/5 正确归并；指纹与镜像实算一致；报告对象回读一致断言过。判据 UNX-B2-S015-J1 闭合。

### UNX-B2-S016 · 体检报告导出位
【功能】聚合报告落地为 JSON：schema 版本化（v1 冻结，新增字段只追加不改动既有键），导出后回读逐字段相等断言；超大清单（万条级）流式写出防内存爆顶；导出文件名含镜像指纹与时间戳；损坏导出文件（截尾）重读时显性报错，绝不静默半读。
【完成】字段缺失注入检出 10/10；万条级清单流式导出内存峰值硬顶内；截尾文件重读显性报错 3/3；schema v1 与 v1.1 追加字段向后兼容读通；导出路径规范与 _attic 归档口径一致。判据 UNX-B2-S016-J1 闭合。

### UNX-B2-S017 · 体检性能分位账
【功能】建立体检性能账面推算口径：以 1GB 标准镜像在开发机基准运行，记录 P50/P95 全程时延与各分项占比，形成随闸门补测的性能分位账（实机日以真机镜像复核）；性能回归红线：P95 劣化 >20% 即红账；账目只推算不定产线承诺，口径写明"开发机基准"防误读。
【完成】基准十轮运行 P95 <3s 达标，十轮方差在阈值内；分项占比表与代码路径热点一致；劣化注入实验（人为慢速层）触发红账 3/3；口径文档随账发布防歧义。判据 UNX-B2-S017-J1 闭合。

### UNX-B2-S018 · 体检零写红线位
【功能】把"体检全程零写"从纪律升级为机制：体检管线的块层句柄以只读模式打开（写路径 API 在该模式下直接 panic 而非降级），另设影子写探测层——任何绕过句柄的直写尝试（设备级、缓存级、元数据级三面）都会被拦截并显性上抛；零写断言作为每条体检判据的公共前置断言，不逐条重写。
【完成】旁路写注入检出 10/10（三面各取样）；只读句柄 panic 路径断言触发 5/5；公共断言与各分项判据挂接无遗漏（漏挂检出 0）；与存储探针门禁总红线（cmdline 显式开关制）口径一致联签。判据 UNX-B2-S018-J1 闭合。

### UNX-B2-S019 · 多镜像批量体检位
【功能】批量体检调度器：对 N 个镜像（上限 20）顺序体检并聚合总报告，单镜像失败不中断批次（失败镜像独立红账，批次继续），批次终态三态（全绿/有红完成/中断）显性输出；批量进度诚实（已检/在检/待检/失败四态）；批报告含逐镜像指纹与汇总分级统计。
【完成】20 镜像批次全量跑通，注入失败样本的镜像漏检 0 起；单镜像红不扩散断言过；中断恢复语义（断点续批）3/3；批报告统计数与逐镜像报告行数对平。判据 UNX-B2-S019-J1 闭合。

### UNX-B2-S020 · ktest 体检面收编位
【功能】把批一 S001–S019 全部判据收编进 ktest fast 片：每条判据至少一个可运行断言锚（镜像样本注入→体检→断言检出），收编表登记"判据号↔测试名↔样本组"三列映射；绕过检测：凡体检代码改动而对应断言未跑，门禁即红；收编不重写测试体，原断言原样入册。
【完成】19 条判据全部挂接 fast 片，绕过检出注入（删断言跑门禁）10/10 触发红；三列映射表与 ktest 实际清单对平零差；fast 片全量时长增量在预算内；批一收官，S001–S020 二十条全绿。判据 UNX-B2-S020-J1 闭合。

## 批二 · ext4 大文件与巨型文件面（S021–S040）

### UNX-B2-S021 · 大文件边界总纲位
【功能】立 >16TiB 巨型文件支持边界总纲：明确 extent 高 16 位语义（ee 块号高位拼接后 48 位物理块域 × 块大小 → 最大文件域）、inode v2 尺寸字段、页缓存索引 64 位贯通三件套的边界公式；对"支持到哪、拒止从哪开始"逐条成文，边界含糊处（如 32 位偏移 API 窄化点）显式列出而非默认通过。
【完成】边界公式十组采样值验算 10/10 一致；边界含糊点清单全部消除（每点有明确"支持/拒止/EINVAL"三选一裁定）；总纲与 S022–S040 各位实现口径联签一致；随闸门补测标记登记。判据 UNX-B2-S021-J1 闭合。

### UNX-B2-S022 · i_blocks 高位解析位
【功能】实现健壮的 i_blocks 高位字段解析：ext4 以 512 字节扇区计块账，大文件下 i_blocks 高位段（i_blocks_lo[2]+i_blocks_high[2]）拼接错误会静默把账缩水 2^32 倍；解析器显式拼双段、校验低位段回绕语义、对 feature 大文件旗缺席但高位非零的矛盾样本红报。
【完成】注入截断误读的样本 10/10 检出，误读值/正确值双列清单；矛盾样本（旗缺席高位非零）检出 3/3；与 statx 尺寸账联签一致；解析器单测覆盖 lo-only/lo+hi 全零/hi 满值三态。判据 UNX-B2-S022-J1 闭合。
