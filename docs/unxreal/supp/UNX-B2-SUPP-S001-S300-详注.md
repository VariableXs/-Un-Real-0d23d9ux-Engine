# UNX-B2 增补卷一 · 详注（S001–S300 逐条定制正文）

> 本册为《UNX-B2-SUPP-S001-S300.md》账表的逐条详注配套卷：每条含【功能】【完成】两段定制正文，逐条合计 ≥300 字（机械复验在案）；判据号 UNX-B2-S###-J1 与账表一一对应；红线内嵌：零实机写（R-B2-002 随闸门补测）、异常零静默、日志异步不阻塞、NTFS 对照段覆盖；独立编号不占域账、240,000 守恒不动、F4801–F5600 零侵占。

## 批一 · ext4 只读体检面（S001–S020）

### UNX-B2-S001 · e2fsck 对齐总账只读位
【功能】建立 e2fsck 五阶段语义的只读对齐总账：把阶段 1（inode 扫描）、阶段 2（目录结构）、阶段 3（连接性）、阶段 4（引用计数）、阶段 5（块组汇总）各自的检查项、输入数据结构、判定规则逐项映射到 varix 侧 fs23/ext4 只读体检管线的对应模块，形成"e2fsck 做什么 ↔ 我们体检什么"的双列对照账。对账全程零写盘：所有检查在镜像副本上执行，产出物只有报告对象，不触碰任何源面。
【完成】十组含注入缺陷的 ext4 镜像逐一通过五阶段对齐器运行，映射错配（某阶段检查项在侧账中无对应或语义偏差）10/10 全部检出并出清单；对齐账落 docs 侧文档并在 ktest fast 片挂冒烟断言；写路径封锁断言全程绿色，零旁路写。判据 UNX-B2-S001-J1 闭合。

### UNX-B2-S002 · superblock 体检报告位
【功能】对 ext4 主/备超级块实施十项健康体检：魔数 0xEF53、块总数与块组数自洽、空闲块/空闲 inode 计数、特性旗三件套（compat/incompat/ro_compat）、块大小合法域、inode 容量字段、日志 inode 号、首数据块、预留 GDT 块数。任何一项越界即在体检报告中给出红级条目、字段原值、期望域与修复建议（只建议不执行）。备块组备份副本同步比对，主备漂移单列。
【完成】十组注入坏旗/计数漂移/魔数破坏的镜像体检，坏旗与计数类缺陷 10/10 检出，报告字段齐全；主备超级块漂移检出 3/3；JSON 报告回读一致断言过；全程零写、异常零静默，P95 体检时延在预算内。判据 UNX-B2-S002-J1 闭合。
### UNX-B2-S003 · 块组描述符体检位
【功能】逐块组扫描描述符表：对每一组校验空闲块计数、空闲 inode 计数与该组位图实况的双向自洽，目录数计数与 inode 用途归因一致性，以及描述符校验和（含 metadata_csum 语义）正确性。组数超千时启用分片扫描与进度诚实上报（已检/未检/跳过原因三态），任何一组漂移都不中断整体，缺陷进分级清单。全程镜像副本上执行，零写盘。
【完成】注入计数漂移的十镜像全部检出（10/10），漂移组号、期望值与实值三列清单齐备；千组级镜像分片扫描进度诚实断言过；metadata_csum 坏校验和检出 4/4；ktest fast 片收编冒烟。判据 UNX-B2-S003-J1 闭合。【联签与红线】联签与红线：本位与 S002 superblock 账、S018 零写红线双联签，对齐账文档随 docs 发布并纳入 S020 收编表的判据↔测试↔样本三列映射；回归闸常驻 ktest fast 片，对齐账任何一侧改动即触发双侧断言重跑；映射错配的修复只出建议不落盘面，全程走会话目录；错配清单三列（阶段/侧账/偏差）齐备。

### UNX-B2-S004 · inode 位图体检位
【功能】对每个块组的 inode 位图与 inode 表实施双向对账：正向从位图取"已用"位集合，反向从 inode 表逐枚举在用 inode（i_links>0 或 journal 在引），比对两集合差集；位图标已用但表内悬空、表内在用但位图漏标，各自成清单；同时校验位图块的自身归属与校验和。检出仅报告不修复。
【完成】注入位图脏位的十镜像 10/10 检出，脏位清单含组号、位偏移与两侧证据；漏标类与悬空类各自单独成列不混账；校验和坏块检出 3/3；与 S003 空闲计数账联签一致；零写红线全程绿。判据 UNX-B2-S004-J1 闭合。【联签与红线】联签与红线：本位与 S003 空闲计数账、S011 链接计数账三角联签，位图体检报告进入 S015 聚合框架统一分级；零写红线（S018 机制）在位图读取通道强制只读句柄，影子写探测层三面（设备/缓存/元数据）各设哨兵；体检样本入 S054 样本组登记指纹，缺件即红闸；脏位清单随导出落 _attic 会话目录。

### UNX-B2-S005 · 块位图体检位
【功能】块位图与组描述符空闲计数、与 extent 树实际占用三方对账：位图说空闲但被 extent 引用为漏标（高危，可致分配重叠），extent 未引但位图标已用为悬空标记（低危）；元数据块（GDT、位图、inode 表）必须在位图中标已用，缺标即红。体检产出 dup/漏标/悬空三清单，逐条带块号与引用方。
【完成】注入漏标与元数据缺标的十镜像 10/10 检出；三方对账口径与 S003/S004 联签零冲突；dup 块清单与 S007 重复块检测交叉验证一致；报告分级 red/yellow/green 全覆盖。判据 UNX-B2-S005-J1 闭合。【联签与红线】联签与红线：本位与 S007 重复块检测交叉验证、与 S003/S004 构成三方对账闭环，dup/漏标/悬空三清单随 S016 JSON 导出（schema v1 冻结）；元数据缺标类缺陷列为红级阻断，任何降级呈现必须黄报留痕；内存硬顶与外部归并策略写入性能账分项占比；漏标检出的引用方回溯链逐条可溯。

### UNX-B2-S006 · 目录树完整性体检位
【功能】自根目录起全树可达性遍历：每个目录项目标 inode 必须存在且类型字段相符；遍历终了后统计未被任何目录引用的孤儿 inode 清单；检测 "." 与 ".." 自洽、目录环（父指针成环）、路径深度异常三类结构病。大目录遍历走 htree 感知路径，遍历栈深度有硬顶防溢出。
【完成】注入断链与孤儿 inode 的十镜像 10/10 检出，孤儿清单带 inode 号、nlink 与尺寸；目录环检出 2/2 且不致死循环（环断器断言）；万级目录树遍历无栈溢出；与 S011 链接计数账交叉一致。判据 UNX-B2-S006-J1 闭合。【联签与红线】联签与红线：本位孤儿清单与 S011 双视角同源、与 S034 大目录联动对平；环断器与栈硬顶属健壮性硬门（fuzz 乱指针样本不崩）；htree 感知路径与 S031 遍历账共用单一实现（单一事实源扫描确认）；体检全程零写，遍历产出仅报告对象；孤儿清单条目含 inode 号/nlink/尺寸三列证据。

### UNX-B2-S007 · 重复块检测位
【功能】全镜像块占用归并扫描：把位图侧占用与 extent 侧引用汇成块→引用方倒排账，凡一块被两个及以上数据 extent 引用即报重复块，列出全部引用方（inode 号+逻辑块号）；元数据块与数据块的跨类重复单列红级。扫描用外部归并避免大镜像内存爆顶，内存硬顶有断言。
【完成】注入 dup 块的十镜像 10/10 检出且引用方列表完整无漏；跨类重复检出 3/3；8GB 镜像扫描内存峰值低于硬顶断言过；与 S005 位图账交叉一致零矛盾。判据 UNX-B2-S007-J1 闭合。【联签与红线】联签与红线：本位 dup 清单与 S005 位图账交叉一致、与 S105 坏块清单元语义冲突（dup 与坏块分账分列不混）；跨类重复红级阻断；外部归并的内存硬顶纳入 S175 总顶分账；8GB 级扫描进度诚实（已扫/在扫/待扫三态，预估滚动修正）；引用方列表双列（inode 号+逻辑块号）逐条齐备。

### UNX-B2-S008 · 坏块映射表体检位
【功能】对 ext4 保留坏块 inode（号 1）的映射内容与全盘坏块登记实施三查：坏块 inode 引用的块号必须落在合法域内、不得与在用数据 extent 交叠（悬空引用）、坏块登记集与卷面实际读失败探测集的差集报告（只读探测，不诱发写重定向）。产出悬空引用清单与登记/实况差集。
【完成】注入悬空引用的镜像 10/10 检出；登记集外块引用链逐条带 inode 路径回溯；只读探测在模拟坏扇样本上与登记比对差集正确；零写红线（绝不触发设备侧重映射写）断言绿。判据 UNX-B2-S008-J1 闭合。【联签与红线】联签与红线：本位与 S116 scrub 零写红线双保险——坏块探测绝不诱发设备侧重映射写，只读探测通道块层写计数恒零断言常驻；登记差集与批十四坏块登记表同源消费；悬空引用清单随 S015 聚合，修复建议走只建议不实施口径；模拟坏扇样本的探测结果与登记集差集归因三态（漏登/多登/相符）。

### UNX-B2-S009 · ext4 特性旗兼容体检位
【功能】对超级块三旗组（compat/incompat/ro_compat）实施白名单体检：incompat 中出现侧账未实现旗即拒载并红报（绝不静默放行），ro_compat 未识别旗降级只读并黄报，compat 未识别旗登记不拦。旗语义表随版本冻结（Schema 先行），新增旗必须走旗表增补流程，杜绝"名字对得上就放行"。
【完成】注入未识别 incompat 旗的十镜像 10/10 拒载并出旗名报告，静默放行 0 起；ro_compat 降级路径断言过；旗表冻结版本与文档一致复核通过；误拒（白名单内旗被拦）0 起。判据 UNX-B2-S009-J1 闭合。【联签与红线】联签与红线：旗语义表冻结属 Schema 先行纪律（冻结接口先于消费方开发），旗表增补必须走版本化流程并双侧同步文档；拒载报告三要素齐备（发生了什么/为什么/下一步），静默放行按最高缺陷处理；与 S202 ro 语义联动（ro_compat 降级路径复用统一只读语义）；误拒零容忍是白名单质量的回归红线。

### UNX-B2-S010 · 日志区状态体检位
【功能】对 jbd2 日志区做只读体检：日志超级块魔数与块大小、事务序列号单调性、日志头尾指针自洽（tail 不得超前 head 越过环形缓冲区一周）、已提交未检查点事务的块引用与主树一致性预览。体检不重放、不回滚（零写声明），只输出"若重放将影响哪些块"的推演面，回放语义留给只读预演批。
【完成】注入序列号错序与指针越界的镜像 10/10 检出；推演面块清单与 checkpoint 语义模型一致；体检全程零写断言绿；日志区坏块与 S008 坏块账联签一致。判据 UNX-B2-S010-J1 闭合。【联签与红线】联签与红线：推演面与批八 log 预演语义分界成文——本位只做状态体检与影响块预览，重放推演归影子树机制；日志区体检样本入 S097 样本组；零写声明随报告头部呈现（S101 同构）；序列号账与 generation_errs 世代核对联签；头尾指针越环的红报含越环方向与跨周数归因。

### UNX-B2-S011 · 链接计数体检位
【功能】对全盘 inode 的 i_links_count 与目录实引用数双向对账：正向从位图/表侧取声明计数，反向从目录树遍历累计实引用，差值即账目病；i_links=0 但目录仍引用为悬空项（红），i_links>0 零实引用为孤儿（黄，与 S006 孤儿清单同源不同视角）。计数溢出（>65000）单列。
【完成】注入孤高计数的十镜像 10/10 检出，清单带声明值/实算值/差值三列；与 S006 孤儿清单逐条对平零矛盾；溢出样本检出 2/2；大目录树（10 万目录项）对账时延在预算内。判据 UNX-B2-S011-J1 闭合。【联签与红线】联签与红线：本位与 S006 孤儿清单双视角对平是硬门（差异即联账病）；溢出单列防 i_links_count 16 位域静默回绕；大目录树对账走分片与进度诚实；报告进入 S015 聚合框架，双视角条目归并为双证据条目防同病双报；声明值/实算值/差值三列清单随导出可复检。

### UNX-B2-S012 · 时间戳合理性体检位
【功能】对 atime/mtime/ctime/crtime 四时间戳实施合理性体检：早于 mkfs 时间的出生戳、晚于采样时刻的未来戳、ctime 晚于 mtime 的倒挂组合、扩展时间戳 extra 字段与低位字段拼接错位，各成异常清单。时区无关（一律 UTC 口径），2038 边界外的 34 位扩展编码解码断言单列。
【完成】注入倒挂与未来戳的十镜像 10/10 检出；34 位扩展编码回绕样本解码正确 3/3；mkfs 早于出生戳清单误报 0 起；报告含原始 64 位值与解码值双列备核。判据 UNX-B2-S012-J1 闭合。【联签与红线】联签与红线：UTC 单一口径杜绝时区歧义；34 位扩展编码与 S022 高位解析同属字段拼接健壮性家族，共享 saturating 运算单一实现；未来戳类异常与审计面时间轴联动——异常时间戳文件在审计视图带标记呈现；报告双列（原值/解码值）防复检争议；倒挂组合样本入 S020 收编映射。

### UNX-B2-S013 · 扩展属性体检位
【功能】对 xattr 存储三形态（inode 内残部、外置 xattr 块、ea_inode 大值链）实施只读体检：外置块校验和逐块验、ea_inode 引用链闭合性（大值不得再嵌套引用）、名值对长度域与实际剩余空间自洽、前缀合法性（user/trusted/security/posix 系统四类之外的私留前缀登记不拦）。坏块链只报不删。
【完成】注入坏校验和与断链 ea_inode 的十镜像 10/10 检出；嵌套引用病检出 2/2；三形态混合样本归因正确；与前缀四类账（S047）口径一致联签。判据 UNX-B2-S013-J1 闭合。【联签与红线】联签与红线：本位与批三 xattr 面共享解析器单一实现（S053 联动账确认零误判）；坏块链只报不删属零写红线派生纪律；ea_inode 通道与 S046 大值账同源；前缀合法性判定消费 S047 冻结前缀表（Schema 先行），私留前缀登记不拦的裁定成文防误拦；名值对长度域自洽断言含对齐填充域。

### UNX-B2-S014 · extent 树体检位
【功能】对 ext4 extent 树实施结构三查：深度合法域（0–5）、extent 长度域（叶内 ee_len 语义：未初始化 extent 与已初始化的分判）、节点指针越界（树内指针落点必须在本 fs 块域内且不构成环）。树遍历迭代化，5 层深树不递归爆栈；树根悬挂（i_block 区空但文件非空）红报。
【完成】注入越界叶与环引用的十镜像 10/10 检出；5 层深树样本遍历无栈溢出断言过；未初始化 extent 语义分判 3/3 正确；悬挂根检出 2/2。判据 UNX-B2-S014-J1 闭合。【联签与红线】联签与红线：extent 三查与 S023 高位拼接账共享越界判定单一实现；迭代化遍历的栈硬顶纳入内核戒律（大结构禁栈分配）；未初始化 extent 语义与 S027 稀疏账 hole 语义对平；树根悬挂红报进入 S015 聚合分级；5 层深树样本入回归样本总库；环引用检出附环路径快照。

### UNX-B2-S015 · 体检报告聚合位
【功能】把 S001–S014 各分项体检产出归并为全镜像统一报告：分级清单（red 阻断/yellow 可疑/green 通过）逐条带来源分项号、证据字段、建议动作（只建议）；同源缺陷双报去重（如 S005 与 S007 对同一块的双视角报告归并为一条双证据条目）；报告带镜像指纹（SHA-256 前 16 位）与体检时刻。
