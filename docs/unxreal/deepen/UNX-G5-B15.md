**功能语义**：90,000 行的守恒断言落地：逐条行数求和=90,000（15 批×6,000）机检、与批册/主册两处记载三方一致。守恒账的纪律与全域同构（AI-83 断言器三源对账的域内预演）——域内先自证守恒，波次闭账的全域断言才有域级可信基础。任何单条行数修订（深化期细化）必须走守恒重算：条内结构调整可以，批总和 6,000 不可以破。

### UNX-F27483 · F-ID 连续性断言
**功能语义**：F27201–F27500 的连续性机检：编号无跳号、无重号、无越段（本域段外编号零使用）。连续性是 ID 体系的法律——跳号意味着"有一个条目被悄悄吞了"，重号意味着两账打架，都是域账事故。断言器随每批收口跑、收官全量跑，结果入账。与主汇编册的对照断言：主册域节的编号序列与批册完全一致——两处账一个序。
**完成路径**：模型面立连续性检查器；机检面全段扫描+重号/跳号注入检出验证；断言面按 J1 复测——连续性机检全绿、重号跳号零命中、主册批册一致性断言过。
**风险与边界**：连续性约束本域段——与其他域段的边界（F27200 归 G4 段管、F27501 归本域后续批）在段表登记，边界模糊是撞号之源。
