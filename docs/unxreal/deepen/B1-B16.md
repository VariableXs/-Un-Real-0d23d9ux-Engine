### UNX-F4301 · bind mount 基础语义
- 域/批：B1/B16｜判据：UNX-F4301-J1 mount(source,dst,MS_BIND) 后经 dst 路径访问得源子树同内容（1,000 次逐内容 diff=0），bind 关系可查（绑定对账（src,dst）在册）｜纯功能行数：300 行（绑定主语义 120 + 内容一致性账 100 + 绑定对账 80；测试段不计）｜状态：[已深化]

- **语义边界**：只做 bind 基础语义与关系登记；不做只读组合（F4308 分账）；不做递归（F4304/F4305 分账）；"同内容"口径=读路径内容与元数据逐项一致（写穿透两侧同体——非快照拷贝）；bind 关系登记口径=树节点携带源指针（对账可枚举——非外挂表）。
- **依赖与嫁接源**：依赖 F4221 mount 树/F4227 枚举/F4241 五参调用面；被 F4302–F4318 全批与 C1/L1 消费；嫁接源为 Linux bind mount 语义（Linux 权威口径），只跟随。
- **风险与回退**：同体破（两侧内容漂移——bind 做成了拷贝）——内容 diff 断言（1,000 次逐字节），漂移即红；关系丢失（bind 对不在册——对账空转）——对账断言（建立后立即可查 10/10），丢失即红；遮蔽失效（dst 原内容漏出——覆盖不净）——遮蔽断言（F4303 联动注入），失效即红。

### UNX-F4302 · bind 子树内容一致性
- 域/批：B1/B16｜判据：UNX-F4302-J1 bind 建立后源侧与 bind 侧双路径读同一文件内容哈希逐次一致（1,000 次 diff=0），任一侧写对另一侧立即可见（可见性注入 100 次零滞后）｜纯功能行数：260 行（哈希对账 100 + 可见性账 90 + 滞后守卫 70；测试段不计）｜状态：[已深化]

- **语义边界**：只做一致性验证断言；不做 bind 建立（F4301 消费）；"立即"口径=写系统调用返回后即可见（F4229 原子律联动——无延迟重广播机制）；哈希口径=内容 SHA-256 与 size/mtime 元数据双对（元数据漂移也算红）。
- **依赖与嫁接源**：依赖 F4301 绑定/F4229 原子律；被 F4315/F4318 消费；嫁接源为 Linux bind 可见性语义，只跟随。
- **风险与回退**：读错位（bind 侧读到旧缓存——缓存键未含 bind 维度）——哈希 diff 断言（1,000 次），错位即红；写滞后（异步广播破同体）——可见性注入断言（100 次零滞后），滞后即红；元数据漂移（size 一致 mtime 偏——部分同步）——双对断言（内容+元数据逐项），漂移即红。
- 正文：实现路径分三步。第一步对账器：双路径哈希对账（源路径与 bind 路径同文件——内容 SHA-256+size+mtime 三元组逐次比对），1,000 次序列断言；第二步可见性：写注入器（源写→bind 读、bind 写→源读双向各 50 次），写返回即读断言（滞后注入零命中——写路径无异步环节声明）；第三步守卫：对账器挂 F4234 操作后自动核对钩（bind 存在期每次操作后双路径抽对账——万次零漏钩）。数据结构：哈希对账器 + 写注入器 + 自动核对钩。与现存内核衔接点：F4301 bind 项消费（对照账）；F4234 断言器复用（注记）。与 Windows 对照：Windows junction 可见性=名字解析即时（同构目标）；对照登记：双路径对账为域验收设施（NT 无等价账——投影不消费）。判据 UNX-F4302-J1 的复测方式：ktest 哈希 diff 1,000 次 + 可见性 100 次 + 自动钩留痕，宿主侧全跑。

### UNX-F4303 · bind 挂载点遮蔽语义

- **定位**：bind 挂载点的遮蔽与可逆——bind 建立后 dst 原内容被**遮蔽**（经 dst 访问得 bind 源内容——原目录项在 bind 层之下不可达：遮蔽是覆盖栈语义的自然结果，F4306 详账），原内容零泄漏（1,000 次访问零次漏出——泄漏即遮蔽破：解析器若在部分路径上穿透到下层就是 bug）；umount 后原内容**恢复逐字节一致**（可逆断言：bind 期间 dst 原内容未被触碰——遮蔽不等于修改，恢复即证明；逐字节对比含 mtime——bind 期间原内容只读不可变）。
- **语义边界**：只做遮蔽与可逆验证；不做 bind 建立（F4301 消费）；"零泄漏"口径=经 dst 全路径形态访问零次得原内容（含子路径/含 openat 相对路径）；"恢复"口径=内容+mtime 逐字节（bind 期间原内容 mtime 不变——不可变证明）。
- **依赖与嫁接源**：依赖 F4301 绑定/F4228 覆盖栈；被 F4306/F4314 消费；嫁接源为 Linux 挂载遮蔽语义，只跟随。
- **风险与回退**：遮蔽漏（子路径穿透——解析器遮蔽规则不全）——零泄漏断言（全路径形态 1,000 次），漏即红；误改原内容（bind 期间写入穿透到下层——遮蔽变修改）——不可变断言（umount 后逐字节+mtime 对比），误改即红；恢复缺失（umount 后内容异常——遮蔽层误删）——恢复断言（逐字节 diff=0），缺失即红。
- 正文：实现路径分三步。第一步遮蔽验证：dst 全路径形态访问集（直接/子路径/相对路径/openat 四形态×250 次）零次得原内容断言（遮蔽规则全路径覆盖）；第二步不可变证明：bind 前快照（内容+mtime）与 bind 期间原内容无访问通道声明+umount 后逐字节对比（diff=0——遮蔽层对下层零写入的结构性证明）；第三步可逆回归：bind→umount 循环 100 组（每次恢复 diff=0——可逆性稳定）。数据结构：快照对账器 + 全形态访问集 + 可逆循环账。与现存内核衔接点：F4301/F4228 消费（对照账）；umount 面 F4242 复用（注记）。与 Windows 对照：Windows 挂载点卸载恢复=卷卸载后原目录可见（同构目标）；遮蔽可逆为挂载语义通则（两侧同构）。判据 UNX-F4303-J1 的复测方式：ktest 全形态零泄漏 1,000 次 + 不可变逐字节 + 可逆循环 100 组，宿主侧全跑。
