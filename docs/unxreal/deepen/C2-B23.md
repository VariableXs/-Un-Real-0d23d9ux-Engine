### UNX-F9241 · 内存族 E 型总纲（地址空间错误面）
- 域/批：C2/B23｜判据：UNX-F9241-J1 地址空间错误面判据过，四类错误域（对齐/越界/耗尽/权限）逐格落账，与本批矩阵映射一致格过｜纯功能行数：400 行（四类错误域映射 140 + 逐格落账编排 130 + 矩阵一致对账 130）｜状态：[已深化]

- **定位**：本条是 B23 内存族错误矩阵批（F9242–F9259 各专条）的总纲：地址空间错误面按四类错误域（对齐/越界/耗尽/权限）归类落账，给出全批"构造→注入→检出→对账"的矩阵体例基线，是 E 型正反双判据（非法参数全 EINVAL、地址耗尽全 ENOMEM）的批级锚点。
- **语义边界**：只管错误域归类与矩阵体例基线；各专条格构造归 F9242–F9253；探针总成归 F9254；SIGSEGV 投递机制本体归 B11/A4（本批只铺观测面）；权限族矩阵全域归 B24（F9261 判定域）。
- **依赖与嫁接源**：嫁接 mmap(2)/mprotect(2)/brk(2) man-pages ERRORS 段错误码语义；锚定 B13 错误矩阵总装体例、B06/B07 深化册正判据面、A4 页表底座消费协议、B12 错误判定器出口。
- **风险与回退**：风险一为四域归类争议格（一构造可归两域，如未对齐带 MAP_FIXED 既是参数域又是地址域）——回退为归类优先级表冻结：参数合法域（EINVAL）先于资源域（ENOMEM）先于投递域（SIGSEGV），逐格唯一归属断言；风险二为总纲与专条重复铺设（总纲写入了专条构造细节）——回退为总纲只含映射表与体例声明、构造细节零进入（grep 构造词零命中断言）。
- **正文**：实现路径分三步：第一步立四类错误域映射表——对齐域（非页对齐 addr/old_addr → EINVAL）、越界域（坏指针 EFAULT、运动期越界 SIGSEGV）、耗尽域（地址空间/映射数/堆耗尽 → ENOMEM）、权限域（锁页越限 → EPERM），四域×触发条件×错误码三列十九行落账；第二步立逐格落账编排——F9242–F9253 十二条矩阵格按域归类登记（对齐域 F9243/F9245/F9246、越界域 F9242/F9250/F9251、耗尽域 F9244/F9247/F9248、权限域 F9249），每格带构造步骤与预期 errno 双列；第三步立矩阵一致对账——映射表与本批批注四错误域逐格比对，格号零缺零越（域外格计零断言），与 B13 错误矩阵总装体例同构对齐。与现存内核衔接点：错误码枚举出口与 B12 判定器单源；矩阵体例与 B13/B21 同构。与 Windows 对照：Windows 错误域族 ERROR_INVALID_PARAMETER/ERROR_NOT_ENOUGH_MEMORY/ERROR_ACCESS_DENIED 近似四域划分，映射注记随 F9256 对照格落账。判据 UNX-F9241-J1 的复测方式：ktest 三断言——映射表十九行齐、域归类零缺零越、矩阵一致对账全过。

### UNX-F9242 · mmap 坏 addr 提示与坏映射探针矩阵
- 域/批：C2/B23｜判据：UNX-F9242-J1 mmap addr 非法提示值注入判据过，提示值零副作用正判据格过，映射后访问坏区间 SIGSEGV 路径格过｜纯功能行数：360 行（提示值注入矩阵 130 + 零副作用正判据 110 + SIGSEGV 路径 120）｜状态：[已深化]

- **定位**：本条立 mmap 第一参数 addr 的提示语义错误矩阵：无 MAP_FIXED 时 addr 仅为内核选址提示（非法值零副作用不报错）与映射后访问坏区间的 SIGSEGV 投递路径——"提示值不报错、坏访问才报错"两面对照矩阵。
- **语义边界**：只管 addr 提示面与映射后越界访问观测；非对齐 EINVAL 面（带 MAP_FIXED）归 F9243；ENOMEM 面（地址耗尽）归 F9244；SIGSEGV 投递机制本体与 si_addr 逐格核归 F9250（本条消费其路径出口）。
- **依赖与嫁接源**：嫁接 mmap(2) man-pages "addr gives a hint" 段与 MAP_FIXED 语义对照；锚定 B06 mmap 母体选址器、A4 页表底座 #PF 路径、F9250 SIGSEGV 矩阵、F8921 参数探针。
- **风险与回退**：风险一为提示值被误当请求（内核强制落位提示地址致与 FIXED 语义混淆）——回退为提示格：无 FIXED 时实际落址与提示值解耦断言（落址页对齐且由分配器自选，落址不等于提示值亦合法）；风险二为越界访问误伤内核（红线零内核损坏承诺）——回退为越界注入全用户态界内构造（内核侧 VMA 查找空返回后才走投递路径），零内核态解引用断言。
- **正文**：实现路径分三步：第一步立提示值注入矩阵——无 MAP_FIXED 时 addr 仅为提示：注入未映射高位地址、已占用地址、零值三态，映射均成功且实际落址由内核分配器自选（落址与提示值解耦可观测），返回地址页对齐断言；第二步立零副作用正判据——提示值注入前后 VMA 链表快照零变化、提示值本身不建任何 VMA/PTE（映射计数恒定探针）、成功路径无半建态（失败零残留断言），三探针逐格核；第三步立 SIGSEGV 路径——映射成功后按返回地址+len 越界 8 字节访问（读/写双态），#PF 触发、si_addr=越界访问字节地址、SIGSEGV 投递至触发任务三点逐格断言（投递机制与 F9250 单源，本条只铺映射关联格）。与现存内核衔接点：地址分配器与 B06 mmap 母体单源；#PF 入口与 A4 页表底座联动。与 Windows 对照：VirtualAlloc 的 lpAddress 非 MEM_FIXED 时同为提示语义，错误域对齐；对照注记随 F9256 落账。判据 UNX-F9242-J1 的复测方式：ktest 三断言——三态提示注入表、VMA 快照零变化探针、越界 SIGSEGV 三点断言。

### UNX-F9243 · mmap 未对齐 EINVAL 矩阵
- 域/批：C2/B23｜判据：UNX-F9243-J1 非页对齐 addr/length 注入矩阵判据过，全 EINVAL 逐格检出（MAP_FIXED 时全 EINVAL），页掩码对账格过｜纯功能行数：360 行（非对齐注入矩阵 140 + EINVAL 逐格检出 110 + 页掩码对账 110）｜状态：[已深化]

- **定位**：本条立 mmap 非页对齐参数的 EINVAL 矩阵：MAP_FIXED 置位时 addr 非页对齐全 EINVAL（上游硬规则）、无 FIXED 时 addr 非对齐为合法提示、length 非页倍数上取整不报错——三分格对账与页掩码核算格。
- **语义边界**：只管对齐域 EINVAL 与取整语义；提示值零副作用归 F9242；耗尽域归 F9244；页大小常量与 2M 大页边界值深化归 F9251（本条只跑 4K 基准页）。
- **依赖与嫁接源**：嫁接 mmap(2) man-pages EINVAL 段（"MAP_FIXED and addr is not a multiple of the page size"原文语义）；锚定 A4 PAGE_SIZE 掩码、B06 母体取整函数、F9251 边界值格。
- **风险与回退**：风险一为 length 取整语义漂移（实长不可观测致取整静默丢失）——回退为实长探针格：映射后 VMA 实长（快照）==上取整等式逐格断言；风险二为无 FIXED 非对齐 addr 被误判 EINVAL（与 FIXED 格混流）——回退为旗标维双列矩阵（FIXED 有/无分列），检出表逐列互斥断言。
- **正文**：实现路径分三步：第一步立非对齐注入矩阵——addr 维度：页界+1/+255/页界-1 三态 × MAP_FIXED 有无双旗标共六格，length 维度：非页倍数（len=1、len=4095）两格，合计八格注入表；第二步立 EINVAL 逐格检出——带 MAP_FIXED 且 addr 非对齐三格全 -EINVAL（上游硬规则逐格核）；无 FIXED 的 addr 非对齐三格不报错（提示语义，返回对齐落址正判据）；length 非倍数两格不报 EINVAL（内核向上取整，映射实长=上取整到页界，快照可观测实长），八格检出表落账；第三步立页掩码对账——成功路径返回地址满足 (ret & (PAGE_SIZE-1))==0、实长满足对齐上取整等式，与 B06 母体取整函数单源复测。与现存内核衔接点：页掩码与 A4 页表底座 PAGE_SIZE 常量单源；EINVAL 出口与 B12 错误判定器同函数。与 Windows 对照：SYSTEM_INFO.dwPageSize 取整等价，VirtualAlloc 非对齐基址自动选页界；对账注记随 F9256。判据 UNX-F9243-J1 的复测方式：ktest 三断言——八格注入表、EINVAL 检出逐格断言、页掩码等式单源复测。

### UNX-F9244 · mmap ENOMEM 矩阵（超限/无空间）
- 域/批：C2/B23｜判据：UNX-F9244-J1 地址空间耗尽注入判据过，全 ENOMEM 格过，max_map_count 上限格过，与 RLIMIT_AS 联动格过｜纯功能行数：360 行（地址空间耗尽注入 130 + max_map_count 上限 120 + RLIMIT_AS 联动 110）｜状态：[已深化]

- **定位**：本条立 mmap ENOMEM 耗尽域矩阵：用户地址空间无空洞、max_map_count 映射数上限、RLIMIT_AS 地址空间限值三耗尽源逐格注入——全 ENOMEM 单码出口与限值联动回环格。
- **语义边界**：只管 mmap 耗尽域；munmap/mprotect 区间不存在 ENOMEM 归 F9245；mremap/madvise ENOMEM 归 F9247/F9248；rlimit 表本体与三输入判定归 B19（本条消费限值）；malloc 失败消费链归 F9259。
- **依赖与嫁接源**：嫁接 mmap(2) man-pages ENOMEM 段（"No memory available / maximum number of mappings exceeded"原文语义）；锚定 B19 rlimit 表（RLIMIT_AS）、B06 VMA 计数器、B12 判定器 ENOMEM 出口。
- **风险与回退**：风险一为耗尽注入污染测试环境（大块映射残留致后续用例异常）——回退为耗尽套件自清理：每轮结束全额 munmap 回收+资源快照零残留断言；风险二为 max_map_count 冻结值与他格测试布局冲突（小块映射计数提前触限）——回退为计数格独立测试任务隔离+冻结值入批级常量账单。
- **正文**：实现路径分三步：第一步立地址空间耗尽注入——测试进程以大步长（256GiB）连续匿名映射直至地址空间无空洞，末次 mmap 返回 -ENOMEM（上游语义：无可用地址区间），耗尽前末次成功与首次失败夹逼可观测，失败后 munmap 单格即恢复可映射（资源释放回环断言）；第二步立 max_map_count 上限格——循环小块 mmap（4KiB 粒度）计数至冻结上限（本内核以常量替代 /proc/sys/vm/max_map_count，冻结值落账），超限次映射 -ENOMEM 且计数器与实际 VMA 数逐次一致（探针核对），munmap 后计数回退可再映射；第三步立 RLIMIT_AS 联动——setrlimit(RLIMIT_AS, 64MiB) 后单次大映射（超限值）直接 -ENOMEM（非部分成功），拆分小映射累计触限同样 -ENOMEM，限值恢复后同请求成功（联动回环），与 B19 rlimit 表限值单源对账。与现存内核衔接点：VMA 计数与 B06 母体单源；限值判定与 B19 资源矩阵对账。与 Windows 对照：无 max_map_count 等价（内部 VA 位图管理），ERROR_NOT_ENOUGH_MEMORY 近似耗尽域；注记随 F9256。判据 UNX-F9244-J1 的复测方式：ktest 三断言——耗尽夹逼断言、上限计数逐次核对、RLIMIT_AS 联动回环。

### UNX-F9245 · munmap/mprotect 坏区间矩阵
- 域/批：C2/B23｜判据：UNX-F9245-J1 未对齐区间注入判据过，munmap 全 EINVAL 格过，mprotect 坏 prot 全 EINVAL 格过，区间不存在全 ENOMEM 格过｜纯功能行数：360 行（未对齐区间注入 120 + mprotect 坏 prot 矩阵 120 + 区间不存在 ENOMEM 120）｜状态：[已深化]

- **定位**：本条立 munmap/mprotect 坏区间错误矩阵：munmap 未对齐 addr EINVAL、mprotect 坏 prot 位 EINVAL、区间不存在 ENOMEM 三格——第二调用族（区间参数面）的错误出口全集。
- **语义边界**：只管 munmap/mprotect 两调用错误面；mmap 参数面归 F9242/F9243/F9244；PROT_NONE 置后的访问 SIGSEGV 归 F9250；区间查找数据结构本体归 B06（本条消费不重铺）。
- **依赖与嫁接源**：嫁接 munmap(2)/mprotect(2) man-pages ERRORS 段（EINVAL/ENOMEM 行原文）；锚定 B06 VMA 查找树、F9250 投递矩阵（PROT_NONE 联动）、B12 判定器。
- **风险与回退**：风险一为部分重叠区间判定歧义（区间一半映射一半空洞时行为分岔）——回退为混合区间格显式冻结：本内核任一页未映射即整区间拒绝（判据权威面），构造步骤与断言落账；风险二为坏 prot 位误通过（未定义位静默忽略）——回退为 prot 合法集白名单校验（R/W/X/NONE 四值组合掩码），集外位一律 EINVAL 断言。
- **正文**：实现路径分三步：第一步立未对齐区间注入——munmap(addr+1) 与 mprotect(addr+2048) 未对齐 addr 注入全 -EINVAL（两调用 addr 均要求页界，上游语义逐格核），munmap len 非页倍数不报错对照格（上取整语义，与 F9243 mmap 取整同族）单列；第二步立 mprotect 坏 prot 格——prot 注入三态：合法集外位（PROT_READ|0x80）、全 F 掩码、负值，全 -EINVAL（合法集只有 R/W/X/NONE 四值组合，白名单校验），PROT_NONE 合法格正判据（置位成功且后续访问走 F9250 投递路径单源）；第三步立区间不存在 ENOMEM——munmap/mprotect 注入全未映射区间与跨映射+空洞混合区间，全 -ENOMEM（判据冻结面：任一页未映射即整区间拒绝），部分重叠格构造单列断言，区间查找与 B06 查找树同函数。与现存内核衔接点：区间查找与 B06 VMA 查找树单源；prot 位校验与 B02 旗标校验同函数族。与 Windows 对照：VirtualProtect 坏参数 ERROR_INVALID_PARAMETER、未提交页 ERROR_NOT_COMMITTED；映射注记随 F9256。判据 UNX-F9245-J1 的复测方式：ktest 三断言——未对齐注入表、坏 prot 三态格、区间不存在 ENOMEM 表。

### UNX-F9246 · brk 坏值矩阵（越下界 EINVAL）
- 域/批：C2/B23｜判据：UNX-F9246-J1 低于初始堆底注入判据过，全 EINVAL 格过，返回新 break 正判据格过，与 B07 brk 档对账一致｜纯功能行数：320 行（越下界注入 110 + 正判据回环 100 + B07 对账 110）｜状态：[已深化]

- **定位**：本条立 brk 坏值矩阵：低于初始堆底请求全 EINVAL、成功路径返回新 break 正判据、边界夹逼（恰等堆底合法、低于堆底拒绝）——B07 brk 档正判据的反向注入面。
- **语义边界**：只管 brk 错误面与正判据回环；sbrk 封装语义归 libc 消费面（F9259 联动登记）；堆页表扩缩机制本体归 B07 母体（本条对账不重铺）；存活对象保护归 libc 分配器消费面。
