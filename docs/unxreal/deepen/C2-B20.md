### UNX-F9181 · setuid/setreuid 语义档（三身份翻转协议）
- 域/批：C2/B20｜判据：UNX-F9181-J1 翻转协议判据过，特权根全翻格过，非特权互转格过，保存身份规则逐格过｜纯功能行数：400 行（三身份翻转状态机 150 + 特权根全翻与非特权互转 130 + 保存身份规则 120）｜状态：[已深化]

- **定位**：本条是身份族（F9182–F9187/F9193–F9195 各专条）总纲与 setuid/setreuid 语义档：进程三身份（ruid/euid/suid）翻转协议——特权根（euid==0）任意全翻、非特权只能在现值集合内互转 euid，setuid 程序安全模型（保存身份规则）的地基格。
- **语义边界**：只管 uid 翻转协议；setresuid/setfsuid 归 F9182；gid 族归 F9183（对称协议引用不重铺）；EPERM 矩阵归 F9184；补充组集归 F9185；exec s 位联动归 F9195（C1 联签）；C1 身份字段消费协议归 F9193。
- **依赖与嫁接源**：嫁接 setuid(2)/setreuid(2) man-pages（三身份定义、特权/非特权两分支、setreuid -1 占位原文）；锚定 B05 三身份档（语义基准对账）、F9193 消费协议（C1 身份字段单源）、F9184 EPERM 矩阵、F9195 exec 联动。
- **风险与回退**：风险一为非特权降权后不可逆丢权（suid 未保住致回不去特权身份）——回退为保存身份规则硬规则：非特权 setuid(x) 只动 euid 且 suid 保持原特权身份（经典 setuid 程序往返 euid:0→x→0 全过），状态机断言；风险二为 setreuid -1 占位漏处理（-1 被当 uid 0xFFFFFFFF 写入）——回退为占位格：ruid=-1 或 euid=-1 各自保留现值，uid_t 无符号域负值哨兵注入。
- **正文**：实现路径分三步：第一步立翻转状态机——task 身份三元组（ruid/euid/suid u32×3），setuid 分支伪代码冻结：euid==0 → 三元组全=x；else x∈{ruid,suid} → euid=x，else -EPERM；setreuid(r,e) 双参独立分支（-1 保留/非特权 e 只可取 r 或 s），判定表 12 格落账；第二步立特权与非特权双面——特权根全翻：setuid(100) 后三身份全 100（不可逆丢弃特权对照格）；非特权互转：初始 (100,0,100)（s 位程序态）setuid(100)→(100,100,100)、setreuid(-1,0)→euid 回 0 成功（suid 规则红利），双面逐格断言；第三步立保存身份规则——suid 三用途格：①非特权 euid 可随时设回 suid ②setreuid 换 ruid 时 s 作合法源 ③exec 后 suid=ruid 惯例（F9195 联动声明），三用途探针各一断言。与现存内核衔接点：身份字段与 C1 进程对象单源（F9193 协议）。与 Windows 对照：Windows 令牌模型无三身份对偶（TokenUser 单一+模拟 Impersonation 分层），setuid 程序范式无直接等价（服务账户/RunAs 另族）；本条按 Linux 上游冻结。判据 UNX-F9181-J1 的复测方式：ktest 三断言——12 格判定表、特权/非特权双面、suid 三用途探针。

### UNX-F9182 · setresuid/setfsuid 语义档
- 域/批：C2/B20｜判据：UNX-F9182-J1 三参数独立翻转判据过，-1 占位不变语义格过，fsuid 特权限制格过｜纯功能行数：360 行（setresuid 三参独立翻转 130 + -1 占位语义 110 + setfsuid 特权限制 120）｜状态：[已深化]

- **定位**：本条立 setresuid（ruid/euid/suid 三参独立翻转，-1 占位）与 setfsuid（文件系统 uid，VFS 权限检查用身份，返回旧值）语义档——三身份模型的完整操作面（F9181 的扩展操作族）。
- **语义边界**：只管两操作语义；基础三身份模型与 setuid/setreuid 归 F9181（本条消费其状态机）；EPERM 细则归 F9184；fsuid 在 VFS 权限检查的消费点归 B02（挂点声明）；setfsuid 返回值约定差异（恒返旧值零错误路径）注记本格。
- **依赖与嫁接源**：嫁接 setresuid(2) man-pages（-1 占位、非特权新值须∈{现 r,e,s} 规则原文）与 setfsuid(2) 段（无权限检查例外、返回旧值语义）；锚定 F9181 三元组状态机、F9193 C1 字段单源、B02 open 权限检查（fsuid 消费挂点）、F9184 矩阵。
- **风险与回退**：风险一为 -1 占位与合法 uid 值混淆（uid_t 全 1 值边界）——回退为占位格：uid 值域 [0,65535] 冻结声明（0xFFFFFFFF 恒为占位哨兵永不作真实 uid），边界注入断言；风险二为 setfsuid 零错误返回被误判（非法值静默不变无 errno 可查）——回退为判别格：调用后回读 fsuid 判实际生效（返回旧值≠设置成功），非法值注入回读不变断言。
- **正文**：实现路径分三步：第一步立三参独立翻转——setresuid(r,e,s) 八组合探针（-1 组合×3+全指定+部分指定），特权根任意组合全过、非特权新值须∈{现 r,e,s} 全集校验（违反全 EPERM 归 F9184），逐组合终态断言；第二步立 -1 占位格——setresuid(-1,200,-1) 后 ruid/suid 原值保持 euid=200，三占位独立声明（任一 -1 只影响自身位），uid=0xFFFFFFFF 边界哨兵（永不作真实 uid）断言；第三步立 setfsuid——old=setfsuid(200) 返回旧 fsuid，VFS 权限检查消费 fsuid 挂点声明（B02 open 探针：fsuid=200 后访问 uid=200 文件过/uid=0 文件拒，桩断言），非特权非法值（500∉{r,e,s}）静默不变回读判别、特权任意值过对照。与现存内核衔接点：fsuid 挂点与 B02 权限检查单源；三元组与 F9181/F9193 单源。与 Windows 对照：Windows 无 fsuid 对偶（令牌一次性绑定访问检查）；对账注记。判据 UNX-F9182-J1 的复测方式：ktest 三断言——八组合矩阵、-1 占位与哨兵、fsuid 回读判别。

### UNX-F9183 · setgid/setregid/setresgid 语义档
- 域/批：C2/B20｜判据：UNX-F9183-J1 组身份三操作判据过，与 uid 族翻转协议对称可观测，补充组集零影响声明格过｜纯功能行数：360 行（setgid/setregid 130 + setresgid 与 uid 对称 120 + 补充组集零影响 110）｜状态：[已深化]

- **定位**：本条立组身份三操作语义档：setgid/setregid/setresgid 与 uid 族（F9181/F9182）协议逐条对称（egid==0 特权分支、非特权集合内互转、-1 占位）——组身份面操作号全铺设，对称性即判据。
- **语义边界**：只管 gid 三操作；补充组集 getgroups/setgroups 归 F9185（本条零影响声明对接面）；EPERM 细则归 F9184；三身份基准归 B05（对账）；umask 归 F9186。
- **依赖与嫁接源**：嫁接 setgid(2)/setregid(2)/setresgid(2) man-pages（对称协议原文）；锚定 F9181/F9182 uid 状态机（对称对账单源）、F9185 补充组集、F9193 C1 字段、B05 三身份档。
- **风险与回退**：风险一为对称性破缺（gid 面 -1 占位或特权分支与 uid 行为漂移）——回退为对称格：uid/gid 同构 12 格判定表并排跑（同输入模式双面终态一致），差一格 fail；风险二为 setgid 误动补充组集（主组翻转换补充组清空）——回退为零影响格：翻转前后 getgroups 读数逐项一致断言。
- **正文**：实现路径分三步：第一步立 setgid/setregid——rgid/egid/sgid 三元组建账（C1 字段），setgid 分支：egid==0 全翻/非特权 x∈{r,s}→e=x，setregid(r,e) 双参 -1 占位分支，与 F9181 同构判定表并排落账；第二步立 setresgid 对称——三参独立翻转八组合探针与 F9182 同构，特权/非特权双面对排断言（对称性声明：uid/gid 判定同函数参数化，grep 单源核）；第三步立补充组集零影响——预置补充组 {10,20,30}，setgid(40)/setresgid(-1,40,-1) 翻转后 getgroups 回读 {10,20,30} 逐项一致（主组与补充组正交声明），与 F9185 对接点登记。与现存内核衔接点：gid 字段与 C1/F9193 单源；对称实现与 uid 判定同函数。与 Windows 对照：Windows TokenGroups 即补充组集（TokenPrimaryGroup 仅 POSIX 子系统语义用），组翻转无 setgid 对偶（CreateProcessAsUser 换令牌）；对照表落账。判据 UNX-F9183-J1 的复测方式：ktest 三断言——gid 判定表与 uid 并排、八组合对称探针、补充组零影响回读。

### UNX-F9184 · 身份翻转 EPERM 矩阵（特权规则）
- 域/批：C2/B20｜判据：UNX-F9184-J1 非特权提限全 EPERM 矩阵判据过，逐码与 Linux 语义一致，特权翻转零残留格过｜纯功能行数：340 行（EPERM 矩阵逐码 130 + Linux 语义一致核 100 + 特权翻转零残留 110）｜状态：[已深化]

- **定位**：本条立身份族权限矩阵总装：setuid/setreuid/setresuid/setfsuid/setgid 族的非特权提限注入全 EPERM、特权翻转零残留（翻转后三元组无旧身份尾巴）——B24 特权矩阵域在身份面的分域落点。
- **语义边界**：只管身份族 EPERM 面；矩阵域总装归 B24（本条分域登记对接）；特权位判据源归 B03；nice 面 EACCES/EPERM 分立归 F9170（对照格）；setgroups 特权限制归 F9185。
- **依赖与嫁接源**：嫁接 setuid(2) 等 man-pages ERRORS 段（EPERM 语义原文）；锚定 B24 特权矩阵域（分域登记）、B03 特权位、F9181/F9182/F9183 状态机（非法侧出口）、B13 错误映射账（对账）。
- **风险与回退**：风险一为特权判定时点错误（翻转前后特权态缓存失真致越权放行）——回退为时点格：特权判据每次调用时点求值（降权后提限全 EPERM 时序断言，F9168 棘轮同构）；风险二为零残留破坏（特权 setuid(100) 后 suid 残留 0 致非特权回提）——回退为零残留格：特权全翻后三元组逐一断言（r=e=s=x 全等），残留扫描探针。
- **正文**：实现路径分三步：第一步立 EPERM 矩阵——四操作×非特权非法注入全 EPERM（setuid 值域外/setreuid 非法组合/setresuid 新值∉{r,e,s}/setfsuid 静默例外单列注记），16 格矩阵逐格断言；第二步立一致核——与 man-pages ERRORS 段逐码比对表（码名/触发条件/返回路径三列），与 B13 映射账对账一致（零分歧声明），与 F9170 nice 面两码分立对照注记（身份面无 EACCES 单一 EPERM）；第三步立零残留——特权 setuid(100) 后 (100,100,100) 全等断言、特权 setresgid(0,0,0) 回特权全翻断言、降权→提限 EPERM 时序三连断言（棘轮同构），残留扫描（三元组任一位≠目标即 fail）。与现存内核衔接点：特权位与 B03 时点求值单源；分域登记与 B24 体例单源。与 Windows 对照：Windows AdjustTokenPrivileges 特权开关模型与身份翻转异构（令牌整体替换 vs 三元组逐位）；差异账落账。判据 UNX-F9184-J1 的复测方式：ktest 三断言——16 格 EPERM 矩阵、比对表三列、零残留时序三连。

### UNX-F9185 · getgroups/setgroups 语义档（补充组集）
- 域/批：C2/B20｜判据：UNX-F9185-J1 组集读写回环判据过，size 不足全 EINVAL 格过，特权限制格过｜纯功能行数：340 行（组集读写回环 120 + size 不足 EINVAL 110 + setgroups 特权限制 110）｜状态：[已深化]

- **定位**：本条立补充组集语义档：getgroups（读：size=0 探数/list 容量写入）与 setgroups（写：特权限定）——VFS 组权限检查的补充身份源（access 检查遍历集合），与 F9183 主组正交面。
- **语义边界**：只管组集读写；组权限检查消费点归 B02/B1（挂点声明）；NGROUPS_MAX 上限冻结值（16）落账本格；setgroups 特权判据归 B03/F9184 联动；组号值域与 gid 同域。
- **依赖与嫁接源**：嫁接 getgroups(2)/setgroups(2) man-pages（size=0 返回组数、list 过小 EINVAL、NGROUPS_MAX 上限原文）；锚定 F9183 主组正交、B02 权限检查挂点（fsuid 同挂点族）、F9193 C1 字段、B03 特权位。
- **风险与回退**：风险一为 size=0 与小 list 语义混淆（size=0 是探数不算错）——回退为双态格：size=0 → 返回组数（不写 list 不报错）、0<size<组数 → -EINVAL（拒绝不截断），两态对照断言；风险二为组集上限溢出（setgroups 超 NGROUPS_MAX 写穿）——回退为上限格：超限 -EINVAL（setgroups 面上游语义），边界 16 恰好过/17 拒双断言。
- **正文**：实现路径分三步：第一步立读写回环——setgroups({10,20,30}) → getgroups(size=8,list) 回读 {10,20,30} 且返回 3，逐项有序一致（集合语义落账有序扫描），size=0 探数返回 3 断言；第二步立 EINVAL 矩阵——getgroups(size=1) 组集 3 项 → -EINVAL、size=2/3 边界（2 拒 3 过）双断言、setgroups 空集合法（清空组集回读零项）三格落账；第三步立特权限制——非特权 setgroups 任意注入全 -EPERM（与 F9184 矩阵联动行）、特权全过（对照列），VFS 挂点声明：access/open 权限检查遍历补充组集（B02 探针：文件组 20 权限 r--，uid 不同但组集含 20 → 读过），桩断言落账。与现存内核衔接点：组检查与 B02 权限挂点单源；上限 NGROUPS_MAX=16 冻结。与 Windows 对照：Windows TokenGroups 上限 1024 语义族近似、无 size=0 探数约定（GetTokenInformation 两次调用法）；对账注记。判据 UNX-F9185-J1 的复测方式：ktest 三断言——回环与探数、EINVAL 边界双态、特权对照与 VFS 桩。

### UNX-F9186 · umask 语义档（继承与返回旧值）
- 域/批：C2/B20｜判据：UNX-F9186-J1 返回旧值判据过，fork/exec 继承可观测，与 open 创建模式联动格过｜纯功能行数：280 行（返回旧值回环 100 + fork/exec 继承 90 + open 创建模式联动 90）｜状态：[已深化]

- **定位**：本条立 umask() 语义档：设置进程文件模式创建掩码并返回旧值（单段原子无错误路径）、fork/exec 原样继承、open/mkdir 创建时 mode 与掩码求交——创建期权限默认值的单一控制点。
- **语义边界**：只管 umask 本体；open mode 求交消费点归 B02（挂点联动）；权限检查面（读文件时不适用 umask）分界声明；umask 无读入口（读须借写往返）注记本格。
- **依赖与嫁接源**：嫁接 umask(2) man-pages（返回旧值、mode&07777 掩码、"always succeeds"原文）；锚定 B02 open 语义档（创建模式联动挂点）、B04 fork/execve 继承、F9193 C1 字段、B05 基准。
