- **风险与回退**：风险一为判定域三条件漏一（只校验未开漏越界，或负值漏判走无符号查表误崩）——回退为三条件伪代码冻结：fd<0→EBADF（符号短路）、fd≥上限→EBADF（越界短路）、槽位未开或已关→EBADF（查表），三支路各设专格注入，缺一支路即 fail；风险二为"判定先于操作"被绕过（先解引用对象后验 fd，坏 fd 触发空指针路径）——回退为判序探针：坏 fd 注入时对象解引用计数探针必须为零（未触对象即返回），判序违例即标红。

### UNX-F9222 · dup/dup2/dup3 坏 fd 矩阵

- **语义边界**：只管 dup 族注入；dup3 O_CLOEXEC 到期语义归 B16 F9113；F_DUPFD 复制命令面归 F9102；EBADF 判定域协议归 F9221 总纲；dup2 原子性正判据归 B08 母体。
- **依赖与嫁接源**：嫁接 dup(2) man-pages ERRORS 段（EBADF "oldfd isn't an open file descriptor"与 newfd 越界"out of allowable range"两行原文）与 dup2 equal-fd 段原文；锚定 B08 dup 族母体正判据、B16 F9113 dup3 格、F9221 判定域。
- **风险与回退**：风险一为 newfd 坏值码面漂移（newfd 越界误报 EINVAL 而上游实报 EBADF）——回退为码面冻结格：newfd 越限注入实测 EBADF（与 man-pages "newfd was out of allowable range"行对齐），与 EINVAL 差异注记单列防漂移；风险二为 equal-fd 特例误开新表（dup2(3,3) 误分配新引用致计数漂移）——回退为特例格：equal-fd 路径引用计数不变断言（对象计数前后同值）且 close-on-exec 旗标清理例外逐格断言。
- **正文**：实现路径分三步：第一步立坏值注入矩阵——oldfd 三维（负/未开/已关）×三调用九格全 EBADF；newfd 二维注入×dup2/dup3 双调用：越上限全 EBADF（码面与 Linux 对齐注记）、newfd 未开但合法则正常分配（正判据对照），矩阵表落账；第二步立逐格检出核——矩阵表（构造/预期/实测三列）逐格核对零混码，与 F9221 三条件判定域对格（每格归因登记入三条件之一），检出率全中断言；第三步立 equal-fd 正反格——dup2(3,3) 返回 3 且引用计数不变（正判据，旗标清理例外注记）、dup2(坏值,坏值) 同值注入返回 EBADF 不开表（反判据）、dup3(3,3,*) 返回 EINVAL（与 dup2 差异对照，引 B16 F9113 格互认）三格并列落账。与现存内核衔接点：与 B08 dup 族判定函数单源。与 Windows 对照：Windows 无 dup 等价（DuplicateHandle 坏句柄 ERROR_INVALID_HANDLE）；映射随 F9236。判据 UNX-F9222-J1 的复测方式：ktest 三断言——九格加 newfd 组全检出、归因表零混码、equal-fd 三格并列。

### UNX-F9223 · pipe 系统调用错误矩阵（EFAULT/EMFILE/ENFILE）
- 域/批：C2/B22｜判据：UNX-F9223-J1 三错误码注入矩阵判据过，坏 pipefd 指针全 EFAULT 格过，逐码与 Linux 一致｜纯功能行数：340 行（三码注入矩阵 120 + 出参回滚格 110 + 逐码一致核 110）｜状态：[已深化]

- **语义边界**：只管 pipe 面三码；管道读写错误（EPIPE/EAGAIN）归 F8966/B06 管道母体；pipe2 扩展旗标归后续扩号；EMFILE/ENFILE 细则矩阵归 F9224/F9225（本条只铺 pipe 行）。
- **依赖与嫁接源**：嫁接 pipe(2) man-pages ERRORS 段三行原文（EFAULT/EMFILE/ENFILE）；锚定 B15 F9093 管道账正判据、B22 F9224/F9225 耗尽矩阵（联动格）、F9221 判定域。
- **风险与回退**：风险一为 EFAULT 时双 fd 泄漏（管道已建两 fd 已分配后出参拷贝失败，fd 悬空泄漏）——回退为回滚硬规则：出参拷贝失败即回滚两 fd 分配（位图回收+对象引用释放），注入后 fd 表占用计数回归基线断言；风险二为 EMFILE/ENFILE 判序漂移（先进程后系统判序颠倒致码面漂移）——回退为判序格：双耗尽态叠加注入必 EMFILE（进程级先行），单耗尽各归其码，判序伪代码冻结。
- **正文**：实现路径分三步：第一步立三码注入矩阵——EFAULT 组（pipefd=NULL/未映射/只读页三格全 EFAULT）；EMFILE 组（预占 fd 至软限额后 pipe 全 EMFILE）；ENFILE 组（系统文件表上限桩注入后 pipe 全 ENFILE）三组九格逐格落账；第二步立出参回滚格——坏 pipefd 注入后 fd 表占用计数探针断言回归基线（回滚生效零泄漏），管道对象引用计数回归零，10 次注入零泄漏零 panic，回滚序（建管→分配 fd→拷贝出参→失败即回滚）伪代码冻结；第三步立逐码一致核——九格与 pipe(2) man-pages ERRORS 段逐行比对表落账，判序格（EMFILE 优先于 ENFILE 双耗尽叠加注入）断言，与 F9093 正判据双成分并列（正常 pipe 返回 0 且两端可读写对照）。与现存内核衔接点：fd 分配回滚与 B08 分配器单源；系统文件表桩与 B15 账单源。与 Windows 对照：Windows CreatePipe 坏指针 ERROR_NOACCESS、配额耗尽 ERROR_NO_MORE_FILES；映射随 F9236。判据 UNX-F9223-J1 的复测方式：ktest 三断言——九格逐码、回滚零泄漏十次、判序叠加格。
