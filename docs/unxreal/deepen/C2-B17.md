### UNX-F9121 · mremap 语义档（MREMAP_MAYMOVE/MREMAP_FIXED）
- 域/批：C2/B17｜判据：UNX-F9121-J1 迁移映射判据过，MAYMOVE 位语义格过，old_size 匹配校验格过｜纯功能行数：400 行（迁移映射主干 150 + MAYMOVE/FIXED 位语义 130 + old_size 匹配校验 120）｜状态：[已深化]

- **定位**：本条是 mremap 总纲语义档：对既有映射做扩展/收缩/搬迁三态操作——glibc realloc 大块路径与堆收缩的底层依赖，MREMAP_MAYMOVE（允许搬迁）与 MREMAP_FIXED（指定新址）两位构成操作面，页表实际操作经 F9122 挂点转发 A4。
- **语义边界**：只管 mremap 语义判定与区间裁决；页表直改归 A4（零触及）；错误码矩阵细节归 F9123；MADV_DONTNEED 回收归 F9125；mmap/munmap 本体归 B02/F8804（消费不重铺）。
- **依赖与嫁接源**：嫁接 mremap(2) man-pages（MREMAP_MAYMOVE/MREMAP_FIXED 位语义、EINVAL/ENOMEM/EFAULT 触发条件）；锚定 F9122 页表消费挂点、F9136 对齐探针、B02 VMA 红黑树（区间查找单源）。
- **风险与回退**：风险一为 new_size=0 语义漂移（glibc 大块 free 依赖 unmap 等价行为）——回退为显式格：new_size=0 等价整段解映射断言，后续同址 mmap 成功证明释放；风险二为收缩残留（old_size>new_size 时高端页未释放）——回退为收缩格：[new_size, old_size) 区间页表逐页解除+RSS 减账断言。
- **正文**：实现路径分三步：第一步立迁移映射主干——mremap(old_addr, old_size, new_size, flags, new_addr) 入口先经 F9136 对齐探针（old_addr/new_addr 4KiB 对齐），再查 B02 VMA 红黑树定位 [old_addr, old_addr+old_size) 必须精确落在单一 VMA 内，三路径状态机：原址扩展（VMA 尾邻接空闲 VA 直接扩 vm_end，无需搬迁）、迁移（无法原址扩且 MAYMOVE 置位——经 F9122 挂点做页表级搬迁，内容零复制：PTE 迁移而非数据页 memcpy）、收缩（new_size<old_size 截断高端并归还统计账）；第二步立 MAYMOVE/FIXED 位语义——未置 MAYMOVE 且无法原址扩 → -ENOMEM；MREMAP_FIXED 必须与 MAYMOVE 同置且 new_addr 页对齐、[new_addr, new_addr+new_size) 与旧区间零重叠（重叠 → -EINVAL），FIXED 置位时目标区间既有映射先拆后迁（上游语义）；第三步立 old_size 匹配校验——old_size 与 VMA 实长不符 → -EFAULT（区间跨越两个 VMA 注入即此态）、old_size=0 零值特例冻结返回 -EINVAL（上游歧义注记落账）；new_size=0 等价 unmap 整段（glibc free 路径依赖）。与现存内核衔接点：VMA 树与 B02 mmap 三联单源；页表搬迁全经 F9122 挂点转发 A4，本域零页表直改。与 Windows 对照：VirtualAlloc 无运行期搬迁等价（HeapReAlloc 用户态复制），mremap 搬迁是 POSIX 特有能力；本条按 Linux 上游冻结。判据 UNX-F9121-J1 的复测方式：ktest 三断言——三路径状态机（扩/迁/缩）各一断言、MAYMOVE/FIXED 位组合矩阵、old_size 三态（匹配/不匹配/零值）校验表。

### UNX-F9122 · mremap 与 A4 页表底座消费协议

- **语义边界**：只管转发协议与依赖登记；页表本体实装与 PTE 格式归 A4 域（零触及）；语义判定本体归 F9121；错误矩阵归 F9123。
- **依赖与嫁接源**：嫁接 A4 任务书 mmap 底座冻结接口声明（页表挂点清单）；锚定 handoff 跨域冻结清单（未 finalize 依赖登记体例）、F9121 主干、B02 VMA 结构（vm_flags 读取面）。
- **风险与回退**：风险一为 A4 缺席时被误当页表实装（假成功）——回退为桩态硬规则：挂点桩只记录调用轨迹（区间/操作类型/时序）供 ktest 观测，绝不真改页表，轨迹缺失即 fail；风险二为 A4 finalize 后接口签名漂移致本域重编——回退为转发签名冻结声明（入参 vma/src_addr/dst_addr/nr_pages，返回零或负错误码），A4 只换实现不换签名。
- **正文**：实现路径分三步：第一步立消费协议落账——mremap 迁移路径的页表操作冻结为四个挂点：pte_range_move（区间 PTE 批迁移）、pte_entry_unmap（收缩端解除）、tlb_flush_range（搬迁后 TLB 失效）、vm_stats_reaccount（驻留/映射统计重记账），调用序=语义判定（本域）→挂点转发（A4 执行）→返回新址，任何挂点失败即整体回滚（迁移原子性承诺：要么全迁要么不迁，禁止半迁中间态，失败注入断言零半迁）；第二步立 PTE 迁移挂点声明——挂点函数签名冻结（入参 vma/src_addr/dst_addr/nr_pages，返回 0 或负错误码），语义约束声明：PTE 迁移必须保留页引用计数与脏位/访问位（迁移零数据复制），桩态下轨迹逐项断言（四挂点调用序：move 前置检查、后 flush、终 reaccount）；第三步立未 finalize 依赖登记——handoff 清单登记行：依赖方 C2/B17、被依赖域 A4、接口名 mmap 底座冻结接口、状态=未 finalize、降级路径=桩态可测（语义判定与错误矩阵在桩态下全量可测，页表真操作项随 A4 联签补测登记），双签解锁条款落账。与现存内核衔接点：A4 冻结接口为唯一页表通道；B02 VMA 结构提供属性读取面。与 Windows 对照：Windows 无等价分层（MiUnmapAndMove 类内部路径不开放）；分层为内核内部设计，对照免。判据 UNX-F9122-J1 的复测方式：ktest 三断言——四挂点调用序轨迹断言、迁移原子性失败注入回滚零半迁、登记行与降级桩态可测。

- **语义边界**：只管 mremap 面三码注入；全命令面错误矩阵总装归 B13 与 B21–B28 扩展域；对齐探针本体归 F9136（本条消费）；OOM 联动 ENOMEM 归 F9135 联签面。
- **依赖与嫁接源**：嫁接 mremap(2) man-pages ERRORS 段三码定义原文；锚定 B13 错误矩阵体例、F9136 probe_align 单源、F9135 OOM 联动声明、F9121 位语义格。
- **风险与回退**：风险一为判序漂移（映射查找先于对齐校验致裸地址误返 EFAULT）——回退为判序硬规则：对齐校验先于 VMA 查找先于容量裁决，判序断言矩阵锁定（未对齐必返 EINVAL）；风险二为 EPERM 语义空置被误当实装——回退为预留声明格：本内核单用户域零 CAP 判定，EPERM 行为保留注入位不实装，声明落账。
- **正文**：实现路径分三步：第一步立三错误码注入矩阵——EINVAL 组：old_addr 非 4KiB 对齐、new_addr 非 4KiB 对齐（FIXED 态）、old_size=0 零值特例、FIXED 未同置 MAYMOVE、[new_addr, new_addr+new_size) 与旧区间重叠、flags 含未定义保留位，六格全 -EINVAL；ENOMEM 组：未置 MAYMOVE 且 VMA 尾无邻接空闲 VA、迁移目标 VA 空间耗尽（预占高位后注入）、记账压力注入（F9135 联动），三格全 -ENOMEM；EFAULT 组：old_size 大于实际 VMA（区间跨两 VMA 注入）、区间全裸未映射，两格全 -EFAULT；第二步立逐码一致核——与 mremap(2) man-pages ERRORS 段逐码比对表（码名/触发条件/判序三列），与 Linux 上游行为逐格一致零分歧；第三步立非页对齐判序——addr 未对齐注入 64 组（±1/±2048/±4095/奇值），全 -EINVAL 且零 -EFAULT 混淆（判序断言：未对齐先拒不查映射表，返回 EINVAL 而非 EFAULT 即证校验先执行）。与现存内核衔接点：对齐判定与 F9136 probe_align 共用单源；ENOMEM 容量裁决与 F9135 联动；VMA 查找与 B02 单源。与 Windows 对照：Windows 错误码 ERROR_INVALID_PARAMETER/ERROR_NOT_ENOUGH_MEMORY 族，映射表随深化落账。判据 UNX-F9123-J1 的复测方式：ktest 三断言——十一格注入矩阵全过、三列比对表、64 组对齐扫描零混淆。
