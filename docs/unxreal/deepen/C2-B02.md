- **语义边界**：只做 fd 回收；不做文件对象引用计数本体（F8803/内核 VFS 防重）、不做 O_CLOEXEC exec 关闭（F8835 联测防重）。
- **依赖与嫁接源**：消费 FdTable 存量结构；嫁接源为 Linux man-pages close(2) NOTES（"返回值不保证缓冲落盘"明文），只跟随。

- 正文：实现路径分三步。第一步回收时序：close 释放 fd 表槽位并立即回池，紧跟的 open 断言可取回同号（10^3 次复用链断言），回收动作入 fd 生命周期账（开/关/复用三事件）；第二步双 close 防护：第二次 close 同号返 EBADF 且留痕（防重复释放导致悬挂槽），与 F8812 探针联动验证坏 fd 注入不崩内核；第三步时序语义账：close 返回值仅报告关闭过程错误（EBADF/EINTR 可重试语义），写缓存落盘时序显式落账——"close 成功 ≠ 数据已持久"，glibc/应用需 fsync（后续批次挂点）保证，语义声明入档防下游误用。与现存内核衔接点：FdTable 释放路径扩容。与 Windows 对照：Windows CloseHandle 同样不保证写穿（FlushFileBuffers 对应 fsync），语义同构。判据 UNX-F8823-J1 的复测方式：ktest 复用链/双 close/时序账三类用例批跑全过。
