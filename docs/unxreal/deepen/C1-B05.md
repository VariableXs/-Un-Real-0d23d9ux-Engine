### UNX-F8081 · R_X86_64_GLOB_DAT 族应用
- 域/批：C1/B05｜判据：UNX-F8081-J1 GLOB_DAT 逐项应用后 GOT 值与 Linux 基准机一致，应用计数与 DT_RELA 中该类型计数一致｜纯功能行数：240 行（族应用器 90 + 计数对账 70 + 判据件 80；测试段不计）｜状态：[已深化]
- **定位**：GLOB_DAT 是数据引用重定位族——glibc 动态程序的全局变量地址槽（GOT）内核只写初值（加数+基址），符号终值留给 ld.so；本条把族应用做成逐项算法与计数对账，是 F8002 三族总述的第一条专条。
- **语义边界**：只做 GLOB_DAT 应用与对账；不做符号解析（C5 主权——本条初值语义按 F8002 边界声明）；不做 GOT 区权限管理（F8008/F8009 面）。
- **依赖与嫁接源**：依赖 F8084 遍历器（条目供给）、F8007 落位账（目标区间）；嫁接源为 ELF64 规范 R_X86_64_GLOB_DAT（type=6）加数语义与 Linux 内核初值路径。
- **风险与回退**：目标越界（偏移指向段外）静默写坏内存——逐项目标地址先验后写（F8097 矩阵联防）；幂等性（重复应用）以加数语义允许（值不变）并登记重复事件。
- 正文：实现路径分三步。第一步族应用器：遍历器供给的条目流中 type==6（GLOB_DAT）逐项处理——目标地址=段内偏移换算+基址，先验目标∈已落位可写区间（区间账），写入初值=加数+基址（符号项初值，C5 主权注记在代码处显性）；应用后逐项回读校验。第二步计数对账：应用计数与 DT_RELA 全表中 type==6 计数一致（遍历器账交叉）——计数不符即遍历遗漏红灯；对账入 F8100 账本。第三步判据件：GLOB_DAT 密集样本（构造+真实 glibc 镜像）应用后 GOT 区与 Linux 基准机同镜像装载结果逐项 diff 一致（真机窗）；计数对账机检常跑。与现存内核衔接点：F8002 三族总述承接（承接非重复——总述钉判据、本条钉族算法）；F8084 为条目源。与 Linux 对照：GLOB_DAT 初值（加数+基址）语义与 Linux 侧 ld.so 接管前的 GOT 状态逐项对齐。与 Windows 对照：PE 导入表（IAT）初值语义对位——标注机制差异。判据 UNX-F8081-J1 的复测方式：ktest 宿主面跑构造样本逐项断言+计数对账；真实镜像 GOT diff 在真机窗复验（随闸门补测）。

### UNX-F8082 · R_X86_64_JUMP_SLOT 族与 PLT 挂点
- 域/批：C1/B05｜判据：UNX-F8082-J1 JUMP_SLOT 逐项应用后 PLT/GOT 联动正确，延迟绑定场景内核侧初值与 Linux 一致｜纯功能行数：240 行（族应用器 90 + PLT 联动判据 70 + 判据件 80；测试段不计）｜状态：[已深化]
- **定位**：JUMP_SLOT 是函数调用重定位族——PLT 的延迟绑定机制（首调用走解析器）建立在 GOT 槽初值正确之上；内核写对初值、ld.so 才能接管延迟绑定，本条把初值语义与 PLT 联动判据钉死。
- **语义边界**：只做 JUMP_SLOT 初值应用；不做延迟绑定执行（ld.so 主权）；不做 BIND_NOW 变体（DT_FLAGS 绑定模式由 ld.so 消费转录账——本条只转录）；初值写法按 Linux 语义（推送索引指向 PLT0 或直接加数——两形态按样本 DT_FLAGS 判）。

- **风险与回退**：两形态初值混淆（BIND_NOW 样本写了延迟形态）会让 ld.so 解析器错位——形态判据以 DT_FLAGS 转录账单源；目标越界防线同 F8081（先验后写）。
- 正文：实现路径分三步。第一步族应用器：type==7 逐项——目标换算+先验（同 F8081 纪律），初值按绑定形态：延迟绑定态写"PLT0 推送路径初值"（GOT 槽指回 PLT 压索引序列）、BIND_NOW 态写加数+基址（与 GLOB_DAT 同构）；形态判以 F8085 转录账 DT_FLAGS 单源。第二步 PLT 联动判据：应用后 GOT 槽与 PLT 条目序号联动核对（第 n 个 JUMP_SLOT 对应第 n 个 PLT 条目——计数与序号双向机检）；联动错位（样本重排）即红灯。第三步判据件：延迟/立即两形态样本各 5，初值与 Linux 基准机同镜像装载态逐项一致（真机窗）；联动机检常跑。与现存内核衔接点：F8002 承接（族专条）；C5 延迟绑定接管语义在初值处显性注记（内核止步点）。与 Linux 对照：GOT 初值两形态与 Linux/ld.so 约定逐项对齐。与 Windows 对照：IAT 延迟加载（delay load）语义对位——标注。判据 UNX-F8082-J1 的复测方式：ktest 跑联动机检+构造样本初值断言；真实镜像初值 diff 真机窗复验（随闸门补测）。
