- **语义边界**：只做编号分配与唯一性纪律；不做盘上编号映射（fs 嫁接层职责——本条是内存侧分配语义，fs 回填盘上号时经同一账核对）；不做全局唯一（POSIX 语义明确 per-sb）；F4030 的根 ino 声明值在本分配器下保留校验。

- **风险与回退**：分配器复用已释放号造成幻影（新 inode 与缓存旧 dentry 撞号）——释放号进隔离带（代际计数：释放号打代标，重分配必须隔代，缓存侧见代不匹配即失效）；分配账溢出——计数器式账（非逐笔历史），滚动无损判据。

- **语义边界**：只做 mode 九位判定与 root 特权；不做 ACL 扩展（联签件）；不做凭据来源（F4005 传递）；sticky/setgid 的目录行为语义在挂载旗与 B12 联动处消费（本条判定矩阵以普通位为准，特殊位行为注记归属）。
- **依赖与嫁接源**：依赖 F4004 编码/F4005 凭据；被 open/exec/chmod 族消费；嫁接源为 POSIX.1-2017 XBD 4.4 权限判定算法与 Linux generic_permission 语义，只跟随。
- **风险与回退**：组命中歧义（属主位拒绝但组位允许——POSIX 规定属主匹配后不再看组）——三路选择严格串行（先属主、不匹配才组、再其他），短路语义用例钉死；root 特权误用（x 位全无也能执行）——POSIX 口径 root 执行仍需任一 x 位存在，用例钉死防"全能 root"误实现。

### UNX-F4045 · i_blocks 与按需推导
- 域/批：B1/B03｜判据：UNX-F4045-J1 i_blocks 按 512B 扇区单位从 i_size 推导（稀疏语义零块账），推导值与手工计算 1,000 例一致｜纯功能行数：220 行（推导函数 80 + 扇区账 70 + 对账 70；测试段不计）｜状态：[已深化]
- **定位**：st_blocks 的推导口径——按 512B 扇区单位从 i_size 推导（POSIX 惯例：blocks=size/512 向上取整，稀疏语义允许小于），推导值与手工计算 1,000 例一致。st_blocks 是 du/df 类工具与配额观测的输入，单位错（扇区 vs 块）是经典歧义源，本条把口径钉死。
- **语义边界**：只做推导与对账；不做真实分配账（fs 嫁接层职责——推导值是"合理默认"，fs 可回填真实值，回填经同一账）；稀疏语义（size 大 blocks 小）只立账面兼容，真稀疏分配归 fs。
- **依赖与嫁接源**：依赖 F4044 size 事实源/F4008 sb（块大小参数）；被 stat 面（F4051）消费；嫁接源为 POSIX st_blocks 512B 口径惯例，只跟随。
- **风险与回退**：块大小混用（512B 扇区与 fs 逻辑块混淆）——推导函数固定 512B 口径常量，fs 逻辑块换算独立函数（两个函数两个名，防混用）；推导与真实分配漂移——fs 回填真实值时落"回填"标记，对账区分推导/回填双源。
