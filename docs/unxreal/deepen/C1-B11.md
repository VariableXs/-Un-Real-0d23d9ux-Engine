- 域/批：C1/B11｜判据：UNX-F8207-J1 子进程改地址空间行为按 Linux 语义处置（未定义行为显性档），_exit 约定样本 10/10 同码｜纯功能行数：240 行（约束档 80 + 未定义显性件 80 + _exit 样本判据 80；测试段不计）｜状态：[已深化]
