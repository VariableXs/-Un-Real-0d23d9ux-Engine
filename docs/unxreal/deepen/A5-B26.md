## F3704 组合覆盖（参数组合的 n-wise）

**定位**：参数维的落地：入口参数的 n-wise 配对覆盖（v1=pairwise）——"单看都合法、搭起来才炸"的参数交互病——以 O(k²) 预算抓 O(2^k) 空间的交互病。
**语义边界**：pairwise 的理由（判据行内嵌：全组合 2^k 不可行（k=10→1,024 组合×每组合多例——爆炸）；单参数不够（交互病invisible）；pairwise 是折中的数学（多数参数病是二元交互（经验律——pair 覆盖抓二元交互——k 参数的 pair 数=k(k−1)/2（**分母显式**——k=10→45 pair——预算可算）；pair 表的生成（参数对 (pi, pj)×值域笛卡尔——每 pair 的值组合集合=覆盖单元——每单元至少一 input 命中=covered）；**pair 账守恒**（covered+blind==总 pair 单元数（F3552 同律——组合维自己的守恒式）；高阶（n=3）留 v2（预算闸门——pair 尚未全绿不谈三阶（判据行：走之前先会爬）。
**判据**：
- J1：n-wise 契约（pairwise+pair 表+分母显式）；M-462 配对全巡（3 参数靶→pair 表全点+至少一 input 逐 pair 命中）。
- J2：组合账守恒（pair 覆盖数+盲区数==总 pair 数。
**纯功能行数**：320（契约 ~110 + 用例 ~105 + 守恒论证 ~105）
**依赖与嫁接源**：F3682 schema（参数与值域的来源）；F3706 靶向（盲 pair 的补齐）；F3552 分母纪律（守恒式执法）；F3683 语料（命中 input 的宿主）。
**风险与回退**：pair 盲区顽固（某 pair 组合被守卫条件互斥（参数组合非法——永不可达——回退：不可达 pair 标注（与死边/死状态同法——schema 的约束表达式为证；参数类型异构（有的参数是句柄类（值域无穷——回退：值域的代表元化（句柄取 {null, valid, freed} 三代表——等价类思想（F3705）在参数维的应用；pair 与状态的交互（pair 覆盖在不同状态下意义不同——v1 不展开（与 F3703 的笛卡尔一样留 v2——诚实声明覆盖的粒度边界。
**正文**：交互病的实例与 pairwise 的抓法（判据行展开）：靶 3 参数（type∈{a,b}、len∈{0,MAX}、prio∈{low,high}）——单参数边界测试全绿（各参数的每个值都单独测过）；pair 靶：(len=MAX, prio=high) 组合触发配额计算溢出——**单参数永远抓不到**（两个值各自合法——交互病）——pair 表 3 对×4 单元=12 单元→靶向跑后 11/12 covered、盲 1（恰为病灶对——靶向补齐后 12/12）；M-462 的全巡验证：12 单元逐单元抽 input 验证命中（机读回放——不是报告声称而是逐单元实证）；守恒式的执法（判据行展开）：11+1==12 ✓（covered+blind==全集——组合维自己的分母纪律——报告写 "pair 11/12" 而不是 "91.7%"（分母三件套）；k(k−1)/2 的预算声明（判据行展开）：k=10 的清单入口→45 pair 单元×每单元 ≥1 例→pairwise 预算 ≈45 例/入口——**预算是入口规模的多项式**（相对全组合 1,024×——pairwise 的存在理由）；不可达 pair 的处理（判据行展开）：schema 约束（type=a 时 prio 必 low）→(type=b, prio=low) 之外的组合非法——非法单元标 n/a（不进守恒分母——**分母的口径跟着约束走**（守恒式里 blind 只数可达而未至的）；M-462 复测：全巡+守恒+预算声明+不可达标注。
