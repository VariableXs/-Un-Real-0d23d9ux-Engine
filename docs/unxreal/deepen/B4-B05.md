- **语义边界**：只做编码与判定；不做 flush 派发语义（F6484 防重）、不做设备能力裁断（F6482 防重）；编码位域与 F6403 操作标志域共享空间（flush 类位段显式划分，互不侵占）。

- **风险与回退**：编码位侵占（后段操作类型扩张侵入 flush 位段）——位段边界编译期断言（flush 位段掩码锁定），侵占即编译失败。
- 正文：实现路径分三步。第一步编码定义：PREFLUSH（前刷标志位）、FUA（直达标志位）、组合（双位）三态定义入设计表，位段掩码（flush 域 2 位）锁定并编译期断言与 F6403 全集互不侵占；每编码语义注释（"前刷=刷完才写"级精度）。第二步判定器：`flush_classify(flags)` 三态判定（仅前刷/仅 FUA/组合/无关）唯一可判定，非法组合（如 flush 与 discard 冲突位）100% 拒绝；判定 O(1) 位运算。第三步逐位核对：编码值与设计表逐位比对机检（构建期静态断言+运行期抽验），编码账与 F6410 错误分类学同风格落账。与现存内核衔接点：现存 NVMe Write 命令 FUA 位支持收编（现存的 flush 单独命令路径升级为编码体系）；薄层旧 flush 调用映射到 PREFLUSH 编码。与 Windows 对照：Windows 以 SRB 标志（SRB_FLAG_XXX 与 STORAGE_REQUEST_FLUSH）表达刷盘语义（WDK 文档化），本内核位段锁定+逐位机检，判据 UNX-F6481-J1 的复测方式：三类判定 1,000 组全对、非法组合注入全拒、逐位核对零差异。
