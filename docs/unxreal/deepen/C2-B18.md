### UNX-F9141 · wait4 语义档（状态码四段解码）
- 域/批：C2/B18｜判据：UNX-F9141-J1 四段解码（正常/信号终止/停止/继续）判据过，wstatus 逐位断言格过，rusage 联动格过｜纯功能行数：410 行（四段解码主干 160 + wstatus 逐位断言 130 + rusage 联动 120）｜状态：[已深化]

- **定位**：本条是 wait 族总纲与 wait4 语义档：收割子进程状态并按 Linux wstatus 位域做四段解码（正常退出/信号终止/停止/继续）+rusage 资源账回填——shell 作业控制与 libc system/popen 的地基格，F9142/F9143 兼容面的母体。
- **语义边界**：只管 wait4 判定与解码；waitpid/wait3 别名归 F9142、waitid 归 F9143；僵尸收割协议本体归 F9144（本条消费其状态源）；ECHILD/EINTR 矩阵归 F9145；SIGCHLD 投递归 F9154。
- **依赖与嫁接源**：嫁接 wait(2)/wait4(2) man-pages（wstatus 位域宏 WIFEXITED/WEXITSTATUS/WIFSIGNALED/WTERMSIG/WCOREDUMP/WIFSTOPPED/WSTOPSIG/WIFCONTINUED 与 rusage 结构）；锚定 F9144 ExitStatus 单源、B11 信号表、A5 计时面（ru_utime/ru_stime 单源）。
- **风险与回退**：风险一为位域解码漂移（掩码错一位致正常退出被判停止）——回退为逐位硬规则：解码函数按位掩码提取（低 7 位/0x80/0x7F/0xFFFF 四掩码单源），四段实子逐位回读断言；风险二为退出码 8 位截断丢失（exit(256) 语义）——回退为截断格：exit(256)&0xFF==0 边界断言与上游一致。
- **正文**：实现路径分三步：第一步立四段解码主干——wait4(pid,wstatus,options,rusage) 收割后状态四段解码判定表冻结（按 Linux wstatus 位域）：①正常退出：低 7 位==0（WIFEXITED），退出码取 (wstatus>>8)&0xFF（WEXITSTATUS，8 位截断：exit(256)&0xFF==0 边界格）②信号终止：低 7 位∈1–63 且低 8 位≠0x7F（WIFSIGNALED），终止信号取 wstatus&0x7F（WTERMSIG），core 标志取 0x80 位（WCOREDUMP）③停止：低 8 位==0x7F（WIFSTOPPED），停止信号取 (wstatus>>8)（WSTOPSIG）④继续：wstatus==0xFFFF（WIFCONTINUED）；第二步立 wstatus 逐位断言——四段各构造实子：子 exit(42) → wstatus==42<<8；子被 SIGKILL 终止 → wstatus==9；子自我挂起（WUNTRACED 态）→ wstatus==0x7F|(19<<8)；子继续（WCONTINUED 态）→ 0xFFFF，逐位掩码回读断言（掩码提取函数单源，非值级比对）；第三步立 rusage 联动——rusage 非空时回填被收子累计 ru_utime/ru_stime（子自耗 CPU 时钟，与 A5 计时面单源）、ru_maxrss 页账，rusage=NULL 合法（waitpid 等价路径），四段×rusage 双态矩阵 8 格。与现存内核衔接点：ExitStatus 源与 F9144 单源；信号值与 B11 信号表单源；计时与 A5 单源。与 Windows 对照：GetExitCodeProcess 单一退出码（无四段编码，信号终止经异常码折算）；对照表落账。判据 UNX-F9141-J1 的复测方式：ktest 三断言——四段判定表、逐位掩码回读、8 格 rusage 矩阵。

### UNX-F9142 · waitpid/wait3 兼容面（WNOHANG/WUNTRACED/WCONTINUED）
- 域/批：C2/B18｜判据：UNX-F9142-J1 三标志语义判据过，WNOHANG 零阻塞返回 0 可观测，兼容别名映射格过｜纯功能行数：360 行（三标志主干 140 + WNOHANG 零阻塞可观测 110 + 兼容别名映射 110）｜状态：[已深化]

- **定位**：本条立 waitpid/wait3 兼容面：三 options 标志语义（WNOHANG 非阻塞/WUNTRACED 报停止/WCONTINUED 报继续）与 pid 四态选择语义，wait3/waitpid 向 wait4 的别名转发映射——兼容面零重复实现格。
- **语义边界**：只管三标志与别名面；四段解码本体归 F9141（转发复用）；收割协议归 F9144；continued 事件置位源归 B11 SIGCHLD 链（联动消费）；waitid 的 WNOWAIT 差异归 F9143。
- **依赖与嫁接源**：嫁接 waitpid(2) man-pages（三标志、pid 四态语义原文）；锚定 F9141 wait4 单函数、B11 事件位置位链、F9144 收割序。
- **风险与回退**：风险一为 WNOHANG 误写状态缓冲（返回 0 时 wstatus 被污染）——回退为哨兵格：返回 0 时调用前哨兵值原样断言；风险二为别名双实现漂移（wait3 与 wait4 行为分叉）——回退为单函数转发格：别名只转发不复制逻辑，触号同源 grep 引用核。
- **正文**：实现路径分三步：第一步立三标志主干——waitpid(pid,wstatus,options) 三标志判定：WNOHANG（无可用状态立即返回 0 不挂起）、WUNTRACED（报告已停止而未被报告的子）、WCONTINUED（报告继续子——需任务态 continued 事件位，B11 投递链联动置位），options 非法位（未定义 bit 注入）→ -EINVAL；pid 语义四态（>-1 定点 / 0 同进程组 / -1 任意 / <-1 绝对值组选）判定表；第二步立 WNOHANG 零阻塞可观测——子存活未变状态时 waitpid(pid,&st,WNOHANG) 返回 0 且时钟夹逼 <1ms（零阻塞断言）、返回 0 后 wstatus 内容不被写（调用前哨兵值原样断言）、子退出后同调用返回 pid 且解码一致（F9141 复用）；阻塞对照组：无标志同场景挂起至子退出（双态对照）；第三步立兼容别名映射——wait3(status,options,rusage)≡wait4(-1,status,options,rusage)（别名转发单函数）、waitpid(pid,...)≡wait4(pid,...,NULL)（rusage 槽位空），三入口触号 meter 同源对账（别名零重复实现声明：转发引用核）。与现存内核衔接点：continued 事件位与 B11 联动；四段解码与 F9141 单源；任务态与 B04 fork 档单源。与 Windows 对照：无 waitpid 等价（WaitForSingleObject 单对象+超时近似 WNOHANG 轮询态）；对照注记。判据 UNX-F9142-J1 的复测方式：ktest 三断言——WNOHANG 夹逼与哨兵、WUNTRACED/WCONTINUED 事件格、别名触号同源。

### UNX-F9143 · waitid 语义档（P_PID/P_PGID/P_ALL）
- 域/批：C2/B18｜判据：UNX-F9143-J1 三选择模式判据过，WNOWAIT 保留态格过，si_code 字段逐值格过｜纯功能行数：340 行（三选择模式 130 + WNOWAIT 保留态 100 + si_code 逐值 110）｜状态：[已深化]

- **定位**：本条立 waitid 语义档：idtype 三选择模式（P_PID 定点/P_PGID 组选/P_ALL 全选）、siginfo_t 结构化回填（si_code 六值逐值）、WNOWAIT 保留态（报告不收割）——wait 族结构化报告面，pthread/shell 精细收割依赖。
- **语义边界**：只管 waitid 三模式与结构回填；僵尸收割本体归 F9144；si_code 与 F9141 四段的对账互认面（两 API 同状态解码一致）；WNOHANG/WNOWAIT 组合语义本格；信号本体归 B11。
- **依赖与嫁接源**：嫁接 waitid(2) man-pages（idtype 三值、options 必选项、si_code CLD_* 六值原文）；锚定 F9144 僵尸源、F9141 位域对账、B11 SIGCHLD 值单源。
- **风险与回退**：风险一为 WNOWAIT 语义分裂（保留态被误收割致二次报告失败）——回退为三拍格：报告→再报告→收割三拍断言（保留态可重复读）；风险二为 si_code 与 wait4 解码互斥（同状态两 API 分歧）——回退为互认矩阵：exit/killed/stopped/continued/dumped 五状态双 API 对照零分歧。
- **正文**：实现路径分三步：第一步立三选择模式——waitid(idtype,id,infop,options) 判定：P_PID（定点 id）、P_PGID（进程组 id 内任一子）、P_ALL（id 忽略置 0），选择引擎与 wait4 pid 四态同源转发（单函数复用声明）；options 至少含 WEXITED/WSTOPPED/WCONTINUED 之一否则 -EINVAL（全空注入格）；第二步立 WNOWAIT 保留态——WNOWAIT 置位：目标子状态被报告但不收割（僵尸保留），断言链：首次 waitid(WNOWAIT) 成功回填 infop → 同子二次 waitid 仍可报告同状态 → wait4 终收割后 waitid 返回 -ECHILD（保留-再读-收割三拍）；非 WNOWAIT 态 waitid 即收割（单次消费）；第三步立 si_code 逐值格——infop（siginfo_t）回填逐字段断言：si_signo==SIGCHLD、si_pid/si_uid 源任务身份、si_status（退出码或信号号）、si_code 六值逐格：CLD_EXITED（正常）/CLD_KILLED（信号终止）/CLD_DUMPED（core）/CLD_STOPPED/CLD_TRAPPED（本内核预留格登记）/CLD_CONTINUED，与 F9141 四段位解码对账一致（同状态两 API 解码互认矩阵 5 格：exit/killed/stopped/continued/dumped）；WNOHANG 态无状态返回 0 且 infop 清零（si_pid==0 约定断言）。与现存内核衔接点：僵尸态与 F9144 单源；SIGCHLD 与 B11/B15 单源。与 Windows 对照：无 waitid 等价（JOB 对象通知近似组选）；对照注记。判据 UNX-F9143-J1 的复测方式：ktest 三断言——三模式选择格、WNOWAIT 三拍链、si_code 六值+互认矩阵。

### UNX-F9144 · 僵尸态收割语义与 ExitStatus 消费
- 域/批：C2/B18｜判据：UNX-F9144-J1 收割后资源释放判据过，ExitStatus 结构消费单源格过，二次 wait 全 ECHILD 格过｜纯功能行数：340 行（收割主干 130 + ExitStatus 单源消费 110 + 二次收割拒绝 100）｜状态：[已深化]

- **定位**：本条立僵尸态收割协议：僵尸=任务已终仅存描述符骨架+ExitStatus 结构，收割序四拍（摘链/回填/释放/减账）——wait 族三 API 的公共收割引擎，PID 复用与资源回收的正确性基石。
- **语义边界**：只管收割协议与 ExitStatus 消费；exit 写侧登记归 B04 exit 档（同结构体单源）；PID 分配/释放本体归 C1 进程模型（单源消费）；ECHILD 矩阵归 F9145；收养权转移归 F9153。
- **依赖与嫁接源**：嫁接 wait(2) man-pages 僵尸语义与 ECHILD 原文；锚定 B04 ExitStatus 结构（fork/exit 链写侧）、C1 PID 分配器、B12 等待队列（竞态串行化）。
- **风险与回退**：风险一为并发双 wait 双收割（同子被收割两次资源双重释放）——回退为串行化格：任务锁序下双 wait 一成一 -ECHILD，竞态 100 次复测登记随闸门补测（双轨）；风险二为收割序颠倒（先释放 PID 后回填致 PID 复用读脏状态）——回退为四拍硬序格：摘链→回填→释放→减账，序断言锁定。
- **正文**：实现路径分三步：第一步立收割主干——僵尸态定义：任务已终（exit 路径走完）仅存任务描述符骨架+ExitStatus 结构；收割序=①从父任务子链摘除②ExitStatus 回填调用方缓冲（F9141/F9143 解码消费）③释放 PID 与任务描述符剩余资源④父侧子计数减账，收割原子段单段（无中间态窗口，与并发 wait 竞态经任务锁序串行化——同子并发双 wait 只有一方成功另一方 -ECHILD，竞态 100 次复测登记随闸门补测双轨）；第二步立 ExitStatus 单源消费——ExitStatus 结构（exit_code 8 位+term_signal 7 位+core 位+rusage 摘要四元组）与 B04 exit 档登记单源（fork/exit 链写侧、wait 链读侧同结构体定义引用核），零二次转译（写侧登记什么读侧解码什么）；第三步立二次收割拒绝格——同一子收割后再次 wait/waitpid/waitid 定点注入 → 全 -ECHILD（三 API 一致），ECHILD 与"从无此子"态区分注记（F9145 矩阵引用）；init 收养子的收割权随收养转移（父权翻转后原父 wait → -ECHILD，与 F9153 联动格）。与现存内核衔接点：ExitStatus 与 B04 单源；PID 释放与 C1 进程模型单源；收养联动与 F9153 单源。与 Windows 对照：无僵尸等价（进程对象引用计数归零即清理，退出码经长寿对象查询）；对照表落账。判据 UNX-F9144-J1 的复测方式：ktest 三断言——收割四序轨迹断言、ExitStatus 写读单源引用核、二次收割三 API 全 ECHILD。

### UNX-F9145 · wait 错误矩阵（ECHILD/EINTR/EINVAL）
- 域/批：C2/B18｜判据：UNX-F9145-J1 三错误码注入矩阵判据过，ECHILD 无子进程格过，EINTR 与 SA_RESTART 联动格过｜纯功能行数：300 行（三码注入矩阵 120 + EINTR 重启联动 90 + 无子拒绝格 90）｜状态：[已深化]

- **定位**：本条立 wait 族错误注入矩阵：ECHILD（无子/无匹配状态）、EINTR（阻塞中被信号打断，SA_RESTART 联动）、EINVAL（options 非法位）三码逐格——B12 四输入判定器在阻塞收割面的消费实例。
- **语义边界**：只管 wait 族三码；ESRCH 在 wait 族零出口（声明归本格，补充面归 F9155）；EINTR 判定器本体归 B12（消费对账）；矩阵体例与 B13 一致；WNOHANG 态返回 0 非错误（与 F9142 对照格）。
- **依赖与嫁接源**：嫁接 wait(2) man-pages ERRORS 段三码定义与 signal(7) SA_RESTART 规则；锚定 B12 四输入判定器、F9144 收割选择域、B11 信号挂点。
- **风险与回退**：风险一为 EINTR 后参数破坏（wstatus 缓冲被半写）——回退为哨兵格：EINTR 返回时 wstatus/rusage 缓冲哨兵原样断言；风险二为 SA_RESTART 两态混淆（置位仍返回 EINTR）——回退为两态对账格：与 B12 判定器四输入逐输入对账，SA_RESTART 置=内核重启不返回用户态。
- **正文**：实现路径分三步：第一步立三码注入矩阵——ECHILD 组：无任何子调 wait4(-1)（裸 init 态注入）→ -ECHILD；定点 pid 指向非父子 pid → -ECHILD（选择域外注入）；EINVAL 组：options 未定义位注入 → -EINVAL（三入口 wait4/waitpid/waitid 各一格）；EINTR 组：阻塞收割中投递信号 → -EINTR；第二步立 EINTR 重启联动——SA_RESTART 清：wait4 返回 -EINTR 且 wstatus/rusage 缓冲不被写（哨兵断言）；SA_RESTART 置：内核重启等待不返回用户态（与 B12 四输入判定器逐输入对账：处置器注册/重启旗标/wait 可中断性/返回点四输入），两态各一断言；第三步立无子拒绝格——ECHILD 与"有子未变状态"区分：后者阻塞非错误（对照格声明，本内核无超时参数——阻塞面注记），与 wait 族 ESRCH 零出口声明一并落账（目标不存在归 ECHILD，与 B11 kill 面 ESRCH 差异注记，F9155 补充格引用）；比对表三列（码名/触发条件/优先序：EINVAL 先于选择、选择先于阻塞）。与现存内核衔接点：EINTR 与 B12 判定器单源；矩阵体例与 B13 一致。与 Windows 对照：ERROR_WAIT_NO_CHILDREN 近似、无信号重启语义（事件对象替代）；对账注记。判据 UNX-F9145-J1 的复测方式：ktest 三断言——三码注入矩阵、SA_RESTART 两态、比对表三列齐。

### UNX-F9146 · setpgid/getpgid 语义档（进程组迁移协议）
- 域/批：C2/B18｜判据：UNX-F9146-J1 迁移协议判据过，会话首拒绝 EPERM 格过，僵尸子进程 ESRCH 格过｜纯功能行数：320 行（迁移协议主干 130 + 会话首拒绝 90 + 僵尸目标拒绝 100）｜状态：[已深化]

- **定位**：本条立 setpgid/getpgid 进程组迁移协议：pgid 字段迁移规则（自身/新组/既有组三目标）与三道闸（会话首 EPERM/execve 后 EACCES/僵尸 ESRCH）——shell 作业控制与 F9147 setsid 的地基格。
- **语义边界**：只管进程组迁移；会话建立归 F9147；execve 锁定挂点归 F9150（联动声明）；pgid 字段本体归 C1 任务结构（单源消费）；kill 组投递面归 B11。
