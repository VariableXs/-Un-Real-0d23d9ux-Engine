### UNX-F8901 · gettimeofday 语义档
- 域/批：C2/B06｜判据：UNX-F8901-J1 tv_sec/tv_usec 输出与 clock_gettime(CLOCK_REALTIME) 换算一致 10^3 次，tz 结构遗留 NULL 约定判据过｜纯功能行数：200 行（语义档 100 + 换算对账 60 + tz 档 40；测试段不计）｜状态：[已深化]
- **定位**：gettimeofday 是最老牌的墙上时钟读数号，本条把语义档建成换算级一致判据——输出与 clock_gettime(CLOCK_REALTIME) 换算逐次一致（10^3 次），tz 结构（struct timezone）遗留参数约定（内核已废弃但仍需接受 NULL/非 NULL 两态）判据过，glibc gettimeofday 包装零障碍。
- **语义边界**：只做 gettimeofday 档；不做 clock_gettime 本体（F8902 防重）、不做计时基座（A2 防重）、不做 vDSO（F8912 防重）。
- **依赖与嫁接源**：消费 A2 计时基座产出（F8911 仲裁协议）；嫁接源为 Linux man-pages gettimeofday(2)（tz 参数遗留说明），只跟随。
- **风险与回退**：A2 基座未收口——换算对账以 A2 现存 ClockSource 最小输出先行，基座全量后回归。
- 正文：实现路径分三步。第一步语义档：gettimeofday(tv, tz) 双参语义——tv 必填（NULL 返 EFAULT，Linux 语义：tv 不可为 NULL），tz 可选（遗留时区结构，Linux 内核恒填零值登记），输出字段（tv_sec 秒/tv_usec 微秒）登记；第二步换算对账：与 clock_gettime(CLOCK_REALTIME) 输出换算（sec×10^6+usec ≈ ns/10^3）逐次比对 10^3 次一致（同 tick 内采样，跨 tick 容差登记）；第三步 tz 档：tz=NULL 合法/tz 非 NULL 填零值（Linux 语义：时区已废弃），两态判据过。与现存内核衔接点：ClockSource 读取消费。与 Windows 对照：Windows GetSystemTimePreciseAsFileTime 同角色（100ns 单位），换算对照表入档。判据 UNX-F8901-J1 的复测方式：ktest 10^3 次对账批跑全过，tz 两态断言过。
