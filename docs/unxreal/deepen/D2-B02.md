### UNX-F12823 · Raw↔Virtual 双对齐差异与散布映射算法
- 域/批：D2/B02｜判据：UNX-F12823-J1 双对齐差异散布映射在 100 样本逐节首尾地址与 Windows 映射快照一致，Raw 对齐≠Virtual 对齐样本 ≥20 个全对｜纯功能行数：420 行（双对齐几何计算 150 + 散布映射器 150 + 快照对照账 120；测试段不计）｜状态：[已深化]
- **定位**：FileAlignment（文件粒度，常 512）与 SectionAlignment（内存粒度，常 4K）不等是常态，节内容在文件里"密铺"、在内存里"散布"，本条实现散布映射几何——每节虚位=对齐放大后的 VirtualAddress，文件位=PointerToRawData，两者独立，几何结论与 Windows 映射快照逐节对齐。
- **语义边界**：只做映射几何计算与执行；不做页粒度布置细节（F12824 承接）、不做 BSS 零填充（B03 分层）。
- **依赖与嫁接源**：依赖 F12807 对齐矩阵结论与 F12821 四字段；对现存 `pe.rs` 静态节映射是升级接管（几何口径以现存行为为回归基线）；嫁接源为 Windows `!vad` 映射快照观测，只跟随。
- **风险与回退**：VirtualAddress 未按 SectionAlignment 对齐（畸形）——按 F12807 矩阵拒绝或对齐钳制（钳制事件落账），口径与 Windows 一致。
- 正文：实现路径分三步。第一步几何计算：每节计算 (虚起/虚长/文起/文长) 四元组，虚长取 max(VirtualSize, SizeOfRawData) 对齐放大，checked 算术全程；第二步散布映射器：按四元组把文件字节拷入虚位（经 A4 映射族写路径），映射序按节表序（与 Windows 一致），100 样本首尾地址与快照一致；第三步快照对照：映射完成后读回每节首尾 16 字节与文件视图比对（哈希账），不等即定位到节号报错。与现存内核衔接点：`pe.rs` 映射循环替换为散布映射器。与 Windows 对照：WinDbg `!vad` 或内存快照为对照锚，判据 UNX-F12823-J1 复测方式：100 样本首尾一致率 100%，双对齐差异样本 20/20 全对。
