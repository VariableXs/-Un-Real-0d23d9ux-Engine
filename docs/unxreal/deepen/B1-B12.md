### UNX-F4222 · 覆盖栈语义（新压旧成栈）
- 域/批：B1/B12｜判据：UNX-F4222-J1 同挂载点三次叠挂成三层栈（栈深=3 可观测），路径解析可见面恒为栈顶（顶下穿透注入零命中）｜纯功能行数：320 行（栈结构 110 + 栈深可观测 100 + 可见面断言 110；测试段不计）｜状态：[已深化]

- **语义边界**：只做叠挂成栈与可见面；不做弹栈（F4223）/乱序弹拒绝（F4238 分账）；栈深可观测=接口级（非账面内部——外部可查）；栈顶判定=单点（解析穿引只取栈顶——多入口注入封死）；叠挂的 sb 可同可异（同点挂同 sb 合法——bind 场景 F4231 联动）。
- **依赖与嫁接源**：依赖 F4221 树结构/F4094 穿越接口（B05 预锚兑现）；被 F4223/F4224/F4238 消费；嫁接源为 Linux 同点叠挂成栈语义（mount_on_top），只跟随。
- **风险与回退**：栈塌缩（第三次挂载覆盖第二次——只留一层，历史丢失）——栈深断言（叠挂 3 次后栈深==3 可观测 1,000 例），塌缩注入即红；穿透泄漏（解析走到栈顶但栈下层内容可经某路径直达——覆盖不彻底）——可见面断言（栈顶可见内容验证+顶下穿透注入 1,000 例零命中），泄漏即红；栈深虚报（接口报 3 实际 1——观测失真）——深账核对（栈深接口值与树内实际层数 diff=0）。
- 正文：实现路径分三步。第一步栈结构：挂载点维度覆盖栈（新挂载压栈——栈顶指针更新），同点三次叠挂（三 sb 各异场景）栈深==3 断言+栈深查询接口断言（可观测）；第二步可见面：解析穿引恒取栈顶（F4224 联动——本条断言可见面内容==栈顶 fs 内容 1,000 例），顶下穿透注入（构造下层内容特征路径）零命中；第三步栈账：叠挂序列账（每次挂载的栈位记录）+栈深虚报检测（接口值与实际层数逐例 diff=0）。数据结构：覆盖栈 + 栈深接口 + 可见面断言器。与现存内核衔接点：`fs/fs23_mount.rs` 现存挂载表叠挂语义切换（接管注记：F4236 专项账——现存同点挂载行为按本条升级）；`m700vfs.rs` F216 联动（对照账）。与 Windows 对照：Windows 同目录挂载点重叠=MOUNTMGR 层拒绝或符号链接覆盖（无栈语义——下层不可达性由删链接实现）；覆盖栈为 Unix 人格语义（对照登记：D3 投影损失——栈语义无 NT 等价）；栈深可观测为域验收设施。判据 UNX-F4222-J1 的复测方式：ktest 栈深==3 可观测 + 可见面 1,000 例 + 穿透注入零命中，宿主侧全跑。

- **风险与回退**：恢复失真（弹出后下层内容与弹前不一致——栈操作污染下层）——逐字节断言（三层×弹前快照 diff=0 逐层），失真即红；栈序破坏（弹了中间层——栈结构坏）——LIFO 断言（F4238 联动：乱序弹注入被拒）；空栈崩（无栈可弹时 panics）——空栈拒断言（空栈注入 100 例全 EINVAL 零崩）。
