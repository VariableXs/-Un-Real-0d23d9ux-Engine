## F3721 桩体系总设计（替身三原则与桩清单）

**定位**：桩体系的总纲：替身三原则（确定性/账本化/可控性）+五桩清单（时钟/中断/DMA/存储/网卡 v1）——零 QEMU 产线的硬件替身军团编制表。
**语义边界**：三原则的语义（判据行内嵌：①确定性（同脚本同桩态→同行为——桩的每次回答可复算——B25 fuzz 确定性哲学的硬件版：**测试环境的确定性是被测系统确定性的前提**——桩抖则万测皆抖）；②账本化（每桩操作全记账（F3730）——桩的行为可审计——真硬件是黑箱、桩是玻璃箱——玻璃箱的意义不是好看是**可对账**）；③可控性（时间快慢/中断时序/故障有无全可控——真硬件给不了的场景桩给得了（超时路径/风暴场景/掉电语义——可控性是测试深度的来源）；桩清单 v1（判据行内嵌五桩——清单 const 扩桩走 bump（不静默扩编——每桩入编要过 F3722 ABI 契约）；桩与被测分池（J2——B20 隔离池同律：桩基础设施不吃被测方内存——被测方 OOM 不连坐桩——**裁判席不塌**）。
**判据**：
- J1：替身三原则（各原则一句判据）+桩清单；M-479 三原则首验（时钟桩+中断桩最小联动→三原则逐条断言）。
- J2：桩与被测分池（接口审查——桩的内存通道独立）。
**纯功能行数**：340（三原则 ~120 + 清单 ~110 + 分池论证 ~110）
**依赖与嫁接源**：B20 隔离池（分池同律）；F3530 时钟（时钟桩真源）；F3730 账本（账本化原则的落实条）；F3728 确定性（确定性原则的落实条）；B25 确定性哲学。
**风险与回退**：桩清单缺桩（某外设无桩→该面开发期零测试——回退：清单与硬件面普查对账（硬件导出面 grep 桩清单——缺口即扩桩提案（走 bump 流程）；三原则间的张力（可控性与确定性（注入是可控的、也是确定脚本的一部分——注入入脚本（F3731 编排——可控性在脚本内、确定性在脚本上——不冲突；分池的性能税（B20 实测数据复用。
**正文**：桩为什么是产线的基石（判据行展开）：开发期零 QEMU 的完整含义——不是"没有硬件"而是"硬件的全部行为由桩代言"——桩代言的质量决定内核开发期测试的置信度：**桩的确定性→测试的确定性→缺陷报告的可复现性→修复的可验证性**——四步信任链的第一环就是桩（判据行：桩不可靠则整条产线的证据链从源头软化）；M-479 的三原则首验（判据行展开）：最小联动场景——时钟桩走到 t=100 触发中断桩 raise(IRQ_TIMER)→①确定性断言：同脚本双跑→两桩行为账 diff==0；②账本化断言：两桩的账五字段齐（F3730）且中断账的时戳==时钟账的 tick=100（**跨桩的账可对**——tick 是两桩的共同语言）；③可控性断言：改脚本"t=100 冻结时钟"→中断不触发（同一套桩、同一接口、脚本改一行行为改——**可控性是脚本级的**）；分池的接口审查（判据行展开）：桩的内存申请走桩池（隔离池的桩段）——被测方 malloc 不供给桩、桩 malloc 不占被测——接口审查（签名无共享通道）；M-479 复测：三原则三断言+跨桩 tick 对账+分池审查。

## F3722 桩接口契约（桩与内核的 HAL 边界）

**定位**：桩的合法性来源：桩实现与真硬件同 ABI（接口签名+语义注释）——桩的可替换性来自 ABI 同构——内核不感知对面是桩是硬件。
**语义边界**：HAL 契约的组成（判据行内嵌：签名同构（函数签名逐字相同——编译期保证）+语义注释（每接口的行为语义（成功路径/错误码/副作用——语义是测试的对照物（桩行为与语义注释 diff==0——F3735 判据库的编制依据）；**内核无感原则**（判据行：内核链接桩或链接真驱动、代码零改动——`#ifdef` 都不该有（有 if 的替身是假替身——替换发生在链接期不在源码期）；契约的版本化（J2：HAL 锚（F3738——ABI 变更走 bump——桩库与内核 HAL 同锚对）。
**判据**：
- J1：HAL 契约（签名同构+语义注释+无感原则）；M-480 接口对账（五桩逐桩 ABI 签名与 HAL 头文件 diff==0）。
- J2：契约版本化（HAL 锚——ABI 变更走 bump。
**纯功能行数**：320（契约 ~110 + 用例 ~105 + 无感论证 ~105）
**依赖与嫁接源**：F3738 ABI 锚（版本化的落实）；F3735 判据库（语义注释的消费方）；B28 CI（同 ABI 双编译（桩版/真驱动版）的预接）。
**风险与回退**：语义注释与桩行为漂移（改桩没改注释——回退：注释-行为 lint（F3735 判据库逐条从注释编译——漂移即判据红——**注释是契约、判据是执法**）；桩接口超集（桩多给了真硬件没有的接口（内核误用→真硬件炸——回退：接口面精确对账（M-480 的 diff 双向（多一个接口也是 diff 红——**替身不能比本尊多才**）；ABI 变更的连锁（HAL bump 后五桩全要跟——回退：锚一致性自检（五桩锚与内核锚比对——不齐拦启动（B23 同法）。
**正文**：无感原则的深度（判据行展开）：可替换性的三个层次——源码级替换（ifdef——假替身：内核知道自己在测试）、链接级替换（同符号不同实现——真替身：内核只认符号）、运行级替换（F3737 热插拔——终极替身：内核连链接期都不用选）——v1 落实链接级（构建流水线双产物：桩版镜像+真驱动镜像——**同一内核源码、两个链接产物**——桩版进 CI、真驱动版进硬件验证——两条产线共享 100% 源码）；M-480 的对账执行（判据行展开）：五桩 37 个接口逐个对——签名（参数表/返回类型/调用约定）与 HAL 头 diff==0；接口面双向核（桩 37==HAL 37——多一个少一个都红；语义注释的抽查（判据行展开）：抽 5 接口注释与 F3735 判据用例比对（注释说 EBUSY 判据就断言 EBUSY——**注释、判据、桩行为三点一线**）；语义注释的写法纪律（判据行展开）：注释是"机器可对照"的（结构化字段：成功语义/错误表/副作用集——不是散文（散文注释没法执法——判据行：给机器读的注释要像接口一样有 schema）；M-480 复测：37 接口对账+双向面核+三点一线抽查。

## F3723 时钟桩（虚拟时钟——时间可控）

**定位**：时间的主权：虚拟时钟（桩内计步不走真钟）+变速三原语（快进/单步/冻结）——时间从"流逝的"变成"可编程的"——超时/延迟/定时全场景的实验台。
**语义边界**：三原语的语义（判据行内嵌：快进(n)（tick 直接 +n——超时类路径的瞬间抵达）；单步（+1——细粒度观察）；冻结（停表——"如果时间停止会怎样"的实验（超时不触发/依赖时间的分支锁定）；F3530 时钟源的桩实现（同接口——内核读时无感（F3722 契约——内核调 clock_read() 拿到的是虚拟 tick）；**虚拟时不含墙钟**（J2：桩内时间一律 tick——真钟不进桩行为——F3728 确定性的时间维度保障——判据行：墙钟是确定性的天敌——桩域墙钟零容忍）；时间的记账（每 tick 变更入账（F3730——时间也是操作）。
**判据**：
- J1：三原语（快进/单步/冻结）+F3530 接口实现；M-481 时钟可控（快进 1,000 tick→超时路径触发+冻结→超时不触发（时间的实验可控性双证）。
- J2：时钟确定性（同脚本→同时钟序列（虚拟时不含真实墙钟。
**纯功能行数**：320（原语 ~110 + 用例 ~105 + 无墙钟论证 ~105）
**依赖与嫁接源**：F3530 时钟源（接口真源）；F3731 编排（快进是编排的常用指令）；F3689 三带（超时判据的桩侧配合）；F3728 确定性。
**风险与回退**：快进的语义歧义（快进时"之间"的超时算不算触发（t=50 有超时、快进 1→200——t=50 的超时路径必须触发（快进穿越式——语义显式（穿越触发规则 const——判据行：快进是"时间旅行"——旅行途中的事件都要发生）；冻结的边界（冻结后依赖时间的活锁（等待时间前进的逻辑卡死——回退：冻结预案（冻结场景脚本显式标注依赖（冻结是实验条件不是事故；tick 溢出（虚拟 tick 的位宽——64 位 tick（千年不溢——判据行：时间 位宽是桩的基础设施、不省。
**正文**：时间可控性的测试学意义（判据行展开）：真实硬件的时间测试是等出来的（超时 30s 的测试就跑 30s——CI 跑不动）；虚拟时钟把"等"变成"跳"——**超时测试的时间成本归零**（快进 1,000 tick 瞬间抵达——CI 里万级超时场景成为可能——桩的可控性直接转化为测试吞吐）；M-481 的双证执行（判据行展开）：证一（快进）：脚本设超时 t=1,000→快进(1000)→超时路径触发+超时账时戳==1,000（穿越语义：t=1,000 恰好抵达）；证二（冻结）：同脚本改冻结@t=500→跑 10,000 步（指令级）→超时路径零触发+依赖时间的分支保持 t=500 态——**时间的开与关都是实验变量**；穿越语义的边界例（判据行展开）：快进(500) 从 t=400——t=450 的超时触发（穿越中触发）、触发后挂的新超时（t=460）也穿越触发（递归穿越——规则：快进一次执行完途经的全部到期事件（按 tick 序——穿越是完整的）；与 F3530 的接口验证（判据行展开）：内核调 clock_read() 返回虚拟 tick——内核侧代码与真钟版逐字节同（无感——链接级替换的时钟例证）；M-481 复测：快进触发+冻结不触发+穿越完整+无感验证。

## F3724 中断桩（虚拟中断控制器——触发可控）

**定位**：异步的主权：中断注入三原语（raise/延迟 raise/风暴）——中断从"天降的"变成"可排程的"——B16 前向声明注入面的主体条。
**语义边界**：三原语（判据行内嵌：raise(irq)（当前 tick 即发）；raise_at(irq, tick)（定时——编排的常用指令）；storm(irq, n)（风暴 n 发——间隔由脚本定（不内置随机——随机也是脚本的一部分（F3728 确定性））；B16 前向声明的注入面（F3504 成对事件的注入源——中断进入→B16 埋点捕获→成对（进入/退出）→潜伏期可算——本桩是 B16 中断度量的实验台）；**桩不丢账**（J1 用例：风暴 n=100→丢失计数==0——真硬件可能丢中断、桩不丢（桩的可靠性高于硬件——**桩不模拟硬件的缺陷除非脚本要求**（F3729 故障模式才模拟丢失）。
**判据**：
- J1：注入三原语+B16 埋点对接；M-482 中断注入（单发→B16 埋点成对捕获+潜伏期入账；风暴 n=100→丢失计数==0）。
- J2：注入序确定性（注入脚本（irq, tick) 序列 const——同脚本同注入史。
**纯功能行数**：320（原语 ~110 + 用例 ~105 + 可靠性论证 ~105）
**依赖与嫁接源**：B16 F3504/F3527（成对事件与潜伏期——对接真源）；F3723 时钟（raise_at 的 tick 基）；F3729 故障模式（丢中断是故障模式不是默认行为）；F3731 编排。
**风险与回退**：风暴的排程歧义（n 发的间隔语义（同 tick 多发——中断控制器语义：同 tick 多发按 irq 序排队——规则 const；嵌套注入（中断处理中再注入（嵌套中断——B16 depth 语义对接（depth 字段——嵌套注入合法但要脚本显式；潜伏期失真（桩注入的潜伏期与真硬件不同（桩零延迟 vs 硬件有传播延迟——诚实声明（桩潜伏期=纯软件延迟——硬件传播延迟不在桩域（F3734 等价边界——判据行：测软件的账、不冒充硬件的钟）。
**正文**：中断可控性的意义（判据行展开）：中断是内核最难测的域（异步、时序敏感、不可复现——真硬件上"偶尔才出"的中断病在 CI 里等于不存在）——中断桩把异步变成排程（**中断的时序成为脚本的常量**——每一个中断何时来、来几次、间隔多少——全在脚本里写着——B21 锁压测的"确定性并发"哲学在硬件侧的完成）；M-482 的执行（判据行展开）：单发：raise_at(IRQ_NET, t=50)→tick=50 中断进→B16 埋点成对捕获（进入 t=50/退出 t=53）→潜伏期 3 tick 入账（F3527 消费——**注入与度量的全链打通**）；风暴：storm(IRQ_TIMER, 100)（每 tick 1 发×100 tick）→B16 侧 100 对全捕获→桩侧丢失计数==0（桩的账与 B16 的账双向对平——**两个账本数同一百件事**）；确定性的脚本化（判据行展开）：注入脚本={ (raise_at, IRQ_TIMER, 100), (raise_at, IRQ_NET, 150), (storm, IRQ_DMA, 200, 10) }——脚本 const——双跑注入史 diff==0（J2）；同 tick 多发的排队语义（判据行展开）：storm 与 raise 同 tick→按脚本序+irq 号序（规则 const 入文法）——排队规则确定则行为确定；M-482 复测：单发成对+风暴百发零丢+脚本确定性+排队语义。

## F3725 DMA 桩（虚拟 DMA——拷贝语义与账）

**定位**：搬运的替身：虚拟 DMA（异步拷贝语义+完成事件挂 tick）+拷贝账（字节/方向/校验/时点）——DMA 的异步性可控、账可对。
**语义边界**：DMA 语义（判据行内嵌：请求（src/dst/len/方向）→受理（态机 Idle→Busy——F3732）→完成事件（挂 tick（F3723 联动——t+拷贝时长（虚拟时长 const（桩的 DMA 速度是脚本参数不是模拟硬件速度）；拷贝账四字段（{字节数, 方向, 校验和, 完成时点}——判据行内嵌）；**拷贝忠实**（J2：逐字节等价——桩不做"聪明"优化（不合并不跳过——桩的优化是假证据——真硬件的优化行为留给硬件验证产线——判据行：替身只演本尊的合同角色、不即兴发挥）。
**判据**：
- J1：DMA 语义（请求-完成事件-挂 tick）+账四字段；M-483 DMA 账（拷贝 64KB→账四字段齐+完成时点可复算）。
- J2：拷贝忠实（逐字节等价——memset 语义。
**纯功能行数**：300（语义 ~100 + 用例 ~100 + 忠实论证 ~100）
