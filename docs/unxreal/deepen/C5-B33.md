### UNX-F11841 · 动态链路面消费总锚
- 判据行数：锚点账 140 + 判据 120 + 对账 100；测试段不计
- **定位**：本批总锚，把"动态链路面"定义为一面可联调的端到端链：ld.so cache 查询 → 路径链（DT_RPATH→LD_LIBRARY_PATH→cache→默认目录）→ SONAME 命中 → 加载落地；glibc 2.39 与 musl 1.2.5 双线同验。嫁接源：glibc 2.39 ld.so 手册查找顺序实况（注出处：glibc 2.39 源码 elf/dl-load.c 路径序）与 musl 1.2.5 ld-musl 实况（注出处：musl 1.2.5 ldso/dynlink.c）。
- **语义边界**：联调面管"链怎么走通"；机制内幕归 B22、错误语义归 B23、版本表归 B32（联签 F11857）。只走 L4 工具链产物，不建新链。
- **依赖与嫁接源**：上游 B32 版本面（联签）、B09 三元组基建（判据执行）；B22/B23/B32 全注出处分层。锚定 F11821 消费总锚范式。
- **风险与回退**：双线顺序差异致格不同 → 差异格显式登记（F11632 范式）；缓存副区不可写 → 沙盒只读档，断点呈现。
- **正文三步**：①沙盒内以样例 exe（DT_NEEDED libvxutil.so）走全链，记录每跳应答；②glibc 线按 cache→RPATH→LD_LIBRARY_PATH 顺序比对 S1 基准，musl 线按 ld-musl 层序比对；③对账行数落账；Windows 对照：对照 Windows DLL 搜索序（应用目录→系统目录→PATH，注出处：MSDN Dynamic-Link Library Search Order）体会顺序语义差异，回测 ktest `c5/b33/anchor_fullchain`。

### UNX-F11844 · DT_RUNPATH/DT_RPATH 联调判据
- 判据行数：锚点账 120 + 判据 120 + 对账 100；测试段不计
- **定位**：RUNPATH 生效联调：以 DT_RUNPATH 样例 exe 解析其依赖库成功；RPATH 与 RUNPATH 优先级差异（RPATH 可被 LD_LIBRARY_PATH 前插，RUNPATH 在 LD_LIBRARY_PATH 之后、注出处：glibc 2.39 ld.so 手册 "RPATH is ignored if RUNPATH is present" 及 dl-load.c 顺序）记差异格。
- **语义边界**：管"两 DT 段联调生效"；生成带 RUNPATH 的 exe 用 L4 工具链（-Wl,-rpath），不重写链接器。
