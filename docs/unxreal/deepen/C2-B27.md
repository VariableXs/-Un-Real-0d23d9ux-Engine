### UNX-F9321 · 时间资源错误面总纲（EINVAL 判定域）
- 域/批：C2/B27｜判据：UNX-F9321-J1 时间资源错误面判据过，EINVAL 触发域（非法时钟/非法标志/值域越界）逐格落账，与 Linux 语义一致格过｜纯功能行数：400 行（EINVAL 判定域 150 + 触发域逐格落账 130 + Linux 一致 120）｜状态：[已深化]

- **定位**：本条是时间/资源族 E 型错误矩阵（F9322–F9339 各专条）的总纲：以 EINVAL 判定域为骨架（非法时钟/非法标志/值域越界三触发域）加 EFAULT（坏指针）与 EAGAIN（定时器耗尽）两伴生域，立时间资源错误面的判域全景，B27 批全部注入格的总装配图。
- **语义边界**：只管判域划分与触发域声明；坏指针矩阵归 F9322/F9328/F9329、定时器耗尽归 F9324/F9325、tv_nsec 规范化边界归 F9333（本批判据重心专条）、sched 面归 F9331/F9332；时间资源正判据归 B06/B19/B20 母体深化册（本批只铺错误面零重铺）。
- **依赖与嫁接源**：嫁接 clock_getres(2)/timer_create(2)/setrlimit(2)/sched(7) man-pages ERRORS 段错误清单；锚定 B21–B28 E 型正反双判据体例、B13 错误矩阵总装（B01–B15 轮）、B25 批 E 型总纲体例（F9281 先例）、A2 计时基座（时钟源消费）。
- **风险与回退**：风险一为 EINVAL 触发域重叠漏判（同一注入既坏时钟又坏值域时判定域歧义）——回退为判序合同：时钟校验→标志校验→值域校验三级瀑布（每级判定函数签名冻结），注入格按落点归域，双坏注入断言先级码；风险二为错误面与正判据混铺——回退为域账分层声明：本批号段只含错误注入断言（E- 前缀），正路径断言零条（逐条扫描落账）。
- **正文**：实现路径分三步：第一步立 EINVAL 判定域——三触发域判定表落账：非法时钟域（clockid 未注册值×clock_gettime/settime/nanosleep/timer_create 四入口）、非法标志域（clock_nanosleep TIMER flag 非法位/sched 策略非法值）、值域越界域（tv_nsec≥1e9/rlim 软硬倒置/itimerval 负值/affinity 全零掩码），每域列触发 syscall 集与典型注入构造；第二步立触发域逐格——三域各典型注入一格校准（非法 clockid=99 EINVAL/TIMER flag=0x10 EINVAL/tv_nsec=1e9 EINVAL），触发域归位表落账（批内每专条标注所属域）；第三步立 Linux 一致核——与四 man-pages ERRORS 段逐码比对表（码名/触发条件/判序位三列），与 A2 计时基座冻结接口对账（时钟校验谓词单源引用），比对表落账。与现存内核衔接点：时钟校验与 A2/B20 单源；错误码出口与 B01 errno 通道单源。与 Windows 对照：Windows 计时错误族 ERROR_INVALID_PARAMETER/ERROR_PRIVILEGE_NOT_HELD，映射对账归 F9336；本条按 Linux 上游语义冻结。判据 UNX-F9321-J1 的复测方式：ktest 三断言——三域判定表逐域命中、三格校准注入、比对表三列一致。

### UNX-F9322 · gettimeofday/clock_gettime 坏指针矩阵（EFAULT）
- 域/批：C2/B27｜判据：UNX-F9322-J1 坏指针注入判据过，全 EFAULT 格过，10/10 次检出格过，与 B06 时间族对账格过｜纯功能行数：380 行（坏指针注入 140 + 全 EFAULT 格 100 + 十次检出 60 + B06 对账 80）｜状态：[已深化]

- **定位**：本条立 gettimeofday/clock_gettime 两读取入口的坏指针注入矩阵：tv 指针与 tz 指针坏值（野指针/只读页写目标/部分可访问）全 -EFAULT——时间读取面最基础错误格，与 B06 时间族读取档对账，10/10 次检出为批级可复测性首例。
- **语义边界**：只管时间读取两入口坏指针；非法 clockid EINVAL 归 F9323（gettimeofday 无 clockid 面）；settime 写入面坏指针归 F9329 结构探针联动；时间读取正语义归 B06 母体（零重铺）。
- **依赖与嫁接源**：嫁接 gettimeofday(2)/clock_gettime(2) man-pages EFAULT 行（'points outside accessible address space'原文）；锚定 F8921/F9116 拷贝探针（access_ok 谓词单源）、B06 时间族母体（读取路径单源）、A2 计时基座（时钟源消费）。
- **风险与回退**：风险一为部分可访问页误判（tv 指针跨页首页可写次页只读，半程写失败被当成功）——回退为整段预检格：写目标按结构全尺寸 access_ok 预检（先于时钟读取动作），半程失败态与预检拒绝两态分立断言，失败后时钟态零副作用；风险二为 EFAULT 判定引入时间读取副作用（坏指针时时钟被读取但结果丢弃，观测面污染）——回退为前置校验格：指针预检最先行（EFAULT 优先于一切时钟访问），时钟读取计数器零增量断言。
- **正文**：实现路径分三步：第一步立坏指针注入——指针坏值三态（0/0xFFFFFFFF/只读页写目标）×两入口×两参数位（tv/tz）共 12 格注入，全 -EFAULT 且 errno 单一，部分可访问跨页构造（tv 指针=页尾-4）单列一格亦 EFAULT；第二步立全 EFAULT 与十次检出——12 格逐格重复注入 10 次（批级可复测性首例），检出账本（格号×轮次×结果）全 10/10 检出断言，时钟读取计数器零增量（预检先行副作用零）断言；第三步立 B06 对账——读取路径与 B06 时间族同函数（grep 单源核）、EFAULT 谓词与 F8921 access_ok 同源，对账表两行落账。与现存内核衔接点：读取路径与 B06 单源；预检与 F8921 链单源。与 Windows 对照：Windows GetSystemTime 无指针错误面（调用方缓冲由 ABI 保证），QueryPerformanceCounter BOOL 失败态近似；差异注记归 F9336。判据 UNX-F9322-J1 的复测方式：ktest 三断言——12 格注入全 EFAULT、十次检出账本零漏、B06 单源对账表。

### UNX-F9323 · clock_settime 非法时钟 EINVAL 矩阵
- 域/批：C2/B27｜判据：UNX-F9323-J1 非法 clockid 注入判据过，全 EINVAL 格过，CLOCK_REALTIME 正判据格过，特权检查挂点格过｜纯功能行数：360 行（非法 clockid 注入 130 + 全 EINVAL 格 80 + REALTIME 正判据 70 + 特权挂点 80）｜状态：[已深化]

- **定位**：本条立 clock_settime 的非法时钟注入矩阵：clockid 未注册值全 -EINVAL、CLOCK_REALTIME 合法正判据对照、与特权检查挂点声明（零时钟源直改承诺的红线落点：改时授权面冻结，实装随特权域联签）。
- **语义边界**：只管 clockid 校验面与特权挂点声明；时钟源读取正语义归 B06/A2（消费）；CLOCK_MONOTONIC 等只读时钟的 settime 拒绝（EINVAL，上游语义：非 settable clock）单列注记格；实际改时执行零触及（红线条款）。
- **依赖与嫁接源**：嫁接 clock_settime(2) man-pages EINVAL 行（'clk_id is not supported'/非 settable 语义）与 EPERM 特权注记；锚定 B06 时间族母体（clockid 表单源）、A2 计时基座（时钟注册表）、B03 身份族（特权谓词挂点）。
- **风险与回退**：风险一为非 settable 时钟误放行（MONOTONIC/BOOTTIME 被误当可设置，破坏单调性承诺）——回退为 settable 表格：clockid 注册表带 settable 位，MONOTONIC settime 注入 → EINVAL（单调性不受扰断言：注入后 MONOTONIC 读值仍单调递增）；风险二为特权检查缺位直改时钟（红线违例：无授权面直接落改时路径）——回退为挂点声明格：改时路径必经特权挂点（授权谓词签名冻结），本内核桩态一律拒绝（零直改承诺），桩拒绝计数可观测。
- **正文**：实现路径分三步：第一步立非法 clockid 注入——clockid=99/-1/0x7FFFFFFF 等未注册值×settime/gettime/res 三入口注入（同 clockid 三入口校验一致性断言），全 -EINVAL 零混 EFAULT（互斥扫描）；第二步立 REALTIME 正判据与非 settable 格——CLOCK_REALTIME settime 经挂点桩态（拒绝计数+1，授权面声明而非 EINVAL——错误码差异：桩拒绝属特权面非值域面，单列注记）；MONOTONIC settime → EINVAL 且读值单调性不受扰双断言；第三步立特权挂点声明——挂点签名（clockid/timespec/授权谓词三参）冻结落账，零时钟源直改承诺格登记（红线条款引用），实装随特权域联签（联签编号落账）。与现存内核衔接点：clockid 表与 B06/A2 单源；授权谓词与 B03 单源。与 Windows 对照：Windows SetSystemTime 特权 SE_SYSTEMTIME_NAME，无 clockid 多时钟域；注记。判据 UNX-F9323-J1 的复测方式：ktest 三断言——未注册值三入口全 EINVAL、REALTIME 桩计数与 MONOTONIC 拒格、挂点签名与承诺登记。

### UNX-F9324 · timer_create/timer_settime 错误矩阵（EINVAL/EAGAIN）
- 域/批：C2/B27｜判据：UNX-F9324-J1 两错误码注入矩阵判据过，非法 sigevent 全 EINVAL 格过，定时器耗尽全 EAGAIN 格过｜纯功能行数：380 行（两码注入矩阵 140 + 非法 sigevent EINVAL 120 + 定时器耗尽 EAGAIN 120）｜状态：[已深化]

- **定位**：本条立 POSIX 定时器双入口错误矩阵：timer_create 的 EINVAL（clockid 非法/sigevent 结构非法）与 EAGAIN（定时器配额耗尽，展开归 F9325）、timer_settime 的 EINVAL（value/interval 非法值域）——定时器面错误双源入口格。
- **语义边界**：只管两入口注入面；定时器配额耗尽细则归 F9325（本条单格触发）；定时器正路径与超期通知语义归 B20 休眠族（对账）；timer_delete 缺号 EINVAL 同域并列注记。
- **依赖与嫁接源**：嫁接 timer_create(2)/timer_settime(2) man-pages ERRORS 段（EINVAL 'invalid sigevent'/EAGAIN 'kernel resources for timer creation exceeded'原文）；锚定 B20 定时器挂点（配额消费）、B11 sigevent 通知面（信号通知单源）、F9321 判域表（归域）。
- **风险与回退**：风险一为 sigevent 校验面过宽（合法 SIGEV_SIGNAL 变体被误拒或通知线程号未校验）——回退为 sigevent 协议表：SIGEV_NONE/SIGEV_SIGNAL/SIGEV_THREAD 三通知面逐面校验规则（SIGEV_SIGNAL 的 si_value 合法域/SIGEV_THREAD 桩态声明），合法值零误拒断言；风险二为耗尽态误报 EINVAL——回退为双源分立格：值域合法+配额满注入必 EAGAIN（非 EINVAL），配额计数探针（当前数/上限值）与返回码一一对应断言。
- **正文**：实现路径分三步：第一步立两码注入矩阵——EINVAL 组：非法 clockid timer_create、sigevent 通知类型=99、timer_settime value 含 tv_nsec=2e9、interval 负值四格；EAGAIN 组：配额满态 timer_create 单格触发（细则 F9325）；全格 errno 断言落账；第二步立非法 sigevent 格——通知类型非法值×3、SIGEV_SIGNAL 信号号非法（sig=64）注入 → EINVAL（与 B11 值域表一致）、SIGEV_NONE 合法零误拒对照三面，协议表落账；第三步立定时器耗尽格——预占配额至上限（配额探针观测）后 timer_create → EAGAIN，值域合法前提断言（值域坏值同态注入仍 EINVAL——两源分立），errno 互斥扫描零混。与现存内核衔接点：配额计数与 B20/F9325 单源；sigevent 通知与 B11 单源。与 Windows 对照：Windows CreateWaitableTimer 无 sigevent（通知走回调/APC 分层），满额无配额错误面；差异注记归 F9336。判据 UNX-F9324-J1 的复测方式：ktest 三断言——两码注入全表、sigevent 三面协议格、耗尽 EAGAIN 与两源分立互斥。

### UNX-F9325 · POSIX 定时器耗尽 EAGAIN 矩阵（RLIMIT_SIGPENDING 联动）
- 域/批：C2/B27｜判据：UNX-F9325-J1 定时器上限注入判据过，全 EAGAIN 格过，与 B19 SIGPENDING 联动格过｜纯功能行数：360 行（定时器上限注入 140 + 全 EAGAIN 格 100 + B19 联动 120）｜状态：[已深化]

- **定位**：本条立定时器配额耗尽的 EAGAIN 注入矩阵：进程 POSIX 定时器数触顶（对齐 RLIMIT_SIGPENDING 配额联动）时 timer_create 全量 -EAGAIN——异步信号队列资源治理（排定信号与定时器共池）的错误面，EAGAIN 时间族主格。
- **语义边界**：只管定时器配额注入面；RLIMIT_SIGPENDING 限额本体归 B19 资源族（联动对账）；排定实时信号队列耗尽 EAGAIN（sigqueue 面）同池注记单列；timer_delete 释放恢复正判据随格。
- **依赖与嫁接源**：嫁接 timer_create(2) man-pages EAGAIN 行（'kernel resources... exceeded'原文）与 RLIMIT_SIGPENDING 语义；锚定 B19 限额族深化册（SIGPENDING 值联动）、B20 定时器表（配额计数单源）、B11 实时信号 pending 池（共池对账）。
- **风险与回退**：风险一为触顶边界 off-by-one（上限 N 时第 N 个误拒或第 N+1 个误放行）——回退为边界夹逼格：预占 N-1 后 create 成功、第 N 次 create 成功恰达上限、第 N+1 次 EAGAIN，三段夹逼断言；风险二为释放后配额泄漏（delete 后计数不回还致永久 EAGAIN）——回退为恢复正判据：触顶后 timer_delete 一个再 create 成功（计数回还观测），泄漏即 fail。
- **正文**：实现路径分三步：第一步立上限注入——经 B19 联动置配额=4，连续 timer_create：前 4 个成功（配额计数逐次递增断言）、第 5 次 → -EAGAIN，形成 4+1 精确序列断言；第二步立全 EAGAIN 格——配额满态注入×3（同一进程重复/不同 clockid/合法 sigevent 各态）全 -EAGAIN 且互斥扫描零混 EINVAL，SIGEV 类型无关性断言（NONE/SIGNAL 两态均拒绝）；第三步立 B19 联动与恢复——限额变更实时生效（配额 4→8 后 create 可行，getrlimit 回读同源）、timer_delete 释放后 create 成功（回还断言）；共池注记：排定信号 pending 池与定时器配额分立声明（本内核分立实现，上游语义注记落账）。与现存内核衔接点：配额计数与 B20 定时器表单源；限额与 B19 单源。与 Windows 对照：Windows 可等待定时器无数量配额（对象数受句柄表上限间接约束）；差异注记归 F9336。判据 UNX-F9325-J1 的复测方式：ktest 三断言——4+1 精确序列、满态三构造互斥扫描、B19 实时生效与 delete 回还。

### UNX-F9326 · setitimer 非法间隔矩阵
- 域/批：C2/B27｜判据：UNX-F9326-J1 负值/超上界注入判据过，全 EINVAL 格过，ITIMER_REAL 三类正判据格过｜纯功能行数：320 行（负值超上界注入 130 + 全 EINVAL 格 90 + ITIMER_REAL 三类正判据 100）｜状态：[已深化]

- **定位**：本条立 setitimer 的非法间隔注入矩阵：itimerval.value/interval 负值与超上界注入全 -EINVAL，ITIMER_REAL/VIRTUAL/PROF 三类计时器合法正判据对照——间隔定时器面错误格，与 B20 休眠族对账。
- **语义边界**：只管 setitimer 注入面；三类计时器正语义（到期通知 SIGALRM/SIGVTALRM/SIGPROF）归 B20/B11（对账）；getitimer 回读面正语义归 B20；tv_usec 值域（≥1e6）越界随本格值域集覆盖。
