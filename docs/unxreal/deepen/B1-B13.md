### UNX-F4242 · umount/umount2 语义与 MNT_DETACH 惰性卸载
- 域/批：B1/B13｜判据：UNX-F4242-J1 umount 即时卸载与 umount2 惰性卸载（MNT_DETACH）双模式断言：惰性模式下挂载点立即不可见而打开句柄继续可读写到底（POSIX 口径 1,000 次）｜纯功能行数：320 行（即时卸载 100 + 惰性双态 120 + 口径断言 100；测试段不计）｜状态：[已深化]
- **定位**：卸载双模式语义——umount（即时卸载：busy 即拒 EBUSY——F4243 联动，成功则挂载点立即可见下层）与 umount2(MNT_DETACH)（惰性卸载：**立即**把挂载点从可见树摘除——新路径解析不再见该挂载，但**已打开句柄继续可读写到底**（句柄持有对象引用——对象不灭直到最后句柄关闭才真正回收，POSIX 权威口径 1,000 次断言）。惰性卸载是"摘树不杀对象"的两阶段语义——可见性与生命周期的解耦。
- **语义边界**：只做双模式语义；不做持有计数账（F4243 分账）；不做失效路径细节（F4249 分账——本条立双模式、F4249 立 detach 后行为）；"立即不可见"口径=原子摘除（F4229 原子律复用——无中间可见态）。
- **依赖与嫁接源**：依赖 F4221 树/F4229 原子律/F4243 持有账；被 C2 umount/umount2 消费；嫁接源为 POSIX umount2(MNT_DETACH) 语义，只跟随。
- **风险与回退**：惰性泄漏（detach 后句柄关闭但对象不回收——延迟引用堆积）——回收断言（F4249 联动：最后句柄关闭触发回收，回收计数==延迟引用数），泄漏即红；可见性破（detach 后新 open 仍可达——摘除不彻底）——双态断言（新访问 1,000 例全 ENOENT+旧句柄 1,000 例读写到底），破口即红；即时误拒（无 busy 场景 umount 也 EBUSY——账错）——正常路径断言（无持有 umount 成功 1,000 例）。
- 正文：实现路径分三步。第一步即时：umount 无 busy→原子摘树（F4229 临界区）→可见下层，1,000 例；第二步惰性：umount2(MNT_DETACH) busy 场景→原子摘可见面（树摘除）+句柄继续持对象引用——双态断言（新 open 1,000 例 ENOENT+旧句柄 1,000 例读写到底成功）；第三步口径：惰性语义注记落账（摘树≠杀对象——两阶段声明）+最后句柄关闭回收联动断言（F4249 锚位）。数据结构：摘树通道 + 双态断言器 + 惰性注记账。与现存内核衔接点：`fs/fs23_mount.rs` 卸载入口切换（接管注记）；`m700vfs.rs` F216 联动（对照账）。与 Windows 对照：Windows 无惰性卸载等价（卷卸载锁卷/强拆——FORCE_DISPOSITION 与 POSIX 语义不同：强制卸载破坏句柄 vs POSIX 惰性保留句柄）；MNT_DETACH 为 Unix 人格语义（对照登记：D3 投影损失——强制卸载场景按锁卷投影，句柄保全语义投影不可达）；"摘树不杀对象"与 Windows 句柄引用语义同构（对象存活由引用决定——机制层同构）。判据 UNX-F4242-J1 的复测方式：ktest 即时 1,000 例 + 惰性双态 1,000×2 + 回收联动断言，宿主侧全跑。

### UNX-F4243 · EBUSY 持有计数账（被打开文件/子挂载/cwd）
- 域/批：B1/B13｜判据：UNX-F4243-J1 三类持有源（打开文件/子挂载/进程 cwd）各自计数与总数一致，busy 时 umount 返回 EBUSY 且持有清单可导出（清单=计数），释放后重试成功——域验收"EBUSY 持有计数账"承载条｜纯功能行数：320 行（三源计数 120 + 清单导出 100 + 重试断言 100；测试段不计）｜状态：[已深化]
- **定位**：域验收"EBUSY 持有计数账"承载条——umount 的 busy 判定与持有一览：三类持有源各自计数（①被打开文件——挂载内对象有活 fd；②子挂载——该挂载上有子挂载未卸；③进程 cwd——有进程工作目录落在此挂载内），三源计数与总数一致（分账与总账 diff=0），busy 时 umount 返回 EBUSY 且**持有清单可导出**（清单条数==计数——可观测排障依据：不是只报"忙"，而是报"谁在忙"），释放后重试成功（busy→释放→umount 成功全链）。三源是挂载生命周期的全部占用面（清单完备性=域验收判据）。
- **语义边界**：只做三源计数与清单；不做惰性卸载（F4242 分账——EBUSY 时用户选 detach）；持有源枚举完备性注记（三源之外新源需扩账——扩维声明）；cwd 持有口径=cwd dentry 落挂载内（含挂载点本身——含边界注记）。
- **依赖与嫁接源**：依赖 F4064 引用/F4126 fd/F4221 树/F4204 cwd；被 C2 umount 消费；嫁接源为 POSIX EBUSY 语义与 Linux mnt_has_parent 类判定，只跟随。
- **风险与回退**：计数漂移（三源分账与总账不一致——判定失准）——一致性断言（万次持有负载分账总和==总账 diff=0），漂移即红；清单虚数（清单条数≠计数——排障失真）——清单断言（导出条数==计数逐次核对 1,000 次），虚数即红；漏源（某类持有没计数——busy 误判可卸）——三源×注入矩阵断言（每源独立 busy 注入 100 例全 EBUSY），漏源即红；释放失灵（释放后仍 EBUSY——计数不降）——重试断言（释放→umount 成功全链 1,000 例）。
- 正文：实现路径分三步。第一步三源：三持有计数器（fd 源：挂载内对象 fd 计数/子挂载源：树孩子数（F4221 复用）/cwd 源：cwd 落点计数），万次混合负载分账总和==总账；第二步清单：busy 时导出持有清单（源类+对象标识条目化），条数==计数断言 1,000 次+三源独立 busy 注入矩阵 300 例全 EBUSY；第三步全链：释放（关 fd/卸子挂/切 cwd）→umount 重试成功 1,000 例——全链闭环+域验收承载注记落账。数据结构：三源计数器 + 清单导出器 + 重试账。与现存内核衔接点：`m700vfs.rs` F205 fd 表联动（注记）；`fs/fs23_mount.rs` busy 判定切换（接管注记）。与 Windows 对照：Windows 卸载拒绝=ERROR_DEVICE_IN_USE/ERROR_SHARING_VIOLATION（持有源=打开句柄/卷锁——源集粒度粗于三源：cwd 类无对应——Windows cwd 是字符串不持卷引用）；三源计数与清单为 Unix 人格语义（对照登记：D3 投影按句柄源映射，cwd 源投影损失登记）；"清单=计数"可观测为域验收设施。判据 UNX-F4243-J1 的复测方式：ktest 万次分账 diff=0 + 清单 1,000 次 + 三源矩阵 300 例 + 重试全链 1,000 例，宿主侧全跑。
