### UNX-F4181 · 符号链接存储模型（快/慢链接）
- 域/批：B1/B10｜判据：UNX-F4181-J1 快链接（目标内联 ≤60 字节）与慢链接（外置存储）双形态创建读取往返一致（各 1,000 例），形态自动选择边界（60 字节恰等）断言通过｜纯功能行数：280 行（快链接内联存储 100 + 慢链接外置存储 100 + 边界选择断言 80；测试段不计）｜状态：[已深化]
- **定位**：链接存储的双形态模型——快链接（目标内联 ≤60 字节，直接存于 inode 本体的预留数组）与慢链接（目标外置存储，走数据块/页缓存路径）自动选择，60 字节恰等归快、61 字节归慢，边界一格断言钉死。快链接省一次块分配与读取（解析热路径的主要形态），慢链接兜长目标（PATH_MAX 内全范围），双形态对上层完全透明（readlink/walk 感知不到差异——接口统一）。
- **语义边界**：只做存储形态与自动选择；不做读取语义（F4182 readlink 分账）；60 字节为域权威口径（对齐经典 ext 类 fast symlink 内联容量——EXT4_N_BLOCKS×4−2=58，本域统一取 60 并登记口径差异）；形态一经创建即固定（不因 rename/mtime 变化而迁移——形态是创建时属性）。
- **依赖与嫁接源**：依赖 F4041 inode 元数据（i_symlink 区位）/F4053 inode 操作表；被 F4182/F4184 消费；嫁接源为 POSIX symlink() 语义与 ext4 fast/slow symlink 存储，只跟随。
- **风险与回退**：边界 off-by-one（60/61 判反——恰等格必须钉死）——两格断言（60 快/61 慢各 10 例），判反注入检出；双形态接口分裂（walk 对两形态走不同代码路径——bug 温床）——统一读取接口断言（同接口读两形态，1,000 例往返一致），分裂注入即红；慢链接泄漏（外置块没释放）——删除回收账联动（B04 inode 回收钩子）。
- 正文：实现路径分三步。第一步快链接：inode 内预留 64 字节内联数组（60 数据+长度头），symlink 创建时目标 ≤60 字节直存内联（零块分配），1,000 例创建-readlink 往返一致断言；第二步慢链接：>60 字节目标走外置页缓存路径（inode 记外置标记+块索引），同样 1,000 例往返一致；第三步边界：60 恰等（快）/61（慢）两格注入断言，形态选择器单点判定。数据结构：i_symlink 内联数组 + 外置标记 + 形态选择函数。与现存内核衔接点：`m700vfs.rs` F213 现存链接存储切换为双形态模型（接管注记：现存单一路径存储升级为快/慢分形——内联容量口径 60 登记在案）；`fs/fs23_mount.rs` 链接解析消费统一读取接口（对照账）。与 Windows 对照：NTFS reparse point 同有驻留（resident，内联于 MFT 记录）与非驻留（non-resident，外置簇）双形态——形态自动选择两侧同构；NTFS 内联容量随 MFT 记录碎片化而动态（无固定 60 常数），本域固定 60 为确定性口径（对照登记）；IO_REPARSE_TAG_SYMLINK 的 SubstituteName/PrintName 双串与 POSIX 单目标串的结构差在 D3 投影层映射。判据 UNX-F4181-J1 的复测方式：ktest 双形态各 1,000 例往返一致 + 60/61 边界两格断言，宿主侧全跑。

### UNX-F4182 · readlink 语义与返回长度
- 域/批：B1/B10｜判据：UNX-F4182-J1 readlink 返回目标全串且不追加 NUL（POSIX 口径断言），缓冲区恰等/不足两态行为账齐备（截断不写入越界）｜纯功能行数：260 行（读取主语义 90 + NUL 口径断言 80 + 两态账 90；测试段不计）｜状态：[已深化]
- **定位**：readlink 的 POSIX 权威口径——返回目标全串且**不追加 NUL**（与大多数返回字符串的 syscall 相反——readlink 是"返回字节串"不是"返回 C 串"），缓冲区恰等（bufsize==目标长）完整读出、不足（bufsize<目标长）截断且不越界写一字节。"不追加 NUL"是 C 程序员经典踩坑点（ strcat 惯性），断言钉死防止实现"好心"补零破坏口径。
- **语义边界**：只做正常读取与长度口径；不做截断返回值语义（F4195 分账——本条管"读什么"，F4195 管"截断时返回几"）；readlink 对非链接对象返回 EINVAL（负向格注记——断言集含 1 例 EINVAL 对照格）。
- **依赖与嫁接源**：依赖 F4181 双形态读取接口/F4035 f_op 语义面；被 C2 readlink syscall 消费；嫁接源为 POSIX readlink 语义（返回值不含终结 NUL），只跟随。
- **风险与回退**：好心补 NUL（破坏 POSIX 口径——调用方按 strlen 布局溢出风险）——不追加断言（读出 buffer 末字节可写 sentinel 验证零写入），补零注入即红；越界写（截断时写出 bufsize 边界）——边界写守护断言（kasan 语义哨兵位+长度账），越界注入检出；形态分裂（快慢两形态读取行为不一致）——F4181 统一接口复用断言。
- 正文：实现路径分三步。第一步主语义：readlink(路径,buf,bufsiz) 入口→F4181 统一读取→目标全串拷入（min(全串,bufsiz)），不追加 NUL 断言（bufsiz 恰等时 buf 末字节后置哨兵验证未写）；第二步两态账：恰等态（bufsiz==目标长，完整返回）与不足态（bufsiz<目标长，截断且零越界）各 1,000 例，行为账逐例核对；第三步负向格：非链接对象 1 例 EINVAL 对照（口径完整性）。数据结构：读取账（输入/形态/返回值/写入字节数）。与现存内核衔接点：`m700vfs.rs` F213 现存 readlink 语义切换（接管注记：现存接口对齐不追加 NUL 口径）；C2 readlink syscall 为联签下游。与 Windows 对照：Windows 无 readlink 等价 syscall——读 reparse 目标走 DeviceIoControl(FSCTL_GET_REPARSE_POINT) 返回结构化缓冲（含 SubstituteName 偏移长度对）；"无 NUL 追加"口径在 Windows 由结构长度字段天然保证（对照登记：结构化 vs 字节串两种口径，D3 投影按 SubstituteName.Length 精确映射）。判据 UNX-F4182-J1 的复测方式：ktest 恰等/不足两态各 1,000 例 + NUL 零追加哨兵断言 + EINVAL 对照格，宿主侧全跑。

### UNX-F4183 · symlink 创建与 O_EXCL 语义锚
- 域/批：B1/B10｜判据：UNX-F4183-J1 symlink 创建对已存在目标名返回 EEXIST（10/10），链接本体类型位 S_IFLNK 落账，悬空目标允许创建（POSIX 口径）｜纯功能行数：260 行（创建主语义 90 + EEXIST 守卫 80 + S_IFLNK/悬空账 90；测试段不计）｜状态：[已深化]
- **定位**：symlink() 创建面的三锚——①对已存在目标名（链接路径本身已存在）返回 EEXIST（symlink 不覆盖、无 O_EXCL 覆盖语义——创建面天然排他）；②链接本体类型位 S_IFLNK 落账（inode 类型七类中的 LNK 格真实生效）；③悬空目标允许创建（目标串不需要指向存在文件——POSIX 明文，链接创建时不解引用目标串，字符串即全部语义）。悬空合法是链接与硬链接的第一分野（link() 要求目标存在，symlink() 不要求）。
- **语义边界**：只做创建面；不做 readlink（F4182）/不解决析构语义（unlink 由 F4075 接管）；EEXIST 判定对象是 newpath（链接落位名）非 oldpath（目标串）——参数语义注记防混。
- **依赖与嫁接源**：依赖 F4052 setattr 管道（i_op create 路径）/F4003 类型位；被 C2 symlink syscall 消费；嫁接源为 POSIX symlink 语义（EEXIST/悬空允许），只跟随。
- **风险与回退**：误判对象（对 oldpath 做存在检查——错，老路径不需要存在）——悬空创建断言（1,000 例指向不存在目标全成功），误检注入即红；覆盖写入（已存在 newpath 被覆盖——POSIX 禁止）——EEXIST 断言 10/10，覆盖注入检出；类型位缺失（LNK 位没落——后续 walk 分派全乱）——S_IFLNK 落账断言（stat 类型断言联动）。
- 正文：实现路径分三步。第一步创建主链：symlink(oldpath,newpath)→父目录 i_op.symlink（B08 14 函数表 LNK 格）→inode 分配+S_IFLNK 类型位+目标串按 F4181 形态落库，返回成功；第二步守卫：newpath 已存在（dentry 正命中非负）→EEXIST（10/10 注入），悬空目标 1,000 例创建全成功（不解引用验证：目标串任意字节串含非法路径字符均落库——POSIX 只在解析时才报错）；第三步落账：S_IFLNK 断言（lstat 类型==LNK）+ EEXIST 对象账（判定于 newpath）。数据结构：创建账 + 类型位断言器。与现存内核衔接点：`m700vfs.rs` F213 创建路径切换（接管注记）；F4052 setattr 管道联动（时间戳创建置账）。与 Windows 对照：NT 创建 symlink=设置 reparse point（NtCreateFile+FILE_OPEN_REPARSE_POINT 语境+FSCTL_SET_REPARSE_POINT）——创建时同样不解引用目标串（悬空允许，两侧同构）；Windows 对目录符号链接要求 SYMBOLIC_LINK_FLAG_DIRECTORY 显式标注（POSIX 无此区分——目录/文件链接目标类型在解析时才判定），差异登记；已存在名覆盖在 NT 侧由 CreateDisposition 控制（FILE_CREATE 排他——语义同构于 EEXIST）。判据 UNX-F4183-J1 的复测方式：ktest EEXIST 10/10 + 悬空创建 1,000 例 + S_IFLNK 落账断言，宿主侧全跑。

### UNX-F4185 · 最后一分量跟随/不跟随矩阵
- 域/批：B1/B10｜判据：UNX-F4185-J1 末分量 × 标志 × 系统调用默认值矩阵（stat 跟随/lstat 不跟随/readlink 不跟随等 8 格）全过，默认值表与 POSIX 对照零差｜纯功能行数：280 行（8 格矩阵 100 + 默认值对表 90 + 断言执行 90；测试段不计）｜状态：[已深化]
- **定位**：末分量的跟随决策矩阵——POSIX 各系统调用对"路径最后一段是符号链接"的态度各不相同：stat 默认跟随、lstat 默认不跟随、readlink 恒不跟随（还要读本体）、unlink/rmdir 恒不跟随（删链接不删目标）、chmod 恒跟随、lchown 不跟随、rename 两端不跟随、link 旧端跟随新端不跟随——8 格矩阵把"每族调用对末分量链接的默认行为"钉成对表，与 POSIX 语义逐格零差。这是"同一个链接、不同调用、不同结果"的语义全景（链接语义最容易犯错的集中地）。
- **语义边界**：只做末分量默认值矩阵；不做 *at 标志传播（F4188 分账——本条是默认值层，F4188 是标志覆盖层）；矩阵 8 格=8 族调用（stat/lstat/readlink/unlink/chmod/lchown/rename/link），逐格以 F4172 标志协议消费（NOFOLLOW 位由各族入口预设）。
