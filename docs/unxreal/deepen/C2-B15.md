### UNX-F9081 · LTP 登记总纲（"可跑"三档定义）
- 域/批：C2/B15｜判据：UNX-F9081-J1 三档（全过/部分过/登记待测）定义冻结判据过，档位判分与依赖完成度挂钩规则落账，空档不静默声明落账｜纯功能行数：280 行（三档定义冻结器 110 + 判分挂钩格 90 + 不静默声明格 80）｜状态：[已深化]

- **定位**：本条是 LTP 登记面（F9082–F9089 八族）的总纲：LTP（Linux Test Project）用例在本内核的"可跑"三档定义——全过档（依赖齐备+用例通过）、部分过档（依赖部分齐备，缺项显式列名）、登记待测档（依赖未落，号面映射登记）——冻结判分规则与依赖完成度的挂钩协议。三档使"可跑性"从口号变成可审计分档，空档（无登记）零容忍。
- **语义边界**：只管三档定义与判分协议；各族用例清单归 F9082–F9089、LTP 用例本体移植归 B7 测试域（本域只登记可跑性映射）、依赖完成度数据源是各跨域协议（F9095）与 open_risks（F9097）。
- **依赖与嫁接源**：嫁接 LTP runtest 文件体例（runtest/syscalls 等分文件形态，只跟随体例不跟随数据）；锚定 ktest CheckSet 三态（pass/fail/skip——LTP 三档是其族级聚合形态）、F9095 跨域协议（依赖列名源）、F9097 open_risks（待测档移交）、F9096 验收包。
- **风险与回退**：风险一为三档判分主观化（"部分过"边界模糊）——回退为判分挂钩格硬规则：档位=（通过用例数/用例总数）与依赖齐备度双维判定，比例阈值冻结（全过=100%+依赖齐、部分过=≥1 通过且缺依赖列名、待测=0 可跑用例）；风险二为待测档被当弱化版全过档——回退为待测档在验收包显式计数（F9096 披露项），移交 open_risks 强制。
- **正文**：实现路径分三步：第一步立三档定义冻结器——全过档：族内抽样用例 100% 通过且依赖完成度表全绿；部分过档：至少 1 用例通过、缺依赖项显式列名（列名格式：`依赖域/依赖条目号`）；登记待测档：依赖未落（如 A4 页表全量/B1 VFS 全量），号面映射与预期依赖列名落账；三档判分规则以伪代码冻结（可执行判定）；第二步立判分挂钩格——依赖完成度数据源协议：每档判定引用 F9095 四域协议表+A1/A3/A4/B1/B2 交付态字段（handoff.json 字段对齐），判分可复算（他人按同规则应得同档）；第三步立不静默声明格——八族登记表任何族不得空档（无登记行即收口 fail），空档检查器内置，声明落账入 F9096。与现存内核衔接点：三档是 ktest 三态的族级聚合（pass 率聚合）；依赖列名与 F9095 协议单一源。与 Windows 对照：Windows 无 LTP 等价物（WDK 静态验证替代）；三档分档使 LTP 兼容承诺分级可审计。判据 UNX-F9081-J1 的复测方式：ktest 三断言——三档判分伪代码可执行且三用例（构造三族态）判分一致、依赖列名格式校验、空档检查器演练（构造空档→fail）。
