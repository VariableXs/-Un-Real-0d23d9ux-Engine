### UNX-F0862 · RTE 间接寻址读写原语与访序纪律

### UNX-F0864 · ISA Override 裁决（MADT ISO 消费，F0004 冻结接口）
- 域/批：A2/B04｜判据：UNX-F0864-J1 Override 应用正确率 100%（QEMU 标准 2 条 ISO 全中），冲突检测（同 GSI 双 override）10/10 次红账｜纯功能行数：320 行（ISO 消费 130 + 冲突检测 100 + 裁决账 90；测试段不计）｜状态：[已深化]
- **定位**：ISA 侧 IRQ（0–15）经 IO-APIC 引脚时的极性/触发模式与默认假设不同——MADT 的 Interrupt Source Override 条目逐条声明（源 IRQ→GSI 映射 + 极性 + 触发模式），其中"极性/触发 = active-high/edge 之外的值才写"（ACPI 语义：默认值不写，写即覆盖）；本条消费 F0004 交付的 `IsoEntry` 列表做裁决账：每条 ISO 生成 GSI 的最终触发/极性属性（默认值+覆盖合成），冲突（同 GSI 两条 override）红账，合成结果入 F0865 编码器的默认属性源。
- **语义边界**：只做 ISO 裁决；不做 RTE 写（编码器管）、不做设备侧再声明（设备域 ACPI 资源消费）；合成规则显式表驱动（默认表 × 覆盖项 = 终值），规则外组合红账。
- **依赖与嫁接源**：依赖 F0004 `IsoEntry`（`acpi.rs` 已交付）与 F0863 映射表；嫁接源为 ACPI Spec §5.2.15.2（Override 结构字段语义）与 Linux acpi override 处理惯例，只跟随。
- **风险与回退**：BIOS 谎报（override 与设备真实电气特性不符——真机偶发）——裁决账可被 cmdline 逐 GSI 覆盖（`varix.gsi_attr=N=P,T` 语法，人工裁决权保留），覆盖动作留账，真机判据登记随闸门补测（R-A2-002 同型）。
- 正文：实现路径分三步。第一步 ISO 消费：遍历 `MadtInfo` ISO 列表，逐条解析（bus=0 断言、source IRQ、gsi、极性/触发枚举翻译——0x00 遵从默认/0x01 high-edge 类映射到属性枚举），合成每 GSI 终值属性（`GsiAttr{polarity, trigger}`），默认表（ISA 0–15：高电平/边沿按惯例，其余按默认）先行再覆盖；第二步冲突检测：同 GSI 双 override 红账（10/10 次注入捕获），属性枚举越界值红账，合成账逐条留痕（源 IRQ/GSI/覆盖字段/终值）；第三步验证：QEMU 标准两张 ISO（IRQ2→GSI2、IRQ9 极性覆盖）10/10 次正确合成、冲突注入拦截、cmdline 覆盖通路注入 10/10 次生效留痕。与现存内核衔接点：`acpi.rs` `IsoEntry` 直接消费，`apic.rs` 新增裁决模块。与 Windows 对照：Windows HAL 同样消费 ISO 表（`!pic` 时代产物已废，现代全走 IO-APIC 属性合成），判据 UNX-F0864-J1 的复测方式：QEMU 两条全中、冲突 10/10 次红账、覆盖通路 10/10 次。

### UNX-F0866 · 引脚掩码状态机与写时序纪律
- 域/批：A2/B04｜判据：UNX-F0866-J1 状态机四态迁移正确率 100%（非法迁移 10/10 次拦截），屏蔽生效窗口实测 ≤1µs，状态账与硬件读回一致率 100%｜纯功能行数：280 行（状态机 130 + 写时序 80 + 验证 70；测试段不计）｜状态：[已深化]
- **定位**：引脚掩码位（mask bit）是路由面的"总闸"——配置 RTE 前必须先掩（防半配置 RTE 被硬件投递），配置完再解掩；本条把掩码生命周期做成四态状态机（Unmasked/Masking/Masked/Unmasking）+ 写时序协议（掩→写→验→解掩四步序固化），状态账与硬件读回交叉（软件账与 RTE mask 位一致），非法迁移（Unmasked 态直接写 RTE 等）拦截。
- **语义边界**：只做掩码状态与写时序；不做绑定语义（F0867）、不做迁移序列（F0883 亲和性迁移消费本状态机）；状态机 per-引脚一实例。
- **依赖与嫁接源**：依赖 F0862 原语与 F0865 编码器；嫁接源为 Linux IO-APIC 配置时序（masked-then-write 惯例）与 Intel SDM §10.12.1.2（mask 位语义），只跟随。
- **风险与回退**：掩码后忘解掩（中断永久静默——经典事故）——解掩确认步不可跳过（时序协议硬编码），超时未解掩（配置方崩溃）看门狗回滚账，回滚动作留痕。
- 正文：实现路径分三步。第一步状态机：四态枚举 + 迁移表（合法迁移五条：Unmasked→Masking→Masked→Unmasking→Unmasked 及 Masked 内重配环），迁移函数带表校验，非法迁移红账拦截；第二步写时序：`rte_program(pin, value)` 协议固化——掩位写（经编码器）→掩生效确认（读回 mask=1）→主字段写→读回验证→解掩（如目标态为 Unmasked），五步账逐步落，确认失败即中止回滚；第三步验证：状态迁移表 10/10 次正确、非法迁移注入 10/10 次拦截、掩生效窗口实测（掩写完成到读回确认 TSC 差）≤1µs、状态账与硬件读回 1000 次采样一致率 100%。与现存内核衔接点：`apic.rs` IOAPIC 路径收编。与 Windows 对照：Windows HAL 同样掩后配置时序（内部不可见），本内核状态机与看门狗回滚把事故面显式化，判据 UNX-F0866-J1 的复测方式：迁移 100%、拦截 10/10 次、窗口 ≤1µs、一致率 100%。

### UNX-F0867 · 引脚→向量绑定表与反向查询
