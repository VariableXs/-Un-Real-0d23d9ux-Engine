### UNX-F13023 · guard page 触发栈增长路径（×1000 轮零错位）
- 域/批：D2/B12｜判据：UNX-F13023-J1 触底访问→guard 移除→提交推进→新 guard 布置四步 ×1,000 轮零错位（位图账核对），任务书判据承载｜纯功能行数：360 行（四步协议 130 + 位图账核对 120 + 千轮回归 110；测试段不计）｜状态：[已深化]
- **定位**：本条是栈增长协议的本体条目（任务书判据承载位）——guard 页触碰后的四步自动推进：触底访问触发缺页→移除旧 guard→提交推进一页（提交新页+数据页就绪）→在新的提交边界布置新 guard。四步每次触碰恰执行一遍，×1,000 轮零错位是位图账的机械证明。栈增长是"透明的自动扩展"，错一步栈就静默损坏。
- **语义边界**：只做四步协议本体，触发判定细节（跨 guard 跳跃的溢出分岔）在 F13031、单页推进语义在 F13030；缺页通知消费 A4 分发面；推进粒度一页/次（Windows 单页推进语义，多页跃进属错误）。Windows 对照锚：Windows guard page 自动提交推进语义。
- **依赖与嫁接源**：嫁接源为纯自研（语义跟随公开行为）。上游依赖：A4 缺页分发/提交原语、F13021 布局器、F13022 位图。下游消费：F13025 提交记账（事件源）、F13030/31（语义细分）。现存内核衔接点：四步协议挂缺页处理路径的栈分区（`mm/` 缺页分发面注册栈处理钩子）。
- **风险与回退**：风险是四步非原子中断——步骤间缺页再入（嵌套缺页）导致状态机错乱（guard 双布置或丢失）。对策：栈分区缺页处理串行化（同栈区间缺页队列化），四步内禁再入；回退为四步状态机显式化（每步落账+断言态合法），错乱即报非静默。
- 正文：实现路径分三步。第一步写四步协议：缺页处理钩子判定触底（访问地址<提交边界且>保留底）→四步执行（guard 移除/提交推进一页/新 guard 布置/返回重试），每步 A4 原语调用+账记。第二步写位图账核对：每轮四步前后位图快照差分（预期：guard 下移一页/committed 加一页），差分非预期即失败。第三步写千轮回归：递归驱动样本 ×1,000 轮连续增长，每轮位图核对+终态位图断言（提交页数==初始+轮数）。与现存内核衔接点：钩子注册在 `mm/` 缺页分发面（栈区间标记），原语零改动。与 Windows 对照：四步语义与 Windows 一致（实机缺页计数对照随闸门补测）。判据 UNX-F13023-J1 复测方式：×1,000 轮位图差分零错位断言；四步事件账序断言（移除→推进→布置序）；终态提交页数精确断言。

### UNX-F13026 · PE 头 SizeOfStackReserve/Commit 尊重与默认值
- 域/批：D2/B12｜判据：UNX-F13026-J1 头部定制栈参数 30 样本尊重一致，零值/超大值回退默认行为与 Windows 一致｜纯功能行数：280 行（头字段读取 90 + 尊重逻辑 100 + 回退默认 90；测试段不计）｜状态：[已深化]
- **定位**：本条立栈参数的来源语义——PE 头 SizeOfStackReserve/SizeOfStackCommit 字段（链接器 /STACK 产物）的尊重规则：正常值直接采用；零值/超界值回退内核默认（1MB/4KB 页大小相关）。映像说要多大栈内核就给多大（在合理范围内），这是"尊重产物"纪律在栈维度的体现。
- **语义边界**：只做参数读取与尊重判定，布局展开在 F13021/22（本条产出参数）；回退默认值的"默认"为内核常量（与 Windows 默认对齐：1MB 保留），非用户可配项；超大值上限（保留区与地址空间约束冲突时）按 Windows 口径失败而非静默缩水。Windows 对照锚：PE 可选头 SizeOfStackReserve/Commit 语义与 Windows 默认栈参数。
