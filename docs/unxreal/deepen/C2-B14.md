- **语义边界**：只管消费证据与探针；stdio 缓冲实现（行缓冲/全缓冲切换）归 F9076 单独深化档、号语义归 B02 母体、B6 域包装器实现防重不铺、printf 格式化引擎（不触号）登记"纯用户态"边界格。
- **依赖与嫁接源**：嫁接 glibc syscalls.list（open/read/write/close 四行）与 stdio 内部路径体例；锚定 B02 F8811–F8814 母体格、B1 tmpfs 探针段、F9077 账本格式；探针体例对照 busybox 静态链接法（F9078 统一）。

### UNX-F9063 · glibc malloc/brk/mmap 消费核（B03 号面）
- 域/批：C2/B14｜判据：UNX-F9063-J1 malloc 大小块两路消费证据（brk 顶探/mmap 阈值 128KiB）登记判据过，free 触发 madvise（MADV_DONTNEED）路径证据过｜纯功能行数：240 行（两路证据登记 120 + madvise 路径格 120）｜状态：[已深化]

- **定位**：本条立 glibc 堆分配器的两路消费证据核：小块走 brk（程序断点顶探）、大块（≥MMAP_THRESHOLD 默认 128KiB）走匿名 mmap，free 大块触发 madvise(MADV_DONTNEED) 归还物理页。malloc 是用户态最复杂的号面消费者，两路证据齐备即堆底座可信。
- **语义边界**：只管消费证据登记；malloc arena/_bins 本体归 B6 域、brk/mmap/madvise 号语义归 B03 母体、MMAP_THRESHOLD 动态调整（glibc 阈值自适应）登记为行为注记不展开、mlock 交叉验证格引用 B03 F8824。
- **依赖与嫁接源**：嫁接 glibc malloc.c 阈值体例（DEFAULT_MMAP_THRESHOLD 128KiB）与 brk/mmap 消费路径；锚定 B03 F8818（brk 探顶）/F8815–F8817（mmap 三联）/F8821（madvise 五档）母体格、meter 触号抓取、F9061 全链。
- **风险与回退**：风险一为探针依赖 glibc malloc 交付态——回退为同 F9062 三态协议（料缺 skip 带因、静态映射账照登）；风险二为 madvise 触发条件误判（glibc TRIM_THRESHOLD 语义）——回退为证据格只断言"大块 free 后 MADV_DONTNEED 触号"，阈值细节登记注记。
- **正文**：实现路径分三步：第一步立小块路证据——malloc(4KiB)×N 探针：meter 抓 brk 号（扩展断点）+ 触号次数与 arena 增长对账；登记 brk 探顶语义引用（B03 F8818 母体）；第二步立大块路证据——malloc(256KiB) 探针：meter 抓 mmap（匿名 PROT_READ|WRITE MAP_PRIVATE）号、free 后抓 madvise(MADV_DONTNEED) 号，三号证据链对账；MMAP_THRESHOLD 注记落账；第三步立对账格——两路合计触号清单与 syscalls.list 映射表勾稽零差（malloc 族不触其他号断言），账本登记入 F9077。与现存内核衔接点：探针经 F9061 全链；A4 缺页回调在 mmap 写入路径联动（B03 协议）。与 Windows 对照：Windows 堆走 HeapAlloc（VirtualAlloc 底座）同构两路；brk 是 POSIX 特有形态（Windows 无），消费核登记彰显号面兼容承诺。判据 UNX-F9063-J1 的复测方式：ktest 三断言——小块路 brk 证据、大块路 mmap+free+madvise 三号证据链、勾稽零差断言。

### UNX-F9064 · glibc fork/exec/wait 消费核（B04 号面）
- 域/批：C2/B14｜判据：UNX-F9064-J1 system()/popen() 消费链证据（fork+execve+waitpid）登记判据过，abort() 走 raise(SIGABRT) 证据过｜纯功能行数：220 行（system/popen 链登记 120 + abort 链格 120）｜状态：[已深化]

- **定位**：本条立 glibc 进程族消费证据核：system()（fork+execve+waitpid 三号链，shell 中间层）、popen()（同链+管道 fd 交接）、abort()（raise(SIGABRT)→默认处置 Core 转储路径）。三链是 shell 脚本与崩溃处理的消费命门，与 B04 母体逐号勾稽。
- **语义边界**：只管消费证据登记；system 的 shell 定位（/bin/sh 本体）归 B6/B7 域、abort 的 Core 转储文件本体归 C1 后续批次（F9006 类别标记登记过）、POSIX spawn 消费链（clone 直用）格登记不展开。
- **依赖与嫁接源**：嫁接 glibc system.c/popen.c/abort.c 消费路径体例；锚定 B04 F8832（fork）/F8833（execve）/F8868（wait4/waitpid 转接）母体格、B11 F9004（raise 转接）/F9006（默认表 Core 格）、F9023 管道（popen 链 fd 交接证据）、F9077 账本。
- **风险与回退**：风险一为 system 探针依赖 /bin/sh 存在（busybox 未部署）——回退为三态协议：sh 在位跑全链、不在位以 fork+execve(/kt/dummy)+waitpid 等价链验内核三号（libc 链静态登记照落）；风险二为 abort 的 SIGABRT 默认处置在 ktest 沙箱表现（Core 类别=Term 行为）——回退为断言"进程终止+状态字信号位 6"，转储文件格 skip 带因。
- **正文**：实现路径分三步：第一步立 system/popen 链登记——system(cmd) = fork→execve("/bin/sh","-c",cmd)→waitpid 三号证据四列账；popen 同链+pipe 双 fd 交接格（F9023 联动引用）；第二步立 abort 链格——abort() = raise(SIGABRT)（glibc 内部经 tgkill）→SIGABRT 无 handler→F9006 默认表 Core 类别→进程终止，状态字信号位=6 断言；第三步立勾稽格——三链触号清单与 B04/B11 母体映射表勾稽零差，账本登记。与现存内核衔接点：三链经 F9061 全链；waitpid 转接档与 F8868 单源。与 Windows 对照：system() = CreateProcess(cmd.exe /c) 同神；abort→SIGABRT 是 assert 失败的底座，消费链保真即 shell 生态可信。判据 UNX-F9064-J1 的复测方式：ktest 三断言——system 链三号证据、popen 管道交接格、abort 状态字信号位 6。

### UNX-F9066 · glibc 时间族消费核（B06 号面 clock_gettime/gmtime 缓存）
- 域/批：C2/B14｜判据：UNX-F9066-J1 clock_gettime 直入 syscall（无包装缓存）证据判据过，vDSO 快路径（B06 F8912）优先协商证据过，localtime 时区读文件链证据登记｜纯功能行数：220 行（直入证据 100 + vDSO 协商格 120）｜状态：[已深化]

- **定位**：本条立 glibc 时间族消费证据核：clock_gettime 直入 syscall（时间查询无缓存可做，每调必号）、vDSO 快路径优先协商（glibc 探测 vDSO 符号表后走用户态读时）双路证据、localtime 时区链（读 /etc/localtime 文件）文件族消费登记。时间族是消费频率最高的象限，vDSO 双路是性能面关键格。
- **语义边界**：只管消费证据；vDSO 实现本体归 B06 F8912（本条只登记协商证据）、时区解析（TZif 格式）归 B6/B1 域、gmtime 缓存（时区结构体复用）登记注记、nanosleep 消费格引用 F9046 抽样组。
- **依赖与嫁接源**：嫁接 glibc clock_gettime.c（vDSO 探测 fallback syscall）与 localtime.c（/etc/localtime 打开读）路径；锚定 B06 F8842/F8889 母体格、F8912 vDSO seqlock 协议、F8911 仲裁协议、B1 tmpfs（/etc/localtime 测试件）、F9077 账本。
