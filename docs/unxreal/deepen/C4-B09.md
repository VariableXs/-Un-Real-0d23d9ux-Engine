- 域/批：C4/B09｜判据：UNX-F10569-J1 对端 close 后缓冲排空读得 EOF（0 字节），本端 write 得 EPIPE+SIGPIPE（B01 链复用），10/10 次｜纯功能行数：260 行（EOF 面 90 + EPIPE 面 90 + 判死账 80；测试段不计）｜状态：[已深化]

- **语义边界**：只做 fd 关闭终态；shutdown 面 F10568；两端引用计数与连接对象回收（close 全部 fd 后连接销毁）落账。
