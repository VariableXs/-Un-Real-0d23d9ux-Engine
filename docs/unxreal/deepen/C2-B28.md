- **语义边界**：只管跨族总装与逐格检出；各族单格构造本体归 B21–B27 原批（本条引用联动）；指针等价类分类学归 F9351；坏值注入器机制归 F9349（消费不重铺）。
- **依赖与嫁接源**：嫁接 errno(3) EFAULT 定义（"Bad address"）与 Linux copy_*_user 返回值约定（非零未拷贝字节数转 EFAULT）；锚定 B21–B27 五族指针格号清单、F9351 指针等价类、F8921/F9116 参数拷贝探针总成。
- **风险与回退**：风险一为总装格与原批格漂移（总装重跑与原批结果不一致）——回退为联动回归格：总装矩阵与 B21–B27 原批逐格同构造同预期，双跑结果差一格即 fail；风险二为方向漏测（in 方向全覆盖而 out 方向缺格）——回退为方向配对规则：每个取指针参数按 in/out 属性逐参数登记方向位，矩阵按方向位配对出格，out 缺格即 fail。
- **正文**：实现路径分三步：第一步立五族逐格总装——五族各自登记取指针参数挂点清单（族号/挂点号/参数位/方向位四列），逐挂点出格（四类指针：NULL/用户态越界 0xFFFFFFFFFFFF0000/内核地址 0xFFFF800000000000/未映射页），矩阵规模逐族落账；第二步立 EFAULT 逐格检出——每格注入后断言返回 -EFAULT 且 errno 单一（零 EINVAL/EBADF 混淆），access_ok 预检与页错误路径双检出路径均可达（预检拦截格与页错误兜底格分列）；第三步立拷贝方向双向格——in 方向（内核读用户缓冲，如 write buf）与 out 方向（内核写用户缓冲，如 read buf/stat 结构回填）逐方向断言：out 方向坏指针时内核侧结构不得半写（先拷入栈暂存后提交，失败即回滚）。与现存内核衔接点：拷贝路径与 F8921/F9116 探针单源；检出格预期值与 B13 Errno 单源。与 Windows 对照：Windows 坏用户指针经 SEH/ProbeForRead 捕获转 STATUS_ACCESS_VIOLATION，探针式预检同源不同形；对账注记随深化落账。判据 UNX-F9342-J1 的复测方式：ktest 三断言——五族挂点清单零漏格、全格 -EFAULT 单一、方向位配对出格双向覆盖。

### UNX-F9343 · 全域 EBADF 矩阵总装
- 域/批：C2/B28｜判据：UNX-F9343-J1 五族坏 fd 逐格总装判据过，全 EBADF 逐格检出，fd 空间全域扫描格过｜纯功能行数：380 行（五族逐格总装 140 + EBADF 逐格检出 130 + 全域扫描格 110）｜状态：[已深化]

### UNX-F9346 · 全域 ENOSYS 未实装号矩阵（号面全扫）
- 域/批：C2/B28｜判据：UNX-F9346-J1 号面全扫注入判据过，未实装号全 ENOSYS 逐格检出，与 18 号注册面/COMPAT_TABLE 对账格过｜纯功能行数：400 行（号面全扫注入 150 + ENOSYS 逐格检出 130 + 注册面对账格 120）｜状态：[已深化]

- **定位**：本条对 syscall 号面做全扫注入：注册面（18 号注册表+COMPAT_TABLE）之外的所有号值逐一注入，断言统一返回 -ENOSYS——"号未实装"与"参数非法"（EINVAL）的最终分界格，也是 glibc 回退路径（fallback）依赖的语义格。
- **语义边界**：只管号面全扫与 ENOSYS 出口；注册表本体与分发表结构归 B01 母体（消费）；COMPAT_TABLE 兼容面归 B01 兼容格；EINVAL 与 ENOSYS 分界注记（已实装号参数错为 EINVAL）单列。
