### UNX-F9201 · E 型方法论总纲（正反双判据协议与矩阵记法）
- 域/批：C2/B21｜判据：UNX-F9201-J1 正反双判据双成分协议落账判据过，矩阵记法（错误码×注入点×期望值三列）逐格可复测格过，与 B13 错误编码器总成对账一致｜纯功能行数：420 行（总纲协议落账 150 + 矩阵记法格 140 + 编码器对账 130）｜状态：[已深化]

- **定位**：本条是 B21–B28 八个 E 型批的总纲条：立正反双判据协议（正向语义达成判据+反向错误注入判据双成分齐备方收口）与错误矩阵记法（错误码×注入点×期望值三列表），本批 19 条与 B22–B28 七批共 160 条矩阵条全部按本条体例落账，是错误注入面从散点校验升格为矩阵化判定的方法论冻结格。
- **语义边界**：只管协议与记法体例；错误码编码器本体归 B13 母体（对账不重铺）；文件族六专面矩阵归 F9202–F9209 各专条；B22 fd 族总纲归 F9221（体例同源、面不同）；域级回归消费归 B37。
- **依赖与嫁接源**：嫁接 man-pages errno(3) 错误码清单与 read(2)/write(2) ERRORS 段判序原文；锚定 B13 错误编码器总成（Errno→sysret 单源）、B16 F9105 fcntl 错误矩阵（体例先行例）、A5 ktest 宏族（注入执行器）。
- **风险与回退**：风险一为正反双成分缺一（只注错误码不验正向语义，矩阵假绿）——回退为双成分硬规则：每矩阵格必须同表登记正向构造（合法输入预期成功）与反向构造（注入输入预期错误码），缺任一成分即收口 fail；风险二为注入后内核状态残留（坏指针注入致任务探针卡死污染后续格）——回退为注入自恢复格：每格注入执行前后内核侧快照比对（fd 表占用/内存水位/errno 槽三探针），不一致即标红并隔离该格。
- **正文**：实现路径分三步：第一步立正反双判据双成分协议——正向成分=合法参数路径预期返回值（write 合法 fd 返回正字节数），反向成分=注入参数路径预期 errno（write 坏指针返回 -EFAULT），双成分在判定伪代码中为两独立断言分支（合法路径走值断言、注入路径走码断言），协议文本冻结入册且逐条下挂引用核；第二步立矩阵记法格——三列记法模板落账：错误码列取 errno 名、注入点列取参数槽位（arg0 fd/arg1 buf/arg2 count 三槽）、期望值列取 -Exxx 字面值，每格附构造步骤与复测次数两注记列，五列模板本条冻结后全批沿用零变体；第三步立编码器对账——矩阵期望值列逐格经 B13 编码器编码（Errno→sysret 负值编码），编码结果与 B13 映射账逐码比对零漂移，对账表三列（格号/期望码/编码实测）落账。与现存内核衔接点：Errno 编码与 B13 单源；注入执行器与 A5 ktest 宏族同源。与 Windows 对照：Windows 为 GetLastError/NTSTATUS 双编码体系无 errno 单源约定，映射对照随 F9216 落账（本条只立协议不铺映射）。判据 UNX-F9201-J1 的复测方式：ktest 三断言——双成分协议在案且 19 条矩阵格双成分齐备抽查、三列记法模板抽样重跑可复测、编码对账表零漂移。

### UNX-F9202 · read/write 坏 fd 矩阵（全 EBADF）
- 域/批：C2/B21｜判据：UNX-F9202-J1 负 fd/未开 fd/已关 fd 三类注入矩阵判据过，全返回 -EBADF 与 Linux 逐码一致，10/10 次检出复测格过｜纯功能行数：340 行（三类注入矩阵 130 + 逐码一致核 110 + 复测检出 100）｜状态：[已深化]

- **定位**：本条立 read/write 双调用坏 fd 注入矩阵：负 fd（-1/INT_MIN 极值）、未开 fd（表内未分配槽位值）、已关 fd（close 后复测）三类全返回 -EBADF——文件族 E 型矩阵的首发专面，EBADF 判定域在读写路径的落账格。
- **语义边界**：只管 read/write 双面坏 fd；fd 空间全域扫描归 F9211；close 双关闭竞态归 F9204；坏 fd 与坏 buf 判序（EBADF 优先于 EFAULT）协议归 F9221/F9231 联动面。
- **依赖与嫁接源**：嫁接 read(2)/write(2) man-pages ERRORS 段 EBADF 行（"fd is not a valid file descriptor or is not open"原文语义）；锚定 B03 write·read 深化册正判据面、B08 fd 分配器（槽位态查询）、F9201 矩阵记法。
- **风险与回退**：风险一为负 fd 极值按无符号解析（fd=-1 解析成巨正值后误报越界或其他码而非 EBADF）——回退为有符号解析硬规则：fd<0 一律符号短路直接 EBADF 不查表，极值组（-1/-2/INT_MIN/INT_MIN+1）专测断言；风险二为已关 fd 误触槽位复用（close 后同号被新 open 占用，旧 fd 引用读到新对象假成功）——回退为槽位世代号断言：槽位带世代计数，close 后世代加一，旧世代引用一律 EBADF。
- **正文**：实现路径分三步：第一步立三类注入矩阵——负 fd 组（-1/-2/INT_MIN/INT_MIN+1 四值）×read/write 双调用八格、未开组（预占布局确保的表内空洞值三值）双调用六格、已关组（open 后 close 再用原值）双调用四格，共十八格逐格注入捕获 errno；第二步立逐码一致核——十八格全返回 -EBADF 且 errno 单一，与 man-pages ERRORS 段 EBADF 行两触发条件（无效 fd/未开 fd）逐格比对（三类注入各有落格），比对表三列（注入构造/触发条件/实测码）落账，断言零混码（EFAULT/EINVAL 串扰计数=0）；第三步立复测检出格——十八格各重复注入十次共 180 次，检出计数逐格 10/10（180/180 全中），统计表落账，零 flaky 声明与 F9217 编排互认。与现存内核衔接点：fd 槽位查询与 B08 分配器单源；注入执行经 A5 ktest 宏族。与 Windows 对照：Windows 坏 HANDLE 返回 ERROR_INVALID_HANDLE（六号），与 EBADF 映射对照随 F9216 落账；本条按 Linux 冻结。判据 UNX-F9202-J1 的复测方式：ktest 三断言——十八格矩阵全 EBADF、三列比对表零混码、180 次复测检出全中。

### UNX-F9203 · read/write 坏指针矩阵（全 EFAULT）
- 域/批：C2/B21｜判据：UNX-F9203-J1 NULL/-1/未映射/只读映射写路径四类注入矩阵判据过，全 -EFAULT 格过，部分拷贝残留量声明格过｜纯功能行数：340 行（四类注入矩阵 130 + 一致核 110 + 半程残留格 100）｜状态：[已深化]

- **定位**：本条立 read/write 缓冲指针注入矩阵：NULL（0x0）、-1（全 F 尾地址）、未映射页、只读映射页写路径四类全返回 -EFAULT——EFAULT 拷贝探针在文件族首发的落点，含部分拷贝残留量语义声明（首段有效时已拷字节数先返回），是判序协议 EFAULT 首位的实格。
- **语义边界**：只管 read/write 双面坏 buf；半途拷贝已拷字节数细则归 F9212；ioctl 面坏指针归 B16 F9116；参数槽位提取本体归 F9214 探针总成。
- **依赖与嫁接源**：嫁接 read(2)/write(2) man-pages EFAULT 行（"buf is outside your accessible address space"原文）与 Linux access_ok 前置校验惯例；锚定 B04 mmap 三联深化册（页映射态操纵）、F8921 参数拷贝探针总成、F9201 记法。
- **风险与回退**：风险一为内核空指针解引用 panic（注入后未校验直接 memcpy 崩内核，违反零损坏承诺）——回退为前置校验硬规则：所有用户指针先经范围校验（用户段基址+长度不越界）再拷贝，失败短路 -EFAULT 零裸拷贝路径，100 次注入零 panic 断言；风险二为只读页判定遗漏（write 到只读映射页误走成功路径靠页表写位漏洞绕过）——回退为页表写位探针：拷贝前查目标页写权限位，只读即 EFAULT，探针与页表位逐一对照。
- **正文**：实现路径分三步：第一步立四类注入矩阵——NULL/全 F 尾地址/未映射页（mmap 后 munmap 腾出确定空洞页）/只读映射页（mmap PROT_READ 作 write 目标）四类×read/write 双调用八格主矩阵，附加未映射跨界格四格（buf 合法但 buf+count 跨入空洞页），十二格逐格注入；第二步立一致核——十二格全 -EFAULT 且 errno 单一，与 man-pages EFAULT 行两触发条件（地址空间外/参数指向无权限区）逐格比对表落账，正判据对照格（合法 buf 读写成功返回正数）同表并列验证双成分齐备；第三步立半程残留声明格——构造首页有效+次页未映射+count 跨两页场景：write 返回已写入字节数（部分写非错误码）或 -EFAULT（一字节未写时）两分支语义与 Linux 逐例一致断言，残留量可观测（文件长度与偏移回读核），残留账表落账。与现存内核衔接点：前置校验与 F8921 探针同源；页表查询与 B04 映射账单源。与 Windows 对照：Windows 缓冲无效返回 ERROR_NOACCESS（998 号），无部分拷贝字节返回语义，映射对照随 F9216；按 Linux 部分拷贝语义冻结。判据 UNX-F9203-J1 的复测方式：ktest 三断言——十二格全 EFAULT、双成分对照并列、半程两分支残留量核。

### UNX-F9204 · close 坏 fd 矩阵（含双关闭竞态）
- 域/批：C2/B21｜判据：UNX-F9204-J1 坏 fd 全 EBADF 判据过，双 close 竞态注入第二次全 EBADF 格过，fd 槽位复用零泄漏格过｜纯功能行数：320 行（坏 fd 注入矩阵 110 + 双关闭竞态格 110 + 槽位复用核 100）｜状态：[已深化]

- **定位**：本条立 close 调用坏 fd 注入矩阵与双关闭竞态格：负 fd/未开/已关三类全 EBADF，双 close 竞态注入验证第二次必 EBADF，槽位复用无泄漏（close 释放槽位可被后续 open 复用且世代号推进）——fd 生命周期终点的错误面专条。
- **语义边界**：只管 close 面注入与竞态；dup 族坏 fd 归 B22 F9222；fd 全域扫描归 F9211；close 正判据（引用计数递减/对象释放）归 B05 深化册；复用窗口 use 注入归 B22 F9232。
- **依赖与嫁接源**：嫁接 close(2) man-pages ERRORS 段 EBADF 行（"fd isn't a valid open file descriptor"原文）；锚定 B05 open·close·lseek·stat 深化册正判据、B08 fd 分配器世代号协议、F9201 记法。
- **风险与回退**：风险一为双 close 第二次误成功（槽位已复用后旧 close 误关新对象致对象误释放）——回退为世代号硬规则：close 按槽位+世代双键关闭，世代不匹配一律 EBADF，竞态注入百次断言第二次 close 全 EBADF 且新对象存活；风险二为槽位泄漏（close 失败路径位图未回收致 fd 渐耗）——回退为泄漏探针：close 前后位图占用计数差断言（成功必减一、失败必不变），千次开关回环后位图基线一致。
- **正文**：实现路径分三步：第一步立坏 fd 注入矩阵——负 fd（-1/INT_MIN 两值）、未开槽位（表上限内未分配值）、已关 fd 三类×close 单调用，附加三类×read 联用对照（错误码同源核），七格全 -EBADF 断言落账；第二步立双关闭竞态格——open 得 fd 后双任务并发注入双 close（同世代键同时关），断言恰一成功一 EBADF（fd 表锁序列化保序）、串行双 close 必第二次 EBADF，100 次重复注入零例外零 panic，序列化注记落账（F9217 竞态格确定性依据）；第三步立槽位复用零泄漏格——close 成功后立即 open 新对象断言复用同槽位（最低可用分配序）且世代号加一（新对象带新世代，旧引用不可达），千次开关回环后 fd 表占用计数回归基线（零泄漏核）。与现存内核衔接点：fd 表锁与世代号协议与 B08 分配器单源。与 Windows 对照：Windows CloseHandle 坏句柄返回 ERROR_INVALID_HANDLE，双关闭同为句柄复用攻击面；语义对照随 F9216。判据 UNX-F9204-J1 的复测方式：ktest 三断言——七格全 EBADF、双 close 百次竞态断言、千次回环零泄漏。

### UNX-F9205 · lseek 坏 fd/坏 whence 矩阵
- 域/批：C2/B21｜判据：UNX-F9205-J1 坏 fd 全 EBADF 判据过，非法 whence 全 EINVAL 格过，负偏移全 EINVAL 格过｜纯功能行数：320 行（坏 fd 注入格 110 + 非法 whence 格 110 + 负偏移格 100）｜状态：[已深化]

- **定位**：本条立 lseek 双注入面矩阵：坏 fd 三类全 EBADF 与非法 whence（3/4/负值等封闭值域外值）+负偏移结果全 EINVAL——lseek 参数校验三段判序（fd→whence→offset）的落账格，判序协议 EINVAL 尾位的实格。
- **语义边界**：只管 lseek 面注入；三 whence 基准换算正判据归 B05 深化册；off_t 溢出边界归 F9209；判序协议全域版归 B22 F9231；ESPIPE 管道面注记随管道域。
- **依赖与嫁接源**：嫁接 lseek(2) man-pages ERRORS 段 EBADF/EINVAL 两行（"whence is not valid"与"resulting file offset would be negative"原文）；锚定 B05 lseek 正判据档、F9209 溢出格、F9201 记法。
- **风险与回退**：风险一为 whence 校验后移（先做偏移计算后验 whence，负偏移先报错致错误码判序漂移）——回退为判序硬规则伪代码：先验 fd（EBADF）→再验 whence∈{0,1,2}（EINVAL）→再算新偏移、负结果 EINVAL，判序固定，组合格按判序逐段归因验证；风险二为 whence 值域误宽（接受 3 以上值静默按 SEEK_END 处理致行为漂移）——回退为值域封闭断言：whence∉{0,1,2} 全 EINVAL，-8..8 扫描除三合法值外逐值断言。
- **正文**：实现路径分三步：第一步立坏 fd 注入格——负 fd（-1/-2）、未开槽位、已关 fd 三类注入 lseek 全 -EBADF 六格落账，与 F9202 read/write 面同构（同一 fd 校验函数单源 grep 核为证）；第二步立非法 whence 格——whence=3/4/-1/-255 等非法值注入（fd 合法），全 -EINVAL 且归因 whence 段（哨兵组合：负偏移+非法 whence 组合仍返回 EINVAL 且按 whence 段先行归因），扫描值 -8..8 除 {0,1,2} 外二十值逐值断言封闭值域；第三步立负偏移格——SEEK_SET(-1) 直接负结果全 EINVAL、SEEK_CUR/END 计算后负结果同 EINVAL（偏移原点为零场景），大幅负回退组合格落账，与 B05 正判据对账（偏移≥0 的合法负回退不误伤：成功返回新偏移）。与现存内核衔接点：fd 校验与 F9202 同函数；偏移计算与 B05 lseek 语义档单源。与 Windows 对照：Windows SetFilePointer 无 whence 参数化错误面（移动法差异），ERROR_INVALID_PARAMETER 对照随 F9216；按 POSIX 冻结。判据 UNX-F9205-J1 的复测方式：ktest 三断言——六格 EBADF、二十值 whence 扫描、负偏移组合格全 EINVAL。

### UNX-F9206 · open 坏路径指针 EFAULT 矩阵
- 域/批：C2/B21｜判据：UNX-F9206-J1 坏路径指针注入全 EFAULT 判据过，路径截断注入零越界读格过，10/10 次检出格过｜纯功能行数：320 行（坏路径指针注入 110 + 截断零越界格 110 + 检出复测 100）｜状态：[已深化]

- **定位**：本条立 open 路径参数坏指针注入矩阵：NULL/-1/未映射路径指针全 EFAULT，路径串中途截断（尾页无效）注入验证零越界读——字符串型参数拷贝探针在 open 面的落点，带上限用户串拷贝语义的专格。
