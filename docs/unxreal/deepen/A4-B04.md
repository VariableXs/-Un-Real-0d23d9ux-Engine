- **语义边界**：只做循环骨架与调度纪律；不做回收来源本体（F2466 阶梯与注册器）、不做配额算法（F2465）、不做 swap 执行（F2468 分界）。

- 正文：实现路径分三步。第一步循环骨架：五拍结构编码——睡（等待唤醒事件）、取事件（带代际防旧事件）、算配额（F2465 换算）、回收执行（F2466 阶梯序）、评效与复睡判定（free ≥ high 即退睡，否则调整参数再战），每拍进出处打点；第二步让出点：单轮回收扫描每处理 64 页强制让出一次（调度点挂 A2 让出接口，前向声明），让出计数落账——回收者是长工不是地主，CPU 时间片账受控（单轮时限初值 5ms）；第三步退出判定：退出条件 free ≥ high 判定与 F2461 判定器同源（同一函数），退出时写退出账（本次循环总扫描/总回收/耗时/退出原因），1h 长稳断言循环次数与事件数配平。与现存内核衔接点：`mm.rs` 现存回收线程原型（如有）收编为循环骨架，`MemDomainState` 回收段字段扩展。与 Windows 对照：Windows 的平衡集管理器与修改页写回线程分立，本条单循环 + 阶梯注册器形态更聚合，让出纪律与 Windows 的调度优先级约束等价。判据 UNX-F2464-J1 的复测方式：单轮时限与让出计数账在档（超时注入 10/10 次让出生效），8 核 1h 长稳零饿死（回收者以外任务延迟账正常）零死循环（退出账可复算），事件数与循环数配平断言通过。

### UNX-F2465 · 回收目标与配额（单轮回收量）
- 域/批：A4/B04｜判据：UNX-F2465-J1 单轮配额执行偏差 ≤10% 10/10 轮，配额来源账（水线差→页数换算）可复算｜纯功能行数：280 行（配额换算 100 + 限幅 90 + 偏差账 90；测试段不计）｜状态：[已深化]
- **定位**：回收者每轮回收多少页不是拍脑袋——配额 =（high − free）的换算 + 限幅；配额太小回收不完，太大单轮扫太久违反 F2464 时限，本条把换算公式与限幅参数显式化并记账。
- **语义边界**：只做配额换算与限幅；不做回收执行（F2466）、不做评效（F2472）、不做阶梯策略（F2466）。
- **依赖与嫁接源**：依赖 F2461/F2464；嫁接源为 Linux kswapd 的 high−free 目标语义，实现自研。
- **风险与回退**：换算页数过大（free 跌得深）超过单轮时限——限幅双闸（绝对上限 + 时限预算上限），限幅生效记录在账，深跌场景多轮分摊而不是单轮硬扛。
- 正文：实现路径分三步。第一步配额换算：单轮目标 =（high − free）× 系数（初值 1.0，可调），换算输入与 F2461 判定器同源（同一次 free 快照，防两次读值不一致），换算公式在档可复算；第二步限幅：绝对上限（初值 256 页/轮）与 F2464 时限预算换算上限（时限 ÷ 单页回收均耗时估计）取小者生效，限幅触发记录（限幅前后值）落账；第三步偏差账：每轮实际回收页数与配额比值偏差落账，偏差 ≤10% 断言（10/10 轮构造用例），偏差超限轮次的原因分类（来源枯竭/时限截断/让出中断）随账记录——偏差不是错误而是信息，分类账供 F2466 阶梯调优。与现存内核衔接点：新增配额换算器（`mm.rs` 回收段），无现存等价物。与 Windows 对照：Windows 的工作集目标页数算法同层语义，本条限幅 + 偏差分类账更细。判据 UNX-F2465-J1 的复测方式：构造三级 free 深度用例各 10 轮，配额执行偏差 ≤10% 断言全过，限幅用例（深跌场景）10/10 次正确限幅留痕，换算复算断言（输入快照 + 公式重放 = 配额值）通过。
