### UNX-F0161 · Runtime Services 虚拟地址重映射
- 域/批：A1/B09｜判据：UNX-F0161-J1 SetVirtualAddressMap 调用后运行时服务经新地址可用，旧地址访问断言为零｜纯功能行数：320 行（虚拟地址协商 100 + SetVirtualAddressMap 调用 110 + 旧地址封禁 110；测试段不计）｜状态：[已深化]
- **定位**：ExitBootServices 后运行时服务仍可用：为 EFI Runtime 区协商虚拟地址并调用 SetVirtualAddressMap 完成重映射。
- **语义边界**：只处理 Runtime Services 的 Runtime code/data 两区；Boot Services 区回收归 F0175；虚拟地址空间选择高半区独立窗口（不与内核映像冲突）。
- **依赖与嫁接源**：F0053 ExitBootServices 时序（前置）、B16 页表族（映射载体）；嫁接 Linux `efi_setup_page_tables` 与 `SetVirtualAddressMap` 调用语义。
- **风险与回退**：SetVirtualAddressMap 失败后运行时服务不可用（无法回退物理调用）——失败即降级"无运行时"模式（F0176 全量降级路径），关键依赖（RTC 时间）走物理 RTC 后备并告警。
- 正文：实现路径分三步。第一协商：枚举 EFI Memory Descriptor 中 Runtime code/data 区，为每区在内核虚拟空间 `-64TB` 段内分配对齐虚拟槽位（2M 对齐），构建 `EFI_MEMORY_DESCRIPTOR` 副本（VirtualStart 字段填充）；槽位与内核映像/直接映射区冲突检测（重叠即重选）。第二调用：SetVirtualAddressMap 经本表（注意：调用它自身仍用物理地址、GDT/IDT/页表全部物理态就绪——规范 §8.4 要求），调用前快照全部寄存器环境；返回状态码入账，调用后新虚拟地址生效。第三封禁：重映射后物理 Runtime 区页表项撤销（防误用旧地址），旧地址访问断言——ktest 尝试物理地址调用应 #PF 或映射缺失；运行时服务表指针切换到虚拟地址。与现存内核衔接点：页表操作经 B16 冻结接口；调用点在 F0053 时序链末端。与 Windows 对照：Windows 的 `BlpSetVirtualAddressMap` 在 winload 完成（内核不可见）；Linux 是内核内做。本工程内核内做使时序可断言、失败可降级。判据 UNX-F0161-J1 的复测方式：ktest（QEMU OVMF）断言 SetVirtualAddressMap 成功、新地址 GetTime 可用、物理旧地址访问被断言为零命中、失败注入走降级模式。

- 域/批：A1/B09｜判据：UNX-F0166-J1 ExitBootServices 时固件 watchdog 置 5 分钟语义保留并记录，超时事件路径有账｜纯功能行数：200 行（语义固化 60 + 置数处理 70 + 超时账 70；测试段不计）｜状态：[已深化]

- **语义边界**：固件 watchdog 是 ExitBootServices 副作用（规范 §6.2：EBS 调用后 5 分钟定时器启动）；本条只做"语义保留 + 事件账"，不主动 SetWatchdogTimer（置 0 禁用是合法选项但本工程选择保留——引导期 5 分钟内未到 READY 即有 KASLR/页表问题的信号）。
- **依赖与嫁接源**：F0053 EBS 时序链、F0122 内核看门狗（交接语义）；嫁接 Linux `efi_exit_boot_services` 的 watchdog 处理（Linux 选择置 0 禁用——本工程保留语义是差异点，注释说明）。

- 正文：实现路径分三步。第一语义固化：EBS 调用点标注规范条文（watchdog 语义），调用前显式决策记录（保留 vs 置 0，本工程选保留并注释理由）；决策入 BootManifest。第二置数记录：EBS 返回后记录"固件 watchdog 已启动（5min）"事件入引导账；TSC 基准点记录（供超时预估）。第三超时账：诊断模式显示"距固件复位剩余时间"（按 TSC 换算）；若引导流程超预算（>4 分钟）提前告警；超时事件（真被复位）由下次引导的 F0130 记录（上次引导最深阶段）反推入账。与现存内核衔接点：与 F0122 内核看门狗的交接语义（内核 READY 后固件狗已无意义——但无法取消，注释说明这是规范约束）；F0125 panic 呈现速度预算。与 Windows 对照：Windows winload 退出 EBS 后同样受 5 分钟狗约束（bootmgr 时序）；Linux 选择禁用。本工程保留是"引导进度自我施压"设计。判据 UNX-F0166-J1 的复测方式：ktest 断言语义决策与记录落账、剩余时间显示正确、超预算告警注入、真机被复位场景经 F0130 反推（随闸门补测）。
