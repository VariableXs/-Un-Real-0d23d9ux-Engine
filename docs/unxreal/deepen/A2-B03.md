### UNX-F0841 · 水平触发中断 deassert-EOI 顺序协议
- 域/批：A2/B03｜判据：UNX-F0841-J1 电平触发 IRQ 复挂率 0（10 万事件），顺序违规注入 10/10 次被检测｜纯功能行数：300 行（顺序协议 120 + 复挂检测 100 + 注入 80；测试段不计）｜状态：[已深化]
- **定位**：水平触发（level-triggered）设备中断的 EOI 顺序是本域第一大陷阱区的核心——EOI 发出时若设备信号线仍为有效电平，LAPIC/IO-APIC 会立即重投递（中断风暴的直接来源）；协议纪律是"先让设备 deassert（handler 内处理完设备侧或屏蔽设备），再发 EOI"；本条把顺序协议做成 handler 模板 + 顺序违规检测器，复挂率断言 10 万事件零复挂。
- **语义边界**：只做顺序协议与复挂检测；不做设备侧 deassert 语义（设备域 B4/M5 各管）、不做风暴节流（F0981）；与 F0823 分层：F0823 立出口，本条立顺序纪律。
- **依赖与嫁接源**：依赖 F0823 单点封装与 F0826 ISR 镜像；嫁接源为 Intel SDM §10.8.5（EOI 与电平触发交互）与 Linux handle_level_irq 惯例，只跟随。
- **风险与回退**：设备 deassert 慢（机械式设备电平延迟）——协议带"deassert 等待窗口"（handler 尾检测设备 pending 位，仍 assert 时延迟 EOI 到 work 队列），延迟 EOI 事件记账，等待上限超时红账。
- 正文：实现路径分三步。第一步顺序协议模板：`level_irq_handler_template` 模板函数——进 handler 先屏蔽本向量（防重入），设备处理完成（设备域回调）后确认 deassert（pending 位读回），确认后经 F0823 封装发 EOI，最后解屏蔽；三步序固化，模板外自组顺序的 handler 注册时红账警示；第二步复挂检测器：EOI 后设 100µs 观察窗，窗口内同向量再投递计"疑似复挂"，复挂计数账（per-向量），连续复挂（3 次/秒）升级红账移交 F0981 风暴检测；第三步注入验证：电平触发测试设备（QEMU 档）10 万事件复挂率 0、顺序违规注入（模拟 handler 内先 EOI 后处理）10/10 次被检测器捕获、deassert 慢注入 10/10 次走延迟 EOI 路径。与现存内核衔接点：现存电平类 handler（如有）收编进模板。与 Windows 对照：Windows 同顺序纪律（`!idt` 可见电平中断 handler 结构），本内核复挂检测器把事故预判常驻化，判据 UNX-F0841-J1 的复测方式：10 万事件复挂 0、违规注入 10/10 次捕获、延迟 EOI 路径 10/10 次正确。

### UNX-F0842 · 边沿触发投递与 EOI 去重语义
- 域/批：A2/B03｜判据：UNX-F0842-J1 边沿事件零丢失（10 万边沿 10 万投递），EOI 去重（一次投递一次 EOI）账平｜纯功能行数：260 行（边沿账 100 + 去重 80 + 验证 80；测试段不计）｜状态：[已深化]

- **语义边界**：只做边沿账与去重；不做边沿设备语义（设备域）；三账不平是设备域问题还是本域问题的裁决规则显式化（IRR 积累属正常缓冲）。
- **依赖与嫁接源**：依赖 F0826 IRR 镜像与 F0823 封装；嫁接源为 Intel SDM §10.5.4（TMR 位决定行为）与 Linux handle_edge_irq 惯例，只跟随。
- **风险与回退**：TMR 位误标（本应边沿被标电平）——注册时按 IO-APIC RTE 触发模式位核对 TMR 位图（F0826 消费），不一致红账修正，防行为错配。
- 正文：实现路径分三步。第一步边沿账：per-向量三计数（沿发生/投递/接手），对账规则显式（沿≥投递，差值=IRR 在途合法缓冲；投递=接手强制恒等），账平断言周期跑；第二步 EOI 去重：EOI 前查 ISR 镜像位（该向量在服才许 EOI），重复 EOI（位已清）红账——"多 EOI"虽不风暴但账面污染必须抓；第三步验证：10 万边沿脉冲零丢失（QEMU 档）、三账对平、去重注入（双 EOI）10/10 次红账、TMR 误标注入 10/10 次修正。与现存内核衔接点：现存边沿类路径收编。与 Windows 对照：Windows 边沿中断同样单 EOI 纪律（`!idt` 触发模式可见），判据 UNX-F0842-J1 的复测方式：10 万边沿零丢失、三账平、双 EOI 注入 10/10 次捕获。

- **语义边界**：只做 EOI 路径；不做 MSI-X 分配（F0901）、不做消息编码（F0884）；终结点裁决与 F0835 抑制位策略联动（抑制开启时 MSI 类行为不受影响——本来就不广播）。
- **依赖与嫁接源**：依赖 F0823 封装与 F0835 策略标志；嫁接源为 Intel SDM §10.8.5（EOI 语义）与 PCIe Spec §6.1.4（MSI 中断控制），只跟随。
- **风险与回退**：抑制位开启态下 IRQ 类 EOI 需定向 EOI 补偿而 MSI 类不需要——策略矩阵（三类×抑制开关）显式编码，矩阵外组合拦截，防"为 IRQ 开抑制误伤 MSI"类配置事故。

### UNX-F0844 · IPI 的 EOI 语义与自 IPI 回环

- **语义边界**：只做 IPI EOI 与回环；不做 IPI 业务（F0921）、不做核间应答账（F0924）；回环测试向量走 IPI 区 Reserved 槽。

- **风险与回退**：回环测试高频化影响性能（自检期占用）——回环测试触发档位（启动期每核一次 + 按需），高频常驻档关闭默认，测试频率白名单控制。
