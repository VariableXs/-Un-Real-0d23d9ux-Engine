### UNX-F7282 · dm 表装载事务语义
- 域/批：B5/B05｜判据：UNX-F7282-J1 装载要么全成功要么全不生效（事务性断言，注入中途失败 ×10）；装载成功后表只读不可就地改｜纯功能行数：280 行（事务协议 100 + 中途失败回退 90 + 只读锁 90；测试段不计）｜状态：[已深化]
- **定位**：表装载（load 命令）的事务语义：多段表逐段装载，中途失败（第 17 段参数非法）→前 16 段全部回退——**要么全成功要么全不生效**，半装状态（一半段在表里）是映射残缺的精确形态。装载成功后表只读（不可就地改字段——改表走 reload 协议），只读锁让"表在服役中被偷改"不可能。
- **语义边界**：只做装载事务与只读锁；不做 reload 换表（B03 批）、不做表校验内容（F7242/F7250 复用）、不做多设备装载编排。
- **依赖与嫁接源**：消费 F7202 解析器与 F7216 状态机；嫁接源为 Linux dm table load 事务（load 全过才 bind）语义，只跟随。
- **风险与回退**：回退不彻底（失败后临时表结构残留）——装载用临时表对象（不动现役表），回退=临时对象整体丢弃（无就地回退），事务边界清晰到对象生命周期。
- 正文：实现路径分三步。第一段事务协议：load 命令开临时表对象，逐段装载校验（F7242 预校验链复用），全段过→临时表提交为待激活表（inactive 态），任一段失败→临时对象丢弃+失败账——现役表全程未被触碰（事务隔离）；第二段中途失败注入：10 个注入点（第 1/5/10/17/20 段失败等）各 1 轮=10 轮注入，断言失败后现役表状态与装载前逐字节一致（无扰动断言）、临时对象零残留（内存对账）；第三段只读锁：提交后的表结构只读（字段私有+无 mut 出口，F7208 快照同构），"就地改表"路径编译期不存在，改表唯一合法路径=reload（B03）。与现存内核衔接点：`dm/mgmt_load.rs` 新建，临时表对象复用 F7202 结构。与 Windows 对照：Windows 存储布局变更的事务性（布局提交或回退，无中间布局）同构。判据 UNX-F7282-J1 的复测方式：中途失败注入 ×10 全部回退干净（无扰动+零残留）、事务性断言通过、就地改表编译期不存在验证。

- **语义边界**：只做统计导出与清零；不做统计账本体（F7229）、不做权限本体（F7288）、不做导出格式美化（固定可 diff 格式）。

### UNX-F7286 · dm 设备等待/通知接口（事件挂点）
- 域/批：B5/B05｜判据：UNX-F7286-J1 事件（表变更/错误/排空完成）通知不丢（订阅者全收）；无订阅者时零开销｜纯功能行数：260 行（通知协议 100 + 订阅器 80 + 零开销验证 80；测试段不计）｜状态：[已深化]
- **定位**：事件通知接口让消费方（B1 挂载面/A4 页缓存/ktest/诊断）订阅 dm 事件（表变更/错误/排空完成三类起步）——"通知不丢"（订阅者全收，事件带序列号可补拉）与"无订阅者零开销"（没人订阅时事件生成路径编译期短路）双纪律。F7256 的 reload-done 事件是本协议的第一个实例，本条把协议泛化。
- **语义边界**：只做通知协议与订阅器；不做事件本体（各条目自有）、不做跨域事件路由（K2 域）、不做订阅者鉴权（F7288 管控订阅权限）。
- **依赖与嫁接源**：消费 F7256 事件先例；嫁接源为 Linux dm 事件（dmevent）与 Windows 通知注册（IoRegisterPlugPlayNotification）惯例，只跟随。
- **风险与回退**：慢订阅者拖累事件源（订阅者处理慢阻塞发布者）——发布异步化（事件入订阅者独立队列），发布者只入队不等处理，慢消费者不反压事件源（队列满转补拉模式标注）。
- 正文：实现路径分三步。第一段通知协议：事件三类型静态登记（表变更/错误/排空完成），事件体（序列号/类型/设备/时间戳/载荷摘要），序列号每源单调；第二段订阅器：订阅者注册（回调+过滤器），发布按过滤器分发到各订阅者独立队列，全收断言（订阅者收到的序列号连续无洞，洞=丢失红账），补拉接口（按序列号区间取历史，历史环 256 条）；第三段零开销验证：无订阅者时事件生成路径静态短路（编译期判断），零开销断言（无订阅时事件路径 P99 与基线一致）。与现存内核衔接点：`dm/mgmt_notify.rs` 新建，F7256 事件迁入本协议。与 Windows 对照：Windows PnP 通知注册与事件订阅（ETW listener）同构。判据 UNX-F7286-J1 的复测方式：订阅者全收断言 1000 事件零洞、补拉接口区间取回完整、无订阅零开销断言 5 轮。
