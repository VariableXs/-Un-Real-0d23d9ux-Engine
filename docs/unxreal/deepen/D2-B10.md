- **语义边界**：只做描述符解析与合法性判定，不执行延迟装载动作（动作在 F12982）；attr 位语义判别在 F12988 专门条目（本条按位读取不解释）；描述符数组遍历到全零项止（VC 约定）；不处理 Bound/Unload 附加表的实际使用（登记字段值供后续批）。Windows 对照锚：MSVC delayimp 约定（delayhlp.cpp/delayimp.h 公开语义）与真实 VC 产物实测。
- **依赖与嫁接源**：嫁接源为 MSVC delayimp 公开约定（跟随真实产物行为）。上游依赖：B08 DataDirectory[13] 有效性掩码（描述符定位）、B01 头解析（取数源）。下游消费：F12982 首调链、F12988 attr 判别、F12984 双形态解析。现存内核衔接点：`proc/pe.rs` 导入解析模块追加延迟描述符子模块，与 B05 静态导入模块并列不交叉。

- **语义边界**：只做首调三步链与回填后直调，不做失败重试（F12990）、不做卸载（F12986）、不做钩子通知（F12987 事件挂点本条只留槽位）；单飞（多线程并发首调恰一次解析）在本条立语义、在 F12991 做并发压力验证；回填权限路径与 B05（F12890 页权限面）联测不在本条展开。Windows 对照锚：MSVC __delayLoadHelper2 三步语义。

- 正文：实现路径分三步。第一步建延迟存根三步链：装载期为延迟 IAT 槽填哨兵；首调陷入内核拦截桩→按槽定位描述符与目标符号名/序号；调 B05 解析器取得真实地址。第二步写单飞锁：同槽并发首调以槽地址为键取锁，锁内复查哨兵（二次检查防重复解析），解析恰一次语义成账。第三步写回填与直调路径：解析值回填 IAT 槽（权限路径与 B05 联测点登记）、清哨兵，1,000 轮首调回归断言零失败零重复；回填后直调耗时账导出（直调≈普通调用）。与现存内核衔接点：拦截桩挂 B05 导入模块延迟子面，IAT 页权限调整调 F12890 既有面。与 Windows 对照：首调三步与 __delayLoadHelper2 行为语义一致（解析成功/失败两路），实机耗时对照随闸门补测。判据 UNX-F12982-J1 复测方式：1,000 轮单线程首调零失败零重复解析断言；回填后 10^4 次直调耗时分布落账（双峰可辨：首调惩罚/直调常态）。

### UNX-F12984 · 延迟导入名称/序号双形态解析
- 域/批：D2/B10｜判据：UNX-F12984-J1 双形态样本各 ≥10 个解析与 Windows 一致，pOrdinal 混合形态行为一致｜纯功能行数：260 行（名称形态解析 90 + 序号形态解析 90 + 混合形态仲裁 80；测试段不计）｜状态：[已深化]
- **定位**：本条立延迟导入目标的两种寻址形态——按名称（pINT 项为 hint/Name RVA）与按序号（项高位标记+序号值）——的解析与仲裁。静态导入（B05）也有双形态，但延迟链的形态判定藏在 INT 项编码里且混代产物形态不一，值得独立成条钉死，避免首调链里内联散写。
- **语义边界**：只做目标形态判定与取值，不做符号解析执行（复用 B05 解析器）；序号高位标记（IMAGE_ORDINAL_FLAG 的延迟版）与静态导入的标志位语义分开判（值不同）；混合形态指同一 DLL 描述符下名称项与序号项并存，逐项独立判不整体二选一。Windows 对照锚：delayimp 生成的 INT 项编码约定。
- **依赖与嫁接源**：嫁接源为 MSVC delayimp 编码约定。上游依赖：F12981 描述符（pINT 定位）、B05 解析器（执行体）。下游消费：F12982 三步链（取值调用方）。现存内核衔接点：解析函数挂 `proc/pe.rs` 延迟子面，输出统一"目标符号"类型供 B05 解析器消费。
- **风险与回退**：风险是标志位误判——延迟 INT 项的序号标志与静态导入标志位定义不同（位宽差异），照抄静态版会错判。对策：标志常量独立定义+来源注记（delayimp 约定页），编译期断言与静态版不混用；回退为逐项防御性校验（标志位含糊时按名称尝试、失败再序号，尝试序落账），不武断拒绝。
- 正文：实现路径分三步。第一步写名称形态解析：INT 项按 hint/Name RVA 读名称串，输出目标符号（名称态）。第二步写序号形态解析：高位标志判序号态，提取序号值输出目标符号（序号态）。第三步写混合形态仲裁：逐项独立判定（同一描述符内名称项与序号项并存是合法态），10+10 双形态样本与 5 个混合样本回归，解析结果喂 B05 解析器联测。与现存内核衔接点：统一目标符号类型与 B05 解析器入参对齐（零适配成本）。与 Windows 对照：双形态样本解析目标与 Windows 加载行为（实际绑定到的函数）一致，实机随闸门补测。判据 UNX-F12984-J1 复测方式：双形态各 ≥10 样本解析断言+混合样本逐项判定断言，与工具锚输出比对一致。
