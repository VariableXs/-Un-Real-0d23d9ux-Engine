## F3681 fuzz 总设计（生成/执行/判读三段管线）

**定位**：fuzz harness 的总管线：生成（seed→输入序列）→执行（入口调用+判据采集）→判读（五类词表分类）——用受控随机大规模触碰内核入口，把"没想过的输入"变成"想过的判据"——内核的对抗性体检。
**语义边界**：三段单向管道（判据行内嵌：①生成段（PRNG（确定性伪随机——seed 播种）+双模生成器（F3682）产输入序列；②执行段（按清单（F3692）调入口+采集判据读数（账/覆盖位图/检测器态/时钟）；③判读段（五类词表（F3694）分类→发现或放行）；三段**跑内无回授**（生成段不看执行结果——回授只在跑间的语料进化（F3684）——B21 压力机三层单向管道同哲学：回授是混沌之母）；判读的**纯函数性**（判读只消费判据读数不读环境——同读数必同判读——F3687 复现的架构前提）；确定性链（判据行：seed→输入→执行序→读数→判读——每环可 hash、全链可重放——F3687 的架构化）。
**判据**：
- J1：三段管线（各段职责+跑内无回授）；M-439 三段首跑（最小入口+8 种子语料→一跑全链出判读报告）。
- J2：管线确定性（同 seed 同语料→同输入序列→同判读——无外部熵断言）。
**纯功能行数**：340（管线 ~120 + 首跑用例 ~110 + 确定性论证 ~110）
**依赖与嫁接源**：F3682 生成器（生成段内核）；F3692 入口清单（执行段边界）；F3694 词表（判读段语义）；F3687 复现（确定性链的兑现者）；B21 单向管道哲学。
**风险与回退**：随机性引入不确定性（环境读数漏进生成路径→同 seed 异判读——复现崩塌）——回退：J2 无外部熵断言+接口审查（生成器签名无环境参数——F3661 纯函数审查同法）；判读误报（慢例判崩/合法重操作判崩——发现池被污染）——回退：三带分档（F3689）+五类词表的判据门槛（F3694——每类有客观判据非主观"看起来坏了"）；管线某段崩→整个 fuzz 停摆——回退：段级容错（单例执行异常→记为发现候选（异常本身是判据——不吞异常）。
**正文**：三段的执行序（判据行原文）：`fuzz(seed, corpus, entries) -> for each input: gen(seed_i, entry.schema|corpus) → exec(entry, input) → 采集{账, 位图, 检测器态, 时长} → judge(读数) → 五类分类 → 发现|放行`——M-439 的构造：最小入口（arg 解析桩——schema 三字段：type(u8)/len(u16)/payload)）+8 种子（合法参数组合）→跑 100 例→判读报告（stat/cov/finds/repro 四段——F3696）产出，发现数与判据红点数一致。跑内无回授的理由（判据行展开）：若生成段根据上例执行结果调整下例输入（在线适应）——则输入序列依赖执行时序——重放时序稍有漂移即序列发散——复现不可能；跑间回授（语料进化）是批级状态（跑与跑之间显式传递——状态进档案）——确定性与适应性的两全：**适应在跑间、纯度在跑内**（判据行：进化的自由与重放的纪律分工）。判读纯函数的落实（判据行展开）：`fn judge(r: &Readings) -> Verdict`——Readings={账读数, 位图 delta, 检测器态, 时长}——判读的全部信息量来自 Readings——**信息守恒**（判读器不偷看环境（F3661 同律——纯度的哲学统一：生成器不偷看执行、判读器不偷看环境——各段只吃自己的输入）；M-439 复测：三段序+首跑报告+无回授断言（生成器接口审查）+判读纯函数审查。

## F3682 输入生成器（结构化生成与字节变异双模）

**定位**：生成段的双模引擎：结构化模（按入口 schema 产合法/半合法输入——字段级扰动）与字节级模（对语料直接变异——schema 外暴力）——两模分工覆盖"合法但恶意"与"非法但健壮"两族病灶。
**语义边界**：双模判据（判据行内嵌：结构化模=schema 驱动（入口的输入结构描述——字段表（类型/约束/关系））+扰动词表（边界值注入：0/最大值/越界 1/重叠区间/空满翻转——词表 const——"合法但恶意"（schema 内的语义炸弹：合法长度×重叠区间→别名冲突）；字节级模=语料为底+变异算子（F3685）——"非法但健壮"（解析器防线：拒收路径的账守恒/无内存违纪）；两模的**产出判据不同**（结构化件应被入口 schema 接受（拒收=生成器 bug——自检信号）；字节件走拒收路径也正常（拒收也是行为——判据读数照采——判据行：拒收不是浪费（解析器防线的每次执法都是一次判据验证））。
**判据**：
- J1：双模生成（两模各自判据+扰动词表）；M-440 双模产出（结构化件过 schema 校验+字节件走拒收路径——两模判据落点各自验证）。
- J2：生成封闭（生成器唯一熵源=seed——环境读数（时钟/地址）不得进生成路径）。
**纯功能行数**：320（双模 ~110 + 用例 ~105 + 词表论证 ~105）
**依赖与嫁接源**：F3692 schema（结构化模的蓝图）；F3685 算子（字节模的变换器）；F3683 语料（字节模的底料）；F3681 熵源纪律。
**风险与回退**：schema 漂移（入口改了 schema 没改→结构化件批量拒收——自检信号误判为病灶）——回退：schema 与入口清单同版本锚（F3692 三列与 schema 同 bump——判据行：清单不动 schema 不动）；扰动词表不足（边界覆盖不全是盲区温床）——回退：词表 v1+盲区报告（F3697）暴露未触边+词表扩展走版本；字节模纯暴力低效——回退：语料为底（好底料×变异>纯随机）+覆盖反馈导向（F3684）。
**正文**：双模的互补性核算（判据行展开）：结构化模能表达的病灶空间=schema 内的组合爆炸（字段数 k、每字段词表 m→m^k 组合——3 字段×5 扰动=125 族）——语义病灶的主战场；字节级模的空间=字节域全空间（schema 无关——打的是解析器对"不可能输入"的防御——**解析器不信任输入**这条纪律的实证场）；两模配比由清单指定（每入口标 mode 权重——判据行：配比是工程判断不是玄学（解析型入口偏字节模、语义型入口偏结构化模）。扰动词表的封闭性（判据行展开）：词表 v1 七式（零值/最大/越界+1/越界−1/重叠/空满互换/类型混淆）——每式有判据语义（为什么它是边界：零值探退化为零的除法与空集路径；越界探长度校验；重叠探别名与双释放——词表的每式都是一类已知病灶的疫苗）；M-440 的双模验证：结构化件 10 枚→schema 校验 10/10 过；字节件 10 枚→6 拒收 4 受理——拒收件的判据读数（账差==0+无违纪）照采照判——**拒收路径的全绿也是证据**（判据行：防线在战斗中保持队形）。熵源封闭的实现（判据行展开）：生成器签名 `fn gen(rng: &mut PRNG, src: GenSrc) -> Input`——GenSrc={schema, corpus, operators}——无时钟无地址参数——PRNG 的种子链由 F3681 分发（逐例派生 seed_i=f(seed, i)——例级可独立重放）；M-440 复测：双模产出+两模判据落点+熵源接口审查。

## F3683 语料库（种子集与版本化管理）

**定位**：fuzz 的记忆体：种子集（初始合法输入——人工 crafted）+增量（fuzz 留存的值得复用输入）+全条目溯源（哪次跑哪个 seed 产的——语料是可回放的演化史）——进化算法的基因库。
**语义边界**：语料契约（判据行内嵌字段表：条目={content, hash, run_id, seed, mode, born_edge}——content 输入体/hash 内容指纹/run_id 产出跑号/seed 派生源/mode 生成模（结构化|字节）/born_edge 触发入册的新边 id——六字段齐备才可入册（缺溯源=黑户——拒绝入册）；**入库门槛**（不是所有输入都进语料：新边触发（F3684 反馈）或人工标注——门槛是语料的价值密度（全存=语料爆炸（判据行：语料的每一条都该有存在理由）；版本锚（语料集 hash=逐条 hash 的序贯 hash——入复现三锚（F3687）——重放拿当时的语料快照）。
**判据**：
- J1：语料契约（六字段+入库门槛）；M-441 语料演化（初始 8 种子→跑后增长→逐条溯源可回放（run_id+seed 重产出该条））。
- J2：语料去重（内容 hash 去重——同件不双存+版本锚计算可复算）。
**纯功能行数**：320（契约 ~110 + 演化用例 ~105 + 锚论证 ~105）
**依赖与嫁接源**：F3684 反馈（增量入库的筛选器）；F3687 三锚（语料版本锚的消费方）；F3545 位图（born_edge 的来源）；F3698 入库流水线（语料→ktest 的下游）。
**风险与回退**：语料体积失控（进化无上限→万条语料→跑时内存与时间双爆）——回退：体积 cap（如 4K 条——超限按价值淘汰（价值=born_edge 新鲜度×命中频次——LRU 同族——淘汰事件入报告（可见性）；溯源字段缺失（历史工具产的语料无溯源——黑户件）——回退：入册校验（六字段不齐即拒——老语料迁移时补标 provenance=imported（诚实标注）；语料污染（发现件误入语料（崩溃输入被当种子复用——把病灶当基因传播）——回退：发现件与语料件分流（判读红的输入进立案不进语料——判据行：病灶进病历本不进食谱）。
**正文**：语料的演化语义（判据行展开）：种子集是第 0 代（人工智慧——每个入口至少 1 条合法种子——F3692 清单对账的判据用例素材）；增量是进化代（机器智慧——覆盖反馈选出——born_edge 记录它为什么值得留）；两代的关系（种子给起点、增量给方向——语料库整体是"系统对什么输入敏感"的压缩知识——判据行：语料是 fuzz 的地图（它记着到过哪、哪有新大陆）。M-441 的演化验证：初始 8 种子（每入口 1 条）→跑 500 例→语料增至 23 条（+15 增量）→逐条溯源回放（run_id→该跑档案→seed_i→gen 重产→hash==条目 hash——**回放闭合**（判据行：溯源不是记录癖——是语料可信度的可验凭证——任何一条语料都能被重新推导出来）。版本锚的计算（判据行展开）：`corpus_hash = H(entry_1.hash ‖ entry_2.hash ‖ …)`（按入册序——序固定则锚定）——锚的用途双面：重放握手（F3687——语料快照与档案锚比对——不符拒绝重放）与演化审计（两锚 diff→语料增量集合——演化的可解释账）；去重的实现（判据行展开）：hash 表（内容 hash 48 位指纹——指纹相同才比全内容（防伪碰撞）——入册 O(1)；淘汰的时机（cap 触发时批淘——淘汰名单入报告（F3696 cov 段附注——语料的减法也可见）；M-441 复测：演化+溯源回放闭合+锚复算+去重与淘汰可见。

## F3684 覆盖反馈（边覆盖驱动的进化）

**定位**：跑间回授的计量源：执行→边覆盖位图（F3545 覆盖设施复用）→新边判定→新边输入入语料——进化方向受计量驱动而非随机漂移——fuzz 的指南针。
**语义边界**：闭环四步（判据行内嵌：①采集（执行段顺带采位图 delta（本次跑触发的边集——F3545 位图机制复用（入口×边矩阵）；②新边判定（delta OR 进总位图→有新位→新边；③入册（新边输入按 F3683 契约入语料（born_edge=该新边 id）；④记账（总位图状态入跑档案（进化轨迹的可复现素材）；**单调棘轮**（总位图只增不减——新边累积是棘轮式的（覆盖回退=实现 bug 或重置失职——F3693 自证域）；反馈的确定性（同 seed→同进化轨迹——位图状态是 seed 的函数链——进化的每一步可复算）。
**判据**：
- J1：反馈闭环（四步+单调棘轮）；M-442 进化单调（新边入语料后总覆盖不降+同 seed 重跑进化轨迹逐步复现（位图状态序列 diff==0）。
- J2：反馈封闭（位图尺寸=入口表×边数 const——超界输入拒绝（F3545 尺寸纪律延伸——清单外入口无位图槽位=物理不可达）。
**纯功能行数**：320（闭环 ~110 + 用例 ~105 + 单调论证 ~105）
**依赖与嫁接源**：F3545 覆盖设施（位图机制真源）；F3683 语料（入册下游）；F3693 重置（位图状态的自证对端）；F3697 盲区（总位图的互补读数）。
**风险与回退**：位图饱和（边多入口多→位图巨大→比较成本涨）——回退：分入口位图+汇总位图双层（判据行：细账与总账分层——比较在汇总层、归因在细账层）；伪新边（执行抖动导致偶发边——噪声入册）——回退：新边确认制（连续 2 例触发才入册（单次偶发不算——统计稳定门槛）；反馈回路失控（语料全被新边件占满→种子被挤出）——回退：F3683 cap 与价值淘汰的配合（种子代保护（种子条目不参与淘汰）。
**正文**：覆盖反馈的价值论证（判据行展开）：无反馈的 fuzz=均匀随机打靶（命中率与输入空间成反比——大空间下不可行）；有反馈的 fuzz=朝新边制导（每条新边是一次"这里的输入有信息"的信号——语料向高信息密度区进化——**制导随机的效率证明**：M-442 构造（入口含 12 条边、其中 3 条需特殊参数才达）→无反馈跑 1,000 例覆盖 9 边；有反馈跑 500 例覆盖 12 边——**减半跑数全边达成**（判据行：反馈不是锦上添花是可行性本身）。单调棘轮的执法（判据行展开）：总位图状态{bitmap, popcount}——每次跑后 popcount 只许 ≥（减=红——两因排查：重置失职（F3693 自证红）或位图实现 bug——**回退是事故不是波动**（判据行：覆盖的棘轮与水位棘轮（F3581）同哲学——单向前进的量才可信）。进化轨迹的可复现（判据行展开）：轨迹=（位图状态, 语料状态）序列——同 seed 重跑→逐跑比对（M-442 的 diff==0 断言——进化的确定性是 F3681 确定性链的跑间延伸：seed 决定输入、输入决定位图、位图决定语料——**全链无断点**）；伪新边确认制的成本（判据行展开）：确认跑=该输入重放 1 次（重放便宜——复现基础设施白给）——2/2 触发才入册——噪声入册率≈p²（p 为偶发概率——0.1% 偶发→0.0001% 入册——量化干净）；M-442 复测：制导效率对比+棘轮断言+轨迹复现+确认制噪声核算。

## F3685 变异算子表（封闭算子集 v1）

**定位**：字节级模的变换器：七算子封闭集 v1（位翻转/字节替换/块复制/块删除/块插入/截断/拼接）+参数由 seed 派生——变异的每一步可解释可复算——随机性纪律作用于随机性本身。
