- **定位**：豁免清单"公开"是宪法条款——公开不是"内部可查"，是任何人任何会话都能取到一致快照。本条做公开面生成器：从账本实时生成只读清单件，逐条含四要素，公开面与账本零时差。
- **语义边界**：只做公开面；不做访问控制策略（公开面本就公开，敏感性字段不存在——豁免不含用户数据）；生成器只读。
- **依赖与嫁接源**：依赖 F9621 豁免账与 F9622 ADR 索引；嫁接源为任务书"豁免清单公开"条款，只跟随。
- **风险与回退**：公开面滞后于账本（缓存腐化）——一致性断言（抽样比对账本）随生成跑，滞后超阈值即拒绝服务旧面（宁可短暂不可用不给旧数据）。
- 正文：实现路径分三步。第一步生成器：账本变更事件触发重建（增量重建），输出清单件（逐条 case/原因/ADR 号/解锁条件/登记时刻），格式冻结可机读；第二步一致性断言：公开面条数与豁免账相等+抽样逐字段比对，断言不过即旧面失效；第三步访问账：取数记录（取数方/时刻/版本号）入账（公开也要知道谁在什么时候看到了什么版本——回答"你当时为什么没发现"全靠它）。与现存内核衔接点：公开面为 ltp_ledger 导出面之一，与 F9612 快照同构。与 Linux 基准对照：对齐 distro 公开 known-failure 清单惯例（人话+可机读双形态）。判据 UNX-F9637-J1 的复测方式：公开面与账本一致 10/10 次、四要素逐条齐 10/10 次。
