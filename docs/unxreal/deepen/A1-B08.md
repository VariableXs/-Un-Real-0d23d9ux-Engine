### UNX-F0141 · ISO9660/El Torito 生成器
- 域/批：A1/B08｜判据：UNX-F0141-J1 生成镜像被 xorriso -indev 校验结构合法，真机 UEFI 引导通过｜纯功能行数：340 行（ISO9660 卷结构 130 + El Torito 引导记录 110 + 生成流水 100；测试段不计）｜状态：[已深化]
- **定位**：自研 ISO9660 + El Torito 镜像生成器：卷描述符、路径表、目录记录、引导目录与引导目录记录全链生成。
- **语义边界**：只生成 ISO8859-1 短名（无 Joliet/UDF，UEFI 引导不需要）；ISO 尺寸 = 数据区对齐 2KB 扇区；混排（mixed）模式不做。
- **依赖与嫁接源**：ECMA-119 / ISO9660 规范 + El Torito 规范 1.0；嫁接 xorriso 的结构布局参数与 systemd-boot ISO 样板。
- **风险与回退**：卷描述符一字节错整盘不可读——生成后自校验（解析回读自身结构）+ xorriso 交叉校验双守；生成失败产物带 .broken 后缀不入发布。
- 正文：实现路径分三步。第一卷结构：PVD（主卷描述符）+ VDST 终结符按规范填字段（卷标 VARIX_BOOT、块大小 2048、卷空间大小统计），目录树（boot/EFI/kernel 三目录）路径表与目录记录（记录时间戳用 SOURCE_DATE_EPOCH）生成；L 类型路径表一条即可。第二 El Torito：引导记录卷描述符指向 Boot Catalog，Catalog 含 Validation Entry（校验和算法：前 32 字节短和 = 0x1234）与 Initial/Default Entry（加载段 0x7C0、扇区数、bootable 标志）；EFI 系统分区挂 ISO 内 ESP 镜像条目（El Torito EFI 条目方案）。第三生成流水与校验：输入清单（内核/limine.bin/limine.conf）→ 组装 → 自校验（自解析 PVD/目录/Catalog 断言）→ 输出；xorriso -indev 交叉校验脚本随构建产出。与现存内核衔接点：产物是 F0145 单命令入口的 ISO 分支输出；内核与 limine 二进制来自构建内核产物链。与 Windows 对照：Windows 安装介质 ISO 由 OSCDIMG 生成（微软工具链）；本工程自研生成器消除外部工具依赖、可复现性可控（F0146）。判据 UNX-F0141-J1 的复测方式：构建后运行 xorriso -indev 断言结构合法零告警、自校验解析全过、实机 UEFI 引导登记随闸门补测。

### UNX-F0142 · GPT/ESP 分区镜像生成器
- 域/批：A1/B08｜判据：UNX-F0142-J1 IMG 镜像 GPT 表/ESP FAT 结构与 sgdisk 校验一致，真机引导通过｜纯功能行数：320 行（GPT 表 120 + FAT16 ESP 120 + 组装 80；测试段不计）｜状态：[已深化]
- **定位**：生成 GPT 分区表 + ESP（FAT16）的 HDD/IMG 镜像： Protective MBR、GPT 头、分区项、FAT 文件系统与引导文件齐备。
- **语义边界**：ESP 用 FAT16（小镜像规范与 UEFI 兼容广）；分区数 1（ESP 单分区）；FAT 只实现"构建期静态镜像生成"，不做运行期 FAT 驱动（那是 A3 文件系统域）。
- **依赖与嫁接源**：UEFI 规范 §5（GPT）+ Microsoft EFI FAT32 规范（FAT16 部分）；嫁接 sgdisk/mtools 的结构口径。
- **风险与回退**：GPT CRC 错会让 UEFI 拒盘——GPT 头与分区项数组双 CRC 生成后自校验回读；FAT 一致性（簇链/目录项）生成器内建校验。
- 正文：实现路径分三步。第一 GPT 表：Protective MBR（type 0xEE）→ 主 GPT 头（签名 EFI PART、CRC32 头/表、备份 LBA 指针）→ 分区项（ESP：type C12A7328-F81F-11D2-BA4B-00A0C93EC93B、名称 EFI System）→ 备份 GPT 镜像写盘尾；全表生成后自解析回读校验。第二 FAT16 ESP：BPB 计算（簇大小按镜像尺寸取 4/8 扇区簇）、FAT 表双份、根目录与文件簇链写入（limine.bin/limine.conf/kernel/EFI/BOOT/BOOTX64.EFI）；FAT 生成后用内建解析器回读逐文件哈希断言。第三组装：GPT + ESP 分区镜像 + 对齐填充拼合为 IMG；sgdisk --verify 与 mdir 交叉校验脚本随构建产出。与现存内核衔接点：IMG 是 F0145 的 IMG 分支输出、F0153 多目标同源件；BOOTX64.EFI 为 Limine 的 EFI 加载器。与 Windows 对照：Windows 介质分区用 diskpart 脚本化（运行期工具）；本工程构建期静态生成，镜像哈希可复现。判据 UNX-F0142-J1 的复测方式：sgdisk --verify 零告警、内建 FAT 回读哈希与源文件一致、GPT 双 CRC 校验过、实机引导随闸门补测。
