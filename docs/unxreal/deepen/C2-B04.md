### UNX-F8861 · fork 语义档与 COW 继承（A4 消费）
- 域/批：C2/B04｜判据：UNX-F8861-J1 fork 一次调用双返回（父得子 pid/子得 0）判据过，COW 语义依赖 A4 未收口已记风险，现存最小进程建模路径判据先行全过｜纯功能行数：320 行（fork 号面 130 + 双返回通路 100 + COW 挂点 90；测试段不计）｜状态：[已深化]
- **定位**：fork 是进程族的第一母号，本条把"一次调用双返回"建成判据级事实——父进程得子 pid、子进程得 0（同号双相返回是 Unix 灵魂），COW 继承挂 A4 消费（未收口记风险显式），现存最小进程建模先行全过。
- **语义边界**：只做 fork 号面语义；不做进程对象本体（C1 防重）、不做 COW 页表机制（A4 防重）、不做 vfork（F8862 防重）。
- **依赖与嫁接源**：消费 C1 fork 挂点与 A4 COW 接口（F8857 协议）；对现存 WaitQueue/ExitStatus 为承接扩容；嫁接源为 Linux man-pages fork(2)，只跟随。
- **风险与回退**：C1 未 finalize 时 fork 挂点未就位——号面以现存最小任务派生先行（双返回判据可跑），C1/A4 收口后回归闭账，风险 C2→C1/A4 移交。
- 正文：实现路径分三步。第一步 fork 号面：fork() 无参调用，号面挂 C1 派生通道，派生失败（EAGAIN/ENOMEM）错误分档；第二步双返回通路：派生后父任务返回子 pid、子任务返回 0——同一 syscall 返回点按任务身份分流（r0 槽位写入分相），双返回判据（父子各自读返回值交叉比对）100 次过；第三步 COW 挂点：fork 后地址空间继承走 A4 COW 接口（页共享/写时复制，B03 F8849 COW 消费），A4 未收口期以最小栈模拟继承先行，真 COW 回归登记待补测。与现存内核衔接点：C1 fork 挂点消费，双返回分流函数新增。与 Windows 对照：Windows 无 fork（CreateProcess 全重建），fork+COW 是 Unix 血统优势，对照声明入档。判据 UNX-F8861-J1 的复测方式：ktest 双返回 100 次批跑全过，COW 待补测挂点登记显式。
