## F3763 时序账（tick 与账序）

**定位**：Digest 的时间契约：域 tick 为时间基（F3723 虚拟时钟的域级对端）+账序规则（段内按 tick、段间按聚合序）——时序是账的索引。

**判据**：
- J1：时序契约（域 tick 时间基+跨域 tick 一致+账序规则）；M-521 时序对账（跨域事件 tick 一致）。
- J2：账序确定性（同输入账→同 Digest 序——同 tick 源序 const 决胜。
**纯功能行数**：320（tick 对端 ~110 + 账序 ~105 + 确定性 ~105）
**依赖与嫁接源**：F3721/F3723（tick 语言与虚拟时钟——时间基真源）；B22 三重指纹（确定性同族）；F3768 查询（按 tick 查是本条的索引消费）。
