### UNX-F10481 · ptmx 主设备节点与从端分配
- 域/批：C4/B05｜判据：UNX-F10481-J1 并发 open ptmx 100 次（4 线程×25）零重号零丢号，上限路径返 EAGAIN，每对主从引用计数=2 落配对账｜纯功能行数：340 行（节点分派 110 + 分配器 120 + 错误面对账 110；测试段不计）｜状态：[已深化]
- **定位**：ptmx 是 pty 工厂的售票窗口——open("/dev/ptmx") 一次，内核造一对主从：主端 fd 交调用进程，从端节点挂 /dev/pts 待取。本条建分配器主体与配对账，pty 世界从此有起点。
- **语义边界**：只做 open 分配与主从配对账；从端节点生成（F10482）、解锁授权（F10488）、通路本体（F10483）分条。同进程多次 open 得多对独立 pty，互不共享状态。
- **依赖与嫁接源**：B1 fs23_abstract.rs 设备节点分派联签；嫁接源 Linux pty(7)/pts(4) 与 openpty(3) 语义，只跟随。
- **风险与回退**：并发 open 的编号分配竞态——编号取原子计数器+空闲链双通道，竞态窗口断言零重号；分配中途失败（fd 表满）即回滚整对并归还编号，不留半对。
- 正文：实现路径分三步。第一步节点与分派：ptmx 以字符设备节点挂 fs23_abstract.rs 设备 inode 分派面，open 命中即进 pty 分配器；第二步分配器：原子取号（上限 4096 预埋）→建主从对象（各持环形缓冲、引用计数 2）→主 fd 装入调用者 fd 表（走 proc/ring3.rs fd 安装）→从端待创建标记落配对账；第三步错误面对账：上限满返 EAGAIN、fd 表满 EMFILE、权限不足 EACCES，三错误走 errno.rs 单点并逐条落账。防重声明：pty 是 fd 型字节流设备，与 proc/ipc.rs 定长端口消息总线不同抽象层，互不引用。与现存内核衔接点：fd 安装走 ring3.rs，能力位走 guard.rs。与 Linux 对照：openpty(3) 三次并发得三对互扰为零，判据 UNX-F10481-J1 的复测方式：并发 100 次零重号零丢号、触顶返 EAGAIN、引用计数账逐对=2。

### UNX-F10482 · pts 从设备节点与 devtmpfs 挂接（B1 联签）
- 域/批：C4/B05｜判据：UNX-F10482-J1 open 主端后 /dev/pts/N 节点存在且 ptsname 名字与配对账逐字符一致（100/100 次），串号探针零命中｜纯功能行数：300 行（节点生成 100 + devtmpfs 挂接 100 + 命名账 100；测试段不计）｜状态：[已深化]
- **定位**：从端节点是 pty 的"取货单"——open 主端后内核在 /dev/pts 下挂出与编号对应的节点，等从侧进程来取。本条建节点生成、devtmpfs 挂接与命名账，节点名即事实。
- **语义边界**：只做节点生成与挂接记账；节点权限（F10495）、建删事件流（F10498）分条；/dev/pts 目录本体归 B1 devtmpfs 面，本域走联签接口。
- **依赖与嫁接源**：B1 fs23_abstract.rs inode 分派联签；嫁接源 pts(4) 节点命名条文（/dev/pts/N），只跟随。
- **风险与回退**：编号回收后节点残留（幽灵节点）——节点生命周期绑配对账回收点（F10485），回收即删节点；残留探针常开，幽灵即红账。
- 正文：实现路径分三步。第一步节点生成：F10481 分配成功即生成 /dev/pts/N 节点，N 与配对账编号强一致，生成失败即回滚整对分配；第二步 devtmpfs 挂接：节点创建走 B1 联签接口进 fs23_abstract.rs 的字符设备 inode 面，设备属性（字符设备、pty 从端类）落节点账；第三步命名账：ptsname 名字格式 /dev/pts/%d 与账面逐字符核对，串号探针（open 错编号节点应得互不对应的对端）常开。防重：节点分派与 B1 文件 inode 同源不同实例，联签显式声明。与现存内核衔接点：节点创建接口在 fs23_abstract.rs，事件账供 F10498 对平。与 Linux 对照：openpty 后 /dev/pts 目录即见新节点，判据 UNX-F10482-J1 的复测方式：100 对 open 逐对核对节点名 100/100、串号探针零命中、幽灵节点探针零命中。

### UNX-F10483 · 主从字节通路（复用 B01 环形缓冲体）
- 域/批：C4/B05｜判据：UNX-F10483-J1 主写→从读、从写→主读双向各 10 万字节内容一致零错位，双缓冲水位独立计数｜纯功能行数：360 行（通路主体 140 + 缓冲复用 110 + 方向账 110；测试段不计）｜状态：[已深化]
- **定位**：pty 的本质是两条方向相反的字节通路——主端写的字到从端读出，从端写的字到主端读出。本条建通路本体，复用 B01 环形缓冲（回绕/EOF 语义同一份代码），pty 从此能搬字节。
- **语义边界**：只做通路读写与方向账；EOF/EIO 终态（F10484）、背压（F10489）分条；pty 无 PIPE_BUF 原子写承诺（字符流语义），与 pipe 的原子性差异落账注 pty(7)。
- **依赖与嫁接源**：消费 B01 环形缓冲体（F10401-F10403）；嫁接源 pty(7) 字节流语义，只跟随。
- **风险与回退**：复用缓冲时把 pipe 的 PIPE_BUF 原子性错误带入 pty——通路层显式关原子写分支，防重声明落账；缓冲满路径 F10489 兜底，不静默丢弃。
- 正文：实现路径分三步。第一步通路主体：主→从与从→主两条独立通路，各持环形缓冲实例，读写入口与 B01 pipe 同规则（读空/写满行为一致）；第二步语义差分：pty 按字符流（无原子写承诺、无字节包边界），通路层显式关闭 PIPE_BUF 分支并落差异账——这条差分是防"代码复用带出语义复用"的守门条；第三步方向账：双通路 in/out 字节、水位独立计数，逐通路可查。与现存内核衔接点：缓冲体 import 自 B01 pipe 模块，fd 读写入口走 ring3.rs 统一面。与 Linux 对照：主端 write "hi" 从端 read 得同字节序，判据 UNX-F10483-J1 的复测方式：双向 10 万字节回环零错位、双缓冲水位账独立对平、字符流差异账在册。

### UNX-F10484 · 主端 EOF/EIO 语义（从端全关终态链）
- 域/批：C4/B05｜判据：UNX-F10484-J1 从端全关后主 read 得 EOF（0 字节），主 write 返 EIO 不发 SIGPIPE（与 pipe 判死差异注出处），四格矩阵 10/10 次｜纯功能行数：280 行（关闭探测 90 + 写侧判死 90 + 矩阵对账 100；测试段不计）｜状态：[已深化]
- **定位**：pty 的终态链和 pipe 不同——从端全关后主端 read 得 EOF、write 得 EIO，而且不发 SIGPIPE。本条把这条与 B01 管道"EOF/EPIPE/SIGPIPE 三终态链"的相似但不同之处钉死，差异即防混淆战。
- **语义边界**：只做主端终态（读 EOF/写 EIO）；从端关闭次序与回收（F10485）、悬挂唤醒（F10499）分条；EIO 语义注 pts(4) 条文出处。
- **依赖与嫁接源**：消费 F10483 通路与 B01 等待器；嫁接源 pts(4)/pty(7) 终态条文（EIO 注出处），只跟随。
- **风险与回退**：把 pipe 的 SIGPIPE 语义错误带入 pty 写侧——终态表显式列"pty 主端写不发 SIGPIPE"行，判据含反向断言（SIGPIPE 零投递），防语义串门。
- 正文：实现路径分三步。第一步关闭探测：从端引用计数归零（最后一 pts fd 关闭）即主→从通路置 EOF 位，主端 read 在缓冲排空后返 0；第二步写侧判死：EOF 位后主端 write 返 EIO（Linux pty 事实，注 pts(4) 出处），与 pipe 的 EPIPE+SIGPIPE 链差异落账——无读者挂位检查不触发 SIGPIPE；第三步矩阵对账：从端关闭次序（逐 fd 关 vs dup 副本仍开）×（主读中/主写中）四格矩阵逐格落账。与现存内核衔接点：EOF 位消费 B01 环形缓冲 EOF 机制，EIO 走 errno.rs 单点。与 Linux 对照：`cat /dev/pts/N` 后关从端，主端 read==0；从端关后写主端得 EIO，判据 UNX-F10484-J1 的复测方式：四格矩阵 10/10 次、EOF 10/10 次、EIO 10/10 次、SIGPIPE 零投递反向断言 10/10 次。

### UNX-F10485 · 从端关闭回收与 pts 编号复用
- 域/批：C4/B05｜判据：UNX-F10485-J1 双端引用归零即回收、编号回空闲链，污染-回收-复用循环 100 次零残留（新对缓冲全零）｜纯功能行数：300 行（回收触发 100 + 回收动作 100 + 残留断言 100；测试段不计）｜状态：[已深化]
- **定位**：pty 用完要退房——双端引用归零即整对回收：缓冲清零、配对账除名、编号回空闲链供下次复用。残留是 pty 世界的床底灰尘，本条以"污染-回收-复用"循环把残留探到零。
- **语义边界**：只做整对回收与编号复用；从端单关而主端仍开时仅清从向通路不清对（半开态属 F10484 终态面）；节点删除动作与 F10482 联签。
- **依赖与嫁接源**：消费 F10481 配对账与空闲链；嫁接源 pty(7) 生命周期语义（对端关闭后对可复用），只跟随。
- **风险与回退**：回收与在途读写的竞态——close 路径先摘 fd 表项（引用计数减到零前读写仍合法），归零后回收动作持配对账锁原子完成，在途者已被 F10499 唤醒面兜住。
- 正文：实现路径分三步。第一步回收触发：主/从两端引用计数均归零（两端都关）才整对回收；仅一端关走终态位（F10484）不清账；第二步回收动作：双缓冲清零（先清零再回池，不清零即有残留窗口）、配对账除名、编号 LIFO 回空闲链、节点删除走 F10482 联签接口；第三步残留断言：污染用例（10 万字节写入后回收）→复用同号→断言新对缓冲全零、水位全零、配对账新起。循环 100 次。与现存内核衔接点：回收点挂 ring3.rs close 钩子，编号池与 F10481 同池。与 Linux 对照：openpty/close 循环千次编号稳定复用，判据 UNX-F10485-J1 的复测方式：污染-回收-复用 100 次零残留、半开态不清对 10/10 次、编号回链 100/100。

### UNX-F10486 · 字节流录制器基建（判据主轴前置件）
- 域/批：C4/B05｜判据：UNX-F10486-J1 1 MB 混合流（含回绕边界）录制-回放逐字节零差异，时间戳 100/100 段单调，旁路不持通路锁｜纯功能行数：380 行（录制钩子 130 + 回放器 130 + 时序账 120；测试段不计）｜状态：[已深化]
- **定位**：判据主轴是"pty 上 vim 类全屏程序 + 录制对照"，录制器就是主轴的摄影机——把主从两方向的字节流连字节带时点录下来，回放即复现。本条建录制钩子、流格式与回放对账，主轴工程从此有底片。
- **语义边界**：只做录制/回放基建；场景账与主轴挂接（F10497）、行规程录制基线（B07）分条；录制为旁路记账（不持通路锁、不阻塞主链），与 F10466 观测器同纪律。
- **依赖与嫁接源**：消费 F10483 两通路读写入口；嫁接源 script(1)/ttyrec 的格式思想（只跟随思想，实现按 Varix 账本面），注出处。
- **风险与回退**：录制开销污染被录行为（海森堡式干扰）——钩子纯旁路（无锁追加、批量落账），开销上限断言（录制开关前后吞吐差 <5%），超限红账。
- 正文：实现路径分三步。第一步录制钩子：主→从与从→主两通路各挂旁路钩子，记录（方向|序号|字节区间|相对微秒）四元组，钩子零锁追加、批处理落盘；第二步流格式：流记录格式定版（版本号、方向枚举、时点精度），环形落盘上限预埋（超限滚动覆盖最旧段），格式即回放契约；第三步回放对账：回放器按记录重放出字节序与原始流逐字节比对，时序单调断言（录制序号与回放序号一一对应）。与现存内核衔接点：钩子挂 F10483 读写入口，账面经账本面导出。与 Linux 对照：script(1) 录制 typescript 文件同思想，判据 UNX-F10486-J1 的复测方式：1 MB 流（含回绕边界分段）回放零差异、时序单调 100/100 段、开销差 <5% 断言 10/10 次。

### UNX-F10487 · TIOCGPTN/TIOCSPTLCK ioctl
- 域/批：C4/B05｜判据：UNX-F10487-J1 TIOCGPTN 返编号与配对账一致 100/100，TIOCSPTLCK 写读往返一致且锁位联动 unlockpt 拒绝路径 10/10｜纯功能行数：240 行（ioctl 分派 80 + PTN 面 80 + PTLCK 面 80；测试段不计）｜状态：[已深化]
- **定位**：openpty(3) 的两把小钥匙——TIOCGPTN 问"从端是几号"、TIOCSPTLCK 锁"从端先别让人开"。本条把两把钥匙挂进 ioctl 分派面，glibc 级 pty 初始化序列（grantpt/unlockpt/ptsname）从此能跑通。
- **语义边界**：只做两 ioctl 本体；unlockpt/grantpt 语义（F10488）、winsn/ioctl 大面（B06）分条；参数经 uaccess 判界，int 拷入拷出。
- **依赖与嫁接源**：C2 挂号 ioctl 面（table.rs 号段）；嫁接源 tty_ioctl(2) 两命令语义，只跟随。
- **风险与回退**：非 ptmx fd 误调——命令处理器判 fd 类（ptmx/pts/其他），错类按 Linux 返 ENOTTY，防错类串行。
- 正文：实现路径分三步。第一步分派：两命令经 C2 挂号的 ioctl 面进 pty 处理器，uaccess 判界后 int 拷入拷出（EFAULT 面）；第二步 TIOCGPTN：读配对账编号返 int，编号与账面强一致；第三步 TIOCSPTLCK：锁位写读往返（0/1 双值），锁位=1 时从端 open 拒绝路径（F10488 消费）联动断言。与现存内核衔接点：ioctl 分派走 table.rs 挂号面、errno 走 errno.rs。与 Linux 对照：`ioctl(fd, TIOCGPTN,&n)` 与 ptsname(3) 结果一致，判据 UNX-F10487-J1 的复测方式：PTN 100/100、PTLCK 往返 10/10、错类 ENOTTY 10/10。

### UNX-F10488 · unlockpt/grantpt 语义（B1 权限联签）
- 域/批：C4/B05｜判据：UNX-F10488-J1 锁位下从端 open 拒（EIO）、unlock 后开 100/100，grantpt 权属（uid:tty）账可查 100/100｜纯功能行数：260 行（锁语义 100 + 授权面 80 + 权属联签 80；测试段不计）｜状态：[已深化]
- **定位**：unlockpt/grantpt 是从端节点的"开锁与过户"——锁着时从端 open 被拒（EIO），解锁后才放行；grantpt 把节点权属过户给调用者 uid 和 tty 组。本条把两语义与 B1 权限账联签闭环，openpty(3) 序列全通。
- **语义边界**：只做解锁/授权语义；权限位判定的执行面归 B1 open 检查（本域联签）；两函数皆以主端 fd 为参（ioctl 路径），非 ptmx fd 返 ENOTTY。
- **依赖与嫁接源**：B1 权限账联签（fs23_abstract.rs 节点账）；嫁接源 pts(4) EIO 条文与 openpty(3)/grantpt(3) 语义，只跟随。
- **风险与回退**：解锁与从端 open 的竞态（unlock 中途 open 窗口）——锁位判定在 open 入口单点原子读，解锁持锁位写锁，窗口断言零中间态放行。
- 正文：实现路径分三步。第一步锁语义：unlockpt 清配对账锁位，从端 open 入口判锁位（锁=1 拒 EIO）——"节点在而开不了"正是锁的本意；第二步授权面：grantpt 置节点权属（uid=调用者、gid=tty 组、mode=0600），权属写走 B1 联签接口进节点账；第三步错误面：非 ptmx fd ENOTTY、并发 unlock 幂等（重复解锁成功无害）、uaccess 参数校验 EFAULT。与现存内核衔接点：权属账在 fs23_abstract.rs，判定消费 guard.rs 能力位。与 Linux 对照：openpty(3) 内部正是 grantpt→unlockpt→open 序列，判据 UNX-F10488-J1 的复测方式：锁前拒/锁后开 100/100、权属账 100/100、竞态窗口 1000 轮零中间态放行。
