- 域/批：C4/B07｜判据：UNX-F10525-J1 行首 ^D 提交 EOF（read 得 0），非行首 ^D 提交已缓冲字节（半行读），连续两次行首 ^D 第二次仍 EOF｜纯功能行数：280 行（EOF 语义 110 + 半行面 90 + 链路账 80；测试段不计）｜状态：[已深化]
