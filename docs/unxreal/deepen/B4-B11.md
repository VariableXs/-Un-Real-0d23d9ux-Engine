### UNX-F6601 · DSM/TRIM 命令（deallocate 范围集）
- 域/批：B4/B11｜判据：UNX-F6601-J1 DSM 范围集（最多 256 范围）构造/提交正确，范围 LBA/长度编码与规范一致；空范围集拒绝路径｜纯功能行数：351 行（范围集构造器 130 + 提交与编码验证 120 + 拒绝路径与账 101；测试段不计）｜状态：[已深化]
- **定位**：DSM（Dataset Management）是 TRIM 的载体命令：deallocate 操作把范围集（Range 描述符数组）交给设备回收。本条立范围集构造器（块层 discard 请求→范围集编码）与提交链，范围 LBA/长度 64 位+16 位双字段编码与规范逐位一致，空范围集（零范围数）拒绝路径明确（不提交空命令）。
- **语义边界**：只做 DSM deallocate 构造与提交；不做 TRIM 回收可查询判定（F6602 防重）；不做范围上限分批（F6605 防重）；块层 discard 入口语义消费 F6497（TRIM 顺序契约，不重立）。
- **依赖与嫁接源**：依赖 F6611 ONCS 能力位（dsm 支持裁断）与 F6592 PRP/数据指针面（范围集缓冲传递）；嫁接源为 NVMe 1.4 Dataset Management 命令章节（Range 描述符 16B 结构：LBA 8B+长度 2B+保留），只跟随。
- **风险与回退**：编码错位（保留字段未清零/长度字段溢出）——编码器逐字段断言（保留零断言+长度上溢拒绝）；范围排序语义（设备可要求排序，AD 属性）——排序开关按 identify AD 位裁断，未排序提交被拒即重排档。
- 正文：实现路径分三步。第一步构造器：块层 discard 段列表→范围集转换（每 16B 描述符：SLBA 8B 小端+NLB 2B（长度-1 编码——规范语义）+其余零），构造器逐字段断言（保留字段清零断言、NLB 上限（65536 扇区）拒绝、范围 LBA 不超 NSZE 边界检查）；范围集缓冲挂 F6594 面传递。第二步提交与编码验证：DSM 命令封装（opcode 0x09+AD/IDW/IDR 三 attribute 位按 identify 裁断置位），提交走 F6607 handler 表（分派语义统一），模拟器编码回读比对（模拟器解析范围集→与构造输入逐条全等——编码↔解析互逆），256 范围满集提交正确验证。第三步拒绝路径：空范围集（零范围）提交前拒绝（错误码：空范围集，不发起命令），dsm 能力位假时 DSM 全拒（Unsupported 口径——F6612 语义预演），拒绝账逐次留痕；边界注入（NLB=0 拒绝/LBA 越界拒绝/范围数超 F6605 上限拒绝——后者联动分批注记）全绿。与现存内核衔接点：现存无 DSM（裸命令层预留 opcode 位），本条为新增命令（不影响现有 Read/Write/Flush）。与 Windows 对照：Windows FSCTL_TRAFFIC 类 TRIM 经 stornvme 翻译 DSM（WDM storage trim 语义），本内核编码互逆自证，判据 UNX-F6601-J1 的复测方式：范围集编码互逆全等、满集 256 提交正确、空集与边界拒绝全绿。

### UNX-F6602 · TRIM 判据（回收区段可查询）
- 域/批：B4/B11｜判据：UNX-F6602-J1 TRIM 后 NUSE（已用扇区数）减少可查，回收判定与 DSM 范围账一致；模拟设备支持回读验证｜纯功能行数：311 行（NUSE 回查链 110 + 一致性判定 100 + 回读验证账 101；测试段不计）｜状态：[已深化]
- **定位**：TRIM 提交了不等于回收了——判据必须可查询：DSM 后回查 identify NUSE（已用扇区数）应减少（减少量与 DSM 范围账一致）。本条立 NUSE 回查链与一致性判定：TRIM 前后 NUSE 快照差值↔DSM 范围总扇区数对账（模拟器模拟设备档支持真实回读），回收判定与范围账一致断言——TRIM 语义的闭环证据。
- **语义边界**：只做 NUSE 回查与一致性判定；不做 DSM 构造提交（F6601 防重）；不做空间回收的文件系统层语义（B1 域防重）；NUSE 为估算口径注记（设备可延迟回收——判定按最终一致窗）。
- **依赖与嫁接源**：依赖 F6601 DSM 提交与 F6563 identify（NUSE 字段消费）；嫁接源为 NVMe 1.4 Identify Namespace NUSE 字段语义与 TRIM 延迟回收惯例，只跟随。
- **风险与回退**：NUSE 不减（设备延迟回收，即时判定误报）——最终一致窗（等待窗+重试查询，窗参数冻结），即时误报避免；回读不支持档（模拟器旧档无 NUSE 模拟）——档位探测（不支持档判据标注"模拟档升级后补验"，不假装过）。
- 正文：实现路径分三步。第一步回查链：identify NS 回查封装（CNS=0 单字段裁断——NUSE 提取），TRIM 前快照→DSM 提交→回查轮询（默认窗 2 秒+3 次重试——窗参数冻结页）→后快照，回查链账（前值/后值/差值/等待轮次四列）。第二步一致性判定：差值↔DSM 范围账总扇区数对账（差值≥范围总量即回收成立——设备可超额回收，等号不强制），逐范围追溯档（模拟器支持按范围记账档：每范围回收独立可查——细粒度判定）；不一致处置（差值=0 且窗耗尽→红账+"延迟回收"标注重试上限）。第三步回读验证：模拟设备档（TRIM 后模拟器内存面真实置空洞+NUSE 真实递减）全链验证（三组范围集各 100 扇区/满 256 范围/重叠范围三型，NUSE 差值全部对账一致）；不支持回读档判据标注留痕（诚实口径）；判据页接线 ktest。与现存内核衔接点：现存无 TRIM 面，本条与 F6601 组成 TRIM 全链（不影响既有 IO）。与 Windows 对照：Windows TRIM 判定经 FILE_LEVEL_TRIM 回执（NTFS 语义），本内核 NUSE 对账+细粒度追溯，判据 UNX-F6602-J1 的复测方式：三型范围集 NUSE 对账全一致、最终一致窗生效、不支持档诚实标注。

### UNX-F6603 · Write Zeroes 命令
- 域/批：B4/B11｜判据：UNX-F6603-J1 Write Zeroes 写零正确（含与 deallocate 联动省擦除档），数据回读全零断言；范围边界值全过｜纯功能行数：291 行（命令封装 100 + 联动档 100 + 边界验证 91；测试段不计）｜状态：[已深化]
- **定位**：Write Zeroes（opcode 0x08）是"写零不传数据"命令：不占数据缓冲即可把范围置零，DEAC 位置位时与 deallocate 联动（设备可免实际擦除——SSD 省命）。本条立命令封装与联动档：写零正确（回读全零断言）、联动档（DEAC=1 时模拟器空洞化验证）、范围边界值（最大 NLB/LBA 顶格/跨段）全过。
- **语义边界**：只做 Write Zeroes 封装与验证；不做 DSM deallocate（F6601 防重）；不做 Write Zeroes Uncorrectable（DTYPE 注记后段）；块层写零请求入口语义（块层侧映射）注记不重立。
- **依赖与嫁接源**：依赖 F6611 ONCS（write-zeroes 位裁断）与 F6592 数据指针面（无数据传输——PRP 置零语义）；嫁接源为 NVMe 1.4 Write Zeroes 命令章节（DEAC 位/NLB 编码语义），只跟随。
- **风险与回退**：DEAC 语义误用（设备不支持免擦除却置位）——联动位按 identify 裁断（DC 能力位假时 DEAC 恒零），误置注入拒绝；边界回卷（NLB 编码差一）——边界值表（最小/最大/顶格三值单测）封堵。
- 正文：实现路径分三步。第一步命令封装：Write Zeroes 构造器（SLBA/NLB/DEAC/PRINFO 四字段，无 PRP 传递——规范语义 PRP 字段忽略档注记），能力位裁断（write-zeroes 位假→Unsupported 拒绝——F6612 口径），DEAC 位按 DC（deallocate 联动能力）位裁断置位，封装账逐字段落。第二步联动档：DEAC=1 档模拟器验证（写零范围空洞化——内存面置未分配+NUSE 递减联动 F6602 账对账），DEAC=0 档（真实写零——模拟器内存面置零+回读全零断言），两档行为区分可观测（账面标注档别）。第三步边界验证：范围边界值表（NLB=1 最小/NLB=65536 规范最大/NSZE 顶格末段/跨 NUSE 边界拒绝四型）逐项验证，写零后回读全零断言（每边界型 1KiB 抽验+首尾扇区精验），与 deallocate 组合序（先 Write Zeroes 后 DSM 同范围——最终 NUSE 一致性，F6602 账复用）验证。与现存内核衔接点：现存无 Write Zeroes，新增不影响既有命令。与 Windows 对照：Windows 填零请求经 stornvme 翻译 Write Zeroes（stornvme zeroes 语义），本内核联动档+边界表，判据 UNX-F6603-J1 的复测方式：回读全零、两联动档行为正确、四型边界全过。

### UNX-F6604 · Compare 命令
- 域/批：B4/B11｜判据：UNX-F6604-J1 Compare 比较一致/不一致两路正确（不一致返回 Referenced Compare Fail），比较数据缓冲安全｜纯功能行数：271 行（命令封装 100 + 两路验证 90 + 缓冲安全 81；测试段不计）｜状态：[已深化]
- **定位**：Compare（opcode 0x05）是"不写的验证写"：设备把指定范围与命令附带的比较数据逐字节比对，一致静默成功、不一致返回 Referenced Compare Fail（status 0x284）。本条立封装与两路验证，比较数据缓冲安全（大端按 LBA 尺寸对齐+长度恰好 NLB×LBADS——越界缓冲拒绝）。
- **语义边界**：只做 Compare 封装与验证；不做 Write Zeroes（F6603 防重）；compare-fail status 的错误分类翻译消费 F6596 表（不重立）；比较数据生成方（测试/校验场景）不在本条。
- **依赖与嫁接源**：依赖 F6611 ONCS（compare 位裁断）与 F6592 PRP 面（比较数据传递）；嫁接源为 NVMe 1.4 Compare 命令章节与 Referenced Compare Fail 语义，只跟随。
- **风险与回退**：缓冲越界（比较数据长度≠NLB×LBADS）——长度精确断言（不匹配即拒绝），越界注入拒绝；大缓冲 DMA 面（1MB 比较）——PRP 链复用（F6592），单页路径回归保一致。
- 正文：实现路径分三步。第一步封装：Compare 构造器（SLBA/NLB/比较数据 PRP 三要素），能力位裁断（compare 位假→Unsupported），长度精确断言（缓冲长度=NLB×LBADS——不等即构造期拒绝），封装账落。第二步两路验证：一致路（模拟器内存面数据与比较数据全等→成功完成，账面标注"compare pass"），不一致路（单字节差异注入→Referenced Compare Fail 返回→F6596 翻译为 BLK_STS 拒绝族→请求终态正确），两路各 ≥50 次验证，差异定位档（模拟器报告首个差异偏移——验证精度旁证）。第三步缓冲安全：越界注入（长度多 1B/少 1B/零长三型）构造期全拒，大缓冲档（512B LBA×2048 扇区=1MB）PRP 链传递正确（比较结果与单页档一致），缓冲释放对账（比较缓冲挂摘配对——F6591 思想下沉）。与现存内核衔接点：现存无 Compare，新增不影响既有命令。与 Windows 对照：Windows 无直接 Compare 映射（应用层自比语义），本内核命令级验证更底层，判据 UNX-F6604-J1 的复测方式：两路各 ≥50 全对、fail status 翻译正确、越界三型全拒。

### UNX-F6605 · DSM 范围上限语义
- 域/批：B4/B11｜判据：UNX-F6605-J1 单命令范围数上限（设备 DMRL/规范 256 双约束）裁断正确，超限自动分批提交且分批账守恒｜纯功能行数：271 行（双上限裁断 100 + 分批提交器 90 + 守恒账 81；测试段不计）｜状态：[已深化]
- **定位**：DSM 范围数受双约束：规范 256 上限与设备 DMRL（D.SM 范围上限，identify MDTS 类语义——模拟器档裁断）取最小。超限请求不拒绝而自动分批（多 DSM 命令连续提交），分批账守恒（总范围数与总扇区数在分批前后不变——拆分不丢不重）。本条立双上限裁断与分批提交器。
- **语义边界**：只做范围上限裁断与分批；不做 DSM 编码（F6601 防重——消费其构造器）；分批与块层拆分器（F6405）分工注记（拆分器管 IO 上限、本条管 DSM 范围上限，两层正交）。
- **依赖与嫁接源**：依赖 F6601 构造器与 F6562 identify（DMRL 字段消费——模拟器档位供给）；嫁接源为 NVMe 1.4 DSM NMIC 与范围数约束语义、Linux nvme discard 分批惯例，只跟随。
- **风险与回退**：分批乱序（批间顺序影响回收语义）——分批保序提交（队列对内 FIFO 天然保序+F6548 保序墙思想注记）；分批部分失败（第 2 批失败第 1 批已提交）——部分失败语义（已提交批不回滚、失败批红账+重试档，整体请求部分完成标注）。
- 正文：实现路径分三步。第一步裁断：双上限仲裁（min(256, DMRL)——DMRL 模拟器档三档：256 满额/128 中档/16 紧档），仲裁结果冻结每设备一值，超限判定单点（构造入口），裁断账（请求范围数/上限/分批数三列）。第二步分批提交器：超限范围集按上限切片（顺序切片不重排），每批独立 DSM 命令（F6601 构造器逐批调用），批间顺序提交（同队列对 FIFO），分批账（批号/范围数/扇区数逐批落账）。第三步守恒验证：分批前后对账（总范围数相等+总扇区数相等——零丢零重），三档上限各注入（257 范围/512 范围/1000 范围三型）分批正确（批数=⌈N/上限⌉），部分失败注入（第 2 批模拟器返回错误——后续批继续+失败批重试，终账部分完成标注），DMRL=16 紧档性能注记（批数放大 16 倍——分批开销账）。与现存内核衔接点：现存无 DSM 面无上限语义，本条为 F6601 增量。与 Windows 对照：Windows stornvme TRIM 分批经 storport 请求拆分（SRB 分批语义），本内核双上限裁断+守恒账，判据 UNX-F6605-J1 的复测方式：三档分批正确、守恒对账零偏离、部分失败语义留痕。

### UNX-F6606 · abort 命令（取消在途）
- 域/批：B4/B11｜判据：UNX-F6606-J1 abort 提交（SQID/CID 定向）语义正确，被中止命令终态明确（aborted 码回传）；不可中止完成竞态处置｜纯功能行数：311 行（abort 提交链 110 + 竞态处置 100 + 终态账 101；测试段不计）｜状态：[已深化]
- **定位**：abort（admin opcode 0x08）取消在途 IO 命令：提交 SQID+CID 定向取消请求。本条立提交链与竞态处置：被中止命令以 Aborted by Host（status 0x0xx 独立码）回传终态明确；竞态窗口（abort 在途时命令恰好自然完成——"不可中止完成竞态"）处置明确（完成先到则 abort 返回命令不存在语义档——模拟器按规范口径）。
- **语义边界**：只做 abort 提交与竞态处置；不做超时自动触发 abort（F6614 防重——本条机制、那条自动化策略）；不做 B12 复位升级（升级链接口预留注记）；abort 是 best-effort 语义注记（规范明文——不保证成功）。
