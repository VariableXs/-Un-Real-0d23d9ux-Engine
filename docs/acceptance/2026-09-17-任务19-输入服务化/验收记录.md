## 实机发现并修复的问题

- [x] **订阅游标 off-by-one**：subscribe 设 read_seq=write_seq 导致新订阅者重放最后一条历史事件（实机首轮 seq70 幽灵事件）→ 改 write_seq+1 + 宿主回归用例
- [x] **PS/2 鼠标默认不上报**：复位后需控制器 0xA8 开 AUX 门 + 鼠标 0xF6/0xF4 使能序列，缺 bring-up 时鼠标静默（keyboard 路径无感）→ mouse_bringup() 三步 ACK 序列
- [x] panic handler 只写屏幕不写串口（任务18 已知项）之外的补充：`*.log` 全局 gitignore，验收串口日志只归档本地不入库（与任务17 同惯例）
