## 0. 终态一句话与全景分层图

**一块 1TB 盘插任意电脑：开机默认进 VARIX 内核 + Variable 桌面（与 Windows 侧一模一样）；日常软件走 Wine 兼容层（Windows 完全没开机）；高兼容软件走隐形 Windows 引擎（窗口无缝出现）；游戏/反作弊重启进纯 Windows（盘上自带）；数据/设置/应用清单三世界同一份；拔盘即走、零残留。**

```
┌────────────────────────────────────────────────────────────┐
│ L6 生态层   壁纸生态 · 应用登记 · 皮肤主题 · 扩展点 · 数据开放  │
├────────────────────────────────────────────────────────────┤
│ L5 应用层   desktop taskbar explorer datavault               │
│             app-write app-mind app-code app-fate 设置中心     │
│             第三方软件(三通道) · 嵌入窗口 · 引擎窗口           │
├────────────────────────────────────────────────────────────┤
│ L4 界面层   同一份 React 前端(959 文件) · i18n 三语 · 亮暗主题 │
│             ├─ Windows 侧:WebView2 渲染                       │
│             └─ 内核侧:Servo 渲染(同一份代码)                  │
├────────────────────────────────────────────────────────────┤
│ L3 能力层   Windows:Tauri 本体(650 命令)                      │
│             内核:垫片(554 方法三色映射)→内核系统服务           │
├────────────────────────────────────────────────────────────┤
│ L2 系统层   VARIX:调度/内存/驱动/fs/安全(Wine链·白名单·kvault) │
│             Windows 11:U盘WIN_ENGINE 或 内置盘                │
├────────────────────────────────────────────────────────────┤
│ L1 数据层   SHARED(exFAT 单一事实源) · KV · apps.json · 白名单 │
├────────────────────────────────────────────────────────────┤
│ L0 引导层   ESP(Limine+bootmgr) · bootselect 四卡 · handoff   │
├────────────────────────────────────────────────────────────┤
│ L-1 硬件    U盘五分区(ESP/VARIX_SYS/WIN_ENGINE/SHARED/SNAPSHOT)│
└────────────────────────────────────────────────────────────┘
```

## 1. 三个世界定义

| 世界 | 是什么 | 从哪来 |
|---|---|---|
| **VARIX 内核世界** | 自研隔离 OS + Servo 版 Variable 桌面 + Wine 应用 + (可选)后台引擎 | U 盘 VARIX_SYS，F12 引导 |
| **U 盘 Windows 世界** | 完整 Win11（第 1 批部署），可引导可作引擎镜像 | U 盘 WIN_ENGINE 300GB |
| **内置盘 Windows 世界** | 用户现有 Win11（壁纸/软件原样），Variable 以自启/Shell 模式全屏 | 电脑内置盘，保持默认引导 |

### D 软件生态（三通道+兜底判定流）

```
一个 Windows 软件
   ├─ web 技术做的 ──────────→ 通道一 内核原生(Servo 直跑)
   ├─ 轻量 Win32 ───────────→ 通道二 Wine 兼容层(compatdb 分级登记)
   ├─ 重型/闭源/深度绑定 ────→ 通道三 隐形引擎(后台VM,窗口无缝)

```

### G 安全与隐私（已在位，持续加固）

软件侧既有防线：白名单默认拒绝（vfsguard/msgchan/clip/shm）+ 越权审计；kvault AES-256-GCM 保险箱；PE 拒绝表（组合特征防误拦）；每 exe 独立进程+Job 限额+prefix 隔离；Seccomp 白名单+guard 审计+meter 计量；能力申请式授权；隐私红线（日志不记敏感内容、异步不阻塞）。

**实机四层保障矩阵（对硬件/内存/数据/Windows 回归的正式防线，与《实施总步骤图》1.7 实机安全宪法同源）：**

| 保障层 | 机制 | 已验证证据 |
|---|---|---|
| 硬件安全 | 对固件只做三件正规事（读 BootOrder / 一次性 BootNext / 正常重启），永不刷固件永不改固件设置；软件指令物理上不可达硬件电路（供电/时序由固件与电源芯片管辖） | 实机 F12→VARIX 引导 852ms 链路 ×N 次零异常 |
| 内存安全 | Rust 所有权模型 + 白名单默认拒绝 + 每进程 Job 限额 + Seccomp/guard/meter；内置盘 NVMe 控制器永不初始化；GPU 基建立项以 IOMMU 评估为前置 | ktest 3068 / kcheck 0 |
| 数据安全 | 内核侧 exFAT 只读挂载（写请求显式拒绝，绝不静默降级）；fs23_journal 账本写入；SNAPSHOT 快照滚动；差分升级失败自动回滚；SHARED 用户数据只增不删 | 掉电注入 ×10/×11 零丢失；差分升级断电 ×10 零变砖 |
| Windows 回归 | 拔盘即走（物理，永不失效）→ BootNext 一次性预约（引导）→ 防自锁闸门（逻辑）→ 上机前记录/下机后核验（操作）→ 每里程碑进原生 Windows ×2（流程） | F12 选盘真机链路已走通；BootOrder 只读语义在档 |

## 4. 一致性承诺（"一模一样"的工程定义）

1. **界面层：立即一模一样**——同一份 React 代码，验收=与 Windows 侧截图像素级对照。
2. **功能层：渐进一模一样**——554 方法 100% 有归属；❌→🔶→✅ 收敛；前端零改动。
3. **天花板层：四类永久分流**——Windows 深度集成→Wine/引擎承担；GPU/网络→随基建；反作弊/DRM→纯 Windows；触控板(I2C)内核侧不支持（外接 USB 鼠标第4批通）。
4. 除上述四类，其余全部无天花板。

---

## 5. 生态开放性（长期，Minecraft 式底座）

- **壁纸生态**：网页壁纸即标准 web 内容，Servo 原生渲染——用户/社区壁纸天然兼容。
- **应用登记**：apps.json 单一事实源用户可扩（分级登记/通道映射/角标）。
- **皮肤与主题**：主题体系开放格式，可备份可编辑可导出。
- **扩展点**：脚本/插件接口，沙箱隔离，扩展崩溃不拖垮本体；接口按"十年不变"标准版本化。
- **数据开放**：全开放格式可导出可迁移；卸载不留垃圾；配置可备份可编辑。

## 6. 物理边界（永不承诺清单，与功能矩阵同等效力）

Tauri/WebView2 本体不进内核；双 OS 同时活窗不成立；不重启切系统不成立；反作弊只在纯 Windows；"内存实时互通"仅隐形引擎形态成立；I2C 触控板内核侧不支持；快速启动必须关（与插盘语义冲突）。

---

## 7. 实机安全承诺（与功能承诺同等效力，违反即事故级复盘）

对四个最高关切的正式承诺，每条都可验证、可回溯：

1. **不会威胁硬件**——全程零固件写入、零 BIOS 改动；软件指令物理上无法造成短路或硬件损伤；对固件的全部动作=读 BootOrder + 写一次性 BootNext + 正常重启，三件正规事有代码闸门与用例看护。
2. **不会威胁内存**——内核侧全部内存访问经 Rust 安全模型与白名单仲裁；不初始化、不枚举、不挂载内置盘控制器；后续 GPU/网络基建以 IOMMU 评估为开工前置，无隔离不开工。
3. **不会威胁数据**——内置盘只读（唯一例外=可逆单键关快速启动，先告知后动手）；U 盘上 SHARED 用户数据只增不删；删除类操作先快照；journal+快照双保险有断电注入 ×10/×11 零丢失的实测背书。
4. **操作完永远回得了 Windows**——五重保障逐级兜底：拔盘即走（物理）→ BootNext 一次性（引导）→ 防自锁闸门（逻辑）→ 上机前记录/下机后核验（操作）→ 回归演练常态化（流程）。最坏情况推演：U 盘全损=拔盘后内置盘 Windows 毫发无损，因为 U 盘引导从头到尾没写过内置盘一个字节。
