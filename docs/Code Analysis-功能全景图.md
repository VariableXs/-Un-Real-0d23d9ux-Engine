## 硬性原则（总纲）

1. **零 AI**：全引擎不调用任何网络模型；续写基于语法规则与类型约束枚举。
2. **一版全功能，三端等价**：Windows 独立 / Variable 收件箱嵌入 / VARIX 内核用户态，
   550+ 项功能 100% 可用；疑似冲突能力一律"换实现层"，绝不隐藏、绝不阉割。
3. **功能零修改**：编号、名称、行为、UI 一律以《Code Analysis2.md》为准，
   本工程不做任何功能变更、精简或重设计。
