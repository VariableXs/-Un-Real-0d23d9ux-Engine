# M1 知识归档 · 显示与图形地基（步骤 0268）

> 目标读者：进入 W2/W3 的后续会话。总结 W1（A001~A200）沉淀的可复用结论。

## 架构要点
1. **域文件即 API**：每域一文件（`aurora/*.rs`），纯函数 + 固定容量数组，主机测试即真实验证；跨域复用直接 `use super::<域>::<fn>`，无需运行时。
2. **像素管线**：display（模式/EDID）→ render2d（几何/混合）→ typography（字形点阵 8x8 `GlyphBitmap`）→ compositor（`Layer[16]` z 序 src-over，RGBA8，`LAYER_MAX 16x16`、画布上限 64x64）。
3. **事件管线**：扫描码 → `decode_key_event` → `EventPump`（[Option<Event>;64] 满则丢最旧并计数）→ `route_focus` → 焦点窗口 → `mark_layer_dirty` 脏区。
4. **音频管线**：`synth_*` 定点相位累加（Q16 相位，&0xFFFF）→ `mix_i16`（8 路 Q15 增益 + 软削波 0.9 膝点）→ `PlaybackQueue`（块 FIFO）→ `DmaRing`（留 1 空位判空满）。

## 关键约定（W2 起必须遵守）
- CheckSet 单条 `add(name, passed, detail)`，域自检入口 `run_<域>_checks()`，25 项全真；
  域内 **不得递归调用** 自身 checkup（robust 的 leaf 约定）。
- 内核自检闭环 `robust::run_kernel_checkup()` 现已注册 AURORA 全部域 + W1 集成 + W3 门禁，
  `MAX_DOMAINS=96`——新域接入直接在注册表追加一行即可。
- 时间/延迟一律整数微秒（`latency_ok(measured, budget)`），禁止浮点预算。
