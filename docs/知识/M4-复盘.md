## 教训与根因

1. **挂载名与路径漂移**：`security/aurora.rs` 先后被挂成 `asecurity` 与 `security::aurora`，`run_kernel_checkup` 注册路径一度与 lib.rs 挂载不一致导致编译失败。根因：多会话并行改 lib.rs/robust.rs 没有约定单一挂载名。对策：挂载名以 lib.rs `#[path]` 注记为准，注册前先 grep 挂载名。
2. **工具链易损**：rustup toolchain 目录被清理到只剩 cargo（"Missing manifest in toolchain"），ktest 全挂。对策：`kernel/rust-toolchain.toml` 钉 stable=1.97.1，环境损坏时 `rustup toolchain install 1.97.1 --profile minimal` 重装（代理不稳时多重试）。
3. **重复 id 通知**：NotificationCenter 曾允许重复 id 入队（同一通知重复弹）。已在 push 内拒绝，回归单测覆盖。
