## 域 S：启动剧场与品牌（U-01…U-06）★本计划心脏

> 现状：`BootScreen.tsx` 已实现真实进度驱动的字母描边 + 进度条 + 日志流，但整体是「工程师审美」：字体小、信息密、缺乏仪式感。本域将其重制为 **3A 大作开场级别的启动剧场**——不是把进度条做花哨，而是把「真实加载」这件事本身变成一件值得注视的作品。

### U-01 启动剧场（Boot Cinema）

**一句话**：5 秒左右的、由真实进度驱动的电影级开机仪式。

**功能详述**：
- **构图**：全屏深空黑（`--bg-canvas` 的最深一档，非纯黑，保留 #050607 级微光），中央偏上 38% 屏宽的 **VARIABLE 大字标**（8 字母，详见 U-02），字标正下方 6% 屏宽处是**长椭圆形胶囊进度条**（详见 U-03），胶囊条正下方是**文件流带**（详见 U-04）与三列实时统计（速度 / 剩余项目 / 剩余时间，格式参照环境内传输面板的既有风格：`速度: 7.1 files/s`、`剩余项目: 4 (16.1 KB)`、`剩余时间: 大约 5 秒`）。
- **真实性铁律（继承 ARCHITECTURE_V2 §5，不可违背）**：进度 100% 来自后端 `boot://event`，无任何预设时间线插值。视觉平滑仅允许 rAF 缓动（现实现的 0.12 系数收敛），进度停滞时所有视觉同步停滞。
- **5 秒仪式节拍（诚实版）**：加载快于 5s 的机器，进度到达 100% 后进入「就绪定格」——字标完全点亮、胶囊满格、摘要浮现，定格呼吸 1.2s 再离场；加载慢的机器，剧场自然延长，不伪造加速。快慢机器看到的是同一场戏的不同时长版，而非两种假象。
- **入场编排**（首帧起的 900ms 内，纯 CSS 编排，不占加载路径）：
  1. 0ms：背景从纯黑淡入至深空黑（400ms，ease-out）；
  2. 120ms：8 字母以 40ms 级联间隔淡入至 12% 透明度的「底稿态」（像蚀刻在暗处的轮廓）；
  3. 400ms：胶囊进度条的边框自左端向右端一次性描边成形（350ms，spring）；
  4. 650ms：文件流带开始滚动第一行真实文件名。
- **离场编排**（ready 后，重写现有 full/simple/none 三档）：full=字标整体实心化→一道柔和白光从左向右掠过字标（700ms，遮罩混合）→字标与胶囊以 0.96→1.0→0 三段缩放沉入任务栏方位（继承现有「字母落位任务栏」叙事，升级材质）；simple=整屏 640ms 交叉淡出；none=直接进入。
- **反廉价守则**：禁用表情符号（现有日志行的 📊⏱💾 等 emoji 全部替换为 12px 线性 SVG 微图标）；禁用彩虹渐变、脉冲霓虹、弹跳超调 >6%；所有动效曲线走 tokens.css 的 `--ease-spring` / `--ease-standard`，时长走 `--dur-*` 档位。
- **跳过机制保留**：Esc/空格、<30% 拒绝并给出诚实提示，交互与现状一致。

**技术草案**：重写 `src/system/boot/BootScreen.tsx`（保留全部事件协议与 BootStats 接口）+ `src/styles/boot.css`（从零重写）；新增 `src/system/boot/CapsuleBar.tsx`、`FileTicker.tsx`、`BootWordmark.tsx` 三个子组件；`bootAnim` 设置三档语义不变。

**验收要点**：
- [ ] 拔掉后端（浏览器 dev 模式）时剧场优雅降级为静态字标 + 0% 胶囊，不白屏不报错；
- [ ] 人为注入慢事件（>8s）时进度条与字标描边同步停滞，无假动作；
- [ ] reduce-motion=true 时入场/离场编排全部替换为 ≤80ms 淡入淡出；
- [ ] 1080p / 1440p / 4K 三档 DPI 下字标宽度恒为屏宽 38%±2%，胶囊恒为字标宽的 62%；
- [ ] 全程无 emoji、无裸色值、无超过 6% 的超调。

### U-02 大气字标与字形资产（Wordmark & Glyph Assets）

**一句话**：为 VARIABLE 八字母建立专属 SVG 字形库，替代目前的系统字体 text 元素。

**功能详述**：
- 8 个字母（V-A-R-I-A-B-L-E）逐一手工设计为单路径 SVG（`stroke` 轮廓 + `fill` 实心双形态），字形气质定调为「航空仪表 × 高级制表」：几何骨架、均匀笔画宽、字谷开阔、字间距 0.06em 级的疏朗排布——大气来自克制与留白，不来自装饰。
- 每个字母路径长度由代码实测（`getTotalLength()`），替代目前 340 的估算校准值，描边进度映射 100% 精确。
- 字标资产三件套：启动剧场大字标（38% 屏宽）、关于页徽章、安装器/便携启动器横版小字标，全部出自同一套路径数据，一次设计三处复用。
- 字标支持单一强调色注入（`currentColor` 继承 `--accent`），随主题联动但不做逐字母彩色渐变。

**技术草案**：新增 `src/assets/wordmark/`（8 个 `.svg` + `glyphs.ts` 路径表导出）；`BootWordmark.tsx` 按 viewBox 统一装配。

**验收要点**：
- [ ] 每字母 `getTotalLength()` 实测值写入常量表并有单测锁定（路径被改动即测试失败）；
- [ ] 缩放至 24px 高（关于页徽章）时笔画仍清晰可辨，无糊边；
- [ ] 字标在浅色主题下自动切换为深色底稿轮廓（tokens 联动，无硬编码）。

### U-03 胶囊进度条（Capsule Progress）

**一句话**：长椭圆形边框内以白色条实时填充的进度条，剧场的信息主轴。

**功能详述**：
- 形状为全圆角「体育场」胶囊：外框 1px 半透明白（12% 不透明度），内嵌 3px 高的填充轨道；填充体为纯白（`--text-primary`）圆角条，宽度 = 真实进度 × 胶囊内宽，头部带一枚 6px 流光引导点（同色系 80% 透明度光晕，非彩色霓虹）。
- 填充采用 rAF 缓动收敛（同现有 shown 状态机），**进度倒退被禁止**（真实进度单调不减语义已保证）。
- 填充完成瞬间（100%）触发一次「满格呼吸」：白色条亮度短暂提升 8% 后回落（300ms），随即进入就绪定格。
- 胶囊两端各有一个 2px 端点徽标：左端点在加载中缓慢呼吸（2s 周期），右端点在到达 100% 时点亮——用最小语言表达「还在走 / 到了」。
- 百分比数字不再单独占行，而是以小型等宽字浮在胶囊右端外侧，随进度实时更新（保留无障碍 `aria-live`）。

**技术草案**：`CapsuleBar.tsx` + boot.css 新段落；百分比读数保留现有 `shown` 状态，禁止新建进度状态源。

**验收要点**：
- [ ] 胶囊在任何宽度下圆角半径恒等于高度的一半（真·长椭圆，杜绝「圆角矩形」塑料感）；
- [ ] 填充宽度与后端最后一条事件 progress 的偏差在 120ms 内收敛至 <0.5%；
- [ ] 满格呼吸、端点呼吸在 reduce-motion 下禁用。

### U-04 文件流带（File Stream Ribbon）

**一句话**：胶囊下方快速变换的真实加载文件名跑马灯，配三列实时统计。

**功能详述**：
- 位置在胶囊正下方，单行显示**当前正在加载的真实文件名**（等宽字体、路径从尾部截断保留文件名，悬浮 tooltip 显示全路径）；文件切换时的过渡为「旧行上浮淡出 25% + 新行下移淡入」（120ms，`--ease-standard`），快节奏下形成连续的字节流动画——这正是「与传输面板截图一模一样」的变换方式。
- 文件名下方一行三列统计（沿用传输面板既有文案风格）：`速度: x.x files/s`｜`剩余项目: n (xx.x KB)`｜`剩余时间: 大约 n 秒`——全部由真实事件流计算（速度=累计文件数/耗时；剩余=总数-已载；剩余时间=剩余/速度滑动均值），无任何估算编造。
- 文件名行左侧配 12px 线性 SVG 状态图标（加载中=旋转弧线、告警=三角、错误=叉，替代现有 emoji）。
- 当某任务停滞 >500ms，文件名右侧浮现微型旋转指示（继承现有 STALL_MS 逻辑），停滞不隐藏——诚实呈现。

**技术草案**：`FileTicker.tsx`；`LoadEventPayload` 协议不变，新增的仅是前端派生统计（useMemo，零后端改动）。

**验收要点**：
- [ ] 1000 事件/秒的极端回放压测下无掉帧（rAF 内无布局抖动，transform-only 动画）；
- [ ] 剩余时间在速度波动时用 3s 滑动窗口均值，读数不狂跳；
- [ ] 超长文件名（>80 字符）尾部截断 + tooltip 全路径，不换行不撑破布局。

### U-05 启动交响（Boot Symphony）

**一句话**：基于既有 Web Audio 合成器（sounds.ts）的三层启动音效。

**功能详述**：
- 三层结构随进度递进：0–30% 低频铺底（55Hz 正弦缓升，音量 20%）；30–80% 加入节拍脉冲（与胶囊端点呼吸同相位，每 2s 一次柔和 tick）；100% 就绪瞬间一声上行双音（C5→G5，各 180ms，带 60ms 释放）——像高端汽车的启动自检完成音，克制而有仪式感。
- 全部实时合成，无音频文件资产；音量跟随 `soundVolume` 设置，`soundMuted` 或 DnD 时整体静音（alarm 例外规则不适用于启动音——启动音永远尊重静音）。
- 提供「静音但保留就绪音」的细分选项（设置项 `bootSoundMode`: full/mute/chime-only）。

**技术草案**：扩展 `src/lib/sounds.ts`（新增 `bootSwell/ bootPulse/bootReady` 三个合成函数与调度器）；`DEFAULT_SETTINGS` 增设 `bootSoundMode`；SettingsModal 声音页增一行三选。

**验收要点**：
- [ ] 三段音与进度严格同步（chime 触发点即 ready 事件到达点，不提前）；
- [ ] 系统静音/耳机拔出等设备变化下不抛异常；
- [ ] reduce-motion 不影响声音（声音归声音设置管）。

### U-06 仪式编排器（Ceremony Director）

**一句话**：把「多快算快、何时定格、如何离场」收敛为一个可配置的编排层。

**功能详述**：
- 编排状态机：`entering(900ms) → streaming(主段，时长=真实加载) → readyHold(1.2s 定格) → exiting(按 bootAnim 档位)`。快机器总时长≈真实加载+2.1s，慢机器自动拉长 streaming 段。
- 设置项 `bootPacing`: `cinematic`（默认，完整编排）/ `brisk`（压缩 readyHold 至 400ms、入场 500ms）/ `instant`（等价 bootAnim=none 的直通）——与 bootAnim 正交：bootAnim 管「怎么走」，bootPacing 管「走多慢」。
- 真实摘要（BootStats）在 readyHold 期间以三列小字浮现于统计行下方，替代现有整行 emoji 摘要。

**技术草案**：BootScreen 内新增编排 reducer（纯函数，可单测）；`settings.ts` 增 `bootPacing`；i18n 增对应键（zh/en，过 audit.cjs）。

**验收要点**：
- [ ] 状态机纯函数单测覆盖：快机、慢机、跳过、事件回放四种剧本；
- [ ] brisk 模式下总启动视觉开销 ≤ 现状 +300ms；
- [ ] 三档 bootAnim × 三档 bootPacing 九宫格组合全部可运行且语义正确。

### U-08 材质引擎（Material Engine）

**一句话**：统一的表面材质分级——实心、磨砂、深雾三档质感。

**功能详述**：
- 三档材质语义化：`--surface-solid`（不透明面板）、`--surface-frosted`（亚克力感：backdrop-blur 24px + 8% 白叠层 + 1px 顶部高光描边）、`--surface-deep`（云母感：深色基底 + 微噪声 + 内阴影层次）。
- 桌面部件按信息层级对号入座：桌面=deep、VWM 窗口=solid、悬浮面板（快捷面板/通知）=frosted，规则写入 DESIGN.md 并由 lint 守护。
- 性能预算：frosted 材质同屏并发 ≤ 3 个（超出自动降级为 solid，附 DEBUG HUD 计数）；reduce-motion 或低端机（bgTier 低档）全局降级。
- 噪声纹理用单文件 base64 SVG feTurbulence（0.9KB），不用图片资产。

**技术草案**：tokens.css 材质段 + `src/styles/material.css` 新文件 + `bgTier` 联动逻辑。

**验收要点**：
- [ ] 同屏 5 个 frosted 面板时自动降级至 3 个且 DEBUG HUD 如实显示；
- [ ]低端档机器截图与高端档仅差模糊层，布局零位移。

### U-09 光影系统（Light & Shadow Language）

## 域 P：性能与可靠性（U-19…U-24）

### U-19 启动加速流水线（Boot Pipeline Acceleration）

**一句话**：真实加载的并行化与首屏优先级调度，让 5 秒剧场不必变成 15 秒等待。

**功能详述**：

- 索引预热：上次会话的目录清单与 mtime 快照落盘（`state.json` 邻位 cache），冷启动先用快照呈现、后台校验刷新（校验差异仅重扫变动目录）。
- boot_replay 协议扩展：事件携带 phase 标记，前端剧场在 P0 完成即进入离场编排。

**技术草案**：`src-tauri/src/shell/boot.rs`（假设现名，以实际为准）任务分级改造；缓存文件加 checksum 防脏读。

**验收要点**：二进制对比：冷启动 ready 时刻缩短 ≥40%；脏缓存（手动篡改）下自动全量重扫不崩溃。

### U-20 内存守护（Memory Warden）

**一句话**：工作集感知、泄漏看门狗与内存压力面板。

**功能详述**：
- 每 5s 采样：JS 堆（performance.memory）、Rust 侧进程工作集（Win32 QueryWorkingSet 封装，只读合法 API）、GPU 估计（D3DKMT 统计，只读）。
- 泄漏看门狗：连续 10 分钟 RSS 单调上升 >15% 即托盘告警 + 生成堆快照摘要（对象计数 top10，不抓用户数据内容）；一键「软回收」（drop 空闲缓存 + WorkingSetTrim 自身进程，合法操作）。
- 内存压力联动：系统可用内存 <10% 时全局进入省内存模式（缩略图降档、模糊材质降级、后台索引暂停）。

**验收要点**：注入式泄漏测试（循环分配）10 分钟内被正确识别；软回收后 RSS 下降可观测且无功能异常。

### U-21 渲染帧预算器（Frame Budget Governor）

**一句话**：动画帧率治理——前台 60fps、可见降档、离屏冻结。

**功能详述**：

- 帧预算账本：每个动画声明成本档（轻 ≤0.1ms/帧、中 ≤0.3ms、重 >0.3ms），同屏重动画并发上限 2，超出按声明优先级让位。

**技术草案**：`src/lib/framebudget.ts` + 各动画站点接入；`bgTier` 联动复用。

**验收要点**：滚动万行列表 + 星场壁纸 + 通知入场三并发场景，主线程长任务（>50ms）计数为 0。

**一句话**：跨目录的颜色标签、星标与智能文件夹。

- 标签模型独立于文件系统（环境自建 DB），八色标签 + 自由文本标签 + 星标；文件管理器/桌面图标显示标签角点。
- 智能文件夹：保存查询条件（如「标签=红色 且 近 7 天修改」）生成动态文件夹，置顶于文件管理器侧栏。
- 标签操作入口：右键属性页、批量选中、拖放到侧栏标签容器。

**技术草案**：shell 侧 tags 表（复用现有 DB 基建）+ explorer/桌面图标渲染挂点。

**验收要点**：万级标签查询 <50ms；标签随文件移动/重命名自动跟随（path key 监听）。

### U-27 回收站 2.0（Recycle Bin 2.0）

**一句话**：恢复预览、按来源分组、自动清理策略。

**功能详述**：
- 删除入站时记录来源窗口/应用；回收站主视图按来源分组 + 时间轴两种编排。
- 恢复预览：悬停条目显示缩略图/文本前几行/文件大小与原路径（原路径被占用时提供「恢复到新位置」）。
- 策略引擎：容量阈值（如 2GB）或时间阈值（30 天）自动清理，清理前托盘预警一次；重要标签文件（U-26 星标）永不自动清理。

**技术草案**：扩展现有回收站实现（shell 侧 recycle.rs 域）+ 前端 RecycleBinWindow 重构。

**验收要点**：断电恢复测试：删除记录 DB 与实际文件一致性校验通过；恢复 500 项批量 <3s。

### U-28 传输指挥台（Transfer Command Center）

**一句话**：全部复制/移动/下载任务的统一队列、速度曲线与冲突策略。

**功能详述**：
- 单一传输队列：环境内一切文件传输（文件管理器复制、拖入工作区、版本还原导出）汇入同一指挥台窗口；每任务一行：实时速度曲线迷你图、进度、剩余项/剩余时间（与启动剧场文件流带同源风格）、暂停/取消。
- 冲突策略四选：覆盖 / 跳过 / 保留双方（自动重命名）/ 询问；可设默认值，任务级覆盖。
- 队列调度：并发上限 3（用户 IO 优先，见 U-22），失败项集中重试面板；全部完成后托盘汇总通知（复用 notify 音）。

**技术草案**：`src-tauri/src/shell/transfer.rs` 队列中枢 + `src/features/transfer/` 前端。

**验收要点**：复制中拔盘：任务标记失败而非卡死，可重试路径自动提示；速度曲线数据与任务日志一致。

### U-29 存档柜（Archive Vault）

**一句话**：冷数据归档压缩包 + 完整性审计。

**功能详述**：
- 归档动作：选目录 → 生成 `.vxa` 归档（zstd 压缩 + 清单 + 每文件 SHA-256）；归档过程进 U-28 队列。
- 柜视图：所有归档的卡片墙（名称、原始体积/压缩后、文件数、创建时间、校验状态）；双击挂载浏览（只读虚拟目录，免解压）。
- 完整性审计：定期或手动全量校验和复核，损坏条目标红并支持从可用副本修复（若存在双备份）。

**技术草案**：`src-tauri/src/shell/archive.rs`（zstd FFI 走既有依赖策略）+ 挂载浏览复用 explorer 只读视图。

**验收要点**：10GB 目录归档/挂载/还原往返校验一致；故意翻转 1 字节能被审计检出。

### U-30 数据血缘（Data Lineage）

**一句话**：每个文件「从哪来、被谁用过、去了哪」的本地足迹图谱。

**功能详述**：
- 采集三类事件：进入（拖入/下载/导入）、使用（打开/编辑，经环境内通道的）、离开（导出/复制出环境/焚毁），全部本地存储、仅本人可见。
- 血缘页：按文件查看时间线（事件 + 时间 + 涉及应用）；按目录查看聚合热力（活跃/沉寂文件分布）。
- 隐私自洽：血缘数据本身可被整体导出（JSON）或整体焚毁（走现有焚毁通道），绝不出网。

**技术草案**：shell 侧 lineage 表 + explorer 属性页「来源」段落 + 独立 LineageWindow。

**验收要点**：拖入→编辑→导出全链路事件不漏记；焚毁血缘后 DB 记录与磁盘残留双双为 0。

## 域 K：安全与隐私（U-31…U-36）

### U-31 隐私仪表盘（Privacy Dashboard）

**一句话**：敏感资源访问的本地审计时间线。

**功能详述**：
- 三条审计线：剪贴板读取（环境内应用的 getClipboard 调用）、文件系统敏感区访问（Vault/工作区外的环境目录读取经登记通道的）、嵌入应用的网络出站尝试（联动 netconsent）。
- 仪表盘：按天聚合的访问热力条 + 异常标注（如某嵌入应用深夜读剪贴板）；每条可展开详情（进程、时间、资源、当时是否授权）。
- 只审计环境边界内的合法可见事件，不hook系统全局（不越权、不极端）。

**技术草案**：`src-tauri/src/shell/privacy.rs` 审计表 + `src/features/privacy/` 前端。

**验收要点**：审计开关默认开、可暂停（暂停期间明确标注「记录中断」不留假空档）。

### U-32 应用防火墙 2.0（App Firewall 2.0）

**一句话**：每个嵌入应用的网络策略档案。

**功能详述**：
- 策略档案：每个登记的第三方应用可设网络级别——完全禁网 / 白名单域名 / 全放行；默认禁网（继承 netconsent 的零出站哲学）。
- 出站告警中心：被拦截的出站尝试集中呈列（应用、目标域名、时间、频次），一键放行或保持拦截；高频尝试的应用标红。
- 流量配额：单应用日流量上限（超出自动降为禁网 + 通知），防失控上传。

**技术草案**：扩展 netconsent.rs（域名级白名单库为 MASTER-PLAN M8 范畴，本项做的是**应用级档案与告警中心**这一层，与 M8 互补衔接，不重复造域名库）。

**验收要点**：拦截→放行→再拦截状态切换即时生效；配额触发后应用无法绕过（环境内代理通道统一收口）。

### U-33 诱饵文件系统（Canary Files）

**一句话**：蜜罐文件检测越权访问。

**功能详述**：
- 用户可在敏感目录布放诱饵文件（模板：虚假密码本.txt / 假账单.xlsx 等，内容由环境生成、外观仿真、零真实信息）。
- 诱饵文件的任何「打开/读取」经环境内通道即触发警报：托盘红警 + 隐私仪表盘置顶记录 + 可选自动锁屏。
- 诱饵管理页：布放位置一览、触发历史、一键撤除；与 Vault 的口令保护互补（Vault 管已加密的，Canary 管不该被碰的）。

**技术草案**：privacy.rs 扩展 canary 段 + 诱饵生成器（模板化文本，无真实数据）。

**验收要点**：故意打开诱饵 → 警报 <1s 到达；误报率（正常备份/杀软扫描经环境通道的）可白名单豁免。

### U-34 紧急擦拭（Panic Protocol）

**一句话**：一组全局组合键触发的分级应急响应。

**功能详述**：
- 三级协议（用户可绑定不同组合键，默认均未绑定，显式开启才生效）：
  - L1 锁定：立即进入锁屏（衔接 NEXT-40 N-10）+ 通知静默；
  - L2 会话焚毁：L1 + 关闭全部嵌入应用 + 焚毁临时会话数据（隐身会话/剪贴板历史/通知历史）；
  - L3 撤离：L2 + 环境直接进入「退出刷盘」流程（复用既有零残留退出）。
- 演练模式：设置里可无副作用演练三级流程（走完整 UI 但标记 dry-run）。
- 防误触：三级均需长按组合键 800ms，进度环显示长按进度（无廉价弹窗）。

**技术草案**：`src-tauri/src/shell/panic.rs` + 全局键位联动 kbdhook.rs（共享文件守则）。

**验收要点**：演练模式全程零副作用断言（文件系统 diff 为空）；真实 L2 触发后指定的临时数据残留扫描为 0。

### U-35 信任链中心（Trust Chain Center）

**一句话**：文件签名验证与来源信誉档案。

**功能详述**：
- 登记任何 exe 时自动读取 Authenticode 签名链（WinTrust 合法 API）：签名者、有效期、链完整性；无签名/签名失效在登记卡与 L4 徽标区如实标注。
- 来源标记：文件进入环境的方式（拖入/下载/拷贝）+ 首次时间，构成来源档案；多次签名者一致的软件逐步累积「熟识度」。
- 信任视图：全部已登记软件的签名状态墙，一键重新验证全部。

**技术草案**：`src-tauri/src/shell/trust.rs`（WinVerifyTrust 封装，只读验证）+ 登记卡 UI 扩展。

**验收要点**：签名有效/过期/无签名/被篡改四类样本验证结果全部正确；验证 100 个软件 <10s（并发验证）。

### U-36 隐身会话（Incognito Sessions）

**一句话**：零痕迹的临时工作区，关闭即焚。

**功能详述**：
- 开启隐身会话 = 当前桌面旁生一个临时会话层：会话内打开的文件副本、剪贴板写入、通知、临时下载全部落内存 + 加密临时盘，关闭时整体焚毁（复用现有焚毁引擎）。
- 视觉标识：隐身期间屏幕四角 4px 紫外线蓝细边框常驻 + 任务栏隐身徽标（克制、专业、无粉色间谍帽卡通）。
- 禁止清单：隐身会话内禁用版本快照、血缘记录、索引（并在 UI 明示「此处不被记录」）。

**技术草案**：`session.rs` 隐身层 + explorer/剪贴板/通知三个站点接入开关；焚毁走既有通道。

**验收要点**：隐身会话内创建/编辑/删除 100 文件后关闭，磁盘扇区级残留扫描为 0；正常会话数据零影响。

## 域 E：开放生态（U-37…U-42）

### U-37 协议中枢（Deep Link Hub）

**一句话**：`variable://` URL 协议，外部与内部统一调用入口。

**功能详述**：
- 协议集：`variable://open?path=`（打开文件/目录）、`variable://search?q=`（唤起统一搜索）、`variable://settings?page=`、`variable://transfer/add?src=&dst=`（入传输队列）、`variable://lock`。
- Windows 注册协议仅在**便携部署模式**下写入 HKCU（当前用户级、退出可清，符合零残留原则的例外声明：安装态写入、便携态退订）。
- 内部同样走协议：环境内按钮/宏统一调用协议而非散落 invoke，为插件与 CLI 提供同一套动词表（与 NEXT-40 N-28 API 网关互补：网关管 IPC 权限，本项管动词词汇）。

**技术草案**：`src-tauri/src/shell/deeplink.rs` 协议路由 + 单实例转发的 deep link 参数解析。

**验收要点**：浏览器里敲 `variable://open?path=...` 能唤起环境并定位；未注册宿主上协议调用给出友好降级页。

### U-38 脚本安全屋（Script Safehouse）

**一句话**：用户脚本的沙箱执行、能力声明与签名。

**功能详述**：
- 脚本格式 `.vxsc`（清单 + JS 主体）：清单声明能力（读文件/写文件/网络/UI 通知），执行时按声明授予，未声明能力一律拒绝。
- 沙箱：独立 JS 引擎实例（环境内嵌 runner），无 Tauri IPC、无 Node、文件访问经代理白名单路径；CPU/时长配额（默认 5s）防死循环。
- 来源信任：本地手写脚本默认信任；外部导入的需人工确认能力清单（逐项勾选，复用 WelcomeWizard 的契约式确认交互先例）。

**技术草案**：`src-tauri/src/shell/script/safehouse.rs` + 前端脚本管理页（与 NEXT-40 N-18 宏引擎的关系：宏引擎管 UI 动作录制回放，本项管通用脚本运行时；safehouse 可作为宏的执行后端之一）。

**验收要点**：越权尝试（未声明却读网络）100% 被拒并记录；死循环脚本 5s 被杀且环境无恙。

### U-39 资源包格式（.vxs Packs）

**一句话**：主题+壁纸+音效+图标四合一的皮肤包开放格式。

**功能详述**：
- `.vxs` 包结构（zip 容器 + manifest.json）：声明包含的资源类型与最低版本；导入即预览（四类资源各自 before/after 对照），可选部分应用（只要壁纸不要音效）。
- 导出器：用户当前搭配一键导出为 `.vxs` 分享给他人；与 U-13 Profile 打通（包内可含 Profile 定义）。
- 校验：导入时资源全部过 tokens 校验（禁止裸色值混入）与音量安全检查（音效包峰值限制）。

**技术草案**：`src-tauri/src/shell/pack.rs` + 设置内「外观包」管理页。

**验收要点**：打包→删除原配置→导入→还原，视觉/听觉完全一致；畸形包（缺 manifest/超限音量）拒绝导入且报错叙事清晰。

### U-40 无障碍 2.0（Accessibility 2.0）

**一句话**：屏幕阅读器全景、焦点环系统、色觉模拟器。

**功能详述**：
- ARIA 全景审计：全部交互组件补齐 role/aria-label/aria-live 三件套（启动剧场已有先例），audit.cjs 增无障碍扫描段（缺 label 即 fail）。
- 焦点环系统：全局 Tab 导航可视化（U-09 焦点环令牌统一），新增「焦点跟随提示」——Tab 移动时目标控件名称读出（复用系统 Narrator 兼容模式）。
- 色觉模拟器（开发者向）：设置里内置四类色觉模拟滤镜预览当前界面，供用户检验自己的配色方案对色觉障碍用户的可读性。
- 键盘可达性：所有鼠标可完成的桌面操作（开窗/吸附/切换 Profile）均有键盘路径（与 U-58 键盘全景联动）。

**技术草案**：audit.cjs 扩展 + 各组件 ARIA 补齐（分批）+ `src/lib/a11y.ts` 工具。

**验收要点**：audit 无障碍段 0 告警；纯键盘完成「开开始菜单→开文件管理器→吸附分屏」全流程。

### U-41 多语言中心 2.0（i18n Center 2.0）

**一句话**：翻译工作台、伪本地化测试与 RTL 就绪。

**功能详述**：
- 翻译工作台：设置内嵌的字典浏览/搜索/编辑界面（zh/en 双栏对照、缺失键高亮、一键跳转代码引用），替代直接编辑 dictionaries.ts 的裸奔模式（编辑仍写回源文件，工作台只是安全壳）。
- 伪本地化模式：dev 构建下可开启「[变长加括号][重音字符]」伪翻译，一眼暴露硬编码文案与溢出布局；audit.cjs 接入伪本地化扫描。
- RTL 就绪：tokens 增 `--dir` 逻辑属性（margin-inline 等改造分批进行），本计划内完成两处试点面板（设置/通知中心）的 RTL 正确渲染。

**技术草案**：`src/features/i18nworkbench/` + dictionaries.ts 结构不动只加壳 + CSS 逻辑属性分批迁移。

**验收要点**：伪本地化模式下 0 处未翻译截断；两处试点面板 RTL 截图正确。

### U-42 诊断导出包（Diagnostic Bundle）

**一句话**：一键生成脱敏诊断 zip，附 issue 与求助场景。

**功能详述**：
- 导出内容清单（全部本地生成、用户预览后确认）：版本与构建信息、设置摘要（密码/Vault 相关字段自动剔除）、最近 100 条结构化日志（路径脱敏为相对路径）、性能快照（U-20 采样）、最近一次崩溃叙事摘要、bench 对比数据。
- 预览步骤：导出前逐类勾选 + 脱敏示例展示（用户所见即所得），确认后才落盘。
- 生成物为 zip，命名 `variable-diag-YYYYMMDD-HHmm.zip`，默认放桌面，附 README.txt 说明每项内容。

**技术草案**：`src-tauri/src/shell/diag.rs` + 设置「关于」页入口。

**验收要点**：导出包内 0 条绝对路径、0 个口令字段（扫描断言）；zip 可被诊断查看器（同页）重新打开浏览。

## 域 H：硬件与宿主协同（U-43…U-48）

### U-43 多显示器编排 2.0（Multi-Monitor 2.0）

**一句话**：每屏独立壁纸/任务栏/布局与热插拔记忆。

**功能详述**：
- 显示器档案：每台显示器记录分辨率/DPI/相对位置 + 用户在该屏的壁纸、任务栏方位、默认窗口布局；重新接入同一显示器自动恢复全部。
- 编排面板：屏幕拓扑可视化拖放编辑器（缩略屏块可拖动换位、旋转）；单屏「独立模式」（每屏各自开始菜单）与「主从模式」（主屏开始菜单、副屏任务栏只放窗口按钮）。
- 热插拔事件：接入=通知 + 恢复档案；拔出=其上窗口自动迁回主屏（按比例重排，VWM 布局引擎承接）。

**技术草案**：`src-tauri/src/shell/monitor.rs`（现有 wallpaper 多显示器基础扩展）+ 拓扑编辑器前端；与 AI-2 的多显示器 DPI 实机验收项衔接。

**验收要点**：双屏拔插 20 次窗口零丢失；DPI 混合屏（100%+150%）图标/字号新闻级清晰。

### U-44 外设快捷层（Peripheral Shortcut Layer）

**一句话**：键盘宏层、鼠标手势与媒体键统一接管。

**功能详述**：
- 键盘宏层：可定义组合键序列映射到协议动词（U-37），录制式编辑器（按下即录，重复录制覆盖）；冲突检测与 NEXT-40 N-17 快捷键中心共享词表。
- 鼠标手势：按住右键拖动轨迹识别（↑↓←→、↖↗ 等 8 向、序列组合），默认绑定窗口最小化/关闭/切换；轨迹可视化为一道渐隐光痕（frosted 材质，非廉价彩虹）。
- 媒体键统一：播放/暂停/停止/上一首/下一首/音量全家接管并转发给当前活跃媒体会话（MediaControl 先例扩展），未被占用的媒体键可自定义。

**技术草案**：`src-tauri/src/shell/periph.rs` + 手势识别前端（轨迹采样 + 8 向量化算法，本地实现）。

**验收要点**：手势识别 100 次采样准确率 ≥97%；宏冲突时编辑器即时标红并给替代建议。

### U-45 音频路由器（Audio Router）

**一句话**：每应用音量/输出设备路由与音频效果链。

**功能详述**：
- 每应用音量（现有 F-5 混音器升级）：独立音量 + 峰值表 + 静音记忆（重启保持）。
- 输出路由：每个嵌入应用可指定输出设备（耳机/扬声器/虚拟设备），切换即时生效；默认跟随系统。
- 效果链（全局可选）：夜间压缩（动态范围压低）、响度均衡、低延迟模式三档，全部基于 Windows 内置音频 API 的合法参数（不注入驱动）。
- 音频 HUD：Ctrl+滚轮悬停任务栏音量图标时浮现迷你频谱（4 段柱状，克制风格）。

**技术草案**：扩展 `src-tauri/src/shell/` 混音器实现（IAudioSessionEnumerator 合法接口）+ QuickPanel 混音段升级。

**验收要点**：路由切换延迟 <150ms 无爆音；峰值表与系统音量面板读数一致。

### U-46 色彩与时辰（Color & Circadian）

**一句话**：亮度/色温时段自动调节与夜间模式 2.0。

**功能详述**：
- 时辰曲线：日落/日出之间自动过渡色温（2800K–6500K 线性插值，经合法 gamma API 设置，退出时还原宿主设置）；手动覆盖浮条（一次覆盖 2 小时）。
- 夜间模式 2.0：色温 + 壁纸降饱和 + 通知自动进入勿扰三联动，可分别关闭。
- 与 U-54 节律助手共享时辰状态（一次计算全局消费）。

**技术草案**：`src-tauri/src/shell/circadian.rs` + 任务栏快速开关。

**验收要点**：退出环境后宿主原有 gamma 设置字节级还原；时段过渡无跳变（渐变步长 ≤100K/分钟）。

### U-47 无线中心（Wireless Center）

**一句话**：蓝牙与无线设备状态、电量与快速配对。

**功能详述**：
- 设备墙：已配对蓝牙设备卡片（电量、连接状态、类型图标）；点击连接/断开；低电量预警（<20% 托盘通知，每设备 24h 一次防骚扰）。
- 快速配对向导：扫描 → 发现列表（信号强度条）→ 配对进度 → 成功后可直接指定用途（音频→进 U-45 路由候选；输入设备→进 U-44 手势配置引导）。
- 全部经系统蓝牙 API（只读状态 + 系统托管的配对流），不实现协议栈（不极端化）。

**技术草案**：`src-tauri/src/shell/wireless.rs`（Bluetooth LE 设备枚举合法接口）+ 快捷面板无线段。

**验收要点**：耳机/鼠标/键盘三类设备状态与系统设置页一致；配对向导全程可取消无残留。

### U-48 性能模式切换器（Performance Modes）

**一句话**：静音/平衡/性能三档环境资源策略。

**功能详述**：
- 三档策略矩阵：静音（渲染 30fps 上限、动画精简、索引暂停、IO 全降级——会议/夜间场景）、平衡（默认）、性能（预热全开、帧预算放宽、后台任务满速）。
- 档位联动：静音档自动启用 U-21 降帧与 U-22 IO 降级；性能档与 U-19 预热联动；托盘/快捷面板一键切换，切换有 200ms 全屏边缘微光提示（档位色：静音=月光蓝、平衡=无色、性能=琥珀）。
- 智能建议（本地规则，非 AI）：检测到接电源 + 大型嵌入应用运行 → 托盘建议切性能（可忽略）。
- 与电源计划（NEXT-40 N-20 电源管家）的边界：N-20 管宿主电源计划，本项管环境自身资源策略，二者正交。

**技术草案**：`src/lib/perfmode.ts` 全局上下文 + 三处消费点（framebudget/iogov/预热）接入。

**验收要点**：三档切换 10 次无状态漂移；静音档下 GPU 占用相对平衡档下降 ≥30%。

## 域 A：氛围与沉浸（U-49…U-54）

### U-49 氛围音景引擎（Soundscape Engine）

**一句话**：本地实时合成的环境音场景：雨、林、白噪、粉噪、深夜。

**功能详述**：
- 五个首发场景全部 Web Audio 程序化合成（噪声滤波 + 随机事件粒子：雨滴=短促带通噪声脉冲、鸟鸣=FM 合成短句——参数化随机，非循环音频文件，无版权问题、无限不重复）。
- 场景可叠加（雨+深夜）、音量独立、渐入渐出 2s；与番茄计时联动（专注时段自动播放所选场景，休息停）。
- 睡眠定时：30/60/自定义分钟后自动淡出；全部声音归 soundMuted 总开关管辖。

**技术草案**：扩展 `src/lib/sounds.ts` 或新增 `src/lib/soundscape.ts` + QuickPanel 氛围段。

**验收要点**：连续播放 1h 内存无增长（节点复用，无泄漏）；场景切换无爆音。

### U-50 焦点舱 2.0（Focus Cabin 2.0）

**一句话**：全屏专注模式与干扰拦截。

**功能详述**：
- 进入焦点舱：全屏深色舱体（壁纸压暗 60% + 中央当前任务大字），仅显示：番茄计时、今日专注累计、退出按钮（Esc 双击，复用双 Esc 语义但独立于环境切换）。
- 拦截策略：舱内通知默认静默队列（出舱后汇总）；嵌入应用窗口自动最小化排队；可设「白名单穿透」（如指定联系人消息）。
- 专注账本：每次舱内时长入账，日/周条形图（本地存储，接 U-31 隐私原则——不出网不分析）。

**技术草案**：`src/system/focus/` 新模块 + 通知中心拦截钩子。

**验收要点**：舱内强行唤起的系统级弹窗（宿主产生的）不拦截但记录「舱外事件」出舱提醒；账本数据可导出 JSON。

### U-51 通知交互进化（Notification Interactivity）

**一句话**：可操作通知、进度通知与持久组。

**功能详述**：
- 通知三类扩展：**操作通知**（内联按钮，如传输完成的「打开所在目录」）、**进度通知**（常驻胶囊迷你条实时跟随 U-28 任务，完成自动转操作通知）、**持久组**（同类通知折叠为组，如「3 个传输完成」展开逐条）。
- 排队礼仪：出焦点舱/勿扰后按重要度有序回放（操作>进度>普通），回放可一键全部清除。
- 与 NEXT-40 N-32 智能通知整理的边界：N-32 管「AI 归类整理」，本项管「通知本体交互能力」，是 N-32 的地基。

**技术草案**：扩展 `src/state/notifyStore`（通知模型增 actions/progress 字段）+ 通知中心 UI 升级。

**验收要点**：内联操作点击 ≤1 次跳转到位；100 条积压回放 5s 内完成且不卡 UI。

### U-52 声景反馈系统（Sonic Feedback System）

**一句话**：全系统 UI 音效的材质化重设计与用户自定义。

**功能详述**：
- 音效词典升级：现有 6 音基础上重录合成质感（snap 音更「实木」、trash 音更「纸张」、notify 音去「电子哔」），新增 open/close/window/minimize 四件；全部遵守 ≤400ms + 80ms 防抖既有纪律。
- 声音主题：三套预置（玻璃/木质/暗夜）+ U-39 `.vxs` 包可携带自定义音效主题；每类事件音量系数独立可调。
- 场景感知：深夜（22:00–6:00）自动整体音量 ×0.5（可在设置关闭此智能行为——诚实告知规则）。

**技术草案**：sounds.ts 合成参数表化 + 设置声音页升级。

**验收要点**：三套主题试听切换即时；深夜自动降档在设置中有醒目开关与状态显示。

### U-53 环境辉光（Ambient Glow）

**一句话**：屏幕边缘随壁纸主色呼吸的氛围光。

**功能详述**：
- 壁纸换算主色（canvas 降采样 + OKLCH 提取，本地计算），四边内发光（内阴影式光晕，12px 渐隐，非跑马灯）。
- 呼吸节律 8s 周期、亮度波动 ±6%（克制到「感觉到但不注意到」）；壁纸切换时光色 1.5s 交叉过渡。
- 三个开关：关 / 仅壁纸静止主色 / 动态呼吸；省内存模式（U-20 压力档）自动关闭；bgTier 低档默认关。

**技术草案**：`src/features/background/glow.ts` + wallpaper 管线挂点。

**验收要点**：辉光层 GPU 成本 <0.5ms/帧；纯白壁纸不产生刺眼过曝（亮度钳制）。

### U-54 节律助手（Rhythm Assistant）

**一句话**：久坐、用眼、喝水与休息节律的温和提醒体系。

**功能详述**：
- 四类节律：久坐（默认 50min）、用眼 20-20-20（20min 看远处 20s）、喝水（自定义）、站立 stretch（与久坐错峰）。提醒方式三档可逐项选：仅计数 / 任务栏微标 / 通知+音。
- 提醒礼仪：全屏专注（焦点舱内）自动顺延不打断；深夜时段自动静默只计数；同类提醒 10 分钟内不重复。
- 仪表：今日各节律完成环（四环合一卡片，MiniApp 版进任务栏抽屉）；数据本地 7 天滚动。

**技术草案**：`src/system/rhythm/` + 复用通知/音效通道 + MiniApp 承载（依赖 U-18）。

**验收要点**：全部节律可独立停用（含总开关）；时钟回拨/跨时区不错乱（用单调时钟）。
