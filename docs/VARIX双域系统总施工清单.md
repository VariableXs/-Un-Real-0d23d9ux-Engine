# VARIX + Variable 双域系统总施工清单

> 终局目标：U 盘随插随用；开机默认进 VARIX 内核 + Variable 界面；Windows 以镜像形式随盘携带；
> 软件三通道（Wine / 隐形引擎 / 纯 Windows）；CPU/GPU 由内核统管；四层物理隔离；引导页 5 秒默认可配置。
> 门禁沿用三线全绿（V/C/K）+ 每阶段实机验收。

## 阶段 0：引导选择页（内核画的第一个界面）
- [ ] Limine 配置 U 盘 ESP 为默认引导介质，VARIX 项设为固件默认
- [ ] 内核引导早期绘制选择页：进 Variable（默认 5 秒倒计时）/ 纯 Windows / 上次使用的系统
- [ ] 倒计时秒数、默认项、是否显示菜单写入引导配置文件（U 盘分区，两系统可读）
- [ ] 「上次使用的系统」记忆：每次进入时写回配置文件
- [ ] 验收：真机 U 盘引导，5 秒无操作自动进 VARIX 路径，选 Windows 链到 U 盘 VHDX 引导

## 阶段 1：U 盘分区与便携基建改造
- [ ] 扩展 `portable/AI1/Create-VHDX.ps1`：五分区布局（EFI / VARIX 系统 / Windows 引擎 VHDX / 共享 exFAT / 快照区）
- [ ] 扩展 `Deploy-To-USB.ps1`：新增 VARIX 产物部署段（内核 ELF+引导器+Variable 运行时）
- [ ] Windows 引擎 VHDX 走三级差分链（Base→Apps→User），首次部署脚本化
- [ ] 共享分区挂载约定与目录规范（软件登记表 apps.json、接力队列、白名单）写入共享分区
- [ ] 验收：一键脚本从零产出可引导 U 盘；`Test-VM.ps1` 可在 VM 中整机验收

## 阶段 2：内核欠账清零（能跑的前提）
- [ ] #PF 缺页处理接线：`paging::decide()` 挂入 IDT 0x0E 路径（GrowStack/COW/MapZero/Fault 四路）
- [ ] 用户态进程壳：ring3 切换、首个用户进程创建、加载执行 ELF
- [ ] 基础驱动落地：PS/2 或 USB 键鼠（xHCI 最小栈）、NVMe/AHCI 读写、GOP 帧缓冲显示
- [ ] fs23_journal 接真盘：64 槽内存模型换块设备后端，掉电注入测试保留
- [ ] 验收：内核启动到可交互 shell；ktest 全绿；掉电注入 0 数据丢失

## 阶段 3：Variable 界面上内核（Servo + Tauri 垫片）
- [ ] VARIX 用户态集成 Servo（帧缓冲渲染输出）
- [ ] Tauri IPC 兼容垫片：`invoke` 协议 → 内核服务调用映射层，覆盖 Variable 现用命令面
- [ ] Variable 前端按需裁剪非内核可用能力并如实降级提示（i18n 三语）
- [ ] 变量：vwmStore/几何持久化从 localStorage 迁到内核存储服务
- [ ] 验收：U 盘引导后默认进入 Variable 桌面（任务栏/开始菜单/窗口管理可用）

## 阶段 4：数据总线与白名单
- [ ] 内核共享内存块 + 消息通道两个原语及权限裁决
- [ ] 共享分区读写走白名单（目录/剪贴板/拖放），默认拒绝
- [ ] Uxv 容器接入共享分区作为跨系统数据交换格式
- [ ] 验收：白名单外访问全部被拒并有审计日志；白名单内两系统互通

## 阶段 5：Wine 兼容层通道
- [ ] Wine 移植评估报告：NTAPI 对接面 → VARIX 系统调用映射清单
- [ ] PE 加载器 + Win32 服务台最小可运行集（记事本级目标）
- [ ] 每 exe 独立内核进程 + Job 级资源限额（复用 isolation 设计）
- [ ] 软件分级登记：可跑/逐步补/不可跑 三档，登记表入共享分区
- [ ] 验收：办公/工具类软件在 Windows 关闭状态下实机运行

## 阶段 6：隐形 Windows 引擎通道
- [ ] VHDX 挂载 + VM 拉起/保活/休眠（内核 VM 管理，或 Hyper-V 底座过渡实现）
- [ ] 无缝窗口：画面流 + 输入注入 + VWM 状态机接管外来窗口
- [ ] ramcache：热数据缓存进内存只缓不落盘，关机即清
- [ ] 引擎按需拉起：Variable 点击软件 → 引擎秒级唤起（冷启动 20-40s 如实提示）
- [ ] 验收：后台引擎常驻时 4K 随机读写达可用阈值；无缝窗口延迟 ≤50ms

## 阶段 7：资源统管与打磨
- [ ] 内核资源配额：CPU 核分配/内存水位/GPU 通道给 Variable、引擎、Wine 三方
- [ ] 设置页：引导行为、软件→通道映射规则、共享白名单、性能档位
- [ ] 拔出保护全链验收（usb.rs 看护 + WAL checkpoint + 快照区）
- [ ] 多机适配清单：UEFI/Secure Boot/首次引导引导流程
- [ ] 验收：五分区 U 盘在 ≥3 台不同机型随插随用全流程通过

## 阶段 8：安全加固与隐私
- [ ] Wine 进程默认能力收敛 + 申请式授权 UI
- [ ] PE 加载安全过滤（异常签名/已知模式拒绝表，样本集 ≥20）
- [ ] 救援 CLI 四命令适配 U 盘（export-rescue/repair/force-raster/revoke-list）
- [ ] 能力诚实声明页（隔离边界如实公示）
- [ ] privacy.rs 保险箱体系迁移 VARIX 用户态（密钥仅驻内存断言）

## 阶段 9：升级协议与灾备演练

- [ ] SNAPSHOT 快照调度（每日/每周，保留 3 份滚动）
- [ ] 灾备 SOP（半损坏/全损坏）+ repair 命令真机走通

## 阶段 10：性能基准与生态
- [ ] 基准脚本适配 U 盘场景（引导时长/首帧/交互 P95/引擎冷启动/ramcache 命中率）
- [ ] 基线归档 docs/bench/ + >10% 回归门禁
