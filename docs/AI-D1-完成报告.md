## 3. 共享底盘 dbase（十七项的公共底面）

- **Ease 曲线族**：过冲弹性（105%→100% 回弹 80ms——F080 直用）、弹出
  淡入（150ms——F078 直用），曲线参数只此一处（F124 同参纪律）；
- **FloatLayer 浮层生命周期**：点外关/Esc 关/触发钮关/失焦关 + 焦点归还
  挂账闭环——五条出路逐条记账（本人格「浮层必须有完整消失路径」红线的
  落地形态），F076/F077/F078/F082 消费；
- **Debouncer**：首沿真触发 + 窗内合并 + 尾沿后移（F083 300ms/F088 150ms）；
- **SlidingRate**：同秒替换、窗口摊平、速率 0 不编 ETA（F086 ETA、
  F086 速度曲线）；
- **FocusRing**：Tab 循环/Shift 反向/方向键顶格不循环（F076/F081）；
- **Rect/预算口径/Token**：几何钳制、「不大于」零放水预算、80fps 整数
  帧账（12ms 口径与 star/traysys F075 同一整数口径）、E1 令牌语义位。
