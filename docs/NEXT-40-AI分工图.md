## 1. 从五路到七路

既有五路（AI-1 容器 / AI-2 窗口 / AI-3 引导 / AI-4 智能 / AI-5 体验）已完成 1.0 阶段代码级收口。NEXT-40 规模（40 批 + 4 公共基座）需要扩编两路：

- **AI-6 效率路（新）**：承接效率中枢域 C（命令面板/搜索/剪贴板/截图/快捷键/宏）——这是与既有五路域界完全不重叠的新域，扩编不产生接管冲突；
- **AI-7 空间路（新）**：承接四大功能空间进化域 H（双链图谱/导图推演/PVCCE 健康/FTPE 剧本）——四空间原属 AI-4/5 的浅层 UI，本轮升级为引擎级改造，独立成路防止跨域大改引发回滚冲突。

**降级方案**：若并行资源只有五路，AI-6 并入 AI-4（同属工具生态）、AI-7 并入 AI-5（同属功能空间），见第 7 节映射表；批次顺序不变，仅总工期 +1 个 Wave。

## 3. 七路批次线（每路串行，不许跳批）

### AI-1 容器路（4 批 + 2 基座批）
```
P-3 → P-4 → N-31 洞察 → N-34 焚毁2.0 → N-35 分身 → N-36 接力
```
顺序约束：P-3 是 N-31/N-34 的分片基座；N-35 分身是根级改造（single_instance 命名锁），必须在 N-36 接力前完成（接力依赖实例身份）；N-35 的接管互斥压测是全项目最高风险项，预留双倍缓冲。

### AI-2 窗口路（6 批）
```
N-01 时间机器 → N-02 舞台 → N-03 规则引擎 → N-04 PiP → N-06 动效收口 → N-05 场景（聚合收口）
```
顺序约束：N-05 场景聚合 N-01 快照与 N-02 组，必须最后；N-03 规则的动作适配层依赖 N-01/02/04 的命令面稳定，故排其后；N-06 收口在窗口域迁移完成后（窗口动效是存量最大域）。

### AI-3 系统路（7 批，跨 Wave 2-3）
```
N-19 HUD → N-20 电源 → N-21 网络 → N-22 存储 → N-24 预热 → N-25 自愈 → N-23 外设
```
顺序约束：N-20 电源的节流信号是 N-07/N-09 降级联动的对端（Wave 1 末先冻结事件契约、Wave 2 中实现）；N-24 预热的反馈环依赖 N-31 数据格式（Wave 2 末 AI-1 冻结）；N-23 外设放 Wave 3 是为了给 N-21/N-22 的真机验证让出资源窗口；N-25 自愈收口全系统域（它要能修复 N-19-N-24 的产物）。

### AI-4 智能路（5 批 + 2 共担批）
```
N-26 插件运行时 → N-28 API 网关 → N-27 市场 → N-29 CLI → N-30 浏览器伴侣 ｜ 共担：N-32 通知整理、N-33 情绪引擎
```
顺序约束：N-26 先行（市场与管理它的运行时都依赖权限模型）；N-28 网关先于 N-27 市场（市场的远程源校验复用网关 token 体系）；N-29 CLI 与 N-30 伴侣都是网关消费者，排在最后吃自己的狗粮；N-33 情绪引擎在 Wave 3 末（其输入信号 N-05/N-07/N-11 已在 Wave 1 齐备）。

### AI-5 体验路（6 批 + 1 基座批）
```
P-2 动效内核 → N-07 壁纸工坊 → N-08 主题工坊 → N-09 小组件 → N-10 锁屏 → N-11 实况组件 → N-12 图标包
```
顺序约束：N-07 先行（N-10/N-11 都用它的引擎）；N-08 其次（N-11 季节轮转作用于主题 token）；N-09 组件的沙箱技术复用 N-07 Web 引擎（同批内核抽公共）；N-12 图标包最后（换包节流要避让前面所有 UI 落定期）。

### AI-6 效率路（6 批 + 1 基座批）
```
P-1 命令注册表 → N-13 面板收口 → N-14 统一搜索 → N-15 剪贴板 → N-16 截图 → N-17 快捷键中心 → N-18 宏引擎
```
顺序约束：P-1 先于一切（全域命令注册纪律的基座）；N-17 快捷键中心是**根级迁移**（热键绑定收敛到注册表），排在面板/搜索/剪贴板稳定后、宏引擎（宏触发器依赖热键注册表）之前；N-18 最后（动作库=命令注册表全量+触发器=五类事件源全齐）。

### AI-7 空间路（4 批）
```
N-37 双链图谱 → N-38 导图推演 → N-40 FTPE 剧本 → N-39 PVCCE 健康
```
顺序约束：N-37 先行（图谱渲染与节点绑定增强是 N-38 的地基）；N-38 的 FTPE 导出臂先落地，N-40 的回流臂对齐它（闭环契约 Wave 4 前冻结）；N-39 独立性最强放最后（git/依赖分析不依赖前三者）。
