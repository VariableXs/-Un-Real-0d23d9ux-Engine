## 1. 前置条件清单（SOP 1.8 上机前 7 项 + 本步专属）

1. SecureBoot 判定：`Confirm-SecureBootUEFI`（提权）=Disabled，或本会话不含引导类操作（纯部署可以不引导）；
2. 快速启动已关（HiberbootEnabled=0 注册表回读确认；S0.4 未执行则先执行，见 §4）；
3. BitLocker 状态已记录；本步不涉及反复重启可暂不 Suspend，但部署后首次引导若触发 BitLocker 恢复屏，立即 `Suspend-BitLocker -RebootCount 0`；
4. BootOrder 已截图/文本归档（`_attic/tools/diag-bootorder-readonly.py`）；
5. 内置盘 Windows 引导四件套 hash 基线已记录（`_attic/readonly-*` 范式；内置盘 ESP GUID=425214ee-257c-4aec-b69c-40178a4e847b 已建档）；
6. 本会话步骤卡就绪（本文 §3 即步骤卡）；
7. 用户知情确认（本文开头"拍板"项 + 最坏情况：部署失败 = WIN_ENGINE 分区重部署即可，内置盘零涉及）。

## 2. 三重确认闸门（目标盘 = X: WIN_ENGINE，硬性前置）

> 部署工具目标选错盘 = 全程最大风险。三条全过才允许点"部署"。

1. **盘符核对**：部署工具里目标分区盘符 = X:（卷标签 `WIN_ENGINE`）；
2. **容量核对**：目标分区容量 ≈ 300GB（内置盘 1TB 整盘，量级差一望即知）；WIN_ENGINE 空置（可用 ≈300GB）；
3. **落点实证**：跑只读预检脚本 `_attic/ai2-w1-preflight.py`，输出 `PREFLIGHT=PASS`（脚本核：卷标签 + 容量 + 文件系统 + 空置度 + 内置盘不在候选列表）。**实证不过 = 退出不动**。

## 4. 快速启动关闭（S0.4，若尚未执行）

- 提权：`Set-ItemProperty 'HKLM:\SYSTEM\CurrentControlSet\Control\Session Manager\Power' -Name HiberbootEnabled -Value 0`
- 回读验证 =0 → 重启两次 → 关机再开机应出现引导菜单（不再直跳 Windows）。
- 回滚：HiberbootEnabled=1 即还原。**这是全程唯一允许的"写内置盘"操作（单注册表键、可逆）**。
