## 二、嵌入 API 对接面（阶段 3 施工直接依赖）

| 需求 | Servo API | 结论 |
|---|---|---|
| 输入注入（任务 26/55） | `WebView::notify_input_event` + `notify_input_event_handled(InputEventId)`；`ImeEvent`/`InputMethodType` | ✅ 输入与 IME 通道在嵌入层齐备，键盘回声模型与本项目双 Esc 看护可共存 |
| 渲染输出 | `RenderingContext`（GL/软件）+ WebView 截图 `take_screenshot` | ✅ 帧缓冲输出可落地；GPU 缺位时软件渲染兜底不变 |
| 剪贴板白名单（任务 34 预留） | `ClipboardDelegate` trait 由嵌入方实现 | ✅ 白名单裁决点天然在嵌入层 |
| 帧驱动 | `RefreshDriver` trait | ✅ vsync 通知驱动动画 |

## 三、结论与排序

- 总评：**可承载**。Variable 前端的高风险面只有两项——`backdrop-filter`（22 处毛玻璃）与中文管线；均为降级可解，无"阻断性缺失"。
- 补齐顺序（❌/🔶 → 谁/何时）：backdrop-filter 降级类 → 任务 27 三件套联调时做；剪贴板垫片桥 → 任务 34；CJK 字体专项 → 任务 81；WebGL2 pref 探测 → 任务 27。
- 前置登记：本表依赖任务 22（已完成协议定版）；任务 26 依赖任务 19（AI-K 输入服务，未完成——前端侧原型见 inputBus.ts，实机链路待 19）。
