# Varix STAR I start · 界面与体验设计案 v0.1

**定版**：2026-09-25 ｜ **作者**：AI01 ｜ **状态**：设计讨论稿（Variable 逐条确认后升级 v1.0 冻结）
**设计宪法**：丰盛的界面，极简的工程——高密度、深层级、质感、顶格完成度、4K 精度、风格化创新、顺手易用。界面拒绝极简风；工程侧零死代码零冗余。

---

## 〇、与 Windows 的关系总纲（本案第一原则）

**交互词典对齐 Windows，视觉表达完全自研。**

- 用户从 Windows 过来：**零学习成本**——按钮在哪、右键菜单有什么、拖拽怎么行为、快捷键是什么，全部与 Windows 一致（先照抄交互布局，等我们有自己的按钮形状语汇后再统一替换，届时一次全局换装、不动动线）。
- 用户看到的一切：**没有一处像 Windows 克隆**——配色、材质、光影、动画曲线、图标风格、字体层级全部是 VARIX 自己的设计语汇，按 3A 大作级质感做。
- 一句话：**手感和 Windows 一样熟，眼睛看到的是另一个作品。**

## 一、开机进入动画（Boot Sequence Experience）

1. **序列设计**（四幕，总时长 ≤8 秒，可跳过）：
   - 幕一「点火」：Limine 选单后的黑场中，一枚 VARIX 星徽从暗到亮（0.8s，缓出）；
   - 幕二「聚合」：星徽周围粒子/光线向中心汇聚，同步真实加载进度（进度条不许骗人——幂一进度与真实 init 里程碑绑定，实测几秒就几秒）；
   - 幕三「点亮」：屏幕整体亮度渐升过渡到桌面（0.6s，桌面先骨架后内容）；
   - 幕四「呼吸」：桌面元素错落淡入（任务栏→图标→组件，错峰 80ms），落定后动画即止——**常驻动画只属于交互反馈，不属于待机**。
2. **技术约束**：动画帧率独立于桌面合成器（不互相拖累）；4K 帧资产预生成、运行时零实时模糊/光追类昂贵效果；跳过键（Esc/回车）第一帧即可用。
3. **断电安全**：动画中断任意帧 → 直接落桌面（动画是装饰不是关卡）。

## 二、桌面与窗口体系

1. **图标与网格**：桌面图标尺寸、网格间距、双击间隔**对齐 Windows 规范**（32/48/96px 档位、缩放联动）；图标**视觉**全自研（4K 多分辨率 sprite 套装，风格：光影写实+玻璃质感，单图标含常驻/悬停/按下三态）。
2. **任务栏**：位置/行为对齐 Windows（底部、固定+活动区、右键跳转清单、托盘折叠）；视觉自研——毛玻璃底、悬停浮起、按下下沉。
3. **窗口**：最小化/最大化/关闭/贴边分屏/多窗口层叠全部对齐 Windows 动线；窗口阴影按深度层级分层（活动窗深、非活动浅）；边缘吸附有落点预览。
4. **右键菜单**：结构对齐（新建/排序/刷新/属性的位置一致），菜单分层、悬停子菜单、键盘可导航；视觉自研。

## 三、文件资源管理器（功能克隆 Windows，视觉全新）

**功能对齐清单**（一项不缺）：
- 树形导航窗格（快速访问/此电脑/盘符/目录树展开）
- 地址栏（面包屑 + 可编辑路径 + 下拉历史）
- 搜索框（当前目录递归，搜索中可取消）
- 视图切换：超大/大/中/小图标、列表、**详细信息（表格视图——列：名称/修改日期/类型/大小）**、内容视图
- 排序与分组（点击列头、右键排序方式、分组依据）
- 右键全集：打开/打开方式/剪切/复制/粘贴/删除/重命名/属性/新建（文件夹与常见类型）
- 回收站（删除入站、还原、清空——零真删红线不动摇）
- 剪贴板操作全链（复制/剪切/粘贴保真、大文件异步不卡 UI）
- 拖放（同盘移动/跨盘复制、Esc 取消、合法落点提示）
- 状态栏（选中数/合计大小/数据源如实标注）
- 键盘全可达（方向键导航、F2 重命名、Del 删除、Ctrl+A/C/V/X/Z、Enter 打开、Alt+D 焦点地址栏）

**视觉**：与 Windows 资源管理器**没有任何像素级相似**——自研导航树样式、自研表格样式（斑马纹/悬停行/选中态按 VARIX 语汇）、自研图标体系。数据源页脚如实标注（exFAT SHARED 真挂载 vs 内置演示树，绝不冒充）。

## 四、会话/任务表格（语义待 Variable 确认）

按两种理解都立项，确认后取舍：
- **理解 A（任务管理器）**：进程/会话表格视图——名称/状态/CPU/内存/磁盘，红绿健康灯（账本订阅面），结束任务（二次确认）。系统监视器的表格化升级。
- **理解 B（文件管理器详细信息视图）**：即第三节表格视图——若此意，A 并入系统监视器原计划。

## 五、鼠标操作深化（手感是本域唯一 KPI）

按人格体验标准第 5/8 条全量执行：悬停必有反馈且不可点不装可点；按下有按压态、移出取消、松开才触发；拖拽元素跟手、有落点提示、Esc 放弃；滚轮方向自然、到底有边界感；双击/右键/长按分工明确；防抖全量（连点不触发双份）；**任何点击 100ms 内必有可见反馈**；动画稳定 60fps、打断不跳变。指针方案自研（4K 双倍率 sprite，Windows 指针语义：箭头/手型/文本/忙碌/缩放全保留）。

## 六、下载与安装（无应用商店，浏览器为门）

1. **VARIX 域内置浏览器（Variable 2026-09-25 已拍板方向：Edge 级浏览器下载，不建应用商店——MD1 第 20.2 章同步入宪）**：用户用浏览器正常下载——**不建应用商店**，星图退回其本职（兼容性评级目录），不做商店前端。
2. **下载落点**：SHARED 卷（S:）下载目录，VARIX 域可读。
3. **安装链**：下载物 → vxapp 校验（清单/签名/哈希）→ 四段安装 → **桌面出现图标，尺寸网格对齐 Windows 规范**、图标按本design 案视觉自研三态套装 → 双击即用。
4. **诚实边界**：.exe 真正「下载即可双击运行」依赖 PE 直载通道扩面（M-A→M-G 链）+ Win32 API 覆盖面——本设计案定义的是**体验管线**（下载→出现→双击），管线尽头能跑多少软件由兼容域里程碑决定，两线并行互不阻塞。
5. **安全**：所有下载物过 peblock 门与签名校验，未签名如实标注（不静默拦、也不静默放）。

## 七、4K 资产管线（硬标准，不是口号）

- **全部视觉素材按 4K（3840×2160）原生制作**：图标（多档位 sprite）、壁纸、纹理、动效关键帧、指针——高分屏放大三倍不糊不锯齿；
- 渲染链路按 4K 验收：字形图集、动画插值在 4K 分辨率下逐帧检查；
- 资产管线进 CI：素材尺寸/格式/命名/三态齐全性自动校验；
- 低分屏（1280×800）按比例降采样，不按低分重画——一个源头，处处清晰。
