**定版**：2026-09-25 ｜ **作者**：AI01 ｜ **状态**：设计讨论稿（Variable 逐条确认后升级 v1.0 冻结）
**设计宪法**：丰盛的界面，极简的工程——高密度、深层级、质感、顶格完成度、4K 精度、风格化创新、顺手易用。界面拒绝极简风；工程侧零死代码零冗余。

## 卷首 · 总纲（四域共同的第一原则）

**交互词典对齐 Windows，视觉表达完全自研。**

- 用户从 Windows 过来：**零学习成本**——按钮在哪、右键菜单有什么、拖拽怎么行为、快捷键是什么，全部与 Windows 一致（先照抄交互布局，等我们有自己的按钮形状语汇后再统一替换，届时一次全局换装、不动动线）。
- 用户看到的一切：**没有一处像 Windows 克隆**——配色、材质、光影、动画曲线、图标风格、字体层级全部是 VARIX 自己的设计语汇，按 3A 大作级质感做。
- 一句话：**手感和 Windows 一样熟，眼睛看到的是另一个作品。**

**执行纪律**：无软件商店是宪法级决定（MD1 第 20.2 章），一切「获取软件」路径走浏览器下载 + S: 侧载 + vxapp 校验；每项开工前先落 WP 编号与绑定判据。本册与《MD3 第 6 章》互为镜像（此处从体验视角记，MD3 从任务视角记，两处同账不同面）。

## 卷首·甲 防误解写作规范（本册条文如何写成 AI 不会理解错的句子）

本册的读者包括 AI 施工者——AI 不理解失误的前提是**每条条文只有一种解读**。本册全部条文的写作规范七条，施工时发现歧义条文按此修订：

1. **五要素齐备**：每条设计条文必须含「对象 / 数值 / 单位 / 状态 / 验收」——例：「任务栏高度 48px（100% 缩放，1920×1080 基准），偏差 ≤2px，拖动窗口贴底时任务栏不被遮挡（验收）」。「任务栏要好看」不是条文，是愿望。
2. **禁用模糊词表**：适当、美观、尽量、差不多、合理、优化一下、大概——这些词出现在条文中即文档缺陷。想说「适当留白」必须写成「卡片间距 16px」；说不准数值的，写成「随 E1 主题令牌 `--space-md` 取值」，让数值有唯一出处。
3. **状态穷举**：凡控件必有状态清单（常驻/悬停/按下/禁用/选中/焦点），凡流程必有异常分支（取消/失败/断电/中断恢复）——只写正常路径的条文视为未完成。
4. **视觉词配参照物**：颜色用色板令牌（`--accent`）不用「蓝色」；质感用材质样张文件（`design/assets/material-*.png`）不用「毛玻璃感」；动画用时长+曲线（200ms ease-out）不用「流畅地」——AI 拿到条文时，参照物必须已存在于仓库。
5. **对齐 Windows 的条文必须给「对齐到什么」**：写「对齐 Windows」必须同时给出测量基准（本册卷首·乙的规格基线表），基线表是对齐条文的唯一裁判——条文与基线冲突时，以基线表为准并回改条文。
6. **一处一事实**：同一数值只在一处定义、他处引用（引用格式「见 C-9 表第 N 行」）——两处各写一份 48px，将来一处改一处不改就是事故。
7. **判据绑定**：每节末尾列验收判据，格式沿用 B 判据纪律——实测数据 + 复现命令 + 日期三件齐才算绿。

# 第 1 部分 · A 兼容域（目标②——杠杆最高）

> 域目标：让 VARIX 能真正打开、运行 Windows 软件。

## A-1 提案表

| 编号 | 提案 | 说明 | 量级 |
| --- | --- | --- | --- |
| A1 | PE 直载通道扩面 | M-A→M-G 链：从 SHARED 打开 .exe → peblock 门 → ring3；先静态后导入绑定 | 中 |
| A2 | Win32 API 判例工厂 | 每个常用 API 一条判例 + 实现 + 星卡，按「用户实际装什么」排优先级——兼容面由真实使用数据驱动而非闭门造 | 长期但可并行 |
| A3 | Wine 路线 | Wine 入镜像 + lxrun 实机接线——兼容面的「外包加速器」 | 大 |
| A4 | vxapp 侧载闭环 | S: 放 .vxapp 包 → 校验 → 四段安装 → 桌面出现图标——不用等应用商店就有「装软件」的体验 | 小，杠杆极高 |
| A5 | 兼容性大量拓展深化（Variable 2026-09-25 指定） | 目标：**下载的软件在 VARIX 里完全无感地独立使用**——.exe 双击即开、VS Code 及其各语言生态（扩展/编译器/解释器链）原样可用；**大力复用现有开源项目**（Wine、Mesa、musl/relibc、开源语言运行时等），不自研重复轮子，把开源件接进 VARIX 的判例与垫片体系 | 大，持续 |

## A-1·补 A5 的落地口径

- **无感标准（验收判据）**：下载 → 双击 → 窗口出现，中间零配置、零终端命令、零「切换域」——用户全程不知道兼容层的存在；错误路径（程序不兼容）用三要素文案诚实提示，不闪退不静默；
- **多语言软件链**：VS Code + 各语言运行时（Python/Node/Java/Go/Rust 等）按 A2 判例工厂逐语言过判例——语言链的兼容目标不是「能装」，是「能装扩展、能跑构建、能调试」（以 VS Code 全绿为标志性判据，承接 MD1 S304）；
- **开源复用纪律**：优先列清单评估现有开源件（借力纪律同 MD1 第 18 章），只接不改、版本锁定；自研只做开源件与 VARIX 内核之间的接缝（垫片/判例/差异表）——兼容面的工程预算花在接缝上，不花在重造上。

## A-2 下载与安装（无应用商店，浏览器为门）

1. **浏览器下载（Variable 2026-09-25 已拍板：Edge 级浏览器下载，不建应用商店——MD1 第 20.2 章同步入宪）**：用户用浏览器正常下载——**不建应用商店**，星图退回其本职（兼容性评级目录），不做商店前端。
2. **下载落点**：SHARED 卷（S:）下载目录，VARIX 域可读。
3. **安装链**：下载物 → vxapp 校验（清单/签名/哈希）→ 四段安装 → **桌面出现图标，尺寸网格对齐 Windows 规范**、图标按本设计案视觉自研三态套装 → 双击即用。
4. **安全**：所有下载物过 peblock 门与签名校验，未签名如实标注（不静默拦、也不静默放）。

## A-3 诚实边界

.exe 真正「下载即可双击运行」依赖 PE 直载通道扩面（M-A→M-G 链）+ Win32 API 覆盖面——本设计案定义的是**体验管线**（下载→出现→双击），管线尽头能跑多少软件由 A1-A3 的兼容里程碑决定，两线并行互不阻塞。

## A-4 域内落点

A1 的打开动作落在第 3 部分文件资源管理器右键「打开方式」动线；A4 的安装完成反馈落在第 3 部分桌面图标三态套装。**下载→出现→双击**的体验管线即本部分 A-2 节。

# 第 2 部分 · B 性能域（目标③）

> 域目标：让系统更快更顺，且所有快都可实测、可复现。

## B-1 提案表

| 编号 | 提案 | 说明 | 量级 |
| --- | --- | --- | --- |
| B1 | vxbench 实机首跑 + 基线账本 | 一切优化的前置——没有基线就没有「极大优化」 | 小 |
| B2 | 启动链优化 | 预读窗口对账 + 二次启动 8 秒判据实机化——用户每天感知最强的性能 | 中 |
| B3 | GPU 加速合成器（R3 摸底后决策） | Ivy Bridge 核显有基本 2D/3D 加速能力（Intel GPU 驱动路线），不一定要换硬件 | 大，需摸底 |
| B4 | U 盘 I/O 深化 | 写合并/预读/缓存策略在真 U 盘上调优——B707 族判据实机化 | 中 |

**铁律**：B1 不绿，B2-B4 不开工——没有基线的优化是凭感觉的优化。

## B-2 性能红线（体验域的性能约束，全域通用）

- 开机动画总时长 ≤8 秒——这是 B2 的验收线，也是第 3 部分开机动画的时长上限，实测几秒就几秒，进度条不骗人；
- **任何点击 100ms 内必有可见反馈**；动画稳定 **80fps**（Variable 2026-09-25 拍板：目标 80 帧，60fps 为最低达标线）、打断不跳变——B3 决定这条 KPI 的天花板（软渲染达标后再谈 GPU 加成）；
- **任意软件打开体验**：窗口出现前的等待全程有反馈（指针忙碌态 → 首帧占位窗 → 内容就位），不允许「点了没反应」——打开耗时随应用如实波动，但**帧率与反馈红线对任意软件一视同仁**（打开慢是诚实标注的事，卡死冻结是事故）；
- 丰盛不以卡顿为代价——P95 与帧率实测是验收硬项（见卷尾验收）。

## B-2·补 性能深度优化方向（Variable 2026-09-25 指定）

80fps 打开任意软件的支撑面按四层推进：① 合成器主循环削减空转与冗余合成（脏区策略深化）；② 应用冷启动优化——ELF/PE 装载预取指纹、BOT 预读窗口对账、二次启动减半；③ 渲染路径 GPU 化（B3 摸底后立项，Intel 核显 2D/3D 加速）；④ U 盘 I/O 深化（B4 写合并/预读调优）。每层先过 B1 基线，逐层实测帧率归因——**80fps 是整链的总验收，不是单层指标**。

**获取口径（Variable 2026-09-25 拍板）**：轻量小游戏与媒体三件套（看图/看视频/听音乐）**不做内置开发——下载第三方软件即可**（走 A4 的 vxapp 侧载管线或直接 .exe，由兼容域覆盖）。系统只保证「下载→安装→能跑→体验合规」的管线与手感底座，内容交给开放生态。

## C-2 开机进入动画（Boot Sequence Experience）

1. **序列设计**（四幕，总时长 ≤8 秒，可跳过——上限即 B 域 B2 验收线）：
   - 幕一「点火」：Limine 选单后的黑场中，一枚 VARIX 星徽从暗到亮（0.8s，缓出）；
   - 幕二「聚合」：星徽周围粒子/光线向中心汇聚，同步真实加载进度（进度条不许骗人——进度与真实 init 里程碑绑定，实测几秒就几秒）；
   - 幕三「点亮」：屏幕整体亮度渐升过渡到桌面（0.6s，桌面先骨架后内容）；
   - 幕四「呼吸」：桌面元素错落淡入（任务栏→图标→组件，错峰 80ms），落定后动画即止——**常驻动画只属于交互反馈，不属于待机**。
2. **技术约束**：动画帧率独立于桌面合成器（不互相拖累）；4K 帧资产预生成、运行时零实时模糊/光追类昂贵效果；跳过键（Esc/回车）第一帧即可用。
3. **断电安全**：动画中断任意帧 → 直接落桌面（动画是装饰不是关卡）。
4. **零代码开机（Variable 2026-09-25 拍板）**：开机全程用户**看不到任何内核自检文字**——现有 kinfo 自检输出（self-test PASS、MMIO、ACPI、xHCI 之类逐行日志）从用户视野移除，转入后台日志文件（开机后可在诊断中心查看）；Limine 选单阶段也换成图形化渲染（星徽背景 + 两枚图形条目 + 倒计时环），不再黑屏白字。开发场景保留快捷通道（按 D 键展开原始日志，仅限开发态镜像，用户镜像无此键）——**用户的开机是动画，工程的开机是日志，两者永不混在同一个屏幕上**。

## C-3 桌面与窗口体系

1. **图标与网格**：桌面图标尺寸、网格间距、双击间隔**对齐 Windows 规范**（32/48/96px 档位、缩放联动）；图标**视觉**全自研（4K 多分辨率 sprite 套装，风格：光影写实+玻璃质感，单图标含常驻/悬停/按下三态）。
2. **任务栏**：位置/行为对齐 Windows（底部、固定+活动区、右键跳转清单、托盘折叠）；视觉自研——毛玻璃底、悬停浮起、按下下沉。

# 第 5 部分 · E 个性化与定制域（Variable 2026-09-25 指定新增）

> 域目标：系统「长成用户自己的样子」——一切个性化**随时可改、改完即生效、随时可退回**。定制不是设置一次就锁死的开关，是活的。

## E-1 总原则（本域铁律）

1. **随时可改**：所有个性化项不改系统文件、不动镜像——配置独立存放，改了立刻生效，无需重启、无需重装；
2. **随时可退**：每一项都有一键「恢复默认」；用户自定义前系统自动保留上一版，改坏了随时回退；
3. **预设 + 微调双层**：每项先给一套官方预设（按设计宪法 3A 质感做），用户可在预设基础上逐项微调——不从零开始，也不被预设锁死。

**F016 字体链兼容**——Windows 字体名（宋体/微软雅黑/Consolas）映射到 VARIX 字体族，缺字回退链对齐 MD2 篇 34；应用请求「微软雅黑 9pt」得到视觉同级渲染，不是缺字方块。
**F017 剪贴板格式族**——CF_TEXT/CF_UNICODETEXT/CF_BITMAP/CF_HDROP/自定义格式注册链全通，VARIX 剪贴板协议（B-3901）做格式翻译中枢；跨 Wine/原生窗口复制粘贴保真为验收判据。
**F018 拖放协议互通**——OLE 拖放（DoDragDrop）与 VARIX VXWM 拖放协议双向翻译；跨表面拖文件（Wine 窗口 → 资源管理器）落点预览与 Esc 三取消照走 C-6 红线。
**F019 COM 本地接口最小集**——CoCreateInstance 本地对象族（Shell 链接/拖放源/剪贴板）按判例补齐，不承诺进程外 COM 全集——承诺面写进星卡，不装懂。
**F020 异常与调试面**——SEH/VEH 结构化异常翻译到 VARIX 信号层，崩溃时生成 minidump 进崩溃恢复全书（S209 面）；应用崩溃不拖垮合成器（AI2 隔离防崩纪律的兼容面落点）。
**F021 内存语义对齐**——VirtualAlloc/MapViewOfFile/文件映射语义对齐（写时复制/保护页），伙伴分配器供给策略按大页优先；验收 = 一款开源内存敏感工具（7-Zip 基准）实测无降级。
**F022 时间与定时器族**——GetTickCount/QueryPerformanceCounter/timeBeginPeriod 语义对齐，TSC 时钟源直通（`tsc 2500MHz isa-none` 已实测）；游戏与音视频应用的时基保真判据入册。
**F023 网络栈 Winsock 面**——Winsock2 常用 API（socket/connect/send/recv/select/WSAAsyncSelect）翻译到 smoltcp socket 面，异步模型以消息泵适配；验收 = 一款开源 FTP 客户端全流程可用。
**F024 TLS 与证书库**——rustls 承载 TLS，Windows 证书库语义映射到 VARIX 证书管理器（F-C 域设置面）；DoH 切换（B-604）对 Winsock 面同样生效。
**F025 打印虚拟面**——「打印到 PDF」虚拟打印机先行（开源 PDF 生成库接入，只链接不修改），物理打印机列 STAR I start 后程；打印对话框动线对齐 Windows。
**F026 音频 WinMM/DirectSound 面**——waveOut/DirectSound 常用路径直通 HDA 混音器（B-806/807），每流独立音量；混音器 UI（C 域托盘面）实时显示各应用流——**谁在出声一眼可见**。
**F027 输入法 IMM32 面**——Wine 应用经 IMM32 消费 VARIX IME 组合事件，候选窗统一走 VARIX 渲染（风格不破碎）；组合期零误触（B-904）在兼容面复测。
**F028 高 DPI 感知三态**——DPI-unaware/aware/system-aware 三态如实执行：unaware 程序由合成器位图放大（模糊可接受并标注），aware 程序拿真实分辨率——**尊重程序的自我声明，不越俎代庖**。
**F029 多显示器前瞻接口**——显示配置 API 以单屏实现、多屏语义预留（枚举返回一块屏），接口形状不锁死——未来多屏不破 API。
**F030 安装器兼容模式**——NSIS/Inno Setup/MSI 三族安装器在沙盒（F009/F010）内正常完成安装流，安装进度条与完成页如实呈现；验收 = 三族各一款开源软件安装-卸载全周期在册。
**F031 卸载与残留清扫**——按 F009/F010 沙盒结构卸载即目录+蜂巢+开始菜单项三清，清扫清单给用户过目（回收站语义）；「安装 5 分钟、残留 5 年」在 VARIX 结构上不可能。
**F032 开源运行时直装族**——Python/Node/Java(JDK)/Go/Rust 工具链按 vxapp 打包上架侧载管线，PATH 与解释器解析按会话注入（F011）；每语言一组「装-写-跑-调」判例，VSCode 集成验收承接 S304。
**F033 构建工具链判例**——git/cmake/ninja/make 四件在控制台子系统（F012）全流程绿，网络操作走 Winsock 面（F023）；验收 = 开源小项目从 clone 到 build 到 run 全程在 VARIX 内完成并录制在册。
**F034 字符编码终局**——UTF-8 为系统编码，ANSI 代码页语义在兼容层内翻译（A 代码页 → UTF-8）；乱码事故归档为判例，每个乱码场景有一条判例兜住。
**F035 兼容性自检向导**——用户双击后若失败，弹「兼容性向导」：自动归因五分类（缺 API/缺运行时/架构不符/权限/未知），给出「需要 XX 运行时，去浏览器下载」的可执行指引（无商店原则照走）——**失败也是一次被引导的体验，不是死胡同**。
**F036 星卡自动草稿**——每个成功运行的未知程序自动生成星卡草稿（API 覆盖面/启动耗时/资源画像），用户一键提交进星图（D 域社区通道）；兼容性数据从真实使用里长出来，正是 A2 的数据驱动纪律。
**F037 peblock 门用户可见化**——被门拦下的程序给出「为什么拦我」的完整解释（哪条规则/哪个哈希），允许「我了解风险，仍要运行」的显式越权（越权行为全量审计日志）——**安全不是黑名单的沉默，是规则的透明**。
**F038 应用隔离档位**——每应用三档隔离（宽松/标准/严格）可调（E 域联动），严格档禁网络+只读文档目录；默认标准档，权限变更时弹窗告知——权限体验对齐手机系统的心智模型。
**F039 游戏兼容前瞻面**——DirectX 探测与拒绝表先行（DX9+ 检测后给「切 Windows 域」一键引导，判例 19 诚实边界照走）；wineserver 会话（M-D/M-E）就绪后此面转 Wine DXVK 评估——不做半吊子承诺，做诚实的分流。
**F040 兼容域总判据**——「常用 50 件」清单（文本编辑/压缩/图片/终端工具/开发工具五类各 10 件开源代表）逐件实测建档，通过率每季度刷新进星图——**兼容性不是口号是账本**。

## F-B 性能域深化（F041-F070）

**F041 帧率账本**——合成器逐帧打点（合成耗时/脏区面积/提交耗时）进账本，监视器直接画 80fps 红线图；帧率不是感觉，是每秒 80 行账。
**F042 帧率归因器**——掉帧时自动归因（输入风暴/大脏区/IO 阻塞/调度抢占），监视器给出「上一秒谁偷了帧」的排名——性能问题先可见再可治。
**F043 冷启动画像**——每个应用首次/二次启动的逐阶段耗时（装载/重定位/首帧/可交互）建档入星卡；「打开任意软件」的快慢从黑盒变成五段刻度尺。
**F044 预取指纹 v2**——文件页预取按历史启动指纹（哪些页真正被摸过）调序，对账 BOT 预读窗口；二次启动目标实测减半（承接 MD2 篇 27）。
**F045 页缓存水位策略**——U 盘整机内存 4GB 边界下的页缓存水位线（回收阈值/脏页占比上限）做成旋钮（MD2 附录 K），断电一致性让位规则显式化。
**F046 写合并窗口自适应**——5 秒窗口按负载动态伸缩（空闲收窄到 1s、重载放宽到 8s，fsync 硬承诺不动）；旋钮联动走 ADR。
**F047 调度器延迟预算深化**——交互线程 p99 唤醒延迟 2000μs 预算拆到逐类（输入/合成/音频/普通），超标即归因报告——预算不是平均值是分布。
**F048 CPU 频率联动**——TSC 2500MHz 实测面之上做负载感知升降档（P-state 表驱动），降档不降交互预算；笔记本电池续航与手感联动的第一块旋钮。
**F049 空转清零工程**——合成器空闲 5% 判据（B-501）细化为「空闲态零定时器唤醒」（帧缓冲无脏区即休眠），待机功耗实测入账本。
**F050 中断合并**——输入/网络中断按突发窗口合并（2000ns 预算内批量处理），input-probe flood 已有 flood_dropped 计数（实测 70）——把丢弃变成合并，计数器归零为目标。
**F051 大页策略**——4MB 页用于内核静态区与字形图集，TLB miss 实测对比入账；R3 GPU 摸底时同步评估核显侧大页。
**F052 堆碎片治理**——内核堆（56KB 分块已实测）增长策略改为尺寸分级池，碎片率指标入账本；零堆纪律之外「堆健康」也要有数。
**F053 启动并行度**——init 里程碑依赖图显式化（ACPI/PCI/USB/存储四链并行），串行等待点逐个消除；开机 8 秒线（B2）的分解攻坚图挂账本。
**F054 图像解码 SIMD**——PPM/PNG/JPEG 解码走 SIMD（SSE4.2 基线，AVX2 探测后启用），解码耗时入 vxbench；壁纸 4K 解码 ≤150ms 为验收线。
**F055 字形光栅缓存**——字形图集按 LRU 热度驻留，冷字形驱逐热字形保位；滚动长文档的光栅耗时实测不抖动。
**F056 合成器脏区深化**——光标移动不触发全屏合成（光标层独立），弹窗动画只合成弹窗矩形——把「全屏重绘」从系统词典里删掉。
**F057 IO 调度分级**——前台交互 IO（打开菜单/搜索）优先级永远高于后台（索引/下载），io-pending 指标（实测 avg 9/9 pass）细化为分优先级队列。
**F058 内存压缩前瞻**——4GB 边界的冷页压缩池（LZ4 级算法评估）立项评估不急于上——先测真实工作集，超 3.2GB 再启用。
**F059 网络小包优化**——smoltcp 描述符混表（B-602）之上的批量收包路径，每包处理耗时入账；终端 SSH 打字延迟 ≤30ms 为体验线。
**F060 电量账本**——按应用的能耗画像（CPU 时间/唤醒次数/IO 量折算），设置中心「电池」页显示「今天谁在耗电」——功耗透明是 U 盘整机的体验面。
**F061 基准回归门**——vxbench 六类基准接入 CI 夜跑（QEMU 替身），基线倒退即门禁红——性能资产和代码资产一样不许悄悄缩水。
**F062 性能自检报告**——开机后 10 分钟静默采样生成「系统健康快照」（帧率 P95/IO 延迟/调度超标次数），异常自动转诊断中心工单——性能问题在用户感知之前先被系统自己看见。
**F063 触控板手势前瞻**——HID 触控板多指手势协议评估（Y7000 触控板实测定级），不承诺但把数据面留好。
**F064 音频低延迟链**——混音器单流延迟 ≤20ms 实测线（音乐类应用的可用性门槛），CORB/RIRB 环形缓冲调优入账。
**F065 唤醒源治理**——USB 键鼠（xHC 已 live）之外的唤醒源白名单化，睡眠态每分钟唤醒次数 ≤1 为达标；待机耗电从查不到变成有账。
**F066 文件系统日志策略**——ext4 journal 模式按分区特性选型（data=ordered 基线），断电百次与性能双达标为准；journal 参数进旋钮清单。
**F067 启动 IO 冷热分离**——镜像内只读区（内核/字体/资产）与可写区物理分离，只读区零 journal 开销；BOT 顺序读优势最大化。
**F068 渲染资产按需装载**——4K 壁纸/图标集按主题加载（当前主题外资产不驻内存），内存占用差值入账本——丰盛与省内存兼得。
**F069 性能模式三档**——静音/均衡/性能三档一键切换（调度预算+频率+写合并窗口联动），任务栏托盘直达；档位定义全走旋钮清单，无隐藏魔法数。
**F070 性能域总判据**——80fps 红线（B-2 补）之下每层都有独立判据与账本页，四层优化逐层绿才整链绿——**总指标是试金石，分层判据是施工图**。
