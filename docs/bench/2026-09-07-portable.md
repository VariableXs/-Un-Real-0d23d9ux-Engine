## 2. 沙箱环境参考值（非目标硬件，不可作为验收依据）

- 环境：Linux 沙箱 · 2 vCPU · 3.8 GB RAM · 容器存储（非 USB，非 NTFS，无 BitLocker）
- 采集：Python `open(..., buffering=0)` + `fsync`，512 MB 顺序 + 5 s 4K 随机取样（与 `Bench-Perf.ps1` 同思路的独立实现）
- 用途：**只证明采集链路本身能跑通并产出量级合理的数字**，与U盘性能无关

| 指标 | 沙箱值 | 说明 |
| --- | --- | --- |
| 顺序写 | 985.1 MB/s | 容器后端存储，非U盘 |
| 顺序读 | 5909.4 MB/s | 含页缓存命中，明显高于任何U盘，正好说明该口径受缓存影响 |
| 4K 随机读 | 1991.6 MB/s / 509856 IOPS | 同上，页缓存命中 |

> 读到这里请注意：顺序读 5909 MB/s 这个数字本身就说明**用户态读写口径会被页缓存显著抬高**。
> 因此 `Bench-Perf.ps1` 的报告里固定写明「不等同于 CrystalDiskMark 裸盘值，只做同机横向对比」。
> 真机验收的裸盘指标仍以 CrystalDiskMark 为准，结果附到 `Data/Tests/`。

## 3. 复现方式

```powershell
# 目标硬件上（管理员 PowerShell）
cd portable\AI5
.\Bench-Perf.ps1 -Action Manifest                     # 先看指标与阈值
.\Bench-Perf.ps1 -Action Run -TestDrive E:\ -WriteRepo  # 实测并写回本目录
.\Bench-Perf.ps1 -Action Gate                         # 门禁：未达预算退出码 1
```

`-WriteRepo` 会生成 `docs/bench/<当天日期>-portable.md`，把上表第一列的 ⏭ 换成实测值。

## 4. CI 门禁

`portable/tests/Run-PortableTests.ps1` 会在真 PowerShell 上执行 `Bench-Perf.ps1 -Action Run`
（小样本：64 MB 顺序 / 16 MB 4K / 2 轮启动），验证脚本可运行且产出 `bench-results.json`，
再跑 `-Action Gate`。**该自检必须在 Windows 上执行**，接入方式见 `portable/tests/README.md`。
