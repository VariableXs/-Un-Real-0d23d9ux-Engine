### 0.2 本轮六条立项铁律（每项 V 功能必须全部满足）

1. **实用优先**：每项必须回答「一个真实用户在什么场景下会用到它」，答不上来的不立项；不为演示而生的功能一律不做。
2. **零退化**：任何改动不得让现有观感、操作、性能产生哪怕一点回退；所有新行为**默认关闭或默认等于现状**，用户显式开启才逐步生效。
3. **零键位冲突**：所有新键位一律走 Z-08 键位注册表仲裁；该注册表落地前，本轮新键位只允许 `ctrl+alt+` 空闲槽与裸功能键；不确定的组合一律不占用，且必须让位于系统组合与第三方全局热键。
4. **不弄巧成拙**：不做任何「演示很惊艳、日常是干扰」的花活；动效克制（≤260ms）、文案诚实、降级如实；氛围类功能全部 opt-in。
5. **四大内置应用绝对隔离**：写作空间、思维导图、项目分析、命运推演任何文件零修改；本轮所有功能只作用于桌面壳层、VWM、任务栏、开始菜单、文件管理器、设置与后端 shell 模块；与四空间交互仅限窗口层体验与只读数据消费。
6. **并行工程零破坏**：与 AI-1…AI-5 并行在建的 SUMMIT-90 / APEX-70 各项完全兼容；共享文件（dictionaries.ts、ipc.ts、lib.rs、vwm.ts、StartMenu.tsx、desktop.css）只增不改他人段落，改前 `rg` 核对现状，改后跑 audit；不产生任何跨模块编译依赖与运行时异常。

## 域 A：桌面与图标（V-01…V-10）

> 目标：桌面从「能用」回到 Windows 老用户「随手就能排」的可控度；全部默认等于现状。

### V-01 桌面图标排列系统

- **定位**：复刻 Win10 桌面右键「查看 / 排序方式」双菜单：自动排列、将图标与网格对齐、显示桌面图标开关；排序方式（名称/大小/类型/修改日期）。
- **动机**：老用户整理桌面的第一入口；没有这两级菜单，桌面永远「排不齐」。
- **具体内容**：① 桌面空区右键菜单新增「查看」「排序方式」两个子菜单（与既有 M-15 空区菜单定制互补：M-15 管菜单可编辑性，本项提供默认内容）；② 自动排列 = 图标落点吸附 96px 网格；③ 排序即时重排（走 V-10 的 FLIP 动效）；④ 每项设置持久化。
- **不做清单**：不做自由拖拽与自动排列的混合态（二选一，与 Windows 语义一致）；不做图标坐标云端同步。
- **验收**：100 图标桌面执行四种排序各 10 次，落点误差 0px；设置重启后保持。

### V-02 系统桌面图标管理

- **定位**：「此电脑 / 回收站 / 网络 / 用户的文件 / 控制面板」五个系统图标的显隐管理，设置页 + 桌面右键直达。
- **动机**：Windows.md 1.1 描述的核心桌面能力；新装用户第一件事就是把「此电脑」请回桌面。
- **具体内容**：① 设置 → 个性化 → 桌面图标面板（5 个开关 + 「恢复默认」按钮）；② 图标变化即时生效，无闪烁；③ 拖入回收站的系统图标只是隐藏并如实提示，不产生删除语义。
- **不做清单**：不做系统图标自定义图片（图标包系统 N-12 已覆盖）。
- **验收**：五图标任意组合显隐 20 次零闪烁、零布局跳变；「恢复默认」一键回到出厂组合。

### V-03 桌面图标锁定

- **定位**：一键锁定桌面图标：锁定后图标不可拖动、不可误删、排序冻结；解锁需显式确认。
- **动机**：「手滑把整个桌面拖乱」与「误删客户资料快捷方式」是桌面双杀惨案。
- **具体内容**：① 右键菜单「锁定桌面图标」（有子菜单显示当前状态）；② 锁定期间拖动操作给出轻提示「桌面已锁定」；③ 删除操作在锁定期间转入「移入回收站前需解锁」确认；④ 状态在任务栏托盘不出图标（克制），只在右键菜单可见。
- **不做清单**：不做密码级锁定（不是安全功能，是防手滑）；不锁定新建与重命名（只锁位置与删除）。
- **验收**：锁定态 100 次随机拖动/删除尝试全部拦截；解锁后一切如常。

### V-04 桌面双击空白动作

- **定位**：双击桌面空白处可配置触发动作：无（默认）/ 显示桌面 / 最小化全部 / 打开命令面板 / 锁定环境。
- **动机**：把桌面空白这个最大的「免费热区」还给用户，但默认必须等于现状（无动作）。
- **具体内容**：① 设置项 `desktop.doubleClickAction` 默认 `none`；② 触发判定与图标双击打开互斥（双击图标仍是打开，与 Windows 行为一致）；③ 动作触发有 80ms 内的视觉确认（如显示桌面时窗口轻微下沉提示）。
- **不做清单**：不做双击壁纸换壁纸（易误触灾难）；不做三击、长按手势。
- **验收**：默认配置下 200 次双击空白零动作零提示；开启后命中 100%，与双击图标零串扰。

### V-05 图标标签可读性自适应

- **定位**：桌面图标文字标签根据壁纸局部亮度自动选择「黑字白晕」或「白字黑晕」，晕影宽度 2px、模糊 4px。
- **动机**：浅色壁纸上白字看不清是壁纸自由的最大代价；Windows 用固定阴影凑合，我们可以按局部采样做对。
- **具体内容**：① 对每个图标下方区域采样壁纸亮度（缩略图级计算，一次性、换壁纸时重算）；② 阈值可感知高对比度模式（跟随既有 HC 令牌）；③ 用户可强制指定「总是黑/总是白/自动」。
- **不做清单**：不做逐字母动态反色（过度设计）；不做标签底色色块（破坏观感）。
- **验收**：8 张亮暗混合壁纸 × 每张 12 图标采样，对比度全部 ≥ WCAG AA；换壁纸重算 <50ms。

### V-06 桌面图标密度档位

- **定位**：桌面图标三档预设（小 32 / 中 48 / 大 96px）+ Ctrl+滚轮连续缩放（24–128px），档位记忆。
- **动机**：Windows.md 1.1「查看 → 图标大小」与资源管理器 Ctrl+滚轮行为的桌面版；4K 屏与老 1080p 屏用户需求两极。
- **具体内容**：① 三档菜单项 + 连续缩放（缩放中显示当前像素值 tooltip）；② 网格步长随图标尺寸自动调整；③ 与 V-01 排序联动不跳变。
- **不做清单**：不做每区域独立密度（一桌面一档）；不做图标尺寸动画（即时生效，避免拖泥带水）。
- **验收**：缩放全程无重影无闪烁；重启后档位保持；与自动排列共存无冲突。

### V-07 桌面敲字定位图标

- **定位**：桌面获得焦点后直接敲字，模糊匹配图标名并高亮选中，Enter 打开、Esc 清空，连续敲字 300ms 内累积。
- **动机**：资源管理器与桌面列表的 Windows 标配行为；图标多时比视线搜索快十倍。
- **具体内容**：① 匹配规则：前缀优先、拼音首字母次之（复用开始菜单拼音索引基础设施）；② 多命中时循环高亮（继续敲字过滤）；③ 焦点不在桌面时零开销。
- **不做清单**：不做桌面内联搜索框 UI（保持 Windows「无框敲字」原味）；不做全文搜索（统一搜索 N-14 的地盘）。
- **验收**：200 图标桌面中英文混合名定位 30 次全部命中预期项；与 V-04 双击动作零串扰。

### V-08 回收站图标状态徽标

- **定位**：回收站桌面图标三态：空（原样）/ 有物（角标显示条目数）/ 接近配额（角标变琥珀色）；悬停 tooltip 显示总占用与最早删除时间。
- **动机**：「回收站到底有没有东西、要不要清」目前必须打开才知道；Windows 只做图标形态切换，我们补全信息层。
- **具体内容**：① 复用 U-27 回收站 2.0 的数据源，桌面层只读消费；② 角标样式走既有徽标令牌（与任务栏角标同族）；③ 接近配额阈值 90%。
- **不做清单**：不做自动清空策略（U-27 领地）；不做点击图标直接清空（危险操作必须进回收站界面）。
- **验收**：增删文件到回收站后角标 2s 内更新；三态视觉在浅/深壁纸下均可辨。

### V-09 新建菜单模板中心

- **定位**：桌面与资源管理器右键「新建」子菜单升级为模板中心：内置（文件夹/文本文档）+ 用户自定义模板（任意文件可存为模板，命名与图标可编辑）。
- **动机**：「新建 Markdown 笔记」「新建 PS1 脚本」这种高频动作，Windows 需要注册表 hack 才能加；这是右键菜单里被浪费最严重的一格。
- **具体内容**：① 模板库存于用户数据目录（模板内容与元数据）；② 「保存为模板」入口在文件右键菜单；③ 模板管理面板（重命名/删除/排序）放在设置 → 个性化；④ 新建后直接进入重命名态（与 Windows 行为一致）。与 M-19 右键菜单自定义编辑器互补：M-19 管菜单结构，本项管「新建」内容。
- **不做清单**：不做模板参数化（日期占位符等，避免变成代码生成器）；不做模板分享格式（资源包 .vxs 领地）。
- **验收**：20 个模板的新建、重命名、删除全链路正确；新建文件内容与模板字节一致。

### V-10 图标让位 FLIP 微动效

- **定位**：拖动图标经过时，其余图标以 120ms FLIP 动画弹性让位；松手或取消时归位；reduce-motion 下直接静态换位。
- **动机**：图标重排的「瞬间跳变」是桌面观感里最后一个粗糙点；FLIP 让位置变化可追因。
- **具体内容**：① 复用 vwm.css 既有 spring 令牌（--ease-spring）；② 拖动中实时让位（节流至 60fps 内）；③ 与自动排列共存（自动排列下无让位动画，直接网格吸附）。
- **不做清单**：不做音效；不做跨屏拖拽让位（单屏内）；不让位动画影响落点判定（几何计算先行）。
- **验收**：100 图标桌面连续拖动 60s 零掉帧（60fps 设备）；reduce-motion 下零动画；松手落点与无动画时逐像素一致。

> 目标：开始菜单像个用了十年的菜单（信息架构向 Win10/11 的成熟形态补齐），任务栏图标「会干活」。V-11…V-14 开始菜单归 AI-5，V-15…V-20 任务栏归 AI-2。

### V-11 开始菜单字母索引条

- **定位**：全量应用列表左侧 A–Z 字母索引条，点击/悬停跳转对应字母分组；CJK 应用按拼音首字母归组。
- **动机**：Win10 最被怀念的开始菜单细节——200 个应用里找「微信」，点一下 W 就到，比滚动快且不依赖搜索。
- **具体内容**：① 索引条在应用数 >30 时自动出现，否则隐藏（克制）；② 拖动索引条时中央显示当前字母大字提示（Win10 同款交互）；③ 拼音归组复用既有拼音索引基础设施。
- **不做清单**：不做搜索联动（搜索是 N-14 领地）；不做索引条样式自定义。
- **验收**：500 应用级列表跳转 20 次全部落在正确分组首项；键盘可达（Tab 聚焦后字母键直达）。

### V-12 「最近添加」与「高频使用」自动分组

- **定位**：开始菜单全量列表顶部两个自动分组：「最近添加」（近 14 天新装）与「高频」（本地使用统计 Top 8，可在设置关闭）。
- **动机**：「刚装的那个软件在哪」与「每天要开的那几个」是开始菜单两大真实问题；Win11 的「推荐」只覆盖前者。
- **具体内容**：① 数据源为本地安装时间与本地使用洞察（N-31 领地、只读消费）；② 高频分组默认关闭（隐私偏好保守），开启需显式勾选；③ 分组可整体隐藏。
- **不做清单**：不做手动置顶混入自动分组（固定区是独立概念）；不做云端同步。
- **验收**：新装应用 60s 内出现在「最近添加」；关闭高频分组后零统计残留界面痕迹。

### V-13 固定应用文件夹

- **定位**：开始菜单固定区拖拽一个图标到另一个图标上，合并为可命名文件夹（如「办公」「游戏」），点击展开，支持拖出解散。
- **动机**：Win11 22H2 同款能力；固定区超过一屏后，文件夹是唯一不牺牲一屏可见性的收纳方式。
- **具体内容**：① 合并判定与 VWM 贴靠同语义（拖近 60% 重叠触发）；② 文件夹内最多 24 项（如实提示上限）；③ 文件夹图标 = 前 4 项图标 2×2 合成（复用图标合成基础设施）。
- **不做清单**：不做嵌套文件夹；不做文件夹自动智能归类（绝不替用户决定）。
- **验收**：创建/命名/追加/解散各 20 次零异常；重启后结构保持。

### V-14 开始菜单右键高级操作

- **定位**：开始菜单应用项右键：固定到任务栏 / 固定到「开始」/ 卸载 / 打开文件位置 / 以管理员身份运行 / 属性。
- **动机**：Windows.md 描述的开始菜单标准右键能力；尤其「卸载」与「打开文件位置」是从开始菜单出发的闭环刚需。
- **具体内容**：① 卸载走系统卸载协议（UWP 走注册表协议、Win32 走卸载串），失败如实提示；② 「打开文件位置」复用资源管理器并选中目标；③ 「以管理员身份运行」触发 UAC 语义（与 M-39 提权协作提示联动）。
- **不做清单**：不做静默卸载；不拦截系统卸载确认框。
- **验收**：20 个混合类型应用的六项操作全部正确；权限不足场景提示诚实。

### V-15 任务栏图标中键新开实例

- **定位**：中键点击任务栏应用图标 = 启动新实例（与浏览器中键新标签同语义）；单实例应用如实降级为切换。
- **动机**：Windows 任务栏原生行为，肌肉记忆级；当前环境缺这一格就是「手感不像」。
- **具体内容**：① 中键事件在任务栏图标层统一处理；② 单实例应用中键显示轻提示「该应用仅支持单实例」并切换；③ 与 V-70 中键关闭预览语义并存不冲突（一个是图标、一个是预览缩略图）。
- **不做清单**：不做中键语义自定义（保持 Windows 原味）。
- **验收**：20 个应用中键行为分类正确；无中键设备零影响。

### V-16 拖到任务栏图标打开

- **定位**：把文件拖到任务栏应用图标上悬停 300ms = 用该应用打开此文件（Word 图标 ← 拖入 .docx）；应用不注册该扩展名时图标显示禁止态。
- **动机**：Windows 任务栏被低估的高频能力；「这个文件用 PS 打开」从此不用先开 PS。
- **具体内容**：① 走 shell 文件关联查询判断可开性；② 拖拽悬停时图标放大 1.1 倍 + 高亮（复用既有 hover 令牌）；③ 多文件拖入 = 批量打开（>5 个时确认弹窗）。
- **不做清单**：不做「以管理员身份用其打开」组合（复杂度不值）；不接收不可开类型（禁止态如实）。
- **验收**：20 种扩展名 × 10 应用矩阵测试，可开性与系统行为一致；禁止态零误开。

### V-17 任务栏溢出折叠区

- **定位**：任务栏图标满额时，溢出图标收纳进 `^` 折叠菜单（最近使用排序 + 手动锁定常驻），折叠区可键盘导航。
- **动机**：窗口一多任务栏挤成沙丁鱼罐头，图标挤压动画是「廉价感」重灾区；Win10 溢出机制是成熟解。
- **具体内容**：① 触发阈值 = 图标最小宽度被压缩 20% 时；② 折叠菜单样式与跳转列表（M-10）同族；③ 锁定常驻的图标永远在外；④ 溢出时任务栏左端显示 `^` + 计数。
- **不做清单**：不做双行任务栏（观感风险大）；不做自动智能收纳（用户说了算）。
- **验收**：50 窗口压力下任务栏无挤压跳变；折叠菜单打开 <100ms；键盘全链路可达。

### V-18 运行指示样式三选

- **定位**：任务栏运行指示三种样式可选：Win11 圆点（默认=现状）/ Win10 下划线 / 胶囊；设置项即时预览。
- **动机**：Win10 老用户的下划线肌肉记忆 + 视障用户需要更强的运行态对比；样式差异是「个人手感」不是花活。
- **具体内容**：① 三种样式全部走令牌（宽 3px 下划线 / 6px 圆点 / 全宽 4px 胶囊）；② 与主题强调色联动；③ 高对比度模式下自动用最强对比样式（可覆盖）。
- **不做清单**：不做指示样式动画（呼吸态归 M-16 领地）；不做自定义颜色。
- **验收**：三样式切换零重启即时生效；高对比度联动正确；默认值与现状逐像素一致。

### V-19 关机前会话清单

- **定位**：关机/重启确认对话框中列出「环境内尚在进行的事」：活动 VWM 窗口清单、未完成传输、未保存的速记，逐项可勾选「仍要关机」。
- **动机**：「重启之后我刚才开着哪十个窗口」是失忆惨案；关机前 3 秒的清单是最后的安全网。
- **具体内容**：① 数据源为窗口管理器与传输中心（只读）；② 清单默认折叠（≤3 项时直接展示），展开完整列表；③ 「仍要关机」勾选记忆 30 分钟内不再询问。
- **不做清单**：不拦截系统级关机（只管环境自己触发的关机路径）；不保存窗口会话快照（N-05 工作区场景领地）。
- **验收**：含 20 窗口 + 2 传输的会话关机清单完整；勾选「仍要关机」后不重复打扰。

### V-20 电源菜单增强

- **定位**：电源菜单分列：睡眠 / 休眠（可用时）/ 重启 / 关机；悬停显示上次开机时长与上次关机是否异常。
- **动机**：电源操作是「每天一次」的高频动作，当前信息量为零；「昨晚是不是又异常关机了」一眼可见。
- **具体内容**：① 休眠项仅在系统启用休眠时显示（如实）；② 上次关机状态读取系统事件（只读，复用 V-52 可靠性时间线数据源）；③ 异常关机标记用琥珀色轻提示，不弹窗。
- **不做清单**：不做定时关机（计划任务工坊 V-83 领地）；不做快速启动开关管理（系统设置领地）。
- **验收**：四种电源动作路径正确；异常关机标记与系统事件日志一致；不可用项如实隐藏。

## 域 C：窗口与工作流（V-21…V-30）

> 目标：VWM 手感的最后十个缺口，全部默认关闭或默认等于现状；全部只动 `vwm.ts` / `VirtualWindowFrame.tsx` / `winman.rs` 的最小增量。

### V-21 经典系统菜单复刻

- **定位**：标题栏图标右键 / Alt+Space 唤出经典系统菜单：还原 / 移动 / 大小 / 最小化 / 最大化 / 关闭；「移动」「大小」进入键盘微调模式（方向键 1px、Shift+方向 10px）。
- **动机**：三十年 Windows 肌肉记忆的最后一块拼图；键盘流用户移动窗口从来不用碰鼠标。
- **具体内容**：① 菜单项按当前窗口态动态禁用（最大化的窗口禁用「移动/大小」）；② Alt+Space 走键位注册表（对系统语义让位：前台是系统窗口时不拦截）；③ 键盘微调模式 Esc 退出、Enter 确认。
- **不做清单**：不做菜单项增删自定义；不做系统窗口的菜单注入（只管 VWM 窗口）。
- **验收**：六项操作在正常/最大化/最小化三态下禁用逻辑正确；键盘移动 50 次逐像素符合预期。

### V-22 失联窗口救援

- **定位**：窗口几何在所有可视区之外（拔显示器、DPI 突变、应用自救失败）时：环境启动自动体检 + 任务视图内「找回所有窗口」一键拉回。
- **动机**：多显示器用户拔线后「窗口没了但进程还在」是经典惨案；Windows 自己都没有好答案。
- **具体内容**：① 体检时机：启动、显示器配置变更事件、手动触发；② 拉回策略：保持尺寸、贴到主屏最近可视边缘；③ 体检报告在 toast 显示「找回 N 个失联窗口」。
- **不做清单**：不做持续后台监控（事件驱动够了）；不改窗口尺寸（只挪位置，尊重应用布局）。
- **验收**：模拟拔副屏 20 次全部找回；正常窗口零误判；找回后焦点不抢占。

### V-23 调整大小实时几何提示

- **定位**：拖动窗口边/角时，光标旁显示实时 W×H 数值（等宽字体、80ms 跟随）；Shift 按住 = 等比缩放。
- **动机**：「我需要正好 1280×720 的窗口」目前只能靠截图量；设计/录屏/对比场景刚需。
- **具体内容**：① 提示浮层走既有 tooltip 规范（M-88）；② 等比模式锁定拖动起点比例；③ 数值显示可关（默认开，视觉极轻）。
- **不做清单**：不做数值直接输入框（右键菜单塞输入框太重）；不做预设尺寸吸附（贴靠是 Z 域领地）。
- **验收**：拖动全程提示跟手无跳变；等比模式 20 次比例误差 <0.5%；关闭后零残留。

### V-24 窗口多选编组操作

- **定位**：Ctrl+点击标题栏多选窗口（或任务视图内框选），编组后可批量：一起移动（保持相对位置）、一起贴靠、一起最小化、一起关闭（确认）。
- **动机**：整理「十几个窗口摆位」目前只能一个个拖；批量是桌面整理的最后一公里。
- **具体内容**：① 编组态视觉：所有选中窗口边框走强调色 1px 高亮；② 一起移动 = 平移保持相对几何；③ Esc 退出编组；④ 关闭批量操作需确认。
- **不做清单**：不做编组持久化（会话级即止）；不做保存编组为工作区（N-05 领地）。
- **验收**：8 窗口编组平移 20 次相对位置误差 0px；Esc/误点击都能干净退出。

### V-25 焦点历史回溯

- **定位**：`Ctrl+Alt+[` / `Ctrl+Alt+]`（经注册表仲裁）在最近聚焦窗口历史中后退/前进，如同编辑器的「上一个光标位置」。
- **动机**：Alt+Tab 是「队列」不是「历史」；「我刚从哪个窗口跳过来的」回不去是高频懊悔瞬间。
- **具体内容**：① 历史栈深 20，重复聚焦去重；② 与 Alt+Tab 互不干扰（独立栈）；③ 栈底/栈顶时按键给轻震动反馈（无操作则无动作，不循环）。
- **不做清单**：不做可视化历史列表（克制，栈行为要可预期）；键位不做第二套。
- **验收**：50 次随机聚焦序列回溯正确率 100%；与 Alt+Tab 并行使用零串扰。

### V-26 窗口位置互换

- **定位**：在窗口多选编组（V-24）基础上，编组内两个窗口一键互换几何位置，180ms 位移动画。
- **动机**：「这两个窗口位置换一下」目前 = 两次贴靠四次拖拽；互换是排布动作的原子化。
- **具体内容**：① 编组恰好两个窗口时右键菜单出现「互换位置」；② 动画期间两窗口 alpha 0.9 防遮挡混淆；③ 尺寸不同时取并集区域居中（如实提示不保尺寸）。
- **不做清单**：不做三窗口轮换（复杂度陡增）；不做跨虚拟桌面互换。
- **验收**：同尺寸/异尺寸互换各 20 次几何正确；动画流畅无撕裂。

### V-27 嵌入窗口焦点联动

- **定位**：点击嵌入（L1）窗口内部时，宿主 VWM 框标题栏同步进入激活态视觉（与直接聚焦宿主一致），明确「我在操作谁」。
- **动机**：嵌入窗口内点击后宿主标题栏仍显示「非激活」，用户对层级关系产生疑惑；这是嵌入模式的观感债。
- **具体内容**：① 宿主激活态 = 标题栏文字与控制按钮走激活令牌；② 仅视觉联动，不改系统焦点语义（不抢真实焦点，避免输入劫持）；③ 联动可关（默认开）。
- **不做清单**：不做宿主标题栏显示嵌入进程名（L4 hint 徽标已有该职责）。
- **验收**：20 个嵌入应用点击联动视觉正确；系统焦点行为零变化（IME/键盘不受影响）。

### V-28 窗口分布小地图

- **定位**：任务视图（Win+Tab）内新增「分布」视图：按虚拟桌面 × 显示器网格展示所有窗口缩略位置，点击直达（切换桌面+聚焦窗口）。
- **动机**：窗口跨 4 桌面 2 屏后，「我那个窗口在哪个桌面」全靠脑记；小地图是空间记忆的外挂。
- **具体内容**：① 缩略图 = 窗口截图的 1/8 缩放（复用 capture 基础设施，按需生成不常驻）；② 桌面切换手势（Z-42）在分布视图内同样有效；③ 空桌面如实显示为空。
- **不做清单**：不做小地图拖拽摆位（那是布局快照 Z-40 领地）；不做常驻缩略刷新（性能红线）。
- **验收**：30 窗口 × 4 桌面分布图缩略正确；点击直达 100%；进入视图 <300ms。

### V-29 窗口色带标记

- **定位**：按应用给 VWM 窗口标题栏顶部加 2px 色带（如：工作=蓝、通讯=绿、监控=橙），设置面板集中管理，默认关闭。
- **动机**：多任务态「一眼分类」：扫一眼标题栏色带就知道这类窗口是干嘛的；浏览器彩色标签页的成熟思路。
- **具体内容**：① 色带颜色走强调色 + 语义色令牌（不做任意色，防视觉失控）；② 色带不占标题栏布局高度（覆盖绘制）；③ 高对比度模式下加粗至 3px。
- **不做清单**：不做每窗口独立色（应用级粒度即止）；不做色带动效。
- **验收**：默认关闭时逐像素等于现状；开启后 50 窗口扫读分类准确（用户测试 5 人）；零布局影响。

### V-30 拖拽中断与回弹

- **定位**：VWM 窗口拖拽进行中按 Esc = 取消本次拖拽，窗口回弹到拖拽起点（150ms），无任何残留状态。
- **动机**：拖到一半发现「拿错了窗口」，目前只能硬着头皮放下去再撤销；Esc 取消是文件拖拽的标准语义，窗口版补齐。
- **具体内容**：① Esc 只在拖拽进行中生效（keydown 阶段拦截，不影响 Esc 层级语义 M-34）；② 回弹动画复用 spring 令牌；③ 与贴靠预览共存（Esc 同时清预览）。
- **不做清单**：不做「拖拽中右键取消」（与上下文菜单冲突）；不做多级撤销。
- **验收**：拖拽各阶段（起步/贴靠预览/摆渡预览）Esc 全部正确取消；取消后窗口状态与拖拽前完全一致。

## 域 D：文件与数据（V-31…V-40）

> 目标：高频文件动作再少一步、再稳一分；全部在 `src/system/explorer/**` 与对应 shell 后端增量内完成。

### V-31 文件夹视图记忆

## 域 E：效率中枢（V-41…V-50）

> 目标：键盘流用户的一秒钟都不浪费；全部本地、零出站。

### V-41 内联计算

- **定位**：搜索框 / 运行框 / 命令面板输入算式（`128*7`、`(3+4)^2`、`sqrt(2)`）即时显示结果卡，Enter 复制结果。
- **动机**：Windows 运行框与 macOS Spotlight 的标配能力；「快算一下」不该是打开计算器的理由。
- **具体内容**：① 纯本地表达式求值器（安全子集：四则、幂、开方、括号、百分比、单位换算联动 Z-26）；② 结果卡显示完整算式与结果，方向键可选历史；③ 输入含字母路径时自动让位（不误判为算式）。
- **不做清单**：不做变量/公式记忆（越界成计算器应用）；不做汇率（需网络，红线）。
- **验收**：100 条混合算式结果与标准计算器一致；路径/命令输入零误判；响应 <16ms。

### V-42 屏幕取字 OCR

- **定位**：截图取词升级：框选屏幕区域 → 本地 Windows.Media.Ocr 识别 → 结果入剪贴板并浮窗展示（可编辑修正后复制）。
- **动机**：「图片里的文字」「视频字幕」「软件界面上不让复制的字」——取字是截图工具最高频的真实用途。
- **具体内容**：① 走系统自带 OCR（零新增依赖、零出站）；② 语言跟随系统 OCR 语言包，包缺失时诚实提示「未安装中文识别语言包」并指路；③ 识别置信度低于阈值时浮窗标记低置信词。
- **不做清单**：不做表格结构化识别；不做手写识别；不做在线 OCR 兜底。
- **验收**：印刷体中文/英文各 30 张准确率 >95%；语言包缺失场景提示诚实；识别全程 <800ms。

### V-43 二维码速递

- **定位**：选中文本/链接/文件路径 → 命令面板或右键「生成二维码」→ 浮窗显示本地生成的二维码，手机扫码即取。
- **动机**：把链接/长文本从电脑递到手机，聊天软件传给自己是最土的路；二维码是零账号零网络的正经解。
- **具体内容**：① 二维码生成纯本地库（零出站）；② 长文本自动评估容量并如实提示超限；③ 浮窗支持一键放大（扫码距离）与复制为图片。
- **不做清单**：不做扫码（反向）识别；不做二维码美化（保持标准可扫性）。
- **验收**：URL/文本/路径三类 30 条，三款主流手机相机全部秒扫；超长文本提示正确。

### V-44 纯文本净化粘贴

- **定位**：全局 `Ctrl+Shift+V` = 剥离富文本格式粘贴纯文本（颜色/字体/链接残留全去）；与剪贴板历史（N-15）协同：历史条目可「以纯文本复制」。
- **动机**：从网页/Word 粘贴到笔记/代码编辑器的格式污染是全天候痛点；用户装 PureText 类工具就是为了这一个键。
- **具体内容**：① 全局钩子仅在该组合按下时介入（注册表仲裁，让位检测：目标应用自带此快捷键时不拦截）；② 剪贴板源为图片/文件时不介入（如实透传）。
- **不做清单**：不做「粘贴并匹配格式」的自定义模板；不做剪贴板内容改写历史。
- **验收**：20 个应用（含自带 Ctrl+Shift+V 的应用）行为矩阵正确；格式剥离彻底（含隐藏字符）。

### V-45 命令面板宏收藏

- **定位**：宏引擎（N-18）的宏可「钉选」，钉选宏出现在命令面板顶部「常用宏」区，一键执行。
- **动机**：命令面板是键盘流的中心，但高频宏每次都要搜索是浪费；收藏位补齐「最高频动作一键直达」。
- **具体内容**：① 钉选位 8 个（超出如实提示）；② 拖拽排序；③ 宏删除时钉选位同步清理。
- **不做清单**：不做全局快捷键直接绑宏（键位纪律走 Z-08，不另开通道）。
- **验收**：钉选/取消/排序/执行 30 次全链路正确；与 N-18 权限体系一致（越权宏如实禁用）。

### V-46 全局速记

- **定位**：`Ctrl+Alt+N`（注册表仲裁）呼出速记浮窗：单行/多行快速输入，Esc 关闭，内容自动追加到当日笔记文件（`速记/2026-09-08.md`）。
- **动机**：灵感与待办的半衰期只有几秒；「先开个笔记软件」本身就是遗忘的理由。全局热键 + 零保存负担 = 速记的全部。
- **具体内容**：① 浮窗 300ms 内弹出置顶，输入焦点自动就位；② 文件格式 Markdown，时间戳分节；③ 关闭动画 150ms，绝不打断当前流；④ 与 V-47 隐私开关联动：速记可在设置中完全关闭。
- **不做清单**：不做富文本；不做速记搜索（文件管理器领地）；不做自动整理。
- **验收**：任意应用前台 50 次呼出全部 <300ms；断电场景已保存内容不丢（每次 Esc 即落盘）；关闭后热键彻底注销。

### V-47 搜索历史隐私开关

- **定位**：搜索/命令面板历史三态开关：本地保存（默认）/ 彻底不记录 / 一键清空；设置页可查看当前历史条数。
- **动机**：搜索框是最诚实的隐私泄露面（「你搜过什么」）；给用户明确的控制权是信任问题，不是功能问题。
- **具体内容**：① 「不记录」模式下搜索即时执行、零持久化（进程内存也不留，会话结束即焚——这是不记录，不是焚毁类功能）；② 清空操作有确认且不可撤销（如实警告）；③ 状态在设置页可见。
- **不做清单**：不做历史加密（不记录>加密）；不做按条删除（全有或全无，简单可信）。
- **验收**：三态切换后行为逐一验证；「不记录」模式下文件系统与内存均无搜索词残留。

### V-48 运行框自动补全

- **定位**：运行框输入时下拉补全：历史命令、可执行文件名（PATH + App Paths）、`shell:` 系统目录，Tab/→ 确认，↑↓ 选择。
- **动机**：Windows 运行框三十年没有补全；`ms-settings:`、`shell:startup` 这些咒语没人记得住。
- **具体内容**：① 补全源一次性扫描缓存（启动后台构建，<10ms 查询）；② 分类图标区分（历史/程序/目录）；③ 补全可整体关闭。
- **不做清单**：不做模糊匹配（前缀即可，与 V-39 职责分开）；不做自定义别名（宏引擎领地）。
- **验收**：50 个常用命令补全命中率 100%；扫描缓存构建 <200ms 且不阻塞首启。

### V-49 时间戳速插

- **定位**：命令面板/运行框输入 `now` / `ts` → 结果卡展示当前时间的五种格式（ISO 8601 / Unix 秒 / Unix 毫秒 / 人类可读 / 相对描述），点击即复制。

- **具体内容**：① 全部本地计算（时区跟随系统，夏令时正确）；② 相对描述（「今天是 2026 年第 251 天」）；③ 格式顺序可调。
- **不做清单**：不做时区转换（换算中心 Z-26 领地）；不做时间戳反解（输入戳转时间）。
- **验收**：五种格式与标准库输出一致；跨午夜/跨时区边界 10 例正确。

### V-50 键位速查表导出

- **定位**：快捷键中心（N-17）新增「导出速查表」：当前生效键位方案导出为单页 Markdown / 可打印 HTML（按域分组、冲突项标红）。

- **不做清单**：不做 PDF 直出（HTML 打印足够）；不做在线分享。
- **验收**：导出内容与运行时注册表 100% 一致；让位中的键位如实标注「系统占用」。

## 域 F：系统感知与健康（V-51…V-60）

### V-51 亮度音量微步进

- **定位**：亮度/音量调节支持 1% 微步进（默认仍为 10% 档）：快捷键 `Ctrl+Alt+滚轮`（上下文相关，注册表仲裁）或滑杆悬停后方向键微调。
- **动机**：夜间亮度 10% 跳变像被闪光弹糊脸；1% 微调是夜间用户与录音师的刚需。
- **具体内容**：① 微调模式默认关闭（默认=现状档位）；② OSD 反馈与既有音量/亮度指示同族；③ 不支持的设备（无亮度控制）如实不可用。
- **不做清单**：不做 Gamma/色彩调节（系统领地）；不做音量曲线自定义。
- **验收**：微调模式 1–100 全程步进准确；默认模式与现状逐次一致。

### V-52 系统可靠性时间线

- **定位**：只读读取系统事件日志，生成可靠性时间线：蓝屏、异常关机、驱动故障、系统更新节点，按天排列可下钻事件详情。
- **动机**：Windows「可靠性监视器」深埋在控制面板；「这台机器最近稳不稳」应该一眼可见（这是只读感知，非自愈——自愈归 N-25）。
- **具体内容**：① 仅读取三 个系统通道（System/Application 关键事件），零写入；② 时间线视图与通知存档（Z-47）同族样式；③ 事件详情含来源、ID、原文摘录。
- **不做清单**：不做事件删除/清理（系统领地）；不做故障自动修复（N-25 领地）。
- **验收**：注入测试事件后时间线 5s 内可见；只读声明在 UI 明示；与系统可靠性监视器数据一致。

### V-53 端口占用侦探

- **定位**：进程 ↔ 监听端口映射表：输入端口号查占用进程（PID/名称/路径），或查某进程监听的所有端口；附「复制 netstat 等价命令」按钮。
- **动机**：「端口被占用」是开发部署第一报错；目前要开管理员终端敲 netstat -ano 再开任务管理器对 PID——三步查一端口。
- **具体内容**：① 数据源 GetExtendedTcpTable/GetExtendedUdpTable（只读）；② 搜索框支持「:8080」「chrome」双模式；③ 点击进程可跳转任务管理器定位。
- **不做清单**：不做 kill 进程入口（任务管理器领地，避免重复危险路径）；不做端口转发/代理。
- **验收**：与 netstat -ano 输出 100% 一致（20 端口抽检）；查询 <100ms；UDP/TCP 都覆盖。

### V-54 临时保持唤醒

- **定位**：「保持唤醒」定时器：1 / 2 / 4 小时或「下次空闲前」，倒计时期间阻止睡眠与熄屏；托盘角标倒计时，可随时提前解除。
- **动机**：看片、下载、挂演示时「系统睡了」是经典惨案；临时咖啡因比改电源计划轻得多。
- **具体内容**：① SetThreadExecutionState 实现（会话级，不改电源计划，进程退出自动失效）；② 到期自动恢复并 toast 告知；③ 与电源管家（N-20）状态联动不冲突。
- **不做清单**：不做屏幕常驻亮度（只管睡眠）；不做规则化定时（计划任务工坊 V-83 领地）。
- **验收**：激活期间系统零睡眠（注入等待验证）；到期恢复正确；环境异常退出后无残留唤醒态。

### V-55 大文件雷达

- **定位**：「最近 7 天新增 >500MB 文件」时间线报告：按大小倒序、按目录分组，点击直达文件位置；纯只读。
- **动机**：「C 盘怎么又红了」的第一嫌疑人永远是最近几天新进来的大文件；空间分析器（Z-34）看现状，雷达看「增量」。
- **具体内容**：① NTFS USN Journal 增量扫描（无 Journal 时降级全量 mtime 扫描并如实标注耗时）；② 阈值与时间窗可调；③ 报告可导出为文本（诊断包 U-42 格式兼容）。
- **不做清单**：不做自动清理建议执行（只报告，删不删用户定）；不做实时监控（哨兵 M-27 领地）。
- **验收**：与手动检索结果一致（抽样 20）；USN 路径扫描 <3s；降级路径提示诚实。

### V-56 环境运行时长与重启建议

- **定位**：设置「关于」页与环境信息面板显示：当前环境运行时长、系统 uptime、内存.commit 峰值；连续运行 >7 天时温和提示「考虑重启环境」（可关闭）。
- **动机**：长跑稳定性（S 域）的建设配套可见性；「多久没重启了」是排查卡顿的第一问。
- **具体内容**：① 三项数据只读展示；② 提示为一次性 toast（每 7 天最多一次，绝不弹窗骚扰）；③ 关闭后永不再提示（设置可重开）。
- **不做清单**：不做自动重启；不做健康评分（自愈中心领地）。
- **验收**：时长与 GetTickCount64 一致；提示频率限流正确；关闭态零打扰。

### V-57 进程优先级预设

- **定位**：任务管理器中可为指定进程保存「优先级 + CPU 亲和性」预设，进程下次启动自动应用；仅用户显式创建的预设生效。
- **动机**：渲染/编译机用户的手动日常：每次启动 AfterEffects 都要手动设优先级；预设一次，终身生效。
- **具体内容**：① 预设按进程路径匹配（非名称，防误伤同名）；② 应用失败（权限/进程保护）如实提示不重试；③ 预设列表可导入导出（配置分享 Z-54 格式）。
- **不做清单**：不做「智能」自动调优（绝不替用户猜）；不做实时抢占调度（资源公平调度 M-54 领地）。
- **验收**：20 个进程预设应用正确；无预设进程零干预；权限不足场景提示诚实。

### V-58 更新闲时下载

- **定位**：环境自身更新包（增量更新通道 Z-61 的内容）在「空闲时段」（可配置，默认 02:00–05:00 且空闲 10 分钟）下载；带宽占用在快速面板可见、可暂停。
- **动机**：更新下载抢带宽是后台软件最大恶名之一；「闲时下载」是对用户的礼貌。
- **具体内容**：① 空闲判定 = 无前台全屏 + 无活跃传输 + CPU <20%（复用空闲冻结 Z-59 判定）；② 下载速率上限可设；③ 「立即下载」入口保留（用户说了算）。
- **不做清单**：不做闲时自动安装（下载与安装分离，安装永远显式）；不做 P2P 分发。
- **验收**：空闲判定 20 场景正确；限速生效；手动暂停/恢复无损。

### V-59 断电恢复自检

- **定位**：检测到上次关机为异常断电（脏位标记）后，环境首次启动自动执行轻量自检（数据库完整性、图标缓存、设置文件、回收站索引），报告结果 toast + 详情页。
- **动机**：异常断电后的隐形损坏会在几天后才爆雷；启动自检把「雷」提前到第一时间可见。
- **具体内容**：① 自检四项全部只读+自动修复白名单（如缓存重建），白名单外只报告不修复；② 自检 <5s（并行执行）；③ 结果写入诊断包（U-42）。
- **不做清单**：不做文件系统级修复（chkdsk 系统领地）；不做阻塞式全盘扫描。
- **验收**：模拟脏关机 10 次自检全部触发；正常关机零触发；自检耗时 P95 <5s。

### V-60 启动项耗时归因

- **定位**：任务管理器启动项 tab 增强：每项显示对开机时间的贡献估算（ms）、累计曲线图、「建议延迟」标记（贡献 >500ms 且非安全类）。
- **动机**：开机慢的元凶目前是个黑盒；归因让「禁用哪个」从猜谜变成决策。
- **具体内容**：① 耗时 = 启动到进程首次空闲的采样（本地统计）；② 与启动延迟编排（V-86）联动：一键「延迟 30s」；③ 安全类启动项（杀毒/驱动辅助）不显示建议标记（如实避嫌）。
- **不做清单**：不做自动禁用任何启动项；不做启动项云评分。
- **验收**：20 启动项归因与手工秒表抽样偏差 <15%；建议标记规则正确；一键延迟与 V-86 联动生效。

## 域 G：输入与手感（V-61…V-70）

> 目标：键鼠手感向顶级外设软件看齐，但全部克制、默认现状。V-61/65/66/67/70 归 AI-2，V-62/63/64/68/69 归 AI-5。

### V-61 鼠标手感面板

- **定位**：设置 → 输入：指针速度、双击速度测试区（含测试方块）、滚轮行数、交换左右键；环境内列表即时生效，写回系统设置需显式确认。
- **动机**：Windows.md 9.1 的核心鼠标参数在新版设置里被拆散；一站式面板 + 双击测试方块是「认真对待手感」的标志。
- **具体内容**：① 双击测试方块（双击它变色=速度合适）；② 环境内生效范围明确标注（不影响其他应用）；③ 「同步到系统」按钮带确认与回滚。
- **不做清单**：不做加速度曲线编辑器（小众到极端）；不做写回系统注册表之外的任何绕路。
- **验收**：四参数环境内生效即时；测试方块行为正确；写回/回滚闭环。

### V-62 指针方案管理

- **定位**：指针方案面板：内置 3 套（现状/大号/高对比）+ 导入 .cur/.ani 自定义方案（13 种指针状态逐个可配）；方案即时预览、一键切换。
- **动机**：Windows.md 4.1 的指针方案能力在环境内的补全；无障碍（大号指针）与个性化一次满足。
- **具体内容**：① 状态清单按 Windows 13 态标准（正常选择/帮助/后台/忙…）；② 导入包非法时逐条报错（哪一态缺文件）；③ 高对比度模式联动（HC 开启自动切高对比方案，可覆盖）。
- **不做清单**：不做指针在线市场；不做动画帧编辑。
- **验收**：13 态全部可配可切换；非法包报错定位到态；HC 联动正确。

### V-63 指针轨迹

- **定位**：可选开启的指针轨迹（演示/教学场景）：轨迹长度三档，轨迹为低透明度残影（60ms 衰减），默认关闭。
- **动机**：录屏教学时「观众看不见光标去哪了」；Windows 自带指针轨迹的克制版。
- **具体内容**：① 渲染走合成层（零额外全屏开销）；② 演示模式（V-91）联动可一键开启；③ 轨迹颜色跟随指针方案。
- **不做清单**：不做轨迹颜色自定义；不做点击爆点特效（花活红线）。
- **验收**：开启后 60fps 无掉帧；关闭后零渲染残留；三档长度差异明显。

### V-64 点击涟漪反馈

- **定位**：可选的点击位置涟漪反馈（默认关闭）：点击处一圈 240ms 涟漪扩散，左键白/右键琥珀；仅演示/教学场景建议开启。
- **动机**：与 V-63 配套的演示可见性工具——「看，我点的是这里」。
- **具体内容**：① 涟漪走 --accent 令牌（尊重主题与 HC）；② 与 V-63 一起可在演示模式中统一开关；③ reduce-motion 下退化为 80ms 十字标。
- **不做清单**：不做按键音联动（声音系统领地）；不做双击/长按特殊动效。
- **验收**：开启/关闭切换零状态残留；演示模式联动正确；reduce-motion 退化正确。

### V-65 大写锁定全局提示

- **定位**：CapsLock 切换时屏幕下沿中央轻提示「大写锁定 开/关」800ms 淡出（默认关闭；密码框场景 Windows 已有提示不冲突）。
- **动机**：输密码手滑开 CapsLock 是全球通用惨案；系统只在密码框提示，日常输入全程盲打。
- **具体内容**：① 提示样式与 OSD（音量/亮度）同族；② 仅在环境内键盘焦点时触发（不监听系统全局，克制边界）；③ 全速开关、零后台开销。
- **不做清单**：不做 NumLock/ScrollLock 提示（需求弱）；不做声音提示。
- **验收**：切换触发 100%；非环境焦点零触发；提示不遮挡任务栏。

### V-66 按键重映射

- **定位**：单键级重映射（如 CapsLock→Ctrl、右 Alt→Menu），映射表走键位注册表（Z-08）仲裁与让位协议（Z-09）：系统级冲突时不生效并如实报告。
- **动机**：CapsLock 位置是人体工学最大的历史遗留；PowerToys Keyboard Manager 证明这是百万级需求；环境内补全是键位自由的最后一块。
- **具体内容**：① 仅单键→单键与单键→修饰键；② 重映射对四大内置应用同样生效但不修改其任何代码（全局钩子层实现）；③ 方案随键位方案（Z-14）保存切换。
- **不做清单**：不做组合键→组合键（宏引擎领地）；不做应用级差异化映射（作用域 Z-10 领地的扩展，本轮不做）。
- **验收**：10 组映射全应用生效；与注册表冲突检测正确；方案切换映射随之切换。

### V-67 触控板自然滚动方向

- **定位**：环境内列表/面板的「自然滚动」（内容跟随手指方向）开关：开=触控板方向自然化、鼠标滚轮不变；关=现状；只影响环境内，不改系统设置。
- **动机**：Mac/触屏手机过来的用户对滚轮方向的心智冲突；环境内开关是无风险的折中。
- **具体内容**：① 仅在环境自身组件生效（不 hook 系统滚动）；② 设置项带一行示意图（动画示意方向差异）；③ 连接外接鼠标时自动保持鼠标语义。
- **不做清单**：不做系统级滚动方向修改；不做 per-设备记忆（本轮从简）。
- **验收**：开关切换即时生效于所有环境列表；鼠标滚轮行为恒定不变。

### V-68 打字音效可选

- **定位**：可选的打字键音（默认关闭）：三种克制音色（静音薄膜/茶轴/雨点），音量联动既有声音引擎（A-4），DND 自动静音。
- **动机**：机械感反馈对部分输入流用户是专注增强剂；PowerToys 已验证需求，关键是克制与默认关闭。
- **具体内容**：① 音效 <60ms、随机 pitch 微变（防听觉疲劳）；② 仅环境内焦点生效；③ 与声音系统 mute/音量/DND 全部联动（不另开通道）。
- **不做清单**：不做按 key 声调映射（打字变成弹钢琴的花活红线）；不做录音上传。
- **验收**：三音色试听与切换正确；DND 下自动静音；关闭后零钩子开销。

### V-69 指针精确模式

- **定位**：按住 `Alt`（可配置修饰键）期间指针速度降至 40%（精细选择场景：勾选小目标、像素级操作），松开恢复；默认关闭。
- **动机**：Windows「鼠标加速」争议的核心是快慢不可兼得；修饰键降速是零成本的兼得方案（CAD 软件的标准做法）。
- **具体内容**：① 降速期间指针旁极淡十字标提示（可关）；② 与 Alt 系既有操作共存判定（仅指针移动时生效，不干扰 Alt+Tab 等）；③ 降速比例可调（20–60%）。
- **不做清单**：不做按住切换的锁定模式（误锁灾难）；不做区域触发。
- **验收**：Alt 按住期间像素级选中成功率提升（测试矩阵）；Alt+Tab/Alt+F4 零干扰。

### V-70 拖拽阈值与防手滑

- **定位**：拖拽启动阈值（默认 4px，可调 2–10px）：阈值内的按住移动不算拖拽（视为点击）；适用于图标、列表项、窗口标题栏统一语义。
- **动机**：手抖用户「点一下图标变成拖半屏」；阈值是所有成熟 GUI 的标配防手滑，且与 Windows 行为一致。
- **具体内容**：① 阈值全局统一（一处设置）；② 触控输入自动放大阈值（手指精度低）；③ 不影响 VWM 贴靠（贴靠有自己的触发距离）。
- **不做清单**：不做 per-应用阈值（复杂度）；不做长按替代拖拽。
- **验收**：阈值内 100 次点击零拖拽误判；阈值外拖拽 100% 启动；触控阈值自适应生效。

## 域 H：个性化与氛围·克制版（V-71…V-80）

> 目标：个性化做减法；每一项默认都与现状分毫不差，开启后也是「更像 Windows」而不是「更花」。全部走令牌，零裸色值。

### V-71 本地壁纸精选轮换

- **定位**：内置本地壁纸精选集（8–12 张授权摄影/抽象图），可选「每日轮换」；每张壁纸附一句本地文案（作者/地点/一句话故事），右下角「换一张」轻入口。
- **动机**：Windows Spotlight 的体验价值（新鲜感+故事感）但没有它的出站网络与隐私争议；本地精选是零风险的同等体验。
- **具体内容**：① 图片随安装包内置（体积预算 <15MB，WebP 压缩）；② 轮换仅换壁纸不动主题（不越权）；③ 「换一张」在桌面右键与壁纸快捷操作（M-70）都有入口。
- **不做清单**：不做在线壁纸源（零出站红线）；不做 BING 式问答互动。
- **验收**：轮换时间点精确（本地时钟）；文案双语；关闭轮换后壁纸停留当前张。

### V-72 壁纸饱和度与明度调节

- **定位**：壁纸显示层可调饱和度（60–100%）与明度（80–100%）两个滑杆，实时预览，只为「图标文字可读性」服务。
- **动机**：壁纸太艳导致图标看不清时，用户的唯一选项是换壁纸；调节壁纸本身是「喜欢这张图但要它闭嘴」的正解。
- **具体内容**：① 滤镜在壁纸渲染层一次应用（零运行时开销）；② 预设「原图/柔和/阅读」三档；③ 设置持久化，切换壁纸保持。
- **不做清单**：不做 RGB 通道级调节；不做局部调节（主体保护，算法花活）；不做模糊调节（材质引擎 U-08 领地）。
- **验收**：滑杆实时预览 <16ms；关闭（100%）时逐像素等于原图；性能零回归。

### V-73 农历节气与节日

- **定位**：任务栏时钟悬停卡片与日历面板显示：农历日期、二十四节气、传统节日（春节/中秋等）与公历节日；本地数据表（2020–2040）。
- **动机**：CJK 用户的日用级信息（「今天初几」「什么时候冬至」）；Windows 时钟不含农历是 CJK 版长期的遗憾。
- **具体内容**：① 本地万年历算法（无网络）；② 节气时刻精确到小时；③ 卡片排版与 M-12 时钟细节同族；④ 可整体关闭（非 CJK 用户）。
- **不做清单**：不做黄历宜忌（封建边界）；不做节假日倒计时提醒。
- **验收**：2020–2040 抽样 60 天与标准万年历一致（含无中气置闰月年份）；排版 zh/en 下都成立。

### V-74 界面密度档位

- **定位**：全局界面密度两档：舒适（默认=现状）/ 紧凑（间距 -20%、列表行高 -15%），即时切换即时生效。
- **动机**：小屏笔记本用户「一屏放不下」与大屏用户「太稀疏」不可兼得；密度档位是一处设置的兼得（Windows.md 4.2 紧凑视图的系统级理念）。
- **具体内容**：① 全部通过间距令牌（sp-*）缩放实现，零组件级 hack；② 紧凑档仍满足 44px 最小触控目标（无障碍红线）；③ 设置预览实时。
- **不做清单**：不做三档以上（选择负担）；不做 per-应用密度。
- **验收**：两档切换后全 UI 无布局破损（视觉矩阵回归覆盖）；默认档逐像素等于现状。

### V-75 界面几何风格

- **定位**：圆角档位三选：圆角（默认=现状 8px）/ 小圆角（4px）/ 直角（0px），作用于环境自身 UI（窗口/卡片/按钮）。
- **动机**：Win10 老用户的直角审美与 Win11 圆角审美的分裂是真实的用户分裂；档位化让两种审美都体面。
- **具体内容**：① 走 r-* 令牌全局缩放；② 直角档阴影同步收细（视觉一致性）；③ 四大内置应用不受影响（其内部圆角自成体系，零修改）。
- **不做清单**：不做任意像素值输入；不做混合档（窗口圆角+按钮直角）。
- **验收**：三档切换零布局异常；默认档逐像素等于现状；内置应用视觉零变化。

### V-76 界面字体偏好

- **定位**：界面字体三选：Segoe UI Variable（默认）/ 微软雅黑 / 用户自装字体（指定字体名），附字重档位（标准/加粗偏移）；缺字体时回退默认并提示。
- **动机**：字体是最主观的个性化维度；Windows.md 2.7 的字体体系给了用户选择权，环境侧补全它。
- **具体内容**：① 走 CSS font-family 令牌注入；② CJK 回退链安全（任何选择下中文不豆腐块）；③ 字体不存在时回退 + 一次性提示（不循环骚扰）。
- **不做清单**：不做字体渲染参数（ClearType 系统领地）；不做 per-区域字体（CJK/西文分离，复杂度）。
- **验收**：三源切换 30 个界面无布局崩（长文本截断审计）；回退链正确；重启保持。

### V-77 焦点环样式选择

- **定位**：键盘焦点环三选：系统默认（现状双线）/ 高亮框（加粗 2px）/ 下划线（沿控件底部）；联动高对比度模式（HC 下强制最强可见样式）。
- **动机**：焦点可见性是无障碍与键盘流的交叉刚需；一种样式难两全（密集列表 vs 大面板）。
- **具体内容**：① 全部走 Z-05 焦点规范令牌的变体；② 切换后 Tab 导航抽样验证可见性；③ 样式预览在设置页即时。
- **不做清单**：不做自定义颜色/动画；不做闪烁焦点（光敏性风险）。
- **验收**：三样式在浅/深/HC 主题矩阵下可见性达标（M-82 视觉矩阵纳入）；默认等于现状。

### V-78 全局 UI 图标尺寸档位

- **定位**：环境 UI 图标（按钮/列表/托盘图标）三档：16 / 20（默认=现状）/ 24px，与文字缩放（A 域 80–150%）解耦独立调节。
- **动机**：视力用户与高分辨率用户的两个维度（字大≠图标大）目前被耦合在一个缩放里；解耦是精细化无障碍。
- **具体内容**：① 图标全部 SVG 令牌化尺寸（无位图拉伸模糊）；② 三档切换即时生效；③ 与密度档位（V-74）正交组合不冲突。
- **验收**：三档 × 两密度组合布局无破损；默认档等于现状；托盘图标跟随档位。

### V-79 系统模式与应用模式深浅分离

- **定位**：深浅色设置升级为两列：环境界面模式（任务栏/开始菜单/托盘）与应用窗口模式（环境自身应用面板），可分别设浅/深/跟随系统（Windows.md 2.4 的「自定义」语义）。
- **动机**：Windows 用户熟悉的双轨深浅色（系统深+应用浅）是真实偏好分布；单一开关表达不了。
- **具体内容**：① 两轨独立持久化；② 「跟随系统」模式订阅系统主题变更事件；③ 现有单开关设置无损迁移（升级时默认=两轨同值）。
- **不做清单**：不做定时自动切换（U-46 领地）；不做第三方应用深浅注入（不可能也不该）。
- **验收**：两轨 9 种组合全部正确渲染；迁移零丢失；主题切换零闪白（Z-68 基线保持）。

### V-80 强调色对比度守护

- **定位**：主题工坊选强调色时实时计算与前景/背景的对比度（WCAG），不达标（<4.5:1）时显示琥珀警示并推荐 3 个近似达标色（一键采用）。
- **动机**：「用户选了个粉色强调色然后所有选中文字看不清」是主题自由的暗面；守护是设计系统的责任，但只建议不强制。
- **具体内容**：① 对比度计算本地即时；② 推荐色 = HSV 邻域搜索最近达标色；③ 「仍然使用」允许（用户主权，但 toast 一次性提醒）。
- **不做清单**：不做强制达标（不劫持用户选择）；不做自动全局调色。
- **验收**：30 色测试集警示判定与 WCAG 公式一致；推荐色全部达标且视觉邻近。

## 域 I：开放与工具（V-81…V-90）

### V-81 开放安装器

- **定位**：winget 前端：搜索 / 安装 / 更新 / 卸载（列表、详情、进度、源选择）；无 winget 时诚实降级提示「未检测到 winget，指路安装」；每次操作逐次确认。
- **动机**：Windows.md 7.3 的包管理是现代 Windows 软件管理的正道；「装软件」从「搜索引擎找官网」进化为「一条命令」，但命令行门槛需要 GUI 补全。
- **具体内容**：① 调用本机 winget CLI（零自带源、零自动出站——网络行为全部由 winget 自身发生且逐次可见）；② 「可更新列表」一键全览；③ 安装进度流式解析 winget 输出。
- **不做清单**：不做 winget 之外的源（Chocolatey/Scoop，生态分散）；不做静默批量安装；不做自建软件目录（绝不越权当商店）。
- **验收**：搜索/安装/更新/卸载 20 例全链路正确；无 winget 降级诚实；操作确认不可跳过。

### V-82 环境变量编辑器

- **定位**：用户级环境变量的 GUI 编辑器：PATH 分行列表（拖拽排序、启用禁用行）、变量增删改；改动前自动备份，一键回滚到任意备份点。
- **动机**：PATH 是 Windows 用户最常改也最容易改崩的东西；系统编辑器是一个文本框（分号地狱）。分行+备份+回滚是三大刚需。
- **具体内容**：① 仅用户级（系统级如实只读展示，标注「需要管理员且风险高，本轮不做」）；② 备份保留最近 10 份；③ 改动生效范围明确提示（新进程生效）。
- **不做清单**：不做系统级编辑（提权风险）；不做变量 diff 视图（V-89 通用 diff 可覆盖）。
- **验收**：PATH 增删排序启停 20 次正确；回滚逐字节还原；改后新进程变量生效。

### V-83 计划任务工坊

- **定位**：环境内动作的定时执行：主题切换、壁纸切换、性能模式、提醒、速记回顾、「运行指定命令面板命令」；触发器：时刻 / 间隔 / 空闲 / 登录后。
- **动机**：Windows.md 4.3 计划任务的用户级价值（「晚上十点自动切深色」），系统任务计划程序门槛过高；环境内动作的定时是安全子集。
- **具体内容**：① 动作白名单制（只有环境注册的动作可被定时，绝不执行任意命令）；② 下次触发时间预览；③ 任务列表启停、编辑、执行日志（最近 20 次）。
- **不做清单**：不做系统级任务创建（绝不写系统任务计划程序库）；不做任意命令执行（白名单红线）。
- **验收**：四类触发器各 10 例执行正确；白名单外动作不可配置；执行日志与实际一致。

### V-84 文件关联快照与还原

- **定位**：当前文件关联表（扩展名→程序）快照：命名保存、任意两快照 diff、一键还原到指定快照。
- **动机**：全家桶软件最大的恶 = 静默劫持关联（「PDF 怎么又被 XX 浏览器打开了」）；快照+还原是用户的后悔药。
- **具体内容**：① 快照内容 = 用户级关联（HKCU）；② diff 视图复用 V-89 引擎；③ 还原逐条列出将改回的关联并确认。
- **不做清单**：不做关联实时监控告警（哨兵体系领地）；不做机器级（HKLM）关联操作。
- **验收**：快照→篡改 20 项→还原，关联逐项恢复；diff 零漏报；HKCU 外零写入。

### V-85 卸载善后报告

- **定位**：应用卸载后扫描常见残留位置（ProgramData、AppData、注册表卸载键残留）：只报告（路径+大小），用户勾选后才删除，且删除一律移入环境回收站（可反悔），绝不覆写。
- **动机**：Windows 卸载的「删不干净」是三十年的痛；善后扫描是正当需求——关键是克制：报告在前、确认在中、回收站兜底。
- **具体内容**：① 扫描范围白名单（仅用户目录与已知残留模式，不碰系统目录）；② 勾选删除进回收站（U-27 体系）；③ 报告可导出。
- **不做清单**：不做强制清理、不做注册表深层清扫（风险失控）；**绝不做多次覆写/焚毁类操作（N-34 红线）**。
- **验收**：10 个真实卸载场景残留识别正确；删除全部可从回收站还原；系统目录零触碰。

### V-86 启动项延迟编排

- **定位**：任务管理器启动项每项可设延迟启动（0–120s，默认 0=立即），启动日志时间轴可视化每项实际启动时刻。
- **动机**：开机 40s 里 30s 是启动项打架；延迟编排（先系统就绪、再逐个拉起）是无硬件升级的最大提速（与 V-60 归因联动成闭环）。
- **具体内容**：① 延迟 = 环境启动完成后 N 秒拉起（不依赖系统任务计划）；② 日志时间轴含「若无延迟的理论对比」；③ 安全类启动项（杀毒）默认不显示延迟选项。
- **不做清单**：不做智能自动编排（绝不替用户决定顺序）；不做依赖感知并行（复杂度）。
- **验收**：10 启动项 × 差异化延迟全部按时拉起；日志时间轴与实际偏差 <1s；总启动时间改善可量化。

### V-87 服务依赖图

- **定位**：任务管理器服务 tab 增强：选中服务显示其依赖树（依赖谁/被谁依赖），批量启停操作前置影响分析（「停止 A 将影响 B、C」）。
- **动机**：服务操作最大的风险是不知情连锁；依赖可视化把「胆大操作」变成「知情决策」。
- **具体内容**：① 依赖数据走 SCM API（只读查询）；② 图形走简化树（不做力导向花活）；③ 影响分析在确认框中列全。
- **不做清单**：不做服务属性编辑（描述/启动类型，系统 mmc 领地）；不做自动修复依赖链。
- **验收**：20 个系统服务依赖树与 services.msc 一致；批量操作影响分析零漏项。

### V-88 CLI 交互式教程

- **定位**：`variable-cli tour` 命令：10 分钟渐进式交互教程（窗口管理 → 搜索 → 剪贴板 → 主题 → 自动化五课），每课命令实操+即时验证。
- **动机**：CLI（N-29）能力强大但学习曲线陡；交互教程是开源顶级项目（git 走的 githut-style tutorial）验证过的采用率放大器。
- **具体内容**：① 纯本地、零网络；② 每课结束有 mini 验证（跑对了才下一课，可跳过）；③ 进度本地保存。
- **不做清单**：不做视频/动图教程（维护负担）；不做交互式沙盒之外的自由命令实验。
- **验收**：五课全流程走通；进度保存恢复正确；跳过逻辑自由。

### V-89 配置对比工具

- **定位**：任意两份导出配置（Z-54 格式）的结构化 diff 视图：按设置域分组、增/删/改三色标记、点击跳转对应设置页。
- **动机**：「我的配置和备份差了什么」「两台机器设置不一致排查」；文本 diff 工具看 JSON 是自虐，结构化 diff 是配置管理的最后一块。
- **具体内容**：① diff 算法语义化（数组按 ID 对齐而非下标）；② 与 V-84（关联快照 diff）共用引擎；③ 差异可生成「补丁应用清单」（逐条勾选应用）。
- **不做清单**：不做配置合并自动仲裁（人来决定）；不做云同步 diff。
- **验收**：30 项差异注入的两组配置 diff 零漏零误；补丁清单应用正确。

### V-90 沙盒试用面板

- **定位**：主题 / 壁纸 / 壁纸组合 / 插件（只读类）在沙盒实例（N-35 多环境分身）中先试用：一键「在沙盒打开此主题」，满意后一键「应用到主环境」。
- **动机**：「怕折腾坏不敢换主题」是个性化的最大阻力；沙盒试用是零风险试衣间——N-35 基建的价值放大器。
- **具体内容**：① 试用范围白名单（主题/壁纸/只读插件，写操作类插件不支持并如实说明）；② 「应用回主环境」走标准配置写入路径；③ 试用会话隔离（沙盒内改动不泄漏）。
- **不做清单**：不做试用时长限制；不做自动对比截图（用户自己看）。
- **验收**：10 主题/壁纸试用-应用全链路正确；沙盒隔离零泄漏；不支持项提示诚实。

### V-91 演示模式

- **定位**：快速面板一键「演示模式」：免打扰 + 保持唤醒 + 可选指针增强（V-63 轨迹 + V-64 涟漪一键开）；再次点击全部原样恢复。
- **动机**：投屏前 30 秒的仪式：关通知、防息屏、让指针可见——三个动作一键化（Windows 演示设置的现代化）。
- **具体内容**：① 进入/退出 toast 明确列出改变了什么、恢复了什么（诚实清单）；② 与 V-54 唤醒定时正交（演示模式的唤醒随模式退出解除）；③ 异常退出环境时退出钩子恢复全部状态。
- **不做清单**：不做投屏检测自动进入（误判风险）；不做演示计时器。
- **验收**：进入/退出 20 次状态零残留；异常退出恢复钩子正确；清单与实际状态一致。

### V-92 关机倒计时取消

- **定位**：环境触发的关机/重启执行前插入 10 秒可取消倒计时（环形进度 + 「取消」大按钮）；倒计时结束才真正执行。
- **动机**：误触关机是「一天白干」级惨案；10 秒后悔窗口成本极低、价值极高。
- **具体内容**：① 倒计时 UI 全屏轻遮罩（不吓人但不可忽视）；② `Esc` = 取消；③ 从命令面板/脚本触发的关机可带 `--force` 跳过（脚本通道明示）。
- **不做清单**：不做系统关机事件拦截（只管环境自己发起的）；不做自定义倒计时时长（10s 定档，防选择疲劳）。
- **验收**：误触场景取消 50 次全部成功；`--force` 通道明示且日志记录；倒计时 UI 零渲染负担。

### V-93 Windows 偏好搬家向导

- **定位**：首次运行（或设置页手动触发）向导：从当前 Windows 读取壁纸、强调色、深浅色偏好、区域格式、24/12 小时制，逐项预览、勾选导入。
- **动机**：新用户第一分钟「这不是我的电脑」的疏离感，根源是所有偏好要重设；搬家向导把疏离感变成「它比我还懂我」。
- **具体内容**：① 只读读取系统偏好（注册表/系统 API 用户级）；② 每项独立勾选 + 实时预览；③ 不导入任何系统隐私数据（只搬偏好，红线）。
- **不做清单**：不做反向导出（写回系统，越权）；不做第三方软件偏好搬运。
- **验收**：五类偏好 20 台不同配置机器读取正确；导入逐项生效；跳过全部项也能正常完成向导。

### V-94 键位体检医生

- **定位**：`variable-cli keymap doctor`（+设置页入口）：全量扫描键位注册表，报告冲突对、幽灵键位（注册但无处理器）、让位协议违规（未让位系统组合）、未被使用的空闲推荐槽位。
- **动机**：键位体系越强大越需要体检工具；冲突的排查从「凭记忆翻代码」变成「一条命令出报告」（M-83 是 CI 门禁，本项是运行时医生）。
- **具体内容**：① 报告分级：error（冲突）/ warn（违规）/ info（空闲槽）；② 扫描含插件注册的键位；③ 报告可导出（诊断包格式）。
- **不做清单**：不做自动修复（报告给人，人做决定）；不做实时监听告警。
- **验收**：注入 10 类问题样本全部检出零漏报；正常态零误报；扫描 <2s。

### V-95 卸载器数据抉择

- **定位**：NSIS 卸载流程升级：卸载时选择「保留我的数据」（设置/主题/速记/剪贴板历史）或「彻底清理」，清理前逐屏列出将删除的目录清单（可展开）。
- **动机**：卸载软件是用户信任的最后考验——「偷偷留垃圾」与「偷删用户数据」是两大恶名；诚实清单是唯一解。
- **具体内容**：① 清单按数据类型分组（大小可见）；② 彻底清理走标准删除（**回收站式或直接删除由用户选择，绝不做覆写**——N-34 红线）；③ 保留数据的再安装识别与恢复。
- **验收**：两条卸载路径各 5 次执行正确；清单与实际删除逐项一致；重装后保留数据恢复。

### V-96 桌面归档建议

- **定位**：桌面图标数量超过阈值（默认 80，可调）时，一次性轻提示「桌面有点挤了，要归档吗？」：一键把非系统图标移入 `桌面归档/2026-09` 文件夹（桌面可直达）。
- **动机**：桌面从工作台变垃圾场是渐进式的，用户自己注意不到；温和的建议 + 可逆的归档是桌面卫生的闭环。
- **具体内容**：① 提示每 30 天最多一次（克制）；② 归档前列出将移动的清单（可排除个别项）；③ 归档文件夹自动在桌面创建快捷方式（一键可达）。
- **不做清单**：不做自动归档（永远询问）；不做归档定时任务（V-83 可由用户自建，不默认）。
- **验收**：阈值触发正确；归档清单与实际移动一致；排除项保留原位；快捷方式可达。

### V-97 右键打印

- **定位**：文件右键菜单「打印」：走系统默认打印关联（ShellExecute print 动词），多选批量打印；无打印机关联的文件类型如实置灰。
- **动机**：Windows.md 描述的标准右键能力；「右键打印 PDF」是办公场景的地板功能，环境文件管理器补齐它才算完整。
- **具体内容**：① 关联判断走系统（不自带打印逻辑）；② 批量 >5 个文件确认；③ 打印失败（脱机/缺纸）透传系统错误（如实）。
- **不做清单**：不做打印预览（系统打印对话框自带）；不做打印机选择（系统对话框领地）。
- **验收**：PDF/文本/图片三类 10 文件打印路径正确；无打印机环境置灰且提示诚实。
