# VARIX 双域系统 · AI 分工执行清单

> 用途：把 `docs/VARIX双域系统施工总案.md`（逻辑）与 `docs/VARIX双域系统总施工清单.md`（进度勾选）
> 切成可并行认领的任务块。每个 AI 认领一个或多个块，只做块内的事。
> 认领方式：在本文档对应块的「认领」处填上执行者名字/会话标识 + 日期。

## 分工总览

```
A 组（内核线）：AI-K1 引导与按键 → AI-K2 用户态 → AI-K3 驱动与真盘
B 组（界面线）：AI-V1 Servo 移植 → AI-V2 垫片 → AI-V3 桌面功能迁移
C 组（数据线）：AI-D1 白名单总线 → AI-D2 Uxv 跨系统交换
D 组（兼容线）：AI-W1 Wine 移植 → AI-W2 引擎通道
E 组（基建线）：AI-I1 U 盘五分区 → AI-I2 升级灾备 → AI-I3 基准生态
F 组（体验线）：AI-U1..U5 按专项分包（20 个专项轮转认领）
```

依赖关系：B 组依赖 A 组用户态（AI-K2）；C/D 组依赖 A 组用户态；E1 可立即开工；F 组各步随时跟进度插队。

## 全局纪律（每个 AI 开工前必读）

- 门禁三线全绿才许交付：V 线 tsc+vitest / K 线 ktest+kcheck / 后端 cargo test。
- 每块交付须过六维验收（视觉/逻辑/代码/开放性/简洁性/完善性，见总案框架节）。
- 关键文件改动后必须 grep 复核（Edit 有静默失效前科）。
- 内核文件禁并行 Edit：AI-K1/K2/K3 串行推进内核目录，彼此交接在日志里注明。
- 过程产物进 `_attic/`；文档只进 `docs/`；`.bat/.cmd` 纯 ASCII+CRLF。
- 诚实标注：未做完写 SKIPPED + 原因，绝不臆造。
