

# AURORA-1000 AI 分工完成图（完整版 · 有界面的完整系统）

> 共 **40 个 AI（AI-01 ~ AI-40）**，围绕「**让内核成为有界面的完整系统**」全域分工，每域 25 项，合计 **1000 项功能（A001~A1000，A = Aurora）**。
> 状态：⬜ 未开始 / 🔶 进行中 / ✅ 完成
> 纪律：
> 1. 每个 AI 只写自己域目录 `kernel/varix/src/<目录>`；改 VARIX/PULSAR/QUASAR/TRINITY 既有模块先登记「依赖收口」。
> 2. 完成一项：更新本图 → commit（`aurora1000(ai-XX): Axxx <功能名>`）→ 推送 GitHub。
> 3. 十四律军规贯穿；编号 AI-01 起、A001 起，连续无跳号。
