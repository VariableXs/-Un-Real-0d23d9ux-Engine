- 引导决策：`bootopt: default=varix timeout=3s`

### 本次踩坑记录（复现时注意）
1. **本机无 xorriso**：已从 MSYS2 仓库下载 xorriso 1.5.8 + msys2-runtime 3.6.9 便携包解压到
   `_attic/tools/xorriso-portable/usr/bin/`，加 PATH 即可用（无需装 MSYS2）。
2. **`tools/build-iso.py`（pycdlib 替代实现）已失效**：产出的 ISO 在 Limine 阶段
   `PANIC: iso9660: failed to read file data`，与当前 Limine v12 布局不兼容，勿再使用（建议后续修复或删除）。
3. 无头冒烟命令：
   `qemu-system-x86_64 -cdrom varix.iso -serial stdio -display none -no-reboot -no-shutdown -m 512M -M q35`

## 二、口径界定（重要）

- **QEMU 虚拟机：可引导、可跑完自检，判定为"能正常运行"**。
- 串口冒烟的终点是 `boot complete — halting`（内核态）；**图形桌面接管（gfxsrv 合成 + vport shell 四进程）在无头串口模式下不可观测**，真机上以"开机直达 Variable 桌面"为最终判定（VARIABLE-200 并入判定口径）。
- 更新回滚 / 72h 压测零 panic 属于真机阶段验收项，当前未经实测。

## 三、真机 smoke 准备（对应 docs/真机清单.md）

**产物就绪状态：**
- `varix.iso`（仓库根，今日构建）——Rufus/Ventoy DD 模式烧 USB 即可，ISO 本身就是 USB 产物（DD 可写 + 混合 MBR 已校验）
- BIOS/UEFI 双引导：Limine v12（BIOS El Torito + UEFI ESP 树均在位）

**4 类机器的 BIOS 预设（照清单执行）：**
1. Intel 12/13 代：Secure Boot 关、CSM 关、AHCI、Above 4G 开
2. AMD 7000 系：Secure Boot 关、Resizable BAR 开
3. 老 H81：CSM 开、Legacy 启动、Fast Boot 关
4. 笔记本：Secure Boot 关、独显直连关

**每台记录**：型号 / BIOS 版本 / 启动模式 / 串口日志（与 `fixtures/qemu-smoke.golden` 比对要点见清单）。

**通过线**：内核自检横幅无三重故障、`cpu_reset`=0；终极线 = 开机直达 Variable 桌面。
