# VARIX + Variable 双域系统总施工清单

> 终局目标：U 盘随插随用；开机默认进 VARIX 内核 + Variable 界面；Windows 以镜像形式随盘携带；
> 软件三通道（Wine / 隐形引擎 / 纯 Windows）；CPU/GPU 由内核统管；四层物理隔离；引导页 5 秒默认可配置。
> 门禁沿用三线全绿（V/C/K）+ 每阶段实机验收。
> 分工：本清单管"进度怎么勾"（阶段+专项两层）；每步的详细逻辑与步骤级六维验收（视觉/逻辑/代码/开放性/简洁性/完善性+体验加验）见《VARIX双域系统施工总案.md》。
