# Z-56 扩展兼容承诺与版本矩阵

> AI-14 开放接口组 · 承诺文档。与运行时数据源 `src/lib/ecoMatrix.ts` 同步维护；
> 启动自检 `matrixSelfCheck()` 保证两者不打架。

## 1. 兼容承诺（Engine 1.5 起）

1. **向前兼容 N-1 个 minor**：当前引擎 minor 的上一代资源格式仍可导入；
2. **弃用策略**：标记弃用的格式仍可导入并提示迁移，**≥2 个 minor 后移除**；
3. **拒收只有两种**：格式过旧（< minSupported）或过新（> maxSupported，提示升级引擎）；
4. **矩阵随版本发布更新**：引擎 minor 升级时，本表与 `ecoMatrix.ts` 必须同 commit 更新。

## 2. 版本矩阵（当前）

| 资源类型 | 格式版本 | 最低支持 | 最高支持 | 状态 | 计划移除 |
|---|---|---|---|---|---|
| theme（.vxs 主题 / 令牌覆盖） | 1 | 1 | 1 | 支持 | — |
| script（.vxsc 脚本安全屋） | 1 | 1 | 1 | 支持 | — |
| config（Z-54 分享信封） | 1 | 1 | 1 | 支持 | — |

## 3. 三类第三方资源边界

| 类型 | 载体 | 校验入口 | 失败表现 |
|---|---|---|---|
| theme | `.vxs`（U-39）/ 令牌 JSON | `validateTheme`（Z-50） | 拒绝导入并列出 error |
| script | `.vxsc` 清单（U-38） | `safehouse_review`（能力白名单 + 数据目录围栏） | 未声明能力一律拒绝 |
| config | Z-54 信封 | `openEnvelope`（schema → checksum → 摘要） | 坏 checksum 拒绝并提示重新分享 |

## 4. 判定示例

- `checkEcoCompat("theme", "1")` → `supported`；
- `checkEcoCompat("theme", "0.1")` → `unsupported`（过旧，请重新导出）；
- `checkEcoCompat("theme", "99.0")` → `unsupported`（过新，请升级引擎）；
- 弃用条目 → `deprecated`（可导入 + 迁移提示；必须在矩阵中登记 `removalAt`）。

## 5. 机制保证

- 矩阵自检：条目齐全、min ≤ max、deprecated 必带 removalAt（`matrixSelfCheck`，单测覆盖）；
- 设置页 → 开放接口 → 扩展兼容承诺（Z-56）只读展示矩阵与逐项判定。
