# M-35 滚轮语义全局规范

范围：壳层公共滚动容器（explorer / 开始菜单 / 通知中心 / 设置 / 任务栏）。四大独立软件内部不在范围（隔离红线）。

## 语义

- 纵向滚动容器：滚轮 = 纵向滚动。
- 横向滚动容器（Shift 无语义冲突处）：Shift + 滚轮 = 横向滚动。
- 支持缩放的视图：Ctrl + 滚轮 = 缩放。
- 任务栏空白区滚轮 = 音量步进（settings.wheelVolume，默认关；开启后复用音量浮标联动）。

## 行为表（实施记录）

1. 盘点壳层滚动容器：设置页、开始菜单列表、通知中心、explorer 文件区、任务栏溢出区等，逐一按上表核对。
2. `wheelVolume` 默认 false，避免音量误触；切换在设置页快捷键区。
3. 四大空间内部滚动/缩放语义由各空间自治，本规范不做跨域修改。
