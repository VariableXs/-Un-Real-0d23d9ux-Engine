# 杀软误报处理（B-35）

## 流程（目标 ≤48h 闭环）

1. 收到用户误报反馈（GitHub Issue / 邮件），记录：杀软名与版本、误报文件（NSIS exe / 便携 exe / .uxv）、检测名（如 Trojan:Win32/…）；
2. 本地复检：对照官方发布哈希（Release 附 SHA256），确认为官方构建产物；
3. 向杀软厂商提交白名单申诉：
   - Microsoft：https://www.microsoft.com/wdsi/filesubmission
   - 记录提交回执编号于下表；
4. 修复后更新本表状态；用户侧确认恢复。
