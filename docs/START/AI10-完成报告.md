## 五、已知边界（如实声明）
- V-36 特殊名防呆覆盖 Windows 保留名/非法字符/结尾点空格三类；UNC 路径内核限制无法防。
- U-29 审计/修复基于 zstd 帧级校验，整档位翻转可捕获；不支持 zip/rar（格式自证红线：只用自有 .vxa）。
- U-30 信任链在非 Windows 平台返回 unsupported（WinVerifyTrust 不可用）。
- U-32 防火墙为应用级域名策略引擎（进程画像 + 域名匹配），非内核 WFP 驱动级拦截。
- U-34 L3 级擦拭依赖文件系统覆写语义，SSD wear-leveling 下不承诺物理级不可恢复（如实提示用户）。
- 隐身会话目录为一次性覆写焚毁，非内存盘挂载（Windows 语义下等效"关闭即焚"）。
- 并发会话多次回滚共享文件（ipc.ts/ExplorerWindow.tsx/dictionaries.ts），已全部幂等恢复；本轮提交前最后一次全量自检通过。
