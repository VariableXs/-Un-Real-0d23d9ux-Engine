## 实机过程发现与处置

1. **日志半行错位假信号**：`applog-<天>.log` 被多实例并发追加（僵尸 pid 38600 旧二进制仍在 Session 1 后台运行），出现「新时间戳开头 + 旧格式中间片段」的粘合行（`attach tabbit browser.exe: L3 画面捕获已启动 hwnd=3738726`），grep 时间窗过滤时呈假阳性。核对原文：该格式日志全部出自旧实例时段（1789483xxx），新实例（38564，M3 二进制）零抓屏。僵尸进程受跨会话权限墙保护（taskkill/Stop-Process 均拒绝访问），不影响 Session 2 桌面验收，留待系统重启自然消亡。
2. **旧版 L3 遗留藏窗**：WorkBuddy 宿主窗（hwnd=855570）仍处 (-32000,-32000) 藏窗态（旧版 L3 产物）。它在 BUILTIN_IGNORED 名单（R7 硬约束：平台窗永不干预），看门狗正确地没有碰它。M3 的 `needs_reveal` 唤醒预处理会在未来任何合法收编路径中把同类遗留藏窗还原后再嵌入（embed_close/close_all 亦有 is_offscreen 条件还原兜底）。
3. **空格键假丢**：`pyautogui.typewrite(interval=0.02)` 高速输入时空格偶发丢失，单独 `press('space')` 复核正常 —— 输入链路无问题。
