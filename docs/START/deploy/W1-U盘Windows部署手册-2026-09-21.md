### 0.4 发行版结论：LTSC 2024 为什么没走（2026-09-21 22:11 实测）

- 微软**公开下载 API 实测只提供消费版**（Fido=官方 API 解析，Release 列表当前仅 25H2 v2）；LTSC 官方渠道仅 VLSC/MSDN 订阅（需用户账号）与 90 天评估版（过期需重装，不适合长期 U 盘系统）；
- 第三方镜像未经授权再分发 + 无法验证完整性，**不采用**（版权与供应链安全硬线）；
- 消费版数字许可证不能激活 LTSC——激活也是渠道问题的一部分；
- **补偿措施 = §3 步骤 5c「LTSC 化」**：部署后卸载预装应用、关闭消费者后台连接体验——干净度接近 LTSC 的目标由配置达成，而非发行版；
- 用户日后若有 MSDN/VLSC 订阅拿到 LTSC ISO，放进 `D:\VarixDeploy\` 即可换底重来，流程不变。

### 0.2 部署路线拍板（2026-09-21 21:46，用户确认）：**路线三——干净装 + WE 壁纸库搬家 + 数据走 SHARED**

- **部署内容**：官方 Win11 干净安装进 WIN_ENGINE（不是克隆，系统瘦、余量 ~270GB）；
- **数据**：文档/常用文件放 SHARED（W:）——三世界同一物理分区，天然同源，无需克隆；
- **Wallpaper Engine 壁纸库**：整体搬家到 SHARED（`W:\SteamLibrary`），Steam 加库文件夹即用——内置盘与 U 盘 Windows 共用同一份壁纸文件（步骤见 §2.5）；
- **软件**：U 盘 Windows 侧按需重装（引擎通道成熟后，日常软件也可由引擎/内置盘世界承担）；
- **如实声明（拔盘影响）**：壁纸库搬到 W: 后，**拔掉 U 盘时内置盘的 Steam/WE 会提示"库不可用"**——壁纸跟着盘走是同源的代价；若想拔盘后内置盘也有壁纸，可在内置盘留一份副本（占双份空间，由用户自行权衡，不阻塞部署）。

### 0.3 路线三专属前置：WE 壁纸库搬家（部署前在内置盘执行一次，用户动手，AI 提供步骤）

1. 确认 W:（SHARED）在场且剩余空间 > 壁纸库体积（先看 `Steam\steamapps\workshop\content\431960` 文件夹大小）；
2. Steam → 设置 → 存储 → 添加库文件夹 → 选 **W:\**（生成 `W:\SteamLibrary`）；

4. 迁移完在内置盘重启 WE 验证：壁纸列表完整、可正常应用；
5. 完成后此步骤卡勾结——U 盘 Windows 侧只剩"装 Steam + 登录 + 加同一个库文件夹"（§3 步骤 5）。

## 4. 快速启动关闭（S0.4，若尚未执行）

- 提权：`Set-ItemProperty 'HKLM:\SYSTEM\CurrentControlSet\Control\Session Manager\Power' -Name HiberbootEnabled -Value 0`
- 回读验证 =0 → 重启两次 → 关机再开机应出现引导菜单（不再直跳 Windows）。
- 回滚：HiberbootEnabled=1 即还原。**这是全程唯一允许的"写内置盘"操作（单注册表键、可逆）**。
