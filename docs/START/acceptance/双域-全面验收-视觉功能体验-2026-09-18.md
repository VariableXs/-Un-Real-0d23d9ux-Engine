- [x] **sys_write(fd=1) console 通道纳入镜像门控**（`proc/ring3.rs` 改经 `console::mirror_bytes`）：原实现无条件 `put_byte` 直写 VGA——全速重绘时代每轮被 shell 覆盖不可见；按需重绘后 stdout 回显行 + console 滚动（整屏上移 16px）会永久破坏 shell 画面（07 屏实机像素证据）。boot 链期 mirror 开启，stdout 上屏语义不变；shell 会话期只走串口。
