## 要点摘录

- **结论**：分阶段立项可行；当前只启动 M1（virtio-gpu 2D 通路加速，软件合成保持）；M2 起依赖 QEMU `virtio-gpu-gl`/venus 直通实测数据，不达标则 M3 无限期搁置、M1 成果保留。
- **兜底原则**：SoftGpuChannel 永久保留为默认后端，Vulkan 后端任何阶段失败回退软通道，不阻塞引导（与 xHCI 评估同款兜底逻辑）。
- **明确不做**：compute/游戏级 3D 管线、GPU 虚拟化多租户、反作弊场景（走纯 Windows 通道）。
