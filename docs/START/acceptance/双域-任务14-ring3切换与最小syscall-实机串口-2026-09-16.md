### 途中修复的真实缺陷

1. **诊断地址笔误（红鲱鱼）**：sys_write 诊断块 `translate(0x401_0000)` → `0x401_000`（从未映射地址造成 tr=None 假象）。
2. **ELF 同页多段覆盖 PTE（核心装载 bug）**：hello.elf 的 .rodata@0x401000 与 .data@0x401088 同页，原装载循环每段每页各分配新帧并整体覆写 PTE，W 帧顶掉 R 帧 → MSG 读出全零。修复：页账本（同页共享一帧、按页内真实偏移拷贝、flags 取并集）。
3. **pfh::ensure_pt 大叶拆分**：原 `else if e & P_HUGE != 0 && shift != 21` 排除 2MiB 大叶，把大叶目标帧当页表走、往活内存写伪 PTE。修复：统一拆分（leaf_shift=shift-9，子项继承 user 位）。
4. **exit pid 空转**：sys_exit 硬编码 pid=1（hello 实际 pid=2），exit/reap 空转、"slot_free_again=true" 假通过。修复：DEMO_PID 静态槽登记真实 pid，reap 失败如实 kwarn 并停机。
5. **QEMU 11.1 iretq 窗口 CS 槽 artifact（外部环境问题，守卫兜底）**：偶发地，从用户态进入的中断在返回前 CS 槽被染成 0x2b（=TSS 选择子|RPL3；GDT[5] 非 code 段，真实硬件 iret 必 #GP(err=0x28)），该 QEMU 版本还会容忍首次非法加载（描述符缓存沿用 GDT[3]+Accessed）。已排除内核/用户态写坏（GDT dump 全对、STAR 哨兵完好、hello 用户自检 CS=0x1b），定性 TCG artifact。**保留 `guard_frame_cs` 正式守卫**：iretq 前校验 CS 槽，按目标特权级（resume RSP 用户半区→0x1b，否则 0x8）复位并留痕——真实硬件上同样是正确防御。
