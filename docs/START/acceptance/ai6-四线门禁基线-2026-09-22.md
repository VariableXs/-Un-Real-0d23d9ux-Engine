## 2. 本次修复的门禁回归（AI-6 开单 → 就地修复）

### 2.1 `shell::we_wallpaper::tests::extract_survives_duplicate_keys` FAILED（V 后端）
- **现象**：断言 `extract_first_selected_file(raw) == Some("D:/steam/.../序列 01.mp4")` 得 None。
- **根因**：WE 库搬家（W1-Finalize 把 `D:/steam` 迁至 `W:\SteamLibrary`）后，测试夹具路径**在这台机器上不再存在**；而函数后来加了「文件存在性检查」（防 WE -control ANSI 乱码坏路径的加固），检查把夹具路径跳过 → None。环境变化暴露的**测试机器相关性**缺陷。
- **修复**：抽取核拆为 `extract_first_selected_file_if(raw, exists: impl Fn(&str) -> bool)`（可注入谓词），生产包装传真实 `fs::metadata`，测试传 `|_| true`（恢复机器无关性，加固语义原样保留）。修复后 348/0。
