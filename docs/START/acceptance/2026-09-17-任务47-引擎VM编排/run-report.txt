一、交付文件
  portable/AI-P/Engine-Orchestrator.ps1
      - 五态状态机：Closed(默认)->Launching->Ready->Hibernating/Hibernated->Ready；
        任意态->Failed；TRANSITIONS 表显式建模，非法转移 Assert-Transition 抛错拒绝。
      - 差分盘挂载：HyperV 用 New-VHD -Parent 差分链 + Mount-VHD；
        Qemu 用 qemu-img 建 overlay（QEMU 先行等价 Mount-VHD）。
      - VM 拉起：HyperV 用 New-VM/Start-VM（代际2/关 Secure Boot/动态内存/直挂差分盘，参数化）；
        Qemu 用 qemu-system-x86_64（本环境真实可跑）。
      - 就绪探针：复用 47631 心跳语义（src-tauri/src/vm_agent.rs）——连 127.0.0.1:47631
        发 PING 期望 READY pid=...；agent 回连 47632 发 READY/EXIT 的语义在心跳模拟器中复刻。
      - 保活：就绪后空闲检测心跳轮询（近零占用）。
      - 休眠/恢复：HyperV Save-VM/Restore-VM；Qemu HMP savevm/loadvm 写差分盘快照。
      - 幂等：拉起中/就绪态 LaunchLocked 禁止二次拉起，重复触发返回既有实例不双开。
      - 心跳超时：超过 HeartbeatThresholdSec 未 READY 判超时 -> 重启策略（kill+重拉 agent）-> 超限转 Failed。
      - 状态持久化到 -StateDir\engine-orc-state.json（断点续作）。
