## 三、验收与补齐过程中发现并已修复的真问题

1. **AI-29 半成品入主**：`ai29Checks.ts` 曾被工作区半成品改动把 10 项断言期望值改错（`batteryMinutes` 单位、不存在的 `profileId` 字段、图层去重语义等）。→ 整体恢复到与模型一致的 759e188 版本，3/3 用例绿。
2. **ca-core 4 项断言与实现矛盾（真红却宣称全绿）**：
   - `ai17.rs` X04211（单点归一后恒为 bit0，非 bit4）、X04214（`hw_score=9−汉明距`，满距 0 分，与 X04208/X04220 矛盾）、X04221（九宫格指纹无共线不变性，改为包围盒归一不变）、X04242（同名命中应为真，查询改用异词）；
   - `ai18.rs` X04427：`sec_sensitive` 提示词表漏"卡号"，补上。
3. **AI-09/AI-10 ID 生成错位（500 项无法对账的真 bug）**：`desktop-icons/checks.ts`、`background/checks.ts` 的 `zip(start)` 起始值丢零/错位（20001~20226、20251~20476），生成 `X20001` 等越界 ID。→ 修正为 `2001~2476` 并补 `padStart(5,'0')`，500 项全部落回 X02001~X02500。
4. **【本轮】跨族编号误植 2 处**：`wtree.rs` 的 `X01515`（X01515 属族0061，已由 `framesched.rs` 覆盖）归位为 `X01537`；`routing.rs` 的 `X01518` 为同族误植重复项，移除后族0063 仍恒为 25 项。这 2 处正是"领域02 散项缺 2"的根因。
5. **【本轮】`X13001b` 畸形 ID**：`groupI.ts` 中存在非 `X\d{5}` 的 `X13001b` 变体 → 归位为 `X13032`，V 线 ID 集合恢复规范。
6. **【本轮】内核 no_std 构建 37 个错误**：`inkstack.rs` / `shell/overlay.rs` / `shell/tbengine.rs` 的
   `Vec`/`String`/`format!`/`to_vec`/`to_string` 在 `kernel-image`（no_std）下无法解析，且原有
   `#[cfg(all(not(test), not(feature="kernel-image")))] use std::...` 形同虚设（两个条件互斥，永不为真）。
   → lib.rs 增加 `extern crate alloc;`，并把 `mem::heap::VarixAllocator`（本就实现 `GlobalAlloc` 契约、
   已有 `pub static ALLOCATOR` 实例待用）登记为 `#[cfg(feature="kernel-image")] #[global_allocator]`；
   三个模块改为按 feature 切 `std`/`alloc`。`cargo kcheck` / `cargo kbuild` 均 0 错误通过。
