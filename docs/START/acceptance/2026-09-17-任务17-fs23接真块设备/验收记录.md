## 盘面布局与语义保持

```
LBA base+0          超块（magic "FS23"/version/base_seq/crc23）
LBA base+1..+64     主日志区（64 槽，1 条/块：seq u64/blk u64/tag u32/crc u32 LE）
LBA base+65..+128   副本1（仅 full 档写入）
LBA base+129..+192  副本2（仅 full 档写入）
```

journal 语义逐条与内存版（fs23_journal::Journal）对齐：

- **seq 严格递增**：槽 i 期望 seq = `base_seq + i`（超块水位），断裂/乱序等价撕裂
- **torn 丢弃该点及之后全部**：CRC 不符（半写残留/位腐坏/seq 断裂）→ 停止重放
- **幂等重放**：applied_to 水位去重；同盘面重复 open 结果恒定
- **档位矩阵不变**：off 不落日志 / soft 落盘不 flush / ordered+ 写后 flush / full 三重写（读侧"至少一份完好"救援）
- **检查点仅 tier≥2**；truncate 后超块水位推进、seq 连续；discard_all 同样推进水位
- **超块损坏 → open 保守拒绝**（Err 上层显式 format），绝不静默覆盖旧日志

## 验收一：宿主掉电注入回归 ×10（CrashSim 字节级注入器）

CrashSim 模拟：易失写缓存（flush 才落盘）、第 n 次写后崩溃（易失层丢失）、
第 n 次写撕裂（前 k 字节到达介质）、冻结盘面（掉电后磁盘真实内容）。

| # | 用例 | 注入 | 断言结果 |
| --- | --- | --- | --- |
| ×1 | 干净掉电 | 8 条 append（每条 flush）后掉电 | 8/8 恢复，torn=0 |
| ×2 | 末条撕裂 | 第 8 条只落前 12 字节 | 7 条恢复 + torn=1 |
| ×3 | 写后 flush 前掉电 | 第 5 条槽写后即崩 | 4 条恢复；未确认第 5 条如实丢弃；崩溃后 append 拒绝 |
| ×4 | 档位语义 | soft 不 flush 掉电 / ordered flush 后掉电 | soft 如实全丢 0 条；ordered 8/8 零丢失 |
| ×5 | full 副本救援 | 主份 CRC 破坏 | 副本1 救援，8/8 恢复，torn=0 |
| ×6 | 撕裂点后全弃 | 第 5 条损坏、6-8 完好在盘 | 4 条恢复，第 6-8 条虽完好也弃（语义铁律） |
| ×7 | 链式恢复+检查点 | checkpoint+truncate→append→掉电 | 3 条恢复 seq 水位连续；二次 open 恒定；二次重放零增量 |
| ×8 | 满容量 | 64 槽满 | 第 65 条明确拒绝；恢复后仍满；truncate 后可再写 |
| ×9 | 超块损坏 | CRC/magic 破坏 | open 保守拒绝，不静默覆盖 |
| ×10 | 坏槽覆盖重建 | 恢复后 re-append 覆盖坏槽 | seq 从水位延续不跳号（5,6,7）；再掉电重扫零撕裂 |

另有语义保持用例 5 条（tier 矩阵/Delete+Checkpoint 重放/format 幂等/discard 水位/块大小边界）。

## 验收二：QEMU NVMe 实机掉电循环 ×11 轮

- 环境：QEMU 11.1.0 q35 + NVMe（`nvme-test.img` 512MiB raw 持久文件），内核探针区 LBA 20000+（与 loopback 探针区无交集）
- 协议：每轮启动 QEMU → 内核 open（首轮自动 format）→ append 3 条（tier=writeahead，写后 flush）→ 串口打印 verify → **外部 kill QEMU（模拟掉电）** → 下一轮
- 结果（11 轮全过，串口凭证见本目录 `qemu-serial-fs23-r{1,2,3,10,11}.log`）：

```

r2:  open entries=3  → total=6   torn=0 verdict=ok
r3:  open entries=6  → total=9   torn=0 verdict=ok
...（entries 每轮 +3 单调增长）...
r10: open entries=27 → total=30  torn=0 verdict=ok
r11: open entries=30 → total=33  torn=0 verdict=ok
```

## 边界与如实声明

- 块大小实现固定 512B（非 512 返回 `Unsupported` 如实拒绝，不静默假设）
- 槽记录 24B/512B 块，撕裂检测窗口 = 记录尾部（tag/crc）未达介质判 Bad；
  记录整体未达判 Empty（日志自然终点）——两种撕裂形态均有用例覆盖
- full 档三重写在盘上为"三副本区"，读侧主份优先、副本救援；三份全坏才计 torn
- 掉电注入的撕裂为字节级模拟（半扇区到达介质）；真机瞬时断电的电源级时序
  不在本层验收范围（由介质级 CRC 与档位 flush 语义兜底）
