## 整链叙事（M1–M4 与标志序）

M1（用户态程序）零新增代码：ring3 演示是启动链既有终点（`proc::ring3::run_demo`，任务15 已验收）；里程碑探针在它之前打「读写真盘」三路标志。

```text
会话1（空盘）：
  M2  format base_lba=40000 → 封条 3 条（Write 700..702, tier=3 flush-persisted）
      → ready-for-powercut
  M3  exFAT 挂 SHARED 卷读 /apps.json（322B，契约前缀吻合）
  M4  快照区首写 marker（VARIX-M21-milestone）
  M1  ring3: task15 lifecycle complete（2 轮 spawn/exit/wait + 压力探针）
  —— 脚本 kill QEMU = 模拟断电（NVMe 盘面跨进程持久）——
会话2（同盘面重启）：
  M2  open entries=3 torn=0 replayed=3 base_seq=1（跨断电恢复路径）
      → journal-recovered verdict=ok resumed_seq=4（恢复后可续写）
  M3  exFAT 再读 ok（322B）
  M4  list=3 marker_persisted=true → snapshot-persisted ok（会话1 marker 仍在盘面）
  M1  ring3: task15 lifecycle complete（重启后用户程序再跑通）
```

## 实机证据（QEMU q35 双 NVMe，串口日志 `ms21-session1.log` / `ms21-session2.log`）

```text
-- 会话1（空盘 init 512MiB + 重造 shared exFAT）--
[ INFO] milestone: M2 journal fresh — format base_lba=40000
[ INFO] milestone: M2 journal formatted base_seq=1
[ INFO] milestone: M2 journal sealed entries=3 (tier=3 flush-persisted)
[ INFO] milestone: ready-for-powercut
[ INFO] milestone: M3 exfat-read ok /apps.json len=322 content_ok=true
[ INFO] milestone: M4 snapshot list=1 marker_persisted=false
[ INFO] milestone: M4 snapshot written slot=1
[ INFO] boot complete
[ INFO] ring3: task15 lifecycle complete — 2 轮 spawn/exit/wait + 压力探针全过 — halting
（驱动脚本 kill QEMU = 断电）
-- 会话2（同一盘面重启）--
[ INFO] milestone: M2 journal open entries=3 torn=0 replayed=3 base_seq=1 (powercut-recovery path)
[ INFO] milestone: journal-recovered verdict=ok resumed_seq=4
[ INFO] milestone: M3 exfat-read ok /apps.json len=322 content_ok=true
[ INFO] milestone: M4 snapshot list=3 marker_persisted=true
[ INFO] milestone: snapshot-persisted ok
[ INFO] milestone: M4 snapshot written slot=3
[ INFO] boot complete
[ INFO] ring3: task15 lifecycle complete — 2 轮 spawn/exit/wait + 压力探针全过 — halting
```

- 断电判定：会话2 M2 open 报 `entries=3 torn=0`＝会话1 封条 3 条**跨 kill 全部完好**且零撕裂；`resumed_seq=4`＝恢复后 journal 可继续写。
- 快照持久判定：会话2 `list=3 marker_persisted=true`（score.json@0 由任务18 探针写、marker@1 由会话1 写）→ `snapshot-persisted ok`；会话2 续写 slot=3（追加式槽位推进，容量语义明确）。
- 异常扫描：两会话 `PANIC|KERNEL PANIC` 计数 **0**；既有探针零回归（两会话 `fs23-disk verify verdict=ok`、`shared: verify verdict=ok`）。
