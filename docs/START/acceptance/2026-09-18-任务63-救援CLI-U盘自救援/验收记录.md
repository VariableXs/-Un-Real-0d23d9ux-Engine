## U 盘自救援语义（新增）

- **自动发现**（cli_rescue::discover_data_roots，优先级序）：
  ① `VARIABLE_DATA_ROOT` → ② exe 便携根（.portable / VARIABLE_PORTABLE）→
  ③ 全盘符判据扫描（`X:\.portable` / `X:\data\data.uxv` / `X:\Variable\.portable`）
- **输出写回 U 盘**：缺省 `<数据根父>\rescue\rescue-<epoch 秒>`，不散落宿主
- **向后兼容**：显式路径参数与 B-33 行为完全一致
