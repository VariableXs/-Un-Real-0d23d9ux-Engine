# Z-50 主题令牌开放规范（Theme Token Spec v1）

> AI-14 开放接口组 · 规范文档。第三方主题 = 一组符合本规范的 token 覆盖文件（JSON）。

## 1. 文件结构

```json
{
  "name": "我的主题",
  "tokens": {
    "--v-color-bg": "#0b1122",
    "--v-color-fg": "#dfe7f5",
    "--v-color-accent": "#6f8fd8"
  }
}
```

## 2. 变量命名（变量名即契约）

| 前缀 | 用途 | 值约束 |
|---|---|---|
| `--v-color-*` | 颜色 | `#rrggbb` / `#rgb` / `rgb()` / `hsl()` / `var()` |
| `--v-font-*` | 字体 | CSS font 值 |
| `--v-radius-*` | 圆角 | 像素值（`8` 或 `8px`） |
| `--v-motion-*` | 动效时长 | `120ms` / `0.2s` |

- 变量名必须以 `--v-` 开头（error）。
- 不在上表前缀内的变量：warning（将被忽略，不拦截）。

## 3. 必填变量

缺省回退可用，但以下三项不可省略（error）：

- `--v-color-bg`
- `--v-color-fg`
- `--v-color-accent`

## 4. 对比度底线（防"丑主题"）

正文前景 `--v-color-fg` 与背景 `--v-color-bg` 的 WCAG 对比度必须 ≥ **4.5:1**（error）。
校验器公开 `contrastRatio(fg, bg)` 供第三方自测。

## 5. 校验

- 运行时校验器：`src/lib/themeToken.ts` → `validateTheme(file)`；
- 返回 `{ ok, items[] }`，`items` 区分 error / warning；
- 设置页 → 开放接口 → 主题令牌校验（Z-50）可粘贴 JSON 即时校验；
- `.vxs` 主题包（U-39）导入时对包内 token 文件自动执行同一校验。

## 6. 版本与弃用

- 规范版本：v1（`config`/`theme` 资源格式版本 = `1`）；
- 兼容承诺见 Z-56（`src/lib/ecoMatrix.ts` 与本文档同步更新）。
