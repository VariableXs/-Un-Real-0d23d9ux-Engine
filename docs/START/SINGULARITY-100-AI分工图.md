# SINGULARITY-100（奇点计划）AI 分工完成图

> **版本**：`1.0singularity.q` ｜ **日期**：2026-09-09
> **分工规模**：十路 AI（AI-21 … AI-30），每路 10 项，共 100 项。
> **分工原则**：
> 1. **连续编号块**：每路领一个连续 Q 编号块，边界清晰零争议；
> 2. **文件域隔离**：每路拥有独立的模块文件（`modules/xxx.ts`），跨路共享仅限 S0 地基（只读消费）；
> 3. **接线收敛**：全部对既有文件的接线由 S0/S16 统一完成，各路零越界改既有文件；
> 4. **门禁自证**：每路交付时必须自带单测并过 tsc/vitest，最后 S17 全量门禁统一复验。
> **状态图例**：✅ 已交付 ｜ ⏳ 进行中 ｜ ☐ 未开始

## 12. 交付与同步纪律

1. **顺序**：S0 地基 → 十路并行（模块+测试）→ S16 接线 → S17 全量门禁 → S18 文档与推送。
2. **门禁**：每路交付前自跑 `tsc --noEmit` + 本路 vitest；S17 统一复跑全量（tsc / vitest / cargo check / cargo test / audit）。
3. **隔离**：任何路不得修改既有组件内部逻辑；接线仅 S16 清单五处。
4. **同步**：全部代码 + 三大文档 commit 后 push `VariableXs/-Un-Real-0d23d9ux-Engine` main，本地远端一致才算收官。
5. **诚实**：未实测不打 ✅；环境差异（无电池/无传感器/HDR 不可读）如实降级并在 hub 描述注明。
