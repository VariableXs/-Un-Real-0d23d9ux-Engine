## 2. 完成顺序（每路一条线，按序执行，不许跳批）

### AI-1 容器路（13 批）
```
B-12 → B-13 → B-14 → B-15 → B-16 → B-17 → E-1 → E-2 → B-24 → B-25 → B-26 → E-3 → E-4
```
关键顺序约束：B-13 依赖 B-12 的索引；E-1 依赖 B-14 的容器语义；B-24 依赖 B-15 分卷；E-3 依赖全部前序；E-4 收口零残留验收。

### AI-2 窗口路（15 批）
```
W-1 → W-2 → W-3 → C-1 → C-2 → C-6 → C-3 → C-4 → C-5 → C-8 → W-4 → W-5 → B-27 → D-3
```
关键顺序约束：**C-6 探测器必须先于 C-3/4/5**（它是分级裁判）；C-8 实测回填在四层齐后；D-3 看门狗与 AI-3 的 D-1 联调（Wave 3）。

### AI-3 引导路（16 批）
```
L-1 → L-2 → L-3 → V-1 → V-2 → V-3 → D-1 → D-2 → D-4 → V-4 → V-5 → V-6 → V-7 → V-8 → V-9 → V-10
```
关键顺序约束：D-1（VM 档 Shell）依赖 L-1 引导器与 L-3 降级链就绪；D-1×D-3 联调后才能做 V-8 四阶段交付（交付盘必须含接管能力）；V-9 压测在 V-2 差分链落地后。

### AI-4 智能路（13 批）
```
B-11 → B-18 → B-19 → B-20 → B-21 → B-22 → B-23 → B-28 → B-29 → S-1 → X-1 → X-2 → X-3 → X-4 → X-5 → X-6
```
关键顺序约束：B-28 网络层等待 AI-1 的 E-1（执行档 env 注入白名单代理）；X-2 权限模型冻结后才能做 X-3 API 面；X-6 分发收尾（依赖 X-1/2/3）。

### AI-5 体验路（14 批）
```
F-1 → F-2 → F-3 → F-4 → F-5 → F-6 → F-7 → A-1 → A-2 → A-3 → A-4 → A-5 → D-5 → B-30
```
关键顺序约束：**F-* 必须在 AI-3 的 D-1/D-2（开机直进）之前完成**（接管前能力对等）；**A-* 精修全部压后**（行为冻结后做皮肤，visual-audit 基线只拍一次）；B-30 最后主持，汇总五路证据。
