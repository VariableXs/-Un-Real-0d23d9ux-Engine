# 降级链清单（步骤 0027）

> 原则：任何硬件/能力缺失都有一条可单测的 fallback 路径。每条链的 fallback 单测位于对应域模块。

| 触发条件 | 降级路径 | 单测位置 |
|---|---|---|
| 无 GPU / GPU 初始化失败 | 真 GPU → vgpu 软件实现 → 纯 CPU 软光栅 | `aurora::gpu` fallback 档位单测 |
| SIMD（SSE/AVX2）不可用 | SIMD 填充 → 标量填充（结果等价） | `aurora::render2d` fallback 等价性 |
| 无 EDID / EDID 校验失败 | 实测模式 → 内置 VESA 兜底表 | `aurora::display` 默认模式单测 |
| 多屏枚举失败 | 独立多屏 → 单屏镜像 | `aurora::display` 降级单测 |
| 无 TTF 字体 | 轮廓字形 → 内置 5x7 点阵字形 | `aurora::typography` 点阵回退 |
| 字体缺字 | 主字体 → fallback 链 → 占位框 | `aurora::typography` fallback 链 |
| 合成超帧预算 | 关模糊/阴影 → 全软合成 | `aurora::compositor` 效果开关单测 |
| 图像解码失败/截断 | 完整解码 → 渐进行 → 拒绝并保留占位 | `aurora::image` 截断语料单测 |
| 贴靠目标不可达 | 贴靠 → 平铺布局 | `aurora::window` 降级单测 |
| 无合成器 | 合成 → 窗口直接绘制 | `aurora::desktop` 直绘路径 |
| 内存超图层/缓冲预算 | 淘汰最旧快照 → 关闭效果 | `aurora::compositor` 内存预算 |
| 无串口 | 串口日志 → 内存环形缓冲 | `logger` fallback |

## W1 收口归档（步骤 0267，M1）

| 触发条件 | 降级路径 | 单测位置 |
|---|---|---|
| 无 HDA 声卡 | HDA → USB Audio → NullSink 静默（不 panic） | `aurora::audio` `degrade_chain` / `W1-I06` |
| 设备采样率不支持 | 重采样（`DegradeStep::Resample`） | `aurora::audio` `degrade_chain` / `W1-I06` |
| 触控板失联 | 鼠标接管（`DegradeLevel::Fallback`） | `aurora::input` `degrade_level` / `W1-I06` |
| 手柄失联 | 忽略（`fallback_hint`） | `aurora::input` `fallback_hint` / `W1-I06` |
| 图像坏流 / 冷门格式 | AVIF→WebP→JPEG→PNG → 占位符 | `aurora::image` `decode_best_effort` / `W1-I06` |
| 合成单帧超 60fps 预算 | Full→Reduced→Minimal（砍效果档位） | `aurora::compositor` `degrade_for_budget` / `W1-I06` |
