## 0. 总纲

### 0.1 立项铁律（六条）

1. **零重复**：W-001…W-200 每一项都经过与 455 项存量（355 + 100）的逐条比对；每条含 `边界` 行，写明与最近似存量项的分界。
2. **不伤手感**：所有新动效默认**轻量**或**关闭**；开启后不得拖慢任何既有交互；reduce-motion / safeMode / static 下自动降级为无动画或静态表达。
3. **零侵入**：一律通过 `ai04:open-feature` 挂载协议、CustomEvent 总线、CSS 叠层与只读 DOM 观察实现；对既有文件的改动仅限「一行 import 激活」级接线。
4. **诚实实现**：每项都有真实代码路径（前端模块 / Rust 命令 / CSS 层），无占位、无假开关；依赖系统 API 的功能在不可用时如实降级并提示。
5. **离线可用**：200 项全部本地运行；涉及语音的功能使用本地识别引擎（离线模型），涉及网络的功能零联网（读本地状态）。
6. **体量克制**：每项功能对启动耗时贡献 ≤ 8ms、对常驻内存贡献 ≤ 6MB（hub 关闭时模块整体卸载）。

### 0.2 与存量 455 项的关系（去重声明）

- 存量六计划：NEXT-40（N，35）+ ASCENT-60（U，60）+ APEX-70（Z，70）+ SUMMIT-90（M，90）+ 化境 V-100（V，100）+ 奇点 SINGULARITY-100（Q，100）= 455 项。
- 本计划为**第七计划**，对以上全量去重后立项。典型边界示例：
  - Q-51「GPU 画布」≠ W-090「CPU 潮汐」（前者 GPU→极光强度，后者 CPU→粒子潮汐密度，硬件轴不同）；

  - V-63「指针轨迹」≠ W-144「光笔」（前者是轨迹残影，后者是光标携带微型光晕照亮其下的界面区域）；
  - U-20「内存守护」≠ W-193「内存地平线」（前者是实时守护动作，后者是跨版本最低占用基线的水位线归档）。
- 全部 200 条的 `边界` 行见各域明细；关键项另见附录 B 最近邻索引。

### 0.4 统一运行底座（W 系列共享基建）

全部 200 项共享同一底座（与奇点 singularity 体系**平行共存、独立开关、互不依赖**）：

- **W 注册表**（`src/system/nova/registry.ts`）：200 项元数据（编号/域/默认开关/参数 schema），localStorage 独立键空间 `nova.registry`，纯逻辑可测。
- **新星中枢**（`NovaHub`，`ai04:open-feature { feature: "nova-hub" }`）：十六域控制台——搜索、逐项开关、参数调节、状态总览。
- **新星运行时**（`NovaRuntime`）：按注册表状态激活 16 个域模块，统一降级链（reduce-motion / safeMode / static）。
- **Rust 脉搏扩展**（`src-tauri/src/shell/nova.rs`）：`nova_pulse_ex`（扩展硬件采样：分核/CPU 温度/电流/蓝牙）、`nova_file_scan`（文件元信息批量）、`nova_audio_env`（环境声级）、`nova_bluetooth_watch`（蓝牙插拔）。
- **样式层**（`src/styles/nova.css`）：全部动效与面板样式，`nova-` 前缀类名，遵循 tokens.css 语义变量，reduce-motion 全量降级。
- **本地语音底座**（`novaVoice.ts`，仅域 13/14 消费）：离线识别 + 本地 TTS 引擎封装，无网络调用。

## 1. 域一：启动与品牌剧场（W-001…W-012）

> 存量覆盖：U-01…06 冷启动六件套、Q-01…07 唤醒/谢幕/巡礼/剧本/解说/彩蛋/问候、N-10 锁屏仪式。本域补齐**启动的物理感、预报性、情绪性与声音维度**。

### W-001 启动温度制式（Boot Temperature）
按电源状态区分点火制式：完全冷启动走「熔炉升温」段落（辉光从暗到亮 2.4s）、快速启动走「余烬复燃」（0.9s 短促亮起）、会话恢复走「无点火」直接进入。制式由 Rust boot 阶段上报的真实电源状态驱动。
**边界**：Q-01 唤醒握手管「失焦回归」的剧场；W-001 管「不同电源状态」的冷启差异，时间线不重叠。
**验收**：三种制式各自触发正确（以真实 boot 事件为源）；reduce-motion 下全部退化为 120ms 亮度过渡。

### W-002 启动天气预报（Boot Forecast）
启动第 1 秒在胶囊条旁打出一行英文微预报（HUD 文案纪律）：`EXPECTED 6.2S · DISK BUSY`，基于最近 20 次启动的阶段均值 + 当前磁盘繁忙度预测本次耗时；结束时回写误差（诚实校准）。
**边界**：Q-93 启动火焰图是事后诊断图；W-002 是事前预报，且带误差回写闭环。
**验收**：预报误差均值 ≤ 25%；样本 < 5 次时显示 `LEARNING` 而非编造数字。

### W-003 跳映启动（Skip-Start）
启动中按任意键：只压缩**纯视觉段落**（帷幕/粒子暖场），真实加载阶段（图标索引/模块挂载）如实保留并即时给出 `SKIPPED CINEMATICS ONLY` 自报行，绝不假装加载完成。
**边界**：U-06 仪式编排器管启动节奏编排；W-03 是用户主动跳过视觉层的交互权，且诚实自报跳过内容。
**验收**：跳映后启动总耗时缩短仅等于被跳过的视觉段时长；自报行如实出现。

### W-004 启动声场景感知（Sound Scene Sense）
启动音在静音环境（上次会话末音量 ≤ 10%）自动降为 30% 音量轻响；深夜时段（23:00–06:00）自动静默改为一次 60ms 微振动视觉（若硬件支持）；可关。
**边界**：Z-45 系统声音方案管方案切换；W-04 管启动音的**场景自适应**（音量/时段双因子）。
**验收**：双因子叠加规则可解释（设置页明示）；用户显式调大音量后本会话不再干预。

### W-005 多屏顺次点火（Cascade Ignite）
多显示器环境下启动：主屏先亮（真实就绪即点亮），扩展屏以 150ms 交错顺次「点亮接力」——每块屏亮起代表该屏的壁纸/图标层真实挂载完成，不是纯表演。
**边界**：U-43 多显示器编排管布局编排；W-05 管**启动时序的物理接力语义**。
**验收**：单屏环境零行为；接力时序与真实挂载完成事件一致；reduce-motion 下同时点亮。

### W-006 启动足迹墙（Boot Footprints）
设置-启动页的仪式化足迹墙：最近 20 次启动每枚一行光点，耗时→色温（快=冷白、慢=暖红），悬停看该次各阶段耗时。是「启动的年轮」而非诊断工具（诊断走 Q-93）。
**边界**：Q-93 火焰图是单次深钻分析；W-06 是 20 次的仪式化年轮总览。
**验收**：数据同源（bootTimeline）；墙渲染 ≤ 50ms；清零按钮真实清空。

### W-007 下次启动预览（Next-Boot Preview）
关机流程中（V-19 会话清单旁）追加一张「下次启动预览」卡：将随开机自启的应用列表 + 预估启动时长 + 上次实际值，让用户在关机时就「预演」下次开机。
**边界**：V-19 管关机前的清单确认；W-07 管对未来一次启动的**前瞻性预演**。
**验收**：自启列表与真实自启一致（读启动项登记）；无自启项时如实显示 `CLEAN BOOT`。

### W-008 品牌星座（Brand Constellation）
启动尾声：品牌字标的点阵化作可交互星座——启动完成后 4s 内鼠标可点任一星点，展开该星对应的本版能力介绍（数据读 W 注册表 changelog 字段）；4s 后星座归位为标准字标。
**边界**：Q-03 首跑巡礼是全屏巡礼卡；Q-06 品牌时刻是特定日期彩蛋；W-08 是**常态化的字标可探索层**。
**验收**：星点信息与注册表一致；4s 自动归位不打扰；bootAnim=none 时不出现。

### W-009 启动里程碑微音（Milestone Notes）
启动进度跨过 25% / 50% / 75% / 100% 四个真实里程碑时播放四个上行微音（Do-Re-Mi-和音，时长各 90ms），为视觉不便用户提供「听进度」能力。
**边界**：U-05 启动交响是整体配乐编排；W-09 是**里程碑离散事件音**（且是主要无障碍价值）。
**验收**：音量跟随系统；静音环境联动 W-04 规则；四音与真实里程碑对齐（不虚构进度）。

### W-010 电源仪式音（Power Rite Music）
关机/重启瞬间的告别音设计：一段 1.2s 的下行收束音（可换 3 种制式：弦乐收束/钟摆止息/静默），与 Q-02 谢幕剧场视觉同步，构成视听双通道告别。
**边界**：Q-02 管谢幕视觉；W-10 管谢幕的**声音维**；Z-45 声音方案不含电源时刻专用制式。
**验收**：音画同步误差 ≤ 80ms；静音设置下自动静默。

### W-011 启动情绪测温（Exit Mood Thermometer）
按上次会话的结束方式差异化本次启动情绪：正常退出→标准剧场；崩溃/异常终止→「安抚版」素净启动（去繁复粒子、灰白基调、一行 `RECOVERED CLEANLY`）；强制断电→「检视版」启动前先完成 V-59 断电自检再进剧场。
**边界**：U-23 崩溃叙事管崩溃时的叙事；W-11 管**崩溃后的下一次启动**的情绪差异化。
**验收**：三种情绪判定来自真实的 lastExit 状态；安抚版不掩盖任何自检结果。

### W-012 启动源流戳（Startup Source Stamp）
桌面就绪后 2s 内，屏幕右下角一枚 16px 半透明源流戳：`COLD` / `FAST` / `RESUME` / `RECOVER`，标注本次会话的真实来源；悬停展开该来源的完整判定链（供工程师与高级用户溯源）。
**边界**：Q-05 启动实况解说在启动过程中随阶段解说；W-12 是启动**完成后**的静态源流印记。
**验收**：四种戳互斥且判定链真实可查；dev 模式戳常显，普通模式 2s 淡出。

## 2. 域二：窗口与空间（W-013…W-025）

> 存量覆盖：吸附/快照/时间机器/舞台/手势/排列画廊/体征环/偷看等 40+ 项。本域补齐**质量物理、磁吸手感、结构族谱、空间折叠**。

### W-013 窗口质量物理（Mass Physics）
窗口面积映射惯性质量：拖拽大窗口（≥ 60% 屏幕面积）起步延迟 60ms、停止有余韵 80ms；小窗口轻快如纸。物理曲线可关。让「大而重」成为身体感受。
**边界**：Q-14 动量拖拽给拖拽加速度倾斜（角度）；W-13 给**起步/停止的时间惯性**（质量），二者可叠加但机制独立。
**验收**：惯性参数与面积单调相关；reduce-motion 下物理关闭仅保留语义。

### W-014 磁吸边缘手感（Magnetic Edge）
窗口拖至吸附线前 6px 进入「磁场」：吸附线亮起 + 指针出现 3px 阻尼区（吸附前轻微引力感），进入即吸附线呼吸确认。是吸附的**手感前置层**，不改变 U-14 吸附逻辑。
**边界**：U-14 智能吸附管吸附规则；W-14 管吸附**发生前 6px 的触觉预告**。
**验收**：阻尼区不影响非吸附路径的拖拽；吸附成功率不因手感层下降。

### W-015 窗口族谱（Window Genealogy）
命令面板新增「窗口族谱」：以进程父子树展示当前全部嵌入/原生窗口的诞生关系（谁启动了谁），子窗口连线父窗口；点击节点聚焦、右键结束整树。
**边界**：N-01 窗口时间机器管窗口的历史时间线；V-28 窗口分布小地图管空间分布；W-15 管**结构族谱**（诞生关系树）。
**验收**：树刷新 ≤ 300ms；steam 收编树（embed 协议）正确呈现父子链。

### W-016 Z 序阴影深度（Z-Shadow）
窗口阴影深度映射 z 序高度：最顶层窗口阴影最深（ elevation 立体感），下层逐级变浅，形成「空气透视」层次；焦点切换时阴影深度平滑过渡 200ms。
**边界**：U-09 光影系统是全局光影规范；Z-39 标题栏自定义管标题栏；W-16 是**z 序→阴影深度**的动态映射层。
**验收**：10 层窗口深度单调递减；static 模式下按焦点双层分档。

### W-017 空间气味标记（Space Scent)
每个虚拟桌面分配一枚专属强调色相（VWM 桌面维）；切换桌面瞬间环境辉光（U-53）闪现该桌面色相 600ms——用颜色做空间记忆锚点（「我在蓝色桌面工作」）。
**边界**：V-29 窗口色带标记是给窗口打色；W-17 是给**桌面空间**打色并与辉光联动。
**验收**：色相列表与既有主题强调色错开（避免混淆）；reduce-motion 下仅任务栏桌面指示点变色。

### W-018 键盘吸附格阵（Key Snap Lattice）
`Win+方向` 之外新增 `Alt+小键盘 1-9`：九宫格直达吸附（1=左下、5=居中最大化、9=右上等），是纯键盘的完整格阵吸附；连按同格二次 = 恢复原位。
**边界**：U-14 吸附是鼠标拖拽触发；Z-11 键盘网格是**导航**；W-18 是**几何摆放**的键盘直达。
**验收**：9 格覆盖全部屏幕区域；连按二次恢复经过真实几何记忆（Z-37）。

### W-019 几何裁剪（Geometry Snap-8）
窗口系统菜单「对齐几何」：宽高一键取整到 8px 网格（消除像素级参差），并提供「对齐到屏幕安全区」选项（距边 8px 统一留白）。
**边界**：V-23 调整大小实时几何提示是**过程中的提示**；W-19 是**事后的批量整形**动作。
**验收**：裁剪后坐标 mod 8 == 0；最大化/贴边窗口自动跳过。

### W-020 焦点回声（Focus Echo）
非焦点状态超 10s 的最后一个焦点窗口，其任务栏图标出现 4s 一次的柔和呼吸微光——「回声」提示用户那个未完成的对话还开着；点击即归位。可关。

## 6. 域六：文件与数据能力（W-064…W-076）

> 存量覆盖：预览/标签/回收站/校验/重命名/篝火/批量属性等 34+ 项。本域补齐**文件活性、借阅语义、增长预测与数据叙事**。

### W-064 文件脉搏（File Pulse)
正在被写入的文件（日志/下载/渲染输出）图标上出现 2s 周期的**脉搏微光**——一眼识别「哪些文件活着」；写入停止 5s 后脉搏停息。

**验收**：活文件识别来自文件系统监听（只注册当前可见目录）；脉搏开销每目录 ≤ 1 监听句柄。

### W-065 目录人口普查（Census Report)
文件夹右键「人口普查」：类型构成饼图 + Top5 类型清单 + 平均文件年龄 + 空文件/超大文件极值，一页报告即完成目录「摸底」。

### W-066 借阅书架（Borrow Shelf)
侧栏新「借阅书架」：拖文件上书架 = 借出（书架记录来源目录），拖走使用后可「归还」回原位；48h 未归还的书目淡化为逾期色——为「临时抓几个文件来用」的场景建立秩序。
**边界**：Q-50 收藏抽屉是异构收藏（不回还）；W-66 是**借出-归还**闭环语义。
**验收**：归还=移动回原目录（原目录已删则提示降级为复制）；书架容量 24 册上限。

### W-067 文件墨阶（Size Ink)
文件列表名字加粗随体量分级加深：MB 级 300 字重、GB 级 500 字重+8% 灰底、「巨石」（≥ 10GB）附微图标——用排版重量直觉传达体量。

右键目录「增长预报」：读最近 30 天增长曲线外推未来 30 天（线性+加权双模型），预报到达「红色水位」（剩余空间 10%）的日期；纯本地数学。
**边界**：Z-34 是现状分析；W-68 是**未来外推**预报。
**验收**：预报线与历史数据点同图呈现（诚实显示置信带）；样本 < 14 天显示数据不足。

### W-069 文件迁途志（Move Journal)
文件在环境内的每次移动/重命名都记录**轨迹链**（旧路径→新路径 + 时间）；右键「迁途志」查看该文件的完整路径演变——找回「那个被我挪走的文件」。
**边界**：U-30 数据血缘管**数据衍生**关系；W-69 管**物理路径**的迁移轨迹。
**验收**：仅记录环境内操作（系统外移动如实断链）；志保留 90 天滚动。

### W-070 标签代数（Tag Algebra)
标签系统新增**代数视图**：任意多标签交/并/差组合保存为「代数文件夹」（如 `工作 ∩ 未完成 - 已归档`），实时物化结果；组合可命名可共享（Z-54 格式）。

### W-071 预览幽灵页（Ghost Page)

### W-074 目录季节环（Season Ring)

### W-075 回收站出身簿（Bin Provenance)
回收站每项附「出身」徽标：由哪个应用删除（V-02 图标）+ 原路径 + 入站时间；支持按出身应用筛选——「刚才那个软件删了什么」一查便知。

### W-076 近踪动港（Recent Haven)
侧栏「最近用过的文件夹」动态区：最近 5 个**真实浏览过**的目录自动浮列（并按使用频率排序），一周未访问即淡出——「刚才那个目录在哪」的动线缓存。

**验收**：仅记录文件管理器真实访问；隐身会话（U-36）不记录；上限 5 枚防膨胀。

### W-095 磁盘巡逻灯（Disk LED)

## 9. 域九：兼容性防线（W-102…W-113）

对 IME 组段丢失型应用（输入法候选被窗口重绘吞掉）：环境自动检测组段中断特征并触发**组段接力**（重放组合）——「打字丢字」的兼容救火。

### W-107 DPI 转场防腐（DPI Morph)

**边界**：Z-19 混合 DPI 管**适配**；Z-66 图标零闪烁管图标；W-107 管**转场瞬间**的窗口视觉防腐。
**验收**：揭幕后窗口渲染清晰度与稳态一致；转场不增加变更耗时。

### W-108 遗留应用医院（Legacy Hospital)
Win7 时代遗留应用的专属「医院」入口：体检（DPI 模糊/字体发虚/缩放错位三查）→ 治疗（高 DPI 虚拟化/禁用缩放/兼容垫片，对应已知处方）→ 复查记录归档。

**验收**：处方数据库内置 20+ 常见遗留应用；治疗可逐一撤销。

### W-109 游戏反作弊礼让（Anti-Cheat Yield)
检测到反作弊驱动加载（全屏游戏特征）：环境**主动全面礼让**——暂停一切全局钩子/悬浮层/截图能力直至游戏退出，杜绝 hook 冲突导致的封号风险。
**边界**：Z-18 全屏协议管全屏避让；W-109 是**反作弊驱动**专项的深度礼让（更严）。
**验收**：礼让期内环境全局功能确实停用（矩阵 Q-98 可查）；退出 30s 后恢复。

### W-110 蓝屏检尸官（BSOD Forensics)

**边界**：U-23 崩溃叙事管**环境自身**崩溃；W-110 是**系统级蓝屏**的检尸（如实声明边界：不替系统背锅也不甩锅）。
**验收**：minidump 解析在本地；无法解析时如实 `INSUFFICIENT DATA`；结论措辞经中立审校词表。

### W-111 色彩模式转影（Color Morph)
HDR↔SDR 或深浅模式切换：叠加一层 2s 的**色彩过渡影**（旧色彩空间向新空间插值渐变），杜绝观感跳变——与 Q-81 三拍仪式叠加可用（仪式管情绪、转影管色彩连续）。
**边界**：Q-59 HDR 感知管**认知提示**；Q-81 管深浅**仪式**；W-111 管色彩**连续性技术影**。
**验收**：转影期间零白闪（复用 Z-68 门禁）；reduce-motion 直接切换。

### W-112 同名实例仲裁（GPU Arbitration)
同一应用多实例争抢 GPU（检测到双实例高负载同进程名）：弹「仲裁卡」建议——限制后台实例帧率 30fps / 分核亲和——用户一键选择，环境不擅自动手。
**边界**：M-54 资源公平调度管**全局资源**调度；M-42 实例徽标管**区分标识**；W-112 是**同名实例 GPU 争抢**的建议仲裁。
**验收**：检测窗口 2s 防误报；仲裁动作经用户确认才执行；可设永久策略。

### W-113 系统更新护城河（Update Moat)
检测 Windows 大版本更新待重启：环境提前弹出「护城河」卡——列出更新后可能失效的环境设置（已知兼容矩阵）+ 一键备份这些设置（V-84 快照）+ 回滚指引。
**边界**：Z-61 增量更新管**环境自身**更新；W-113 管**系统更新**对环境的前置防护。
**验收**：风险清单来自兼容矩阵真实登记；备份可还原；无更新时零打扰。

### W-117 敏感文件气泡（Access Bubble)

### W-118 阅后即焚剪贴板（Burn After Read)

**边界**：Q-65 剪贴板过期是**特征识别**的自动 TTL；W-118 是**用户显式标记**的一次性语义。

### W-119 后台心跳墙（BG Pulse Wall)
hub 面板：后台运行的应用各一枚「心跳行」——网络/磁盘/CPU 微活动电平（6px 三电平行），一眼看穿「谁在偷偷干活」；点击行直开应用详情。
**边界**：Q-84 声音透视管**音频**流；W-119 管**后台系统活动**电平墙。

### W-120 信任衰减曲线（Trust Decay)
信任链（U-35）中每个插件的信任分随时间/事件衰减：90 天未更新 -5%、崩溃 +10%、越权调用 +30%——衰减曲线可视，跌破阈值建议复审。
**边界**：U-35 管信任**决策**；W-72 插件体检管**性能**评分；W-120 管**信任值的时间动态**。
**验收**：衰减公式透明可解释；事件驱动分可人工复核修正。

### W-121 隐私剧场排演（Privacy Rehearsal)
教育性「排演剧场」：模拟一次隐私泄露场景（沙盒化演示：某插件如何读取目录并外传），以剧场动画+解说呈现，让用户**看懂**风险机制——演练结束一切自动销毁。
**边界**：Q-96 崩溃演练管**工程**演练；W-121 是**隐私教育**排演（面向用户认知）。

### W-189 睡眠孵化器（Hibernation Nest)
空闲 30 分钟的应用：从「冻结」（Z-59）升级「入眠」——工作集**换出到盘**（内存归零、恢复 1.5s 内热还原）；睡眠列表在 hub 可见可唤醒——内存的深睡病房。
**边界**：M-06 窗口挂起管**手动挂起**；Z-59 管**渲染冻结**；W-189 管**内存换出**的自动深度睡眠。
**验收**：入眠内存释放 ≥ 90%；唤醒恢复还原率 100%（窗口内容/滚动位）；手动唤醒优先级最高。

### W-190 崩溃单步重放器（Crash Replay)
崩溃转储（M-53）的「重放器」：对可确定性重放的崩溃（纯逻辑类）一键**单步重放**——逐步执行到崩溃点，每步状态对照——崩溃案发现场的重演。
**边界**：M-53 管转储收集符号化（事后分析）；Q-96 管主动注入演练；W-190 管**逐帧重放**调试。
**验收**：仅确定性崩溃可重放（UI 崩溃如实标 `NOT DETERMINISTIC`）；重放 100% 复现崩溃点；仅 dev 可见。

### W-191 GPU 诊断砚（GPU Inkstone)
GPU 帧耗时的「砚台图」：每帧 GPU 时间以墨点沉积（越慢墨越浓），长时间观测形成**墨沉积图**——帧性能的视觉化「研墨」。
**边界**：Q-94 长任务看板管 **CPU 主线程**任务；W-191 管 **GPU 帧级**耗时（不同硬件域）。
**验收**：采样零干扰（GPU 计时戳）；墨图保留最近 5 分钟；阈值浓墨对应真实掉帧。

### W-192 多环境军棋推演（Sandbox Wargame)
多分身（N-35）之间的**军棋推演**：沙盒 A/B 对照运行同一负载（同一壁纸/同一插件集），产出性能/内存/能耗三方对照战报——分身环境当军棋用。
**边界**：N-35 管多分身本体；V-90 沙盒试用管插件试用；W-192 管**分身间对照**推演。
**验收**：推演负载注入同步（时钟对齐）；战报三方数据实测；非对照期分身零额外开销。

### W-193 内存地平线（Memory Floor)
跨版本的「内存地平线」：历史版本空载内存最低值水位线（虚线标注 `FLOOR 382MB @v1.4`），新版本若击穿地平线（更低）→ 更新水位；若逼近红线（+15%）→ 警报——内存的地质层。
**边界**：U-20 内存守护管**实时守护**（当下维）；W-193 管**历史地平线**（版本间维）。
**验收**：地平线数据随版本发布实测更新；击穿/逼近判定可解释；水位线在 hub 图表常显。

### W-194 可复现指纹（Build Fingerprint)
构建产物的**可复现性指纹**：同源码两次构建的哈希比对（一致=可复现构建达成），指纹徽章打在发版物与 ECG（Q-100）——供应链可信的基石。
**边界**：M-87 发版演练管**流程**演练；W-194 管**产物可复现**验证。
**验收**：指纹算法（内容寻址哈希树）；不可复现时如实标 `NOT REPRODUCIBLE` 并列差异文件。

### W-195 白纸视角（Fresh Eyes)
开发者命令 `nova fresh-eyes`：以**全新用户视角**启动一沙盒（零设置/零历史/首次引导全流程），供开发者体验「第一次」——设计师的白纸。
**边界**：N-35 沙盒管隔离环境；W-195 是**首跑状态**的专用沙盒（清零视角）。
**验收**：白纸沙盒与真首跑全流程 1:1（引导/空态/默认值）；退出即销毁不留残留。

### W-196 性能气象站（Perf Weather)
hub 的「性能天气」播报：当前性能状态的气象隐喻（晴/多云/雨/风暴 = 空闲/常态/繁忙/过载），含「未来 30 分钟预报」（基于使用规律）——性能的天气学。
**边界**：N-19 性能 HUD 是**数据面板**；W-196 是**状态隐喻**播报（面向普通用户的翻译）。
**验收**：气象判定与 HUD 阈值同源；预报规律来自本地使用模式；纯娱乐性预报误差如实标注。

### W-197 工程星象（Eng Zodiac)
工程质量的「十二星象盘」：测试覆盖/文档比率/依赖健康/门禁通过率等 12 指标映射为 12 星座（各星座亮暗=指标健康），一屏尽览工程命盘——质量的占星学（实质是趣味化 dashboard）。
**边界**：Q-100 版点心电图管**版本间趋势**（时间线）；W-197 管**当前全指标**盘面（星象盘）。
**验收**：12 指标数据同源真实门禁；暗星点击展开明细；星象命名经词表审校（不迷信化）。

### W-198 发版礼炮（Release Cannon)
发版流程（M-87 演练完成）的收官仪式：版本里程碑墙 + 一轮全屏礼炮动画（2.5s，可跳）+ 版本号烙印入「历史铭牌」——发版也是一场典礼。
**边界**：Q-100 ECG 管**质量数据**叙事；W-198 管**发版时刻**的仪式庆典。
**验收**：礼炮仅在 dev 构建或手动触发（不打扰用户）；铭牌持久化历史版本号；动画 reduce-motion 降级为静态铭牌。

### W-199 性能不朽档案（Golden Archive)
历史最优性能数字的「不朽档案」：各指标历史最佳值（最快启动/最低内存/最高帧率）入档，被超越时档案更新并致敬（`NEW RECORD 3.1s BOOT`）——黄金时代的档案馆。
**边界**：W-193 内存地平线管**内存一项**的地平线；W-199 管**全指标**最佳档案。
**验收**：档案记录含版本/日期/机器上下文；破纪录判定严格（同条件）；档案可导出。

### W-200 测试战绩册（Test Battle Pass)
测试体系的「战绩册」：测试通过率里程碑（1000/1200/1500 用例）逐级解锁徽章，各域测试数分布的功勋墙——测试团队的荣誉册（激励维）。
**边界**：Z-63 回归基线管**基线**；W-200 管**成就叙事**（激励层）。
**验收**：战绩数据同源 vitest/cargo test 真实结果；里程碑判定准确；徽章本地渲染零网络。
