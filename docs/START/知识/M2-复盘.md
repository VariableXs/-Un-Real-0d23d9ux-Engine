# M2 复盘 —— W2 窗口系统与桌面核心（步骤 0515）

> 2026-09-11。含缺陷回溯（0510）、质量度量（0511）、优化空间基线（0519）。

## 做得好的

1. **一域一文件 + CheckSet 自检闭环**再次证明有效：八域 208 项自检一次聚合，回归定位从"看日志猜"变成"看 FAIL 行"。
2. **固定容量数组的纪律**让 fuzz 几乎零成本：五域语料合并跑，无 panic、无泄漏路径。
3. **联调域独立成模块**（`w2_integration.rs`）：跨域契约有了可执行的回归，不再依赖口头约定。

## 改进点

1. **工具链是最大时间黑洞**：rustup 组件下载受代理干扰，`rust-toolchain.toml` 锁 stable 轨道是对的，但"partial install 回滚后 cargo 不可用"要靠整链重装修复 —— 建议归档离线工具链副本。
2. **`run_kernel_checkup` 容量曾落后于注册域数**（32 < 实际注册数，尾部静默丢弃）：静默截断是自检框架的敌人，`register` 满时应至少有 debug 断言。后续在 F 项自检里加一条"注册数 < MAX_DOMAINS"断言。
3. **类型边界**：四套 `Rect` 定义是为 no_std 独立域付出的代价，联调层被迫写坐标转换。M4 若引入共享几何类型需一次性统一，不要渐进混改。
4. **文档先行不足**：步骤手册是单行长文，AI 分段施工靠 `python -c` 切片提取，应让 gen-docs 直接输出按域分节的版本。

## 优化空间基线（步骤 0519：当前 vs 理论）

| 域 | 当前 | 理论 | 缺口来源 |
|---|---|---|---|
| 窗口 | 常量时间 O(1) 操作，数组容量 16 | 同 | 容量已饱和；缺硬件合成联动 |
| 动效 | 帧预算 4ms 逻辑档位 | 60fps 实测 | 无真实帧时钟，待真机 |
| 合成 | 逻辑脏区合成 900µs 档 | 16.6ms/帧 | 无 SIMD/真实像素带宽 |
| 剪贴板 | XOR 演示加密 | AEAD | 密码学栈未引入 |
| 会话 | 逻辑哈希 rounds 可调 | Argon2id | 同上 |
| 工作区 | 布局校验和 | 断电安全写 | 需存储域配合 |
