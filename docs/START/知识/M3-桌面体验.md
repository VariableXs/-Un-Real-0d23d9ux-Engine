# M3 知识归档 · 桌面体验与基础应用（步骤 0748）

> W3（AI-17~AI-24）的可复用知识沉淀，供 W4 及后续波次复用。

## 1. 八域布局与职责

| 域 | 模块 | 要点 |
|---|---|---|
| AI-17 设计系统 | `kernel/varix/src/designsys/` | 六类令牌单一数据源（色彩/字体/圆角/间距/阴影/动效），一处改处处改；对比度 AA/AAA 守护；主题热切换用代数计数（generation 翻转），不重建令牌表 |
| AI-18 文件管理器 | `kernel/varix/src/fileman/` | VfsTree 静态数组 + 路径栈；预览摘要（kind/size/head）；拖拽防环（拒绝移入自身后代）；回收站可恢复 |
| AI-19 设置中心 | `kernel/varix/src/settings/` | key 分段校验（100 开关/200 百分比/300 枚举）；serialize + FNV-1a 校验和；历史撤销/重做一键回滚 |
| AI-20 基础应用 | `kernel/varix/src/apps/` | 计算器用 token 流求值（深度上限防栈爆）；日历 Zeller 公式；全离线可用 |
| AI-21 终端 | `kernel/varix/src/terminal/` | 字符网格环形缓冲；输出洪峰丢最旧行不 panic；CSI 转义解析器；快捷键映射表 |
| AI-22 编辑器 | `kernel/varix/src/editor/` | GapBuffer（光标即 gap_start）；分块大文档；无限撤销栈容量上限安全拒绝 |
| AI-23 图像查看 | `kernel/varix/src/imageview/` | Bitmap 静态尺寸 O(1) 像素访问；魔数识别（PNG/JPEG/BMP）；解码失败→纯色占位图 |
| AI-24 播放器 | `kernel/varix/src/player/` | frame_no(elapsed,fps) 与 advanced_at(ms,speed) 同一时间轴推导音画同步；解码失败跳下一媒体 |

## 2. 跨域约定（W4 必须沿用）

1. **主题**：一切视觉值从 designsys 令牌取，禁止硬编码颜色/字号/间距（lint 检查）。
2. **设置**：一切偏好走 settings key 段位校验，导入导出必须带 FNV-1a 校验和。
3. **协作接口**：终端→编辑器 `send_selection_to_editor`；文件管理器→图像查看器
   `preview()` + `open_with()`；编辑器主题档 `THEME_LIGHT/DARK/HC` 与终端 `scheme_valid` 对齐。
4. **性能预算**：用 `*_budget_ok(us, budget)` 纯函数判定，w3gate 统一联测。
5. **降级链**：每个域必须有「损坏→默认值」路径，且被单测覆盖。

## 3. no_std 域代码风格

- 固定容量数组 + `usize` 计数，禁 Vec/String/Box；返回值用 `Option/Result`，越界安全拒绝。
- CheckSet 自检 25 项/域，`all_passed()` 全绿才算闭环。
