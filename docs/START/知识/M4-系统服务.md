# M4 知识归档：系统服务与互联（步骤 0991）

## 架构决策

1. **八域服务层全部纯逻辑 + 固定容量数组**：netweb/notify/search/sysmon/pkgstore/printing/a11y/apower 均 no_std 无分配，环形缓冲（MetricRing=64、History）+ 定容表（PROC_CAP=16、MAX_JOBS=8、MAX_DEVICES=16），越界策略统一为「截断/驱逐最低优先级/返回错误码」，杜绝 panic 路径。
2. **服务互联走显式数据面**，不引入消息总线：浏览器下载完成后由调用方把产物登记进 fileman VfsTree（步骤 0969 场景）；搜索结果通过 `SearchResult{kind,id}` 归一化，启动器只消费 `launch_first(apps,q)`。
3. **沙箱权限位复用 AI-08 appfw**：商店安装（pkgstore::install_with_deps 拓扑序 + sign/verify 防篡改）后，应用进程的 NET/FS 权限由 `sandbox_check` 位掩码裁决，商店不做第二套权限模型。
4. **电源域与既有 VARIX-500 power.rs 共存**：AURORA 侧挂 `apower` 别名（`#[path="power/aurora.rs"]`），ACPI S0~S5 状态机、S0ix、D-state、每瓦性能、策略与睡眠唤醒全部收口在 `run_apower_checks()`。
5. **无障碍门禁是硬门禁**：`screen_reader_complete` 要求所有交互节点带标签，违规即 FAIL；对比度按 WCAG 放大整数口径断言。

## 预算达成（2026-09-11）

- 唤醒延迟 ≤ 900ms（红线 500ms 优 / 1s 上限）
- 帧预算 16.7ms（60fps）、启动 < 3s、内存 < 1GB —— 由 perf::perf_selfcheck 统一判定
- 文档搜索 < 100ms、候选 < 30ms 在域内 budget 断言

## 可复用经验

- 「下载失败不落盘」类跨域不变量放进集成域（w4_integration）而非单域，避免两边都测、两边都漏。
- fuzz 语料确定性（固定 seed + 轮数），CI 可重放：`fuzz_netweb/fuzz_search/fuzz_notify/fuzz_sysmon/fuzz_pkgstore/fuzz_printing` 各 2000 轮合并跑。
