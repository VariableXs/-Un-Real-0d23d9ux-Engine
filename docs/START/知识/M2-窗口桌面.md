## 2. 关键约定（改代码前必读）

1. **所有域 `no_std` 无分配**：固定容量数组 + `usize` 计数，返回 `Option`/枚举，不 panic。
2. **Rect 有四套**：`window::Rect{x:i32,y,w:u32,h:u32}`、`widgets::Rect`（同 window）、`motion::Rect{x:i32,y:i32,w:i32,h:i32}`、`compositor::Rect{x:usize,...}`。跨域传坐标先转换，勿混用。
3. **剪贴板新鲜度**：`paste(seen_seq=0)` 表示跳过校验；非 0 必须等于槽 seq 否则 `Stale`。
4. **僵尸窗两阶段**：销毁先置 `alive=false`（defunct），`alive_count` 不计；`invariants_ok` 校验无泄漏。
5. **事件溢出**：队列满则丢弃并计数（`event_dropped`），绝不阻塞也不 panic。
6. **动效负载模型**：`motion_load_permille` 汇总活跃动画，≥400 Reduced / ≥750 Minimal / ≥1000 Static。
7. **启动进度必须真实**：`boot_progress_is_real` 校验进度与阶段一致，禁止假报 100%。
8. **自检入口**：每域 `run_<domain>_checks() -> CheckSet`，全部注册进 `robust::run_kernel_checkup()`（容量 96，当前约 47 域）。

## 3. W2 联调场景怎么跑

```bash
cargo ktest aurora::w2_integration   # 八条跨域场景 + CheckSet 汇总测试
```

新增跨域行为时：先在对应域加单测，再在 `w2_integration.rs` 加场景断言，最后把新域接入 `run_kernel_checkup`。
