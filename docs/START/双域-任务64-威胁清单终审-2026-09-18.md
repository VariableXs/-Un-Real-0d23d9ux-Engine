## 二、「什么救不回来」诚实清单（与任务 67 SOP 呼应）

- RAM KV（KV-RAM session）：断电即失——设计语义，页脚公示。
- RamBlk/ramcache：关机清零（hash 零残留断言），不承载持久态。
- 保险箱 KEY_SLOT：焚毁后不可恢复（设计承诺）。
- 审计账本满容后的新写入：明确拒绝，不覆盖旧证据。
