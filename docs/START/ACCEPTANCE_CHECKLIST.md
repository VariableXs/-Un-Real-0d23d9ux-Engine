# Variable 验收手测清单（批次 E-8 收尾）

安装包：
- NSIS：`src-tauri/target/release/bundle/nsis/Variable_1.0.0_x64-setup.exe`（3.6 MB）
- MSI：`src-tauri/target/release/bundle/msi/Variable_1.0.0_x64_en-US.msi`（5.1 MB）

## 1. 安装 / 卸载
- [ ] NSIS 安装包双击安装 → 桌面/开始菜单出现 Variable
- [ ] MSI 安装 → 控制面板"程序和功能"可见，可卸载且卸载后无残留目录（数据目录按需保留）
- [ ] 安装后首次启动 → 启动仪式完整播放（阶段4/5 退出编排、字母落位、任务栏展开）
- [ ] 卸载后重装 → 旧数据（schema 版本）正常迁移，无损坏

## 2. 多语言（E-8a）
- [ ] 设置 → 通用 → 语言切到 繁體中文：UI 词条变繁体、日期"2026年9月5日 · 週五"
- [ ] 切到 English：词条与日期格式（Friday, September 5）正确
- [ ] 切回简体，重启应用语言保持；繁体专有词覆盖：軟體/檔案總管/設定

## 3. 设置页（E-8b）
- [ ] 外观：任务栏位置（底部）切换后 UI 联动正确，重启保持
- [ ] 关于页：版本号 v1.0.0（读自 tauri.conf.json）、Schema 版本、便携标识、离线声明

## 4. 拼音/首字母搜索（E-8c）
- [ ] 开始菜单输入 `sz` → 命中"设置"；`swdt` → 命中"思维导图"；`bj` → 命中"笔记"
- [ ] 开始菜单输入原文子串（如"文件"）正常过滤；Enter 转全局搜索
- [ ] 命令面板/全局搜索输入字母 → 文档/导图标题按拼音回退命中
- [ ] 最近使用行跟随搜索词过滤

## 5. 通讯软件通知（E-8d，边界功能）
- [ ] 运行微信，标题出现「微信(N)」→ Variable 右上角通知 + 横幅
- [ ] 同一未读计数不重复提醒；计数变化后再次提醒
- [ ] QQ/钉钉/飞书同规则；Variable 不读取消息正文（仅窗口标题）
