### 1.6 实机安全三问（凡接触真机的步骤，六问之外必答；答不出不许上机）

1. **这一步碰不碰内置盘与固件？** 碰 = 停。内置盘全程只读（只读体检类除外，且须先过"落点内容实证不过就退出不动"闸门）；固件只允许"读 BootOrder + 写一次性 BootNext + 正常重启"三件正规事，永不写固件设置。
2. **这一步失败后，Windows 还回得去吗？** 论证不出"回得去"的路径 = 不做。每步回滚路径必须预先写进步骤卡（见各批"回滚"行），不许事后补救式思考。
3. **断电/强拔/半途崩溃的最坏后果是什么？** 必须有已演练过的预案（journal 零丢失 / 快照回滚 / 防自锁闸门）才继续；没有预案先补预案再上机。

### 1.7 实机安全宪法（三红线 · 五重保障 · 三纪律，全程有效，任何步骤不得豁免）

**三红线（违反任何一条 = 立即停止并按事故复盘）：**

| 红线 | 内容 | 物理保证 |
|---|---|---|
| 红线一 | **不碰硬件**：永不刷写固件/BIOS、永不改固件设置项、永不执行固件更新 | BIOS 在主板独立芯片，U 盘上任何软件指令都到达不了它；对固件只有三件正规事（读 BootOrder / 一次性 BootNext / ResetSystem 正常重启） |
| 红线二 | **不碰内置盘**：绝不写内置盘任何字节（ESP/BCD/注册表/引导配置全部只读）；只读体检须带"落点内容实证不过就退出不动"闸门 | 内核不挂载内置盘 NTFS（架构上够不着 = 保持够不着）；Windows 侧脚本一律按标签定位 + assign 后回读确认落点 |
| 红线三 | **不删用户数据**：U 盘上操作全部可回滚；SHARED 用户数据只增不删；任何删除类操作先快照 | SNAPSHOT 快照滚动 + 差分升级失败自动回滚（断电 ×10 零变砖已实测） |

**"Windows 永远回得去"五重保障（最高优先级关切，五层逐级兜底）：**

| 层 | 保障 | 单层失效场景 | 兜底层 |
|---|---|---|---|
| ①物理层 | **拔盘即走**：U 盘引导从不写内置盘引导数据；拔掉 U 盘 = 固件直接找内置盘 = 原生 Windows，零依赖 | 无 | 物理规律，永不失效 |
| ②引导层 | **BootNext 一次性预约**：交接只写 BootNext（重启一次自动清零），永不改 BootOrder 永久引导序；内置盘 Windows 始终是固件默认项 | BootNext 写失败 | ①物理 + ④操作 |
| ③逻辑层 | **防自锁闸门**：Windows 引导项未在 BootOrder 实证存在 → 拒绝写 BootNext，宁可不交接也不困在 U 盘 | — | 闸门用例随 S0.1 入库回归 |
| ④操作层 | **上机前记录 + 下机后核验**：每次实机会话前记录 BootOrder/固件设置/BitLocker 状态；会话后核验 Windows 引导四件套（bootmgr/BCD/bootmgfw.efi/BD）hash 不变 | 操作者失误 | ①物理层永远兜底 |
| ⑤演练层 | **回归验证常态化**：每批次验收必含"进原生 Windows ×2"；M1 关卡连续 10 次交替引导演练 | — | AI-6 执法 |

**三纪律：**

- **BitLocker 纪律**：涉及反复重启的实机排障，一律 `Suspend-BitLocker -RebootCount 0` 无限期暂停（窗口式 suspend 会耗尽 → 保护自动恢复 → 恢复屏拦机）；收尾 Resume 并回读确认保护已恢复；恢复密钥 aka.ms/myrecoverykey 提前可取。
- **SecureBoot 纪律**：上机前提权 `Confirm-SecureBootUEFI` 权威判定（注册表 State\UEFISecureBootEnabled 为佐证）；SecureBoot=True 时**不进行**任何引导类实机操作（0xc000007b = SB 拦截链载镜像）；关闭 SecureBoot 由用户在 BIOS 亲手做，AI 只提供按键路径。
- **快速启动纪律**：HiberbootEnabled=0 确认在先（S0.4），否则 Windows"关机"实为休眠，引导语义全乱、排查全错。

### 1.8 实机操作 SOP（每次真机会话的标准流程，AI-6 抽查执法）

**上机前（7 项全过才插盘，缺一不上机）：**

1. SecureBoot 判定完成：=Disabled，或本次会话不含引导类操作；
2. 快速启动已关（HiberbootEnabled=0 注册表回读确认）；
3. BitLocker 状态已记录；涉及反复重启的已 Suspend -RebootCount 0；
4. BootOrder / 固件启动项已截图或文本记录归档；
5. 内置盘 Windows 引导四件套 hash 基线已记录（_attic/readonly-* 只读体检范式）；
6. 本会话步骤卡就绪：每步的 动作/验证/回滚 三栏齐全；
7. 用户知情确认：本次会话做什么、最坏情况是什么、怎么回来——三句话说清。

**上机中（纪律）：**

- 单步推进：一步 → 一验证 → 一记录，不合并步骤、不跳步；
- 卷访问按标签定位 + assign 后回读标签确认落点；跨会话盘符残留一律不信；
- 任何"落点内容实证不过" = 立即退出不动；
- 物理逃生路径（拔盘）全程常开，任何时刻允许拔盘。

**下机后（4 项核验，全过才会话才算闭环）：**

1. 拔盘 → 冷启动进原生 Windows 成功 ×1；
2. Windows 引导四件套 hash 与上机前基线一致；
3. BootOrder 与基线一致（BootNext 应已自动清零回读确认）；
4. 会话记录（做了什么/异常/下一步）写入 docs/acceptance/。

## 10. 实机安全总账（每个真机接触点 × 风险 × 防线 × 回滚）

> 本章是对四个最高关切——**硬件不受威胁、内存不受威胁、数据不受威胁、操作完永远回得了 Windows**——的总答案表。任何一步实机操作前先查本表。

| 步骤 | 接触面 | 最坏情况 | 防线 | 回滚 |
|---|---|---|---|---|
| S0.2 配置桥 | U 盘 ESP + SHARED | 副本损坏 | 容错三层 + fuzz 1000 组 | 删 module_path 回默认 |
| S0.3 重刷 U 盘 | U 盘 ESP/VARIX_SYS | 刷坏 U 盘引导 | 三证齐 + 落点实证闸门 | esp-backup 备份链回刷 |
| S0.4 关快速启动 | 内置盘注册表 1 键 | 无（可逆单键） | 单键 + 回读验证 | =1 即还原 |
| S1.1 盘体体检 | U 盘（只读） | 无 | 纯只读测试档 | — |
| S1.2 部署 Windows | U 盘 WIN_ENGINE | **目标选错盘** | 三重确认（盘符+容量+落点实证） | 格式化重部署，内置盘零涉及 |
| S1.3 U 盘 ESP 引导项 | U 盘 ESP | 误写内置盘 ESP | GUID 定位 + 四件套 hash 对比 | 删引导文件，内置盘零改动 |
| S1.4 三卡走查 | 引导菜单 | 引导异常 | 手动选卡 + 拔盘物理兜底 | 拔盘回 Windows |
| S1.5 handoff | UEFI BootNext | 循环回 U 盘 | 防自锁闸门 + 一次性语义 + BootOrder 回读 | 关 handoff 开关 |
| S2.07/S2.12 真机验收 | 默认引导项 | 引导异常 | bootselect 手动选卡 + 拔盘 | 选卡 / 拔盘 |
| S3.10 异常演练 | 引擎分区（U 盘） | 引擎损坏 | 差分链 Base 只读 + 重建 SOP | 丢弃重建，双系统不受影响 |
| S4.2 SHARED 直写 | SHARED exFAT | 断电写半截 | 快照 + journal + vfsguard 白名单 | SnapshotArea 回滚 |

**四个关切的正面结论：**

1. **硬件不受威胁**——软件指令物理上无法损伤任何硬件（短路/烧毁/击穿均非软件可达路径，供电时序由固件与电源管理芯片管辖）；对固件只有三件正规事且永不写入；GPU 基建（S4.3）立项时 IOMMU 前置评估，无 DMA 裸窗口不开工。
2. **内存不受威胁**——内核 Rust 所有权模型 + 白名单默认拒绝 + 每进程 Job 限额 + Seccomp/guard/meter；内核不碰内置盘、不初始化内置盘控制器；宿主机器内存只在"作为普通电脑运行 Windows/内核"的常规语义下被使用，无越权通道。
3. **数据不受威胁**——三防线（内核侧 exFAT 只读挂载且写请求显式拒绝绝不静默降级 / fs23_journal 账本写入掉电 ×10 零丢失 / SNAPSHOT 快照滚动+差分升级断电 ×10 零变砖）；SHARED 用户数据只增不删（红线三）。
4. **操作完永远回得了 Windows**——五重保障逐级兜底（1.7 节）：物理层"拔盘即走"永不失效，是所有逻辑保障全部失效后的最终兜底；操作层"上机前记录 + 下机后核验"保证每一步都留有证据与退路。
