### 0.3 成熟度判定（M700 的 Done 定义）

> **内核本体在 QEMU 与真机双环境下：连续 7×24 小时 fuzz + 压力负载零 panic、
> 零内存增长、零预算违例；任意子系统可单独插桩/隔离/回放；一份外来内核

### 0.4 质量军规（M700 版，每项必须全过十四维）

1. **不重复**：立项对照 VARIX-500（500）+ VARIABLE-200（200）+ M400（400）+
   M500（500）+ M600（600）+ 本图（700），共 **2900 项总清单**查重，重复即砍。
2. **极其实用**：每项回答"哪个内核路径、哪类负载会在什么时刻需要它"。
3. **高质量**：每项 = 实现 + 单测（`f<编号>_<要点>`）+ CheckSet 断言 ≥ 25/域 + 仪表。
4. **可优化**：每项自带至少一个计数器/直方图/水位线；无仪表不上线。
5. **创造力**：每域至少 2 项同类内核没有的原创设计，写出设计说明。
6. **开放性**：数据结构与协议全部有公开规范文档，可被第三方复刻。
7. **艺术性**：接口命名、注释、错误码构成自洽优雅的语言；读代码如读文章。
8. **极具创新性**：每域至少 1 项"登月项"，允许标注实验性（EXPERIMENTAL）。
9. **完善性**：无硬件/无内存/无电源/崩溃中四类边缘场景全有降级路径。
10. **可拓展性**：每项预留 v2 接口位；syscall 新号段全部版本化。
11. **完整性**：基础功能 → 细节优化 → 创新表达三层齐备才准收口。
12. **野心性**：不满足于"能跑"，要达到"可以写进论文/作品集"的水准。
13. **崩溃红线**：任何新路径 panic 不拖垮内核；fuzz 号段偏置
    （1/4 野生 + 1/4 原生带 + 1/4 兼容带 + 1/4 新增 `0x4200` 成熟带）。
14. **性能红线**：输入延迟/合成帧时/启动耗时/调度抖动四指标不得回退，CI 预算门守关。
15. **完成即自检**：`cargo ktest --lib` 全绿 + `cargo kbuild` 零告警 + QEMU 冒烟到

## 三、域模块实现约定（AI-01~AI-28 共用）

- 一域一文件：`kernel/varix/src/<domain>.rs`；新域文件名不得与既有模块冲突，
  同名场景必须在文件顶部显式 `pub mod` 并在 `lib.rs` 复查注册行。
- 每域 25 项，按 `// Fxxx 名称` 注释分区；纯逻辑 + 固定容量数组
  （无 Vec/String/Box）；每域导出 `pub fn run_<domain>_checks() -> CheckSet`，
  自检项 ≥ 25；`robust::run_kernel_checkup()` 汇总（排除 robust 自身防递归）。
- 单测：`#[cfg(test)] mod tests`，命名 `f<编号>_<要点>`；
  隔离验证法（/tmp scratch crate）照旧可用。
- 新 syscall：统一占用 `0x4200-0x42FF` 成熟带，号段登记表写入 AI-03 域文档。

### CheckSet 断言铁律（违者必返工）

- 禁止"末态读取"：`set.add` 表达式中的字段读取发生在求值末尾；
  中间读数必须先存 `let`。
- 登记类接口必须去重；自检失败必须 panic 出 `CheckSet::render` 全文。
- 调试用临时 `tmp_dbg` 模块拆断言，验证完立刻删除。

### Rust 红线（沿用实测沉淀）

- `const fn` 不用 `Ord::min`；非 Copy 数组用 `[const { None }; N]`；
  `Result<&mut T,_>` 用 `is_err()`；清未用导入连带查 `mod tests`；
  内层 crate 自带空 `[workspace]`；`cargo ktest` 全量若因 bin unwinding 失败
  则用 `cargo ktest --lib`。

### 中断与运行时代码

- 中断入口 stub 表必须在 `linker.ld` 页对齐 `.stubs` 段，
  生成后 `harden_stub_mapping()` 清 NX/写位；运行时生成代码一律走此路径。
- 致命异常已带 err/rip/cr2（`cpu/idt.rs::isr_dispatch`）；定位流程：
  串口末行 → `info status` → RIP/CR2 → ELF 符号回映射 → 反汇编。

## 四、多会话并行纪律（M700 版）

1. 共享文件（三份 M700 总图、`lib.rs`）编辑前先 `git log` + 重读，只改自己段落。
2. 绝不 `git add .` 盲提；提交前 `git status --porcelain` 甄别，只挑自己域路径。
3. **绝对禁止 `git pull --rebase --autostash`**；对齐远端用
   `git fetch origin main` + 显式 SHA `git reset --mixed`。
4. 推送：`git -c credential.helper= -c credential.helper=wincred push origin main`，
   代理 502 属常态，循环重试 2~6 次；api.github.com 始终可用可做备用通道。
5. 提交信息：`varixm700(ai-XX): Fxxx <功能名>`，一功能一提交或一域一提交。
