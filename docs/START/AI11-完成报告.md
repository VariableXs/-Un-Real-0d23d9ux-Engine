## 四、红线遵守

- 一切硬件/系统 API 只读或合法用户级调用；写操作（代理/电源计划/gamma/优先级/设默认音频设备）全部 UI 显式按钮确认。
- 退出还原宿主状态（gamma 字节级 + 保持唤醒解除）——lib.rs RunEvent::Exit 钩子。
- V-53 无 kill 入口（任务管理器领地）；V-52 不删事件；N-24 只预读不启动进程；N-25 修复仅白名单、不静默删除。
