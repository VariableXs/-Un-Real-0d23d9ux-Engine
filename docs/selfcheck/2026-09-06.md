## 3. 本轮自检发现并修复的问题

1. **`spawn_profiled` 空 cwd bug（端到端测试抓到的真实缺陷）**：裸程序名
   （如 `cmd.exe`）的 `program.parent()` 返回空路径，`current_dir("")` 导致
   CreateProcess 报 InvalidFilename——已改为仅在有目录前缀时设置工作目录。
   这验证了「新通道必须有真实子进程级测试」的纪律价值。
2. bench.cjs 初版两处口径问题：报告日期用 UTC（比本地慢一天）；memory 只统计
   主进程 WorkingSet（不含 WebView2 渲染子进程，严重低估）——均已修正并写入口径说明。

### zcode 包名调查结论

- `@z-ai/zcode`、`@z-ai/cli`、`@zai-org/*`、`zai-code`、`zcode`（现名已被 2020 年
  无关项目占用）在 npm 上均不可用或非目标包；
- npm 生态现状：Z.ai 官方**没有独立发布的 coding CLI npm 包**——官方 GLM Coding
  Plan 路径是在 Claude Code / Codex 等既有工具内配置 ZAI 端点
  （`https://api.z.ai/api/coding/paas/...`），而非独立 CLI；
- 存在 `zcode-app-cli`（kingsword09）——"Unofficial terminal client for the ZCode
  agent runtime"，说明 ZCode agent runtime 本体可能经由非 npm 渠道分发
  （官方安装器/脚本），本机无法在 npm 层面确证。
