# 任务24 · KV 存储与 localStorage 语义差异清单（如实公示）

> 总案验收原文：「完善性=与 localStorage 语义差异清单（如容量上限）如实公示」。
> 本文件是交付物的一部分；v1 未覆盖项同时登记为后续任务输入。

## 语义对齐项（与 localStorage 一致）

- [x] API 形态：get / set / remove / keys 四操作（keys 为增强，localStorage 无一等公民枚举）。
- [x] remove 不存在键 = 静默 no-op、不报错（对齐 `removeItem`）。
- [x] 同键重复 set = 末写生效。
- [x] 值类型：localStorage 全字符串；KV 二进制安全字节串（垫片层做 UTF-8 编解码适配，任务26 落地）。

## 差异项（v1 现状与边界，逐条如实）

- [x] **容量上限**：单值 inline ≤352B / 溢出 ≤32744B（2026-09-18 根因收窄，原 65512）：kheap 仅 256KiB（mem/heap.rs ARENA_BYTES），64KiB 槽整槽 Vec 物化超 slab 单次分配上限 → 实机 alloc panic 静默停摆（见 docs/acceptance/2026-09-18-任务65溢出根因修复/验收记录.md）；分片直写 + 槽 32KiB 后单次堆分配 ≤32KiB。总案口径「值 ≤1MB」v1 未达（`KV_SLOT_BLOCKS` 参数化保留，上调须先解决 kheap/页分配器 fallback）。localStorage 无单值硬限（受总额约束）。
- [ ] **键数上限**：活键 ≤64（= fs23 账本 64 条物理约束，SET/DEL 合计计费）。localStorage 无键数硬限。
- [ ] **总额**：溢出区 64 槽 × 64KiB = 4MiB（localStorage 常见配额 ≈5MiB，同量级）。
- [ ] **满容量行为**：账本满/溢出区满 → `Err(KvError::Full)` 明确报错（总案验收点）；无自动 compact/garbage 回收（大值覆盖后旧溢出槽成垃圾）。localStorage 满 = `QuotaExceededError`。v2 规划：checkpoint+truncate 式 compact（fs23 既有 `truncate_committed` 原语可复用，需先解决 inline 值迁移）。
- [ ] **命名空间**：localStorage 按源（origin）隔离；KV 按显式 `ns` 参数隔离（≤16B）。垫片层 origin→ns 映射在任务26 落地；v1 隔离由宿主用例背书（互不可见/互不可删）。
- [ ] **持久化**：localStorage 无断电保证；KV = fs23 WAL tier3 writeahead（append 返回即 flush 持久化点，断电零丢失 ×10 宿主 + 实机双会话验证）。
- [ ] **读取成本**：get/keys 每次现场重放账本（O(条数) 磁盘读，内存零驻留）。v2 规划：驻留索引缓存。
- [ ] **腐坏语义**：账本槽级撕裂沿用 fs23（该点及之后全部丢弃）；载荷级 fnv 败 = 条目级忽略并回退更早条目（零丢失）；溢出槽腐坏 = 该值回退。localStorage 无此分层。
- [ ] **垫片命令**：kv_get/kv_set/kv_remove/kv_keys 的 shim:// 通道在任务26 落地；v1 仅内核 API + 探针。

## 验收对照（总案 269 行）

- [x] 逻辑 = 断电恢复 ×10 零丢失：宿主 `kv_powercut_x10_zero_loss`（10 轮重开全量断言）+ 实机双会话（boot-counter 累加 + 前会话 10 键核对）。
- [x] 满容量行为：`kv_full_capacity_explicit_error` / `kv_overflow_and_journal_full_explicit_error` 明确报错。
- [x] 代码 = 复用 fs23_journal 后端：`KvStore` 持有 `DiskJournal`，账本槽 24B 头之后的自由区经 `append_slot` 同块携带键值（单块原子），撕裂/CRC/水位语义零另造。
- [x] 开放性 = 命名空间隔离：`kv_namespace_isolation`。
- [x] 完善性 = 本清单。
