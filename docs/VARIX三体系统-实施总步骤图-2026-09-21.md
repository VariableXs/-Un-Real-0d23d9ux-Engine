## 1. 门禁与自检总纲（贯穿所有批次，任何一步不得豁免）

### 1.1 四线门禁（判绿以逐套单跑为准，全量并行有已知互踩）

| 线 | 命令 | 基线（2026-09-20 实测） |

| C 分析器 | cargo test -p ca-core --locked | 356 passed |

### 1.2 六维验收（每功能/重要步骤交付时逐维过，任何一维不达标不算完成）

视觉（截图逐屏对照+png_probe 度量）/ 逻辑（状态机全覆盖+负向用例）/ 代码（门禁全绿+零 unwrap+grep 复核）/ 开放性（可扩展不改核心）/ 简洁性（无重复实现+复杂度预算）/ 完善性（契约清单 100% 登记，❌ 项写明谁在哪个阶段补）。

### 1.3 体验五子项（用户可见界面加验）

①首用理解（第一次见就会用）②反馈即时（≤100ms 可见回应，长任务有进度）③错误可解（发生了什么+我该怎么办）④一致性（同语义全系统同观感）⑤记忆点（有让人愿意展示的亮点）。

### 1.4 部署三证铁律（凡刷 U 盘）

源码 mtime < 构建 mtime < 部署 mtime + 双端 sha256 前缀一致。三证不齐=刷的是旧货，禁止上机。

### 1.5 步骤级自检六问（每步完成必答，答不全不许进下一步）

1. 原始需求逐条列出来，产出逐条对上了吗？
2. 关键改动回读/grep 验证落盘了吗（不信回执信回读）？
3. 四线门禁涉及项单跑全绿了吗？
4. 边界/负向/断电/拔盘路径走过了吗？
5. 涉及用户可见界面的，体验五子项过了吗？
6. 产物归档（docs/acceptance/）+ 日志更新了吗？

## 2. 第 0 批：起航准备（1-2 天）

### S0.1 handoff 三件套提交入库
- 动作：内核 handoff.rs/bootcfg/bootopt/inputsvc/main.rs + 后端 dualboot.rs+注册 + 前端 HandoffCard/handoffView/ipc.ts，显式 add 全部新文件，规范提交。
- 自检：git status 无遗漏文件；四线门禁单跑全绿；5+10 测试全过；防自锁闸门（Windows 引导项未证实拒写 BootNext）用例在跑。
- 验收：push 成功且远端可查；工作区不再有 handoff 未提交项。

### S0.2 L0 配置桥方案 A（boot-select.json 实机通道）
- 动作：①limine.conf 增 `module_path` 挂载 boot-select.json 副本；②部署脚本刷 ESP 副本；③Variable 写 SHARED 时同步 ESP 副本（提权通道）；④cmdline 优先级保持最高。
- 自检：QEMU 全链读副本生效；副本缺失→回退内置默认（契约不破）；副本损坏→容错三层的 fuzz 1000 组不崩；三证齐。
- 验收：实机改 timeout/default_entry，下次引导生效；Variable 设置页 BootCfgView.found=true。

### S0.3 U 盘内核重建重刷
- 动作：重建内核（补鼠标接线 bd32308 + handoff）→ make-iso-qemu.py 刷 isoroot → esp-deploy-switch 部署。
- 自检：三证齐；sha256 双端前缀一致；引导后版本号/构建时间为新。
- 验收：真机 F12 → VARIX 引导 → 三卡菜单含鼠标与交接功能。

### S0.4 关闭快速启动
- 动作：提权改 HiberbootEnabled=0，重启两次确认生效。
- 自检：注册表回读=0；关机→开机出现引导菜单（不再直跳 Windows）。
- 验收：关机→开机路径可进 F12/引导菜单。

## 3. 第 1 批：Windows 11 上盘（1-3 天，可推迟，与第 2 批无依赖）

### S1.1 盘体体检（前置）
- 动作：thinkplus 1TB 顺序/4K 随机性能实测（CrystalDiskMark 或等价，只读测试）。
- 自检：顺序 ≥400MB/s 且 4K ≥20MB/s 才继续（否则如实告知体验预期并停下问询）。
- 验收：测速报告归档 docs/acceptance/deploy/。

### S1.2 Windows 部署到 WIN_ENGINE（W1 路线）
- 动作：Hasleo WinToUSB 部署 Win11 至 300GB NTFS 分区；部署时不启用 BitLocker；装完进系统做首次设置（关快速启动/关休眠或按需）。
- 自检：部署日志无错；首次进入系统正常；激活状态确认（本机数字许可证）。
- 验收：U 盘 Windows 可独立进入桌面，驱动正常（Legion 全家桶）。

### S1.3 ESP 补 U 盘 Windows 引导项
- 动作：ESP 内部署 bootmgr+BCD 指向 WIN_ENGINE；部署脚本探测并登记新引导项号进 boot-select.json（handoff_target 可选内置盘/U 盘 Windows）。
- 自检：bcdedit 回读；断开内置盘 QEMU 演练 U 盘自包含引导成功；BootNext 写入回读一致。
- 验收：F12 菜单出现 U 盘 Windows 项且可引导；handoff 可选择交接目标。

### S1.4 bootselect 三卡真机走查
- 动作：VARIX 卡 / WINDOWS 卡 / FIRMWARE 卡逐卡真机引导 ×3；倒计时默认项验证；键盘+外接鼠标（如已含）双输入。
- 自检：走查记录归档；每卡进入后可正常返回/关机；倒计时归零走默认不采纳未确认预选。
- 验收：三卡 ×3 全 PASS 记录归档。

### S1.5 handoff 交接目标确认
- 动作：A 卡→交接画面 2.4s→自动重启→进入 U 盘 Windows→自启 Variable 全屏，全链走查 ×5。
- 自检：全链计时归档；防自锁闸门在 Windows 项缺失时的拒绝路径演练。
- 验收："选 Variable 就真的进 Variable"在真机成立。

## 4. 第 2 批：Servo 十二步（核心战役，数周）

> 架构：`内核系统服务 ← Tauri IPC 垫片 ← Servo(同一份 React 前端) ← GOP 帧缓冲`
> 铁律：前端零 fork、零语义改动（vitest 全绿为证）；❌ 能力绝不静默，降级+登记+排期。

### S2.01 垫片协议定版
- 动作：以 tools/shim-protocol.source.json 为单源，扩展内核侧生成物；版本协商/三段式错误/事件反向通道定版；协议变更流程写入规范。
- 自检：Rust/TS 双侧类型同源再生一致；三段式各路径用例；禁手改生成物 grep 复核。
- 验收：协议规范文档 + 双侧生成物 ci 一致性检查。

### S2.02 三色审计 554 方法
- 动作：跑 audit.cjs 产出 554 方法逐条归属（✅内核原生/🔶组合映射/❌暂缺），❌ 项逐条写"谁在哪个阶段补"。
- 自检：554 条 100% 有归属（禁止未分类）；抽查 20 条人工核对；🔶 写清由哪些 ✅ 组成。
- 验收：映射表归档 docs/，三色占比公示（首版目标 ✅+🔶 ≥30% 覆盖桌面壳）。

### S2.03 内核 KV 语义桥
- 动作：前端本地存储语义（get/set/remove/keys）透明桥到内核 kvsrv（复用 fs23_journal）。
- 自检：断电恢复 ×10 零丢失；容量边界明确报错；命名空间隔离互不可见；与前端存储语义差异清单公示。
- 验收：桥单文件；ktest 全绿。

### S2.04 vwmStore 持久化迁移
- 动作：窗口几何持久化切 KV，桥内透明转换。
- 自检：前端 git diff 零改动；布局重启还原逐像素一致 ×10。
- 验收：迁移路径可回退记录在档。

### S2.05 输入事件管道
- 动作：内核输入服务→消息通道→DOM 事件（keydown/mouse/wheel/剪贴板）；焦点模型定版。
- 自检：焦点切换 ×1000 无串键；输入延迟基线归档（目标 <30ms）；事件结构与 Wine 通道同源。
- 验收：中文输入法组合期不误触路径验证。

### S2.06 渲染通路（单窗全屏）
- 动作：Servo 输出→共享帧缓冲→内核显示服务合成；脏矩形提交。

- 验收：png_probe 度量通过。

### S2.07 三件套闭环 —— 里程碑 M2「内核里的 Variable 立起来了」
- 动作：桌面壳/文件管理器/设置页在垫片下全功能闭环（文件走 VFS 白名单）。
- 自检：三件套人工全功能走查清单 100%；发现 ❌ 即时补登记；体验五子项全过。
- 验收：真机引导默认进 Variable 桌面，三件套可用；归档 docs/acceptance/。

### S2.08 BootScreen 对接
