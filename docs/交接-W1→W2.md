# 交接 · W1 → W2（步骤 0278）

## 合成器接口约定（W2 窗口系统消费方）
- 图层注册：`compositor::layer_tree_add(&mut LayerRegistry, Layer) -> bool`（满=16 拒绝）。
- 窗口 ↔ 图层映射：一个顶层窗口一个 Layer，`Layer.id` 建议直接用窗口 id 截断 u16。
- 重绘：状态变化 → `mark_layer_dirty(reg, id)` → 合成器读 `dirty_union()` 只重画脏区。
- 动画：`composite_animated(canvas, cw, ch, reg, t)`，t∈0..255；动画参数放 `Layer.anim_dx/dy`。

## 输入接口约定
- 事件类型 `input::Event`（kind/code/x/y/value/device/stamp），泵 `EventPump::push/pop`。
- 焦点路由：`route_focus(event, focus_window) -> u32`；订阅表 `SubscriberTable::subscribe`。
- 快捷键：`match_hotkey(combo_mods, combo_key, cur, key)`；修饰键状态 `ModState::update`。
- 窗口快捷键动作表：`window::Shortcut → WinAction`（`apply_shortcut`），W2 键位不得与之冲突。

## 窗口系统给桌面的约定（W2 内部）
- `WindowManager::create_window/destroy_window/raise/lower/focus/focus_next`；
  僵尸回收语义：id 单调递增、死亡槽复用但 id 不复用（`is_zombie` 可查）。
- 贴靠：`snap_rect(screen, SnapSide) -> Rect`（LeftHalf/RightHalf/…/Center）。
- 关闭确认：`close_window -> CloseResult::{Closed, ConfirmNeeded}`，应用层弹确认后再 destroy。

## 已知边界（W2 起遵守）
- `MAX_DOMAINS=96`；新域 CheckSet 接入 `robust::run_kernel_checkup()` 注册表即可进 domain-gate。
- W2 域集成测试放 `aurora/w2_integration.rs`（命名沿用 `<wN>_integration`），注册进 checkup。
- 改 `aurora/mod.rs` / `robust.rs` / `lib.rs` 前：先 `git log -p` 查并行会话改动，只追加自己的行。
